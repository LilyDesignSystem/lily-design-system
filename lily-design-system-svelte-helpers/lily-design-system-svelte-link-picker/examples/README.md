# Examples — LinkPicker

| File | Shows |
| ---- | ----- |
| [basic.svelte](./basic.svelte) | The four links an app typically defines: Home, About Us, Contact Us, Privacy Policy. |
| [sveltekit.svelte](./sveltekit.svelte) | The same links with SvelteKit's `goto` as `navigate`, and the current page marked. |
| [custom-icon.svelte](./custom-icon.svelte) | Replacing the home icon through `children`. |

Every user-facing string and every route is a prop — the package ships no default list.
