# Changelog — @lilydesignsystem/angular-headless-identifiers

The format is loosely based on [Keep a Changelog](https://keepachangelog.com/)
and the package follows [Semantic Versioning](https://semver.org/).

## 0.1.0 — 2026-11-18

- First release: the 164 national personal identifier components of the Lily Design System catalog for Angular, an
  `-input` and a `-view` for each of 82 identifier types across more than 50 countries, moved here unchanged from
  `@lilydesignsystem/angular-headless` 0.11.0 (spec/headless-identifiers). No dependency on `@lilydesignsystem/angular-headless`.
