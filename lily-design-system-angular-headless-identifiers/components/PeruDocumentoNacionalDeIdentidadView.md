# PeruDocumentoNacionalDeIdentidadView

a read-only display of Peru's Documento Nacional de Identidad (DNI)

This is the Angular headless implementation. See `components/peru-documento-nacional-de-identidad-view/index.md`
in the canonical repo root for the cross-framework documentation.

