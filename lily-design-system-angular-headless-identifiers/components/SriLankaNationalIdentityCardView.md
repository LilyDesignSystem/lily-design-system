# SriLankaNationalIdentityCardView

a read-only display of Sri Lanka's National Identity Card (NIC) number

This is the Angular headless implementation. See `components/sri-lanka-national-identity-card-view/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-sri-lanka-national-identity-card-view></lily-sri-lanka-national-identity-card-view>
```

## Files

- `SriLankaNationalIdentityCardView.ts` — standalone Angular 20 component (signal inputs, OnPush)
- `SriLankaNationalIdentityCardView.spec.ts` — vitest + TestBed render test
