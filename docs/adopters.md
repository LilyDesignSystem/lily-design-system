# Adopters — Lily Design System™

A public, opt-in list of organisations using Lily components in production, per component. It is evidence for
[component status](../spec/components/index.md#maturity), not a requirement for it, and not an endorsement in either direction.

Add your organisation with a pull request. Name only what you run in production, and link a public page that shows it, such as
the service, its accessibility statement or a post about it. `bin/check-lifecycle` checks each component name and link. Nobody
is added on another's behalf, and a row is removed on request.
