## Overview

The Alpine.js example app: a static site generated by `build.mjs` from `components.tsv`, the Alpine headless snippets and the four
Alpine helpers' snippets. It follows the required routes in [AGENTS/examples.md](AGENTS/examples.md): `/`, `/components`,
`/components/{slug}`.

## Rules

- Concrete English strings belong here (the example layer) and nowhere in the headless packages or helpers.
- Examples ship no styles of their own for Lily classes: the look is a root `themes/*.css`. `assets/app-shell.css` is page chrome only.
- Never hand-edit `dist/`; edit `build.mjs`, `lib.mjs`, `src/` or `assets/`.
- A page's options script (`gridOptions`, `boardOptions`, `calendarOptions`, `ganttOptions`) is a classic inline script so it runs before the Alpine module.
- Keep the axe sweep (`e2e/axe-catalog.spec.ts`) exact: a theme finding is listed with its reason, never silenced wholesale.

## Commands

`pnpm build`, `pnpm test`, `pnpm test:e2e`, `pnpm serve`.
