# HangukJuminDeungnokBeonhoInput

An input for entering South Korea's Resident Registration Number.

See `components/hanguk-jumin-deungnok-beonho-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `hanguk-jumin-deungnok-beonho-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<HangukJuminDeungnokBeonhoInput Label="Hanguk Jumin Deungnok Beonho" />
```
