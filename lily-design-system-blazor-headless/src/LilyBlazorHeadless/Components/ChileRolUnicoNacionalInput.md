# ChileRolUnicoNacionalInput

A an input for entering Chile's Rol Unico Nacional (RUN).

See `components/chile-rol-unico-nacional-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `chile-rol-unico-nacional-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<ChileRolUnicoNacionalInput Label="Chile Rol Unico Nacional" />
```
