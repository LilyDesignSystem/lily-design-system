# AotearoaNationalHealthIndexInput

An input for entering New Zealand's National Health Index (NHI) Number.

See `components/aotearoa-national-health-index-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `aotearoa-national-health-index-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<AotearoaNationalHealthIndexInput Label="Aotearoa National Health Index" />
```
