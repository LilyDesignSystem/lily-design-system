# NigeriaNationalIdentificationNumberInput

A an input for entering Nigeria's National Identification Number (NIN).

See `components/nigeria-national-identification-number-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `nigeria-national-identification-number-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<NigeriaNationalIdentificationNumberInput Label="Nigeria National Identification Number" />
```
