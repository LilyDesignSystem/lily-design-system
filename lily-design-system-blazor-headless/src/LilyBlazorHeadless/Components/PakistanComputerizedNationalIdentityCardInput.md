# PakistanComputerizedNationalIdentityCardInput

A an input for entering Pakistan's Computerized National Identity Card Number (CNIC).

See `components/pakistan-computerized-national-identity-card-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `pakistan-computerized-national-identity-card-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<PakistanComputerizedNationalIdentityCardInput Label="Pakistan Computerized National Identity Card" />
```
