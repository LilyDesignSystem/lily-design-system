# IndonesiaNomorIndukKependudukanInput

A an input for entering Indonesia's Nomor Induk Kependudukan (NIK).

See `components/indonesia-nomor-induk-kependudukan-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `indonesia-nomor-induk-kependudukan-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<IndonesiaNomorIndukKependudukanInput Label="Indonesia Nomor Induk Kependudukan" />
```
