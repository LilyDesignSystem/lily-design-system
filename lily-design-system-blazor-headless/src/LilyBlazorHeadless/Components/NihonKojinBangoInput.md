# NihonKojinBangoInput

An input for entering Japan's Individual Number (My Number).

See `components/nihon-kojin-bango-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `nihon-kojin-bango-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<NihonKojinBangoInput Label="Nihon Kojin Bango" />
```
