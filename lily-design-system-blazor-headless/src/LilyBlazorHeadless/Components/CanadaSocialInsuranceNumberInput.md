# CanadaSocialInsuranceNumberInput

An input for entering Canada's Social Insurance Number (SIN).

See `components/canada-social-insurance-number-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `canada-social-insurance-number-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<CanadaSocialInsuranceNumberInput Label="Canada Social Insurance Number" />
```
