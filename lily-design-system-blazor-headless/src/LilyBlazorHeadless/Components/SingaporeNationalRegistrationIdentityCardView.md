# SingaporeNationalRegistrationIdentityCardView

A read-only display of Singapore's National Registration Identity Card number (NRIC/FIN).

See `components/singapore-national-registration-identity-card-view/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `singapore-national-registration-identity-card-view`
- `ChildContent`: RenderFragment — component content
- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<SingaporeNationalRegistrationIdentityCardView Label="Singapore National Registration Identity Card">...</SingaporeNationalRegistrationIdentityCardView>
```
