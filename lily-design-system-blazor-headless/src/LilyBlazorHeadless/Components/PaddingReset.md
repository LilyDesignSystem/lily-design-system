# PaddingReset

A container that resets padding inside fluid-width containers.

See `components/padding-reset/index.md` for canonical documentation.

## Parameters

- `CssClass`: string — extra CSS classes appended to `padding-reset`
- `ChildContent`: RenderFragment — component content
- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<PaddingReset>
    Content
</PaddingReset>
```
