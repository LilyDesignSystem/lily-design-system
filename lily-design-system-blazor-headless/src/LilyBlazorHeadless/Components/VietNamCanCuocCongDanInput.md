# VietNamCanCuocCongDanInput

A an input for entering Viet Nam's Citizen Identification Number (CCCD).

See `components/viet-nam-can-cuoc-cong-dan-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `viet-nam-can-cuoc-cong-dan-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<VietNamCanCuocCongDanInput Label="Viet Nam Can Cuoc Cong Dan" />
```
