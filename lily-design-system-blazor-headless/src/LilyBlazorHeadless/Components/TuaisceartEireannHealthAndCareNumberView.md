# TuaisceartEireannHealthAndCareNumberView

A read-only display of Tuaisceart Eireann Health and Care (H&C) Number unique national healthcare identifier.

See `components/tuaisceart-eireann-health-and-care-number-view/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `tuaisceart-eireann-health-and-care-number-view`
- `ChildContent`: RenderFragment — component content
- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<TuaisceartEireannHealthAndCareNumberView Label="...">
    Content
</TuaisceartEireannHealthAndCareNumberView>
```
