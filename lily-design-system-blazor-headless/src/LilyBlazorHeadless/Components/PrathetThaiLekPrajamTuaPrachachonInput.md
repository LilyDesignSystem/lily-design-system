# PrathetThaiLekPrajamTuaPrachachonInput

A an input for entering Thailand's National Identification Number.

See `components/prathet-thai-lek-prajam-tua-prachachon-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `prathet-thai-lek-prajam-tua-prachachon-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<PrathetThaiLekPrajamTuaPrachachonInput Label="Prathet Thai Lek Prajam Tua Prachachon" />
```
