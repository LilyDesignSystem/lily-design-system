# BharatAadhaarInput

An input for entering India's Aadhaar number.

See `components/bharat-aadhaar-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `bharat-aadhaar-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<BharatAadhaarInput Label="Bharat Aadhaar" />
```
