# PrathetThaiLekPrajamTuaPrachachonView

A a read-only display of Thailand's National Identification Number.

See `components/prathet-thai-lek-prajam-tua-prachachon-view/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `prathet-thai-lek-prajam-tua-prachachon-view`
- `ChildContent`: RenderFragment — component content
- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<PrathetThaiLekPrajamTuaPrachachonView Label="Prathet Thai Lek Prajam Tua Prachachon">...</PrathetThaiLekPrajamTuaPrachachonView>
```
