# ColombiaCedulaDeCiudadaniaInput

A an input for entering Colombia's Cedula de Ciudadania Number.

See `components/colombia-cedula-de-ciudadania-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `colombia-cedula-de-ciudadania-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<ColombiaCedulaDeCiudadaniaInput Label="Colombia Cedula De Ciudadania" />
```
