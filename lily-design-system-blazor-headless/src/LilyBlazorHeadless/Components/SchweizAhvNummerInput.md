# SchweizAhvNummerInput

An input for entering Switzerland's AHV-Nummer / Numero AVS.

See `components/schweiz-ahv-nummer-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `schweiz-ahv-nummer-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<SchweizAhvNummerInput Label="Schweiz Ahv Nummer" />
```
