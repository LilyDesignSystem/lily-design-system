# UruguayCedulaDeIdentidadInput

A an input for entering Uruguay's Cedula de Identidad Number.

See `components/uruguay-cedula-de-identidad-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `uruguay-cedula-de-identidad-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<UruguayCedulaDeIdentidadInput Label="Uruguay Cedula De Identidad" />
```
