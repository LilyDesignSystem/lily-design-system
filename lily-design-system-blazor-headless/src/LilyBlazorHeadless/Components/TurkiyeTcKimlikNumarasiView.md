# TurkiyeTcKimlikNumarasiView

A a read-only display of Turkey's T.C. Kimlik Numarasi.

See `components/turkiye-tc-kimlik-numarasi-view/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `turkiye-tc-kimlik-numarasi-view`
- `ChildContent`: RenderFragment — component content
- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<TurkiyeTcKimlikNumarasiView Label="Turkiye Tc Kimlik Numarasi">...</TurkiyeTcKimlikNumarasiView>
```
