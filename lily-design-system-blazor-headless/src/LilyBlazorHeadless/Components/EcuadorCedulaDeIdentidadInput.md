# EcuadorCedulaDeIdentidadInput

A an input for entering Ecuador's Cedula de Identidad Number.

See `components/ecuador-cedula-de-identidad-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `ecuador-cedula-de-identidad-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<EcuadorCedulaDeIdentidadInput Label="Ecuador Cedula De Identidad" />
```
