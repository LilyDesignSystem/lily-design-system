# SouthAfricaIdentityNumberInput

An input for entering South Africa's Identity Number.

See `components/south-africa-identity-number-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `south-africa-identity-number-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<SouthAfricaIdentityNumberInput Label="South Africa Identity Number" />
```
