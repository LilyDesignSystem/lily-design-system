# AustraliaTaxFileNumberInput

A an input for entering Australia's Tax File Number (TFN).

See `components/australia-tax-file-number-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `australia-tax-file-number-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<AustraliaTaxFileNumberInput Label="Australia Tax File Number" />
```
