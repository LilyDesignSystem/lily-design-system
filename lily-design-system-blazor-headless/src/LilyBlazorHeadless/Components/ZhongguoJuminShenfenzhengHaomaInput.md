# ZhongguoJuminShenfenzhengHaomaInput

A an input for entering China's Resident Identity Card Number.

See `components/zhongguo-jumin-shenfenzheng-haoma-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `zhongguo-jumin-shenfenzheng-haoma-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<ZhongguoJuminShenfenzhengHaomaInput Label="Zhongguo Jumin Shenfenzheng Haoma" />
```
