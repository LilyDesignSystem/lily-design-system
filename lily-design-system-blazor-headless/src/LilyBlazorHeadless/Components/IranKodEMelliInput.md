# IranKodEMelliInput

A an input for entering Iran's National Code (Kod-e Melli).

See `components/iran-kod-e-melli-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `iran-kod-e-melli-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<IranKodEMelliInput Label="Iran Kod E Melli" />
```
