# ArgentinaCodigoUnicoDeIdentificacionLaboralInput

A an input for entering Argentina's Codigo Unico de Identificacion Laboral (CUIL).

See `components/argentina-codigo-unico-de-identificacion-laboral-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `argentina-codigo-unico-de-identificacion-laboral-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<ArgentinaCodigoUnicoDeIdentificacionLaboralInput Label="Argentina Codigo Unico De Identificacion Laboral" />
```
