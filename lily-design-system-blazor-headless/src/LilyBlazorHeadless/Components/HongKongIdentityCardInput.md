# HongKongIdentityCardInput

A an input for entering Hong Kong's Identity Card Number.

See `components/hong-kong-identity-card-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `hong-kong-identity-card-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<HongKongIdentityCardInput Label="Hong Kong Identity Card" />
```
