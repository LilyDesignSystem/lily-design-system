# IbanInput

A an input for entering an International Bank Account Number (IBAN).

See `components/iban-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `iban-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<IbanInput Label="IBAN" />
```
