# SingaporeNationalRegistrationIdentityCardInput

An input for entering Singapore's National Registration Identity Card number (NRIC/FIN).

See `components/singapore-national-registration-identity-card-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `singapore-national-registration-identity-card-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<SingaporeNationalRegistrationIdentityCardInput Label="Singapore National Registration Identity Card" />
```
