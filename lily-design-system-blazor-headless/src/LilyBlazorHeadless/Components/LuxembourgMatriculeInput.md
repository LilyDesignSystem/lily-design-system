# LuxembourgMatriculeInput

A an input for entering Luxembourg's Numero d'Identification Nationale (Matricule).

See `components/luxembourg-matricule-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `luxembourg-matricule-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<LuxembourgMatriculeInput Label="Luxembourg Matricule" />
```
