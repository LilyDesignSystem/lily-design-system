# OsterreichSozialversicherungsnummerInput

A an input for entering Austria's Sozialversicherungsnummer (SVNR).

See `components/osterreich-sozialversicherungsnummer-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `osterreich-sozialversicherungsnummer-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<OsterreichSozialversicherungsnummerInput Label="Osterreich Sozialversicherungsnummer" />
```
