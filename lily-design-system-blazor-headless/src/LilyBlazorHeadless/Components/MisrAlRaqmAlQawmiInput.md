# MisrAlRaqmAlQawmiInput

A an input for entering Egypt's National Number.

See `components/misr-al-raqm-al-qawmi-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `misr-al-raqm-al-qawmi-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<MisrAlRaqmAlQawmiInput Label="Misr Al Raqm Al Qawmi" />
```
