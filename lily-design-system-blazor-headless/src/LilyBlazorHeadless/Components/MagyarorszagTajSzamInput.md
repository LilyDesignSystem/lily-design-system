# MagyarorszagTajSzamInput

A an input for entering Hungary's Tarsadalombiztositasi Azonosito Jel (TAJ).

See `components/magyarorszag-taj-szam-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `magyarorszag-taj-szam-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<MagyarorszagTajSzamInput Label="Magyarorszag Taj Szam" />
```
