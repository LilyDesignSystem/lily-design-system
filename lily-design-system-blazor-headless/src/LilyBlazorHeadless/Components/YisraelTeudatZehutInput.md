# YisraelTeudatZehutInput

An input for entering Israel's Teudat Zehut identity number.

See `components/yisrael-teudat-zehut-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `yisrael-teudat-zehut-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<YisraelTeudatZehutInput Label="Yisrael Teudat Zehut" />
```
