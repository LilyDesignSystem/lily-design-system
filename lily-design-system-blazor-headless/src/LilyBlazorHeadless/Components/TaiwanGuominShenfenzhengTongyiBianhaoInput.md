# TaiwanGuominShenfenzhengTongyiBianhaoInput

A an input for entering Taiwan's National Identification Card Number.

See `components/taiwan-guomin-shenfenzheng-tongyi-bianhao-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `taiwan-guomin-shenfenzheng-tongyi-bianhao-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<TaiwanGuominShenfenzhengTongyiBianhaoInput Label="Taiwan Guomin Shenfenzheng Tongyi Bianhao" />
```
