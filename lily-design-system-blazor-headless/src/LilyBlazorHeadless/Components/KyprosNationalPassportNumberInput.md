# KyprosNationalPassportNumberInput

A an input for entering Kypros's National Passport Number.

See `components/kypros-national-passport-number-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `kypros-national-passport-number-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<KyprosNationalPassportNumberInput Label="National Passport Number" />
```
