# PilipinasPhilhealthIdentificationNumberInput

An input for entering the Philippines' PhilHealth Identification Number (PIN).

See `components/pilipinas-philhealth-identification-number-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `pilipinas-philhealth-identification-number-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<PilipinasPhilhealthIdentificationNumberInput Label="Pilipinas Philhealth Identification Number" />
```
