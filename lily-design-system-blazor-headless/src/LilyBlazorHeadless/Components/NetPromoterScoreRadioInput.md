# NetPromoterScoreRadioInput

A radio input for one choice of a 0-10 Net Promoter Score <input type="radio">.

See `components/net-promoter-score-radio-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `net-promoter-score-radio-input`
- `ChildContent`: RenderFragment — component content
- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<NetPromoterScoreRadioInput Label="...">
    Content
</NetPromoterScoreRadioInput>
```
