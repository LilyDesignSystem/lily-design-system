# BrasilCartaoNacionalDeSaudeInput

An input for entering Brazil's Cartao Nacional de Saude (CNS).

See `components/brasil-cartao-nacional-de-saude-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `brasil-cartao-nacional-de-saude-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<BrasilCartaoNacionalDeSaudeInput Label="Brasil Cartao Nacional De Saude" />
```
