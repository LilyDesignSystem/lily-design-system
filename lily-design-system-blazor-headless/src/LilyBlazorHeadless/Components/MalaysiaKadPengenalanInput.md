# MalaysiaKadPengenalanInput

A an input for entering Malaysia's MyKad Number (NRIC).

See `components/malaysia-kad-pengenalan-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `malaysia-kad-pengenalan-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<MalaysiaKadPengenalanInput Label="Malaysia Kad Pengenalan" />
```
