# TurkiyeTcKimlikNumarasiInput

A an input for entering Turkey's T.C. Kimlik Numarasi.

See `components/turkiye-tc-kimlik-numarasi-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `turkiye-tc-kimlik-numarasi-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<TurkiyeTcKimlikNumarasiInput Label="Turkiye Tc Kimlik Numarasi" />
```
