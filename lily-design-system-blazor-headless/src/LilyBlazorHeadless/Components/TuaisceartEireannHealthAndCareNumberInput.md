# TuaisceartEireannHealthAndCareNumberInput

An input for entering aTuaisceart Eireann Health and Care (H&C) Number unique national healthcare identifier.

See `components/tuaisceart-eireann-health-and-care-number-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `tuaisceart-eireann-health-and-care-number-input`
- `ChildContent`: RenderFragment — component content
- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<TuaisceartEireannHealthAndCareNumberInput Label="...">
    Content
</TuaisceartEireannHealthAndCareNumberInput>
```
