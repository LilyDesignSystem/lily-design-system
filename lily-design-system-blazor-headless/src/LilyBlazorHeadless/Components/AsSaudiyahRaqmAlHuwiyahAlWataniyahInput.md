# AsSaudiyahRaqmAlHuwiyahAlWataniyahInput

A an input for entering Saudi Arabia's National Identification Number.

See `components/as-saudiyah-raqm-al-huwiyah-al-wataniyah-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `as-saudiyah-raqm-al-huwiyah-al-wataniyah-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<AsSaudiyahRaqmAlHuwiyahAlWataniyahInput Label="As Saudiyah Raqm Al Huwiyah Al Wataniyah" />
```
