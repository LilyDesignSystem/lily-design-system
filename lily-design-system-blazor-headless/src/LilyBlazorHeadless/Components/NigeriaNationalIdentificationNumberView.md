# NigeriaNationalIdentificationNumberView

A a read-only display of Nigeria's National Identification Number (NIN).

See `components/nigeria-national-identification-number-view/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `nigeria-national-identification-number-view`
- `ChildContent`: RenderFragment — component content
- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<NigeriaNationalIdentificationNumberView Label="Nigeria National Identification Number">...</NigeriaNationalIdentificationNumberView>
```
