# Examples — `<link-picker>`

| # | File | Demonstrates |
| - | ---- | ------------ |
| 1 | [`01-basic.html`](./01-basic.html) | Home, About Us, Contact Us, Privacy Policy, defined in the `links` attribute. |
| 2 | [`02-events.html`](./02-events.html) | The cancelable `navigate` event for client-side routing, and `current`. |

Each assumes the built module served at `/dist/index.js` (`npm run build` from `lily-design-system-html-helpers/` emits it); adjust the
import path as needed. The `<style>` blocks are the minimum CSS the package itself does not ship.
