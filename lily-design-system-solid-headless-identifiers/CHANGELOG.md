# Changelog — @lilydesignsystem/solid-headless-identifiers

The format is loosely based on [Keep a Changelog](https://keepachangelog.com/)
and the package follows [Semantic Versioning](https://semver.org/).

## 0.1.0 — 2026-11-18

- First release: the 164 national personal identifier components of the Lily Design System catalog for Solid 2.0, an
  `-input` and a `-view` for each of 82 identifier types across more than 50 countries, moved here from
  `@lilydesignsystem/solid-headless` 0.1.1 unchanged (spec/headless-identifiers). `solid-js` and `@solidjs/web` ^2.0.0 as
  peers; no dependency on `@lilydesignsystem/solid-headless`.
