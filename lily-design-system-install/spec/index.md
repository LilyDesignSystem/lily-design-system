# Install Skill — Specification

## Role

A cross-framework playbook for selecting and installing Lily's consumer
packages (tasks.md P22-T7). It is documentation, not a package manager wrapper.

## Acceptance criteria

- [x] The description names concrete install and setup triggers.
- [x] The playbook covers all nine framework families and optional layers.
- [x] It points to framework-specific skills for exact idioms and publication status.
- [x] It makes no public registry or `skills add` availability claim.
