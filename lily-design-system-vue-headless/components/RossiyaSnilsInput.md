# RossiyaSnilsInput

A headless Vue 3 input for Russia's SNILS (Individual Insurance Account Number).

Format: 11 digits as NNN-NNN-NNN CC: a 9-digit account number followed by a Modulus-101 weighted check value.

Companion: `RossiyaSnilsView`.

References: https://en.wikipedia.org/wiki/SNILS_(Russia)
