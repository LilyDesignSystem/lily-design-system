# ColombiaCedulaDeCiudadaniaInput

A headless Vue 3 input for Colombia's Cedula de Ciudadania Number.

Format: 7 or 8 digits plus a trailing Modulus-11 check character computed with repeating weights 2-7 (K represents 10).

Companion: `ColombiaCedulaDeCiudadaniaView`.

References: https://en.wikipedia.org/wiki/Colombian_identity_card
