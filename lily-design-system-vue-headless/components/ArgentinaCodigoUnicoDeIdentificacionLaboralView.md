# ArgentinaCodigoUnicoDeIdentificacionLaboralView

A headless Vue 3 read-only display for Argentina's Codigo Unico de Identificacion Laboral (CUIL).

Format: Displayed as XX-NNNNNNNN-X: a 2-digit prefix, the 8-digit DNI number, and a Modulus-11 check digit.

Companion: `ArgentinaCodigoUnicoDeIdentificacionLaboralInput`.

References: https://en.wikipedia.org/wiki/C%C3%B3digo_%C3%9Anico_de_Identificaci%C3%B3n_Laboral
