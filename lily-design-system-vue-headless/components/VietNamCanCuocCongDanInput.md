# VietNamCanCuocCongDanInput

A headless Vue 3 input for Viet Nam's Citizen Identification Number (CCCD).

Format: 7 or 8 digits plus a trailing Modulus-11 check character computed with repeating weights 2-7 (K represents 10).

Companion: `VietNamCanCuocCongDanView`.

References: https://en.wikipedia.org/wiki/Vietnamese_identity_card
