# MisrAlRaqmAlQawmiInput

A headless Vue 3 input for Egypt's National Number.

Format: 14 digits: century of birth, date of birth (YYMMDD), governorate code, a sequence number encoding sex by parity, and a check digit.

Companion: `MisrAlRaqmAlQawmiView`.

References: https://en.wikipedia.org/wiki/Egyptian_National_Identity_Card
