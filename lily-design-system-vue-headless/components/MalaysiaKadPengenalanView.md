# MalaysiaKadPengenalanView

A headless Vue 3 read-only display for Malaysia's MyKad Number (NRIC).

Format: 7 or 8 digits plus a trailing Modulus-11 check character computed with repeating weights 2-7 (K represents 10).

Companion: `MalaysiaKadPengenalanInput`.

References: https://en.wikipedia.org/wiki/MyKad
