# AustraliaTaxFileNumberView

A headless Vue 3 read-only display for Australia's Tax File Number (TFN).

Format: 7 or 8 digits plus a trailing Modulus-11 check character computed with repeating weights 2-7 (K represents 10).

Companion: `AustraliaTaxFileNumberInput`.

References: https://en.wikipedia.org/wiki/Tax_file_number
