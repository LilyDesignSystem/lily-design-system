# ToolCallStatus

A headless wrapper for the status of a tool call as a word, such as pending, running, done or error.

## Canonical documentation

See [components/tool-call-status/index.md](../../components/tool-call-status/index.md) for the full component documentation: ARIA, behaviour, props and guidance.

## Usage

```vue
<ToolCallStatus>…</ToolCallStatus>
```

## Contract

The status of a tool call as a visible word (pending, running, done, error), in the consumer's language. `status` only sets `data-status` for styling.
