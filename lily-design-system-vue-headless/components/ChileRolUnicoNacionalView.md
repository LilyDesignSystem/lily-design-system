# ChileRolUnicoNacionalView

A headless Vue 3 read-only display for Chile's Rol Unico Nacional (RUN).

Format: 7 or 8 digits plus a trailing Modulus-11 check character computed with repeating weights 2-7 (K represents 10).

Companion: `ChileRolUnicoNacionalInput`.

References: https://en.wikipedia.org/wiki/RUT
