# IndonesiaNomorIndukKependudukanView

A headless Vue 3 read-only display for Indonesia's Nomor Induk Kependudukan (NIK).

Format: 16 digits as PPKKCC-DDMMYY-NNNN: province/regency/sub-district code, date of birth (day +40 for a female holder), and a 4-digit sequence number. No published check digit.

Companion: `IndonesiaNomorIndukKependudukanInput`.

References: https://en.wikipedia.org/wiki/National_identification_number
