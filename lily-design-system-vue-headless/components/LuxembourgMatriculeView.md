# LuxembourgMatriculeView

A headless Vue 3 read-only display for Luxembourg's Numero d'Identification Nationale (Matricule).

Format: 13 digits as YYYYMMDDNNNCC: date of birth, a 3-digit sequence number, a Luhn check digit, and a Verhoeff check digit.

Companion: `LuxembourgMatriculeInput`.

References: https://ccss.public.lu/fr/glossaire/numero-identification-national/matricule-national.html
