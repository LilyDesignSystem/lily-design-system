# PakistanComputerizedNationalIdentityCardInput

A headless Vue 3 input for Pakistan's Computerized National Identity Card Number (CNIC).

Format: 7 or 8 digits plus a trailing Modulus-11 check character computed with repeating weights 2-7 (K represents 10).

Companion: `PakistanComputerizedNationalIdentityCardView`.

References: https://en.wikipedia.org/wiki/Computerized_National_Identity_Card
