# TaiwanGuominShenfenzhengTongyiBianhaoView

A headless Vue 3 read-only display for Taiwan's National Identification Card Number.

Format: 7 or 8 digits plus a trailing Modulus-11 check character computed with repeating weights 2-7 (K represents 10).

Companion: `TaiwanGuominShenfenzhengTongyiBianhaoInput`.

References: https://en.wikipedia.org/wiki/National_identification_card_(Taiwan)
