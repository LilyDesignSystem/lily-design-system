# NigeriaNationalIdentificationNumberInput

A headless Vue 3 input for Nigeria's National Identification Number (NIN).

Format: 7 or 8 digits plus a trailing Modulus-11 check character computed with repeating weights 2-7 (K represents 10).

Companion: `NigeriaNationalIdentificationNumberView`.

References: https://en.wikipedia.org/wiki/National_Identity_Management_Commission
