# TurkiyeTcKimlikNumarasiInput

A headless Vue 3 input for Turkey's T.C. Kimlik Numarasi.

Format: 11 digits, the first never zero: the 10th digit is derived from weighted odd/even digit sums, the 11th is the (always even) sum of the first ten digits.

Companion: `TurkiyeTcKimlikNumarasiView`.

References: https://en.wikipedia.org/wiki/Turkish_Identification_Number
