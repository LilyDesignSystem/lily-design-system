# IranKodEMelliInput

A headless Vue 3 input for Iran's National Code (Kod-e Melli).

Format: 7 or 8 digits plus a trailing Modulus-11 check character computed with repeating weights 2-7 (K represents 10).

Companion: `IranKodEMelliView`.

References: https://en.wikipedia.org/wiki/Iranian_identity_card
