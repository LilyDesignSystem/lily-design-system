# ZhongguoJuminShenfenzhengHaomaView

A headless Vue 3 read-only display for China's Resident Identity Card Number.

Format: 18 characters under GB 11643: region code, date of birth (YYYYMMDD), a sequence number encoding sex by parity, and an ISO 7064 MOD 11-2 check character (X for 10).

Companion: `ZhongguoJuminShenfenzhengHaomaInput`.

References: https://en.wikipedia.org/wiki/Resident_Identity_Card
