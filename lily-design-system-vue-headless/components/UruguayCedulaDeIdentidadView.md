# UruguayCedulaDeIdentidadView

A headless Vue 3 read-only display for Uruguay's Cedula de Identidad Number.

Format: 7 or 8 digits plus a trailing Modulus-11 check character computed with repeating weights 2-7 (K represents 10).

Companion: `UruguayCedulaDeIdentidadInput`.

References: https://en.wikipedia.org/wiki/C%C3%A9dula_de_identidad
