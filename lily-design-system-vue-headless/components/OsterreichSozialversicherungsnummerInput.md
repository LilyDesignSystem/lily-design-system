# OsterreichSozialversicherungsnummerInput

A headless Vue 3 input for Austria's Sozialversicherungsnummer (SVNR).

Format: 10 digits as NNNN DDMMYY: a 3-digit serial number, a Modulus-11 check digit, then date of birth (DDMMYY).

Companion: `OsterreichSozialversicherungsnummerView`.

References: https://de.wikipedia.org/wiki/Sozialversicherungsnummer
