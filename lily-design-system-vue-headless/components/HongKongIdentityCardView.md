# HongKongIdentityCardView

A headless Vue 3 read-only display for Hong Kong's Identity Card Number.

Format: 7 or 8 digits plus a trailing Modulus-11 check character computed with repeating weights 2-7 (K represents 10).

Companion: `HongKongIdentityCardInput`.

References: https://en.wikipedia.org/wiki/Hong_Kong_identity_card
