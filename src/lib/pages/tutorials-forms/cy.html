Tiwtorial ffurflenni hygyrch

Y patrwm y mae pob ffurflen Lily yn ei ddilyn, beth bynnag fo'r fframwaith: labelu pob rheolydd, gwirio wrth gyflwyno, rhoi pob gwall wrth ymyl ei faes, a chrynhoi'r gwallau lle mae'r ffocws yn glanio.

Beth fyddwch chi'n ei adeiladu

Ffurflen dau faes sydd, o'i chyflwyno gyda chamgymeriadau, yn dweud beth sydd o'i le, wrth ymyl pob maes ac mewn crynodeb ar y brig, ac yn symud y ffocws yno, fel bod defnyddiwr bysellfwrdd neu ddarllenydd sgrin yn dod o hyd i'r gwallau ar unwaith. Fe'i dangosir mewn HTML plaen gyda bachau dosbarth Lily; mae pob catalog fframwaith yn creu'r un marcio o'i gydrannau ei hun, Field, Hint, ErrorMessage a ErrorSummary . Tua 20 munud; mae'r tiwtorial HTML yn help yn gyntaf.

Cam 1 — Labelu pob rheolydd, a dweud beth rydych chi'n ei ddisgwyl

<form class="form" novalidate>
  <div class="field">
    <label class="label" for="name">Full name</label>
    <input class="text-input" type="text" id="name" name="name" autocomplete="name" required />
  </div>
  <div class="field">
    <label class="label" for="email">Email</label>
    <p class="hint" id="email-hint">We only use this to send your appointment.</p>
    <input class="email-input" type="email" id="email" name="email"
      autocomplete="email" aria-describedby="email-hint" required />
  </div>
  <button class="button" type="submit">Continue</button>
</form>
  • Elfen <label for> weladwy ar bob rheolydd, byth testun dalfan yn ei lle: mae dalfan yn diflannu wrth i chi deipio.
  • Mae awgrym yn ymuno ag enw'r maes drwy aria-describedby, felly mae darllenydd sgrin yn ei ddarllen gyda'r maes.
  • autocomplete yn gadael i'r porwr lenwi'r hyn y mae'n ei wybod (WCAG 1.3.5).
  • novalidate yn diffodd swigod y porwr ei hun, oherwydd byddwch chi'n dangos y gwallau eich hun, yn eich geiriau ac yn eich iaith. Mae required a type yn aros: mae eich sgript yn eu darllen.

Cam 2 — Gwirio wrth gyflwyno, nid tra bo rhywun yn teipio

Sŵn yw dweud wrth rywun fod eu cyfeiriad e-bost yn anghywir ar ôl un llythyren. Gwiriwch pan fyddan nhw'n cyflwyno. Mae'r 63 thema eisoes yn dangos maes yn annilys dim ond ar ôl iddo gael ei olygu a'i adael (:user-invalid), neu pan fyddwch chi'n gosod aria-invalid="true", felly does dim byd yn troi'n goch wrth lwytho'r dudalen.

Peidiwch byth ag analluogi'r botwm cyflwyno nes bod y ffurflen yn ddilys: ni all botwm wedi'i analluogi ddweud pam.

Cam 3 — Rhoi pob gwall wrth ymyl ei faes

<div class="field">
  <label class="label" for="email">Email</label>
  <p class="hint" id="email-hint">We only use this to send your appointment.</p>
  <p class="error-message" id="email-error">Enter an email address in the right format, like name@example.com</p>
  <input class="email-input" type="email" id="email" name="email" autocomplete="email"
    aria-invalid="true" aria-describedby="email-hint email-error" required />
</div>
  • aria-invalid="true" yn dweud bod y maes yn anghywir; mae'r neges yn dweud pam a sut i'w gywiro.
  • Mae'r neges yn aria-describedby, ar ôl yr awgrym, felly caiff ei darllen pan fydd y ffocws ar y maes.
  • Dywedwch beth i'w wneud, nid dim ond beth sydd o'i le: "Rhowch gyfeiriad e-bost yn y fformat cywir", nid "Annilys".
  • Byth lliw ar ei ben ei hun: y testun yw'r gwall; mae'r ffin goch yn ei ailadrodd yn unig (WCAG 1.4.1).

Cam 4 — Crynhoi'r gwallau lle mae'r ffocws yn glanio

<div class="error-summary" role="alert" tabindex="-1" aria-labelledby="error-summary-title">
  <h2 id="error-summary-title">There is a problem</h2>
  <ul>
    <li><a href="#name">Enter your full name</a></li>
    <li><a href="#email">Enter an email address in the right format, like name@example.com</a></li>
  </ul>
</div>

Rhowch ef ar frig y ffurflen a symudwch y ffocws ato wrth gyflwyno. Mae pob dolen yn mynd yn syth i'w maes. tabindex="-1" yn gadael i'r crynodeb gael y ffocws heb ychwanegu arhosfan tab.

Cam 5 — Y sgript sy'n clymu'r cyfan

const messages = {
  name: { valueMissing: "Enter your full name" },
  email: {
    valueMissing: "Enter your email address",
    typeMismatch: "Enter an email address in the right format, like name@example.com",
  },
};

const form = document.querySelector("form");
form.addEventListener("submit", (event) => {
  form.querySelector(".error-summary")?.remove();
  const errors = [];
  for (const field of form.querySelectorAll("input")) {
    const old = document.getElementById(field.id + "-error");
    old?.remove();
    const describedBy = (field.getAttribute("aria-describedby") ?? "")
      .split(" ").filter((id) => id && id !== field.id + "-error");
    const problem = Object.keys(messages[field.name] ?? {}).find((key) => field.validity[key]);
    if (!problem) {
      field.removeAttribute("aria-invalid");
      field.setAttribute("aria-describedby", describedBy.join(" "));
      continue;
    }
    const text = messages[field.name][problem];
    const message = document.createElement("p");
    message.className = "error-message";
    message.id = field.id + "-error";
    message.textContent = text;
    field.before(message);
    field.setAttribute("aria-invalid", "true");
    field.setAttribute("aria-describedby", [...describedBy, message.id].join(" "));
    errors.push({ id: field.id, text });
  }
  if (errors.length === 0) return; // valid: let it submit
  event.preventDefault();
  const summary = document.createElement("div");
  summary.className = "error-summary";
  summary.setAttribute("role", "alert");
  summary.tabIndex = -1;
  summary.setAttribute("aria-labelledby", "error-summary-title");
  summary.innerHTML = '<h2 id="error-summary-title">There is a problem</h2><ul></ul>';
  for (const { id, text } of errors) {
    const link = document.createElement("a");
    link.href = "#" + id;
    link.textContent = text;
    const item = document.createElement("li");
    item.append(link);
    summary.querySelector("ul").append(item);
  }
  form.prepend(summary);
  summary.focus();
});

Eich negeseuon chi ydyn nhw, yn eich iaith chi: mae validity y porwr yn dweud pa reol a fethodd, ac mae eich tabl yn dweud beth i'w ddweud wrth y person. Nid yw Lily yn cynnwys unrhyw Saesneg i chi ei gyfieithu.

Gwiriwch eich gwaith: cyflwynwch y ffurflen wag gyda'r bysellfwrdd. Mae'r ffocws yn symud i'r crynodeb ac mae darllenydd sgrin yn darllen "There is a problem" a'r ddau wall. Dilynwch ddolen: mae'r ffocws yn glanio yn y maes, sy'n cael ei ddarllen gyda'i awgrym a'i wall. Cywirwch y ddau a chyflwynwch: mae'r ffurflen yn mynd drwodd, heb unrhyw wall ar ôl.

Beth i'w osgoi

  • Cyfyngu neu gywiro'r hyn a deipiodd rhywun heb ddweud; dywedwch wrthyn nhw yn lle hynny.
  • Clirio ffurflen pan fydd gwall: cadwch bopeth a roesant.
  • Gwall sy'n ymddangos dim ond wrth hofran, neu dim ond mewn cyngor offer.
  • Gadael i ffurflen ddod i ben heb rybudd; defnyddiwch timeout-dialog i rybuddio ac ymestyn.

Camau nesaf

  • Hyfforddiant — wyth modiwl, pob un gydag ymarfer a hunanwiriad.
  • ErrorSummary, Field a ErrorMessage yn y catalog.
  • Ffurflen sy'n gweithio ledled y byd — enwau, cyfeiriadau, dyddiadau a chyfeiriad testun.
  • Themâu — y cyflwr annilys y mae pob thema'n ei dynnu.
