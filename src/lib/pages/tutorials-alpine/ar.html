درس Alpine.js

Lily لـ Alpine هي مقتطفات HTML تلصقها في صفحتك، مع إضافة واحدة تمنح المكوّنات التفاعلية لوحة مفاتيحها وحالتها.

ما الذي ستبنيه

نموذج إعدادات صغير: حقلان مسمّيان ومفتاح تبديل وزر حفظ، بسلوك حقيقي للوحة المفاتيح وقارئ الشاشة، دون تنسيق أولًا ثم منسّقًا، في نحو 10 دقائق.

قبل أن تبدأ

تحتاج إلى Node.js وإلى صفحة تحمّل Alpine.js 3 بالفعل. لا يملك Alpine نموذج مكوّنات، لذا فمكوّن Lily هنا ترميز تنسخه، لا استيراد.

الخطوة 1 — ثبّت الإضافة وسجّلها

npm install alpinejs @lilydesignsystem/alpine-headless
<script type="module">
  import Alpine from "alpinejs";
  import lily from "@lilydesignsystem/alpine-headless/plugin";
  Alpine.plugin(lily);
  Alpine.start();
</script>

تسجّل الإضافة سلوك Alpine.data() واحدًا لكل مكوّن تفاعلي، باسم lily متبوعًا باسم المكوّن: lilySwitchButton، lilyTabs، lilyCombobox. مقتطفات كل المكوّنات موجودة في مجلد components/ في الحزمة، ولكل منها تعليق في الرأس يذكر عنصره وصنفه ومفاتيحه وARIA.

الخطوة 2 — مكوّنك الأول

معظم المكوّنات ترميز عادي ولا تحتاج شيئًا من الإضافة:

<button class="button" type="submit">Save</button>

يضيف المكوّن التفاعلي سلوكه باستخدام x-data ويربطه باستخدام x-bind:

<button
  class="switch-button"
  x-data="lilySwitchButton(false)"
  x-bind="button"
  aria-label="Email me about appointments"
>
  Email me about appointments
</button>

يمنحه السلوك role="switch" ويُبقي aria-checked متزامنًا عندما يبدّله Enter أو المسافة أو النقر. الكلمات كلماتك: لا يوفّر Lily أي تسمية أبدًا.

الخطوة 3 — اجمع نموذجًا صغيرًا

<form class="form" aria-label="Settings">
  <div class="field">
    <label class="label" for="name">Full name</label>
    <input class="text-input" type="text" id="name" name="name" autocomplete="name" required />
  </div>
  <div class="field">
    <label class="label" for="email">Email</label>
    <input class="email-input" type="email" id="email" name="email" autocomplete="email" required />
  </div>
  <button
    class="switch-button"
    type="button"
    x-data="lilySwitchButton(true)"
    x-bind="button"
    aria-label="Email me about appointments"
  >
    Email me about appointments
  </button>
  <button class="button" type="submit">Save</button>
</form>

تحقّق من عملك: افتح الصفحة واضغط Tab. ينتقل التركيز عبر الحقلين ومفتاح التبديل والزر. على مفتاح التبديل، Space يبدّله، ويقول قارئ الشاشة «مفتاح تبديل، مفعّل» أو «غير مفعّل». يبدو بسيطًا، وهذا صحيح: المظهر هو التالي.

الخطوة 4 — نسّقه

اربط إحدى السمات الـ63 الجاهزة، فهي تستهدف الأصناف نفسها:

<link rel="stylesheet" href="/themes/light.css" />

أو اكتب CSS خاصًا بك على الأصناف والحالة التي يضبطها السلوك:

.switch-button[aria-checked="true"] { background: var(--color-primary); }
.switch-button:focus-visible { outline: 2px solid var(--lily-focus-ring); outline-offset: 2px; }

نسّق حالة ARIA لا صنفًا من عندك: عندها لا يمكن أن يخالف المظهر ما يسمعه قارئ الشاشة.

الخطوة 5 — شاهد كل شيء يعمل

  • تطبيق أمثلة Alpine.js، lily-design-system-alpine-examples يعرض كل مكوّن منسّقًا: pnpm install && pnpm run build.
  • تتوفر ست أدوات مساعدة لـ Alpine: شبكة البيانات ولوحة كانبان والتقويم ومخطط غانت ومحرّرا Markdown وOrg (@lilydesignsystem/alpine-*).
