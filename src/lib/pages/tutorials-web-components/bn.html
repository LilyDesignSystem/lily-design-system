Web Components টিউটোরিয়াল

ফ্রেমওয়ার্ক রানটাইম ছাড়া নেটিভ কাস্টম এলিমেন্ট। প্রতিটি লাইট DOM-এ আসল <button> বা <input> তৈরি করে, তাই ফর্ম, CSS আর querySelector হাতে লেখা HTML-এর মতোই কাজ করে।

আপনি কী বানাবেন

লেবেলযুক্ত ঘর আর একটি জমা দেওয়ার বোতামসহ একটি ছোট যোগাযোগ ফর্ম, কয়েক লাইনের স্ক্রিপ্টে যুক্ত, প্রথমে সাদামাটা, তারপর স্টাইল করা, প্রায় ১০ মিনিটে।

শুরু করার আগে

আপনার Node.js আর একটি বান্ডলার বা এমন কোনো সেটআপ লাগবে যা বেয়ার মডিউল ইমপোর্ট সমাধান করে। ক্যাটালগে ৬৩৭টির মধ্যে ৬০২টি কম্পোনেন্ট আছে; টেবিলের উপ-এলিমেন্ট আর কয়েকটি তালিকা-আইটেম পরিবার বাদ দেওয়া হয়েছে, কারণ একটি স্বতন্ত্র কাস্টম এলিমেন্ট <tr> বা <li>-এর জায়গা নিতে পারে না।

ধাপ ১ — ইনস্টল ও নিবন্ধন করুন

npm install @lilydesignsystem/web-components-headless
<script type="module">
  import "@lilydesignsystem/web-components-headless";
</script>

প্যাকেজ ইমপোর্ট করলেই প্রতিটি এলিমেন্ট সংজ্ঞায়িত হয়, যার নাম lily- তারপর কম্পোনেন্টের স্লাগ: <lily-button>, <lily-text-input>, <lily-range-fieldset>।

ধাপ ২ — আপনার প্রথম কম্পোনেন্ট

<lily-button type="submit">Send</lily-button>

এলিমেন্টটি নিজের ভেতরে একটি আসল <button class="button"> তৈরি করে, তাই Enter, Space ও বোতামের ভূমিকা নেটিভ। আপনার যোগ করা অ্যাট্রিবিউট সেই ভেতরের এলিমেন্টে পৌঁছায়।

ধাপ ৩ — একটি ছোট ফর্ম তৈরি করুন

<lily-form label="Contact us">
  <lily-field label="Full name" required>
    <lily-text-input label="Full name" name="name" autocomplete="name" required></lily-text-input>
  </lily-field>
  <lily-field label="Email" required>
    <lily-email-input label="Email" name="email" required></lily-email-input>
  </lily-field>
  <lily-button type="submit">Send</lily-button>
</lily-form>

<script type="module">
  const form = document.querySelector("lily-form form");
  form.addEventListener("submit", () => {
    const data = new FormData(form);
    console.log(Object.fromEntries(data));
  });
</script>

<lily-form> পাতার নেভিগেশন থামায় এবং submit ইভেন্টকে ওপরে উঠতে দেয়, তাই কী হবে তা আপনার স্ক্রিপ্ট ঠিক করে। ইনপুটগুলো আসল ফর্ম নিয়ন্ত্রণ, তাই FormData সেগুলো পড়ে।

আপনার কাজ যাচাই করুন: ফর্মে Tab চেপে এগিয়ে যান, তারপর জমা দিন: কনসোলে name এবং emailদেখা যায়। একটি ঘর খালি রাখলে ব্রাউজারের নিজস্ব required যাচাই জমা দেওয়া থামায়।

ধাপ ৪ — স্টাইল দিন

ক্লাস হুক ভেতরের এলিমেন্টে থাকে, তাই ৬৩টি থিম আর আপনার CSS সাধারণ HTML-এর মতোই সেগুলোকে লক্ষ্য করে: 

<link rel="stylesheet" href="/themes/light.css" />

<style>
  .button { padding: 0.75rem 1.5rem; }
  lily-field { display: block; margin-block-end: 1rem; }
</style>

ভেদ করার মতো কোনো shadow DOM নেই: আপনার স্টাইলশিট বা সহায়ক প্রযুক্তি থেকে কিছুই লুকানো নয়।

ধাপ ৫ — সব কিছু চলতে দেখুন

  • প্রতিটি এলিমেন্টের একটি story আছে: pnpm run storybook -এ lily-design-system-web-components-headless।
  • সহায়কগুলোও কাস্টম এলিমেন্ট হিসেবে আসে: <lily-theme-picker>, ডেটা গ্রিড, ক্যালেন্ডার ও অন্যান্য (@lilydesignsystem/web-components-*)।
