Tiwtorial Web Components

Elfennau cyfaddas brodorol heb amser rhedeg fframwaith. Mae pob un yn creu <button> neu <input> go iawn yn y DOM golau, felly mae ffurflenni, CSS a querySelector yn gweithio fel ar HTML a ysgrifennwyd â llaw.

Beth fyddwch chi'n ei adeiladu

Ffurflen gyswllt fach gyda meysydd wedi'u labelu a botwm cyflwyno, wedi'i chysylltu ag ychydig linellau o sgript, yn foel yn gyntaf, yna wedi'i steilio, mewn tua 10 munud.

Cyn i chi ddechrau

Mae angen Node.js arnoch a bwndelwr neu unrhyw drefniant sy'n datrys mewnforion modiwl moel. Mae'r catalog yn cwmpasu 626 o'r 661 cydran; mae is-elfennau tabl ac ambell deulu o eitemau rhestr wedi'u gadael allan, oherwydd ni all elfen gyfaddas annibynnol sefyll yn lle <tr> neu <li>.

Cam 1 — Gosod a chofrestru

npm install @lilydesignsystem/web-components-headless
<script type="module">
  import "@lilydesignsystem/web-components-headless";
</script>

Mae mewnforio'r pecyn yn diffinio pob elfen, pob un o'r enw lily- a slyg y gydran: <lily-button>, <lily-text-input>, <lily-range-fieldset>.

Cam 2 — Eich cydran gyntaf

<lily-button type="submit">Send</lily-button>

Mae'r elfen yn creu <button class="button"> go iawn y tu mewn iddi ei hun, felly mae Enter, Bylchwr a rôl y botwm yn frodorol. Mae'r priodoleddau rydych chi'n eu hychwanegu yn mynd drwodd i'r elfen fewnol honno.

Cam 3 — Cyfansoddi ffurflen fach

<lily-form label="Contact us">
  <lily-field label="Full name" required>
    <lily-text-input label="Full name" name="name" autocomplete="name" required></lily-text-input>
  </lily-field>
  <lily-field label="Email" required>
    <lily-email-input label="Email" name="email" required></lily-email-input>
  </lily-field>
  <lily-button type="submit">Send</lily-button>
</lily-form>

<script type="module">
  const form = document.querySelector("lily-form form");
  form.addEventListener("submit", () => {
    const data = new FormData(form);
    console.log(Object.fromEntries(data));
  });
</script>

<lily-form> yn atal llywio'r dudalen ac yn gadael i'r digwyddiad submit fyrlymu, felly eich sgript sy'n penderfynu beth sy'n digwydd. Mae'r mewnbynnau'n rheolyddion ffurflen go iawn, felly mae FormData yn eu darllen.

Gwiriwch eich gwaith: pwyswch Tab drwy'r ffurflen, yna ei chyflwyno: mae'r consol yn dangos name a email. Gadewch faes yn wag ac mae gwiriad required y porwr ei hun yn atal y cyflwyno.

Cam 4 — Ei steilio

Mae'r bachau dosbarth ar yr elfennau mewnol, felly mae'r 63 thema a'ch CSS eich hun yn eu targedu fel ar HTML plaen: 

<link rel="stylesheet" href="/themes/light.css" />

<style>
  .button { padding: 0.75rem 1.5rem; }
  lily-field { display: block; margin-block-end: 1rem; }
</style>

Nid oes DOM cysgod i'w dreiddio: does dim wedi'i guddio rhag eich dalen arddull na rhag technoleg gynorthwyol.

Cam 5 — Gweld y cyfan yn gweithio

  • Mae gan bob elfen stori: pnpm run storybook yn lily-design-system-web-components-headless.
  • Mae'r cynorthwywyr hefyd ar gael fel elfennau cyfaddas: <lily-theme-picker>, y grid data, y calendr a'r lleill (@lilydesignsystem/web-components-*).
