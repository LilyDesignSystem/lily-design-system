درس Web Components

عناصر مخصصة أصلية بلا بيئة تشغيل لإطار عمل. كل منها يعرض <button> أو <input> حقيقيًا في DOM الخفيف، فتعمل النماذج وCSS و querySelector كما في HTML المكتوب يدويًا.

ما الذي ستبنيه

نموذج تواصل صغير بحقول مسمّاة وزر إرسال، موصول ببضعة أسطر من البرنامج النصي، دون تنسيق أولًا ثم منسّقًا، في نحو 10 دقائق.

قبل أن تبدأ

تحتاج إلى Node.js وإلى أداة حزم أو أي إعداد يحلّ استيراد الوحدات المجرّدة. يغطي الكتالوج 626 من 661 مكوّنًا؛ وتُستبعد العناصر الفرعية للجداول وبضع عائلات من عناصر القوائم، لأن العنصر المخصص المستقل لا يمكن أن يحلّ محل <tr> أو <li>.

الخطوة 1 — ثبّت وسجّل

npm install @lilydesignsystem/web-components-headless
<script type="module">
  import "@lilydesignsystem/web-components-headless";
</script>

استيراد الحزمة يعرّف كل عنصر، وكل منها باسم lily- متبوعًا بمعرّف المكوّن: <lily-button>، <lily-text-input>، <lily-range-fieldset>.

الخطوة 2 — مكوّنك الأول

<lily-button type="submit">Send</lily-button>

يعرض العنصر داخله <button class="button"> حقيقيًا، فتكون Enter والمسافة ودور الزر أصلية. والسمات التي تضيفها تنتقل إلى ذلك العنصر الداخلي.

الخطوة 3 — اجمع نموذجًا صغيرًا

<lily-form label="Contact us">
  <lily-field label="Full name" required>
    <lily-text-input label="Full name" name="name" autocomplete="name" required></lily-text-input>
  </lily-field>
  <lily-field label="Email" required>
    <lily-email-input label="Email" name="email" required></lily-email-input>
  </lily-field>
  <lily-button type="submit">Send</lily-button>
</lily-form>

<script type="module">
  const form = document.querySelector("lily-form form");
  form.addEventListener("submit", () => {
    const data = new FormData(form);
    console.log(Object.fromEntries(data));
  });
</script>

<lily-form> يمنع انتقال الصفحة ويترك حدث submit يتصاعد، فيقرّر برنامجك النصي ما يحدث. الحقول عناصر نموذج حقيقية، لذا يقرؤها FormData .

تحقّق من عملك: اضغط Tab عبر النموذج، ثم أرسله: تُظهر وحدة التحكم name و email. اترك حقلًا فارغًا فيوقف تحقّق required الخاص بالمتصفح الإرسال.

الخطوة 4 — نسّقه

تقع الأصناف على العناصر الداخلية، فتستهدفها السمات الـ63 وCSS الخاص بك كما في HTML العادي: 

<link rel="stylesheet" href="/themes/light.css" />

<style>
  .button { padding: 0.75rem 1.5rem; }
  lily-field { display: block; margin-block-end: 1rem; }
</style>

لا يوجد Shadow DOM يجب اختراقه: لا شيء مخفي عن ورقة الأنماط ولا عن التقنيات المساعدة.

الخطوة 5 — شاهد كل شيء يعمل

  • لكل عنصر story: pnpm run storybook في lily-design-system-web-components-headless.
  • تأتي الأدوات المساعدة أيضًا عناصر مخصصة: <lily-theme-picker>، وشبكة البيانات والتقويم وغيرها (@lilydesignsystem/web-components-*).

الخطوات التالية

  • التدريب — ثماني وحدات، لكل منها تمرين واختبار ذاتي.
  • النماذج الميسّرة — الأخطاء وملخص الأخطاء والتركيز.
  • السمات — تبديل السمة أثناء التشغيل.
  • كتالوج المكوّنات — المرجع الكامل.
