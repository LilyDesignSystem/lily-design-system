Web Components ٹیوٹوریل

بغیر فریم ورک رن ٹائم کے مقامی کسٹم عناصر۔ ہر ایک لائٹ DOM میں حقیقی <button> یا <input> بناتا ہے، اس لیے فارم، CSS اور querySelector ہاتھ سے لکھے HTML کی طرح ہی کام کرتے ہیں۔

آپ کیا بنائیں گے

لیبل والے خانوں اور جمع کرانے کے بٹن والا ایک چھوٹا رابطہ فارم، اسکرپٹ کی چند سطروں سے جڑا، پہلے سادہ، پھر اسٹائل شدہ، تقریباً 10 منٹ میں۔

شروع کرنے سے پہلے

آپ کو Node.js اور ایک بنڈلر یا کوئی بھی سیٹ اپ چاہیے جو سادہ ماڈیول امپورٹ حل کرے۔ کیٹلاگ 661 میں سے 626 اجزاء کا احاطہ کرتا ہے؛ ٹیبل کے ذیلی عناصر اور فہرست کے کچھ خاندان شامل نہیں، کیونکہ ایک خودمختار کسٹم عنصر <tr> یا <li>کی جگہ نہیں لے سکتا۔

مرحلہ 1 — انسٹال اور رجسٹر کریں

npm install @lilydesignsystem/web-components-headless
<script type="module">
  import "@lilydesignsystem/web-components-headless";
</script>

پیکیج امپورٹ کرتے ہی ہر عنصر متعین ہو جاتا ہے، جن کا نام lily- کے بعد جزو کا سلگ ہے: <lily-button>، <lily-text-input>، <lily-range-fieldset>۔

مرحلہ 2 — آپ کا پہلا جزو

<lily-button type="submit">Send</lily-button>

عنصر اپنے اندر ایک حقیقی <button class="button"> بناتا ہے، اس لیے Enter، Space اور بٹن کا کردار مقامی ہیں۔ آپ جو خصوصیات شامل کریں وہ اس اندرونی عنصر تک پہنچتی ہیں۔

مرحلہ 3 — ایک چھوٹا فارم بنائیں

<lily-form label="Contact us">
  <lily-field label="Full name" required>
    <lily-text-input label="Full name" name="name" autocomplete="name" required></lily-text-input>
  </lily-field>
  <lily-field label="Email" required>
    <lily-email-input label="Email" name="email" required></lily-email-input>
  </lily-field>
  <lily-button type="submit">Send</lily-button>
</lily-form>

<script type="module">
  const form = document.querySelector("lily-form form");
  form.addEventListener("submit", () => {
    const data = new FormData(form);
    console.log(Object.fromEntries(data));
  });
</script>

<lily-form> صفحے کی نیویگیشن روکتا ہے اور submit ایونٹ کو اوپر جانے دیتا ہے، تاکہ آپ کا اسکرپٹ طے کرے کہ کیا ہو۔ ان پٹ حقیقی فارم کنٹرول ہیں، اس لیے FormData انہیں پڑھتا ہے۔

اپنا کام جانچیں: فارم میں Tab دباتے ہوئے جائیں، پھر جمع کرائیں: کنسول name اور emailدکھاتا ہے۔ کوئی خانہ خالی چھوڑیں تو براؤزر کی اپنی required جانچ جمع کرانا روک دیتی ہے۔

مرحلہ 4 — اسٹائل دیں

کلاس ہکس اندرونی عناصر پر ہیں، اس لیے 63 تھیمز اور آپ کا CSS انہیں سادہ HTML کی طرح نشانہ بناتے ہیں: 

<link rel="stylesheet" href="/themes/light.css" />

<style>
  .button { padding: 0.75rem 1.5rem; }
  lily-field { display: block; margin-block-end: 1rem; }
</style>

چیرنے کے لیے کوئی shadow DOM نہیں: آپ کی اسٹائل شیٹ اور معاون ٹیکنالوجی سے کچھ بھی چھپا نہیں۔

مرحلہ 5 — سب کچھ کام کرتا دیکھیں

  • ہر عنصر کی ایک story ہے: pnpm run storybook میں lily-design-system-web-components-headless۔
  • معاون بھی کسٹم عناصر کے طور پر آتے ہیں: <lily-theme-picker>، ڈیٹا گرڈ، کیلنڈر اور دیگر (@lilydesignsystem/web-components-*‏)۔
