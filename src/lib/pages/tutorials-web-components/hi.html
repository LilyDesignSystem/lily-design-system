Web Components ट्यूटोरियल

बिना फ़्रेमवर्क रनटाइम के नेटिव कस्टम एलिमेंट। हर एक लाइट DOM में असली <button> या <input> बनाता है, इसलिए फ़ॉर्म, CSS और querySelector हाथ से लिखे HTML जैसे ही काम करते हैं।

आप क्या बनाएँगे

लेबल वाले फ़ील्ड और सबमिट बटन वाला एक छोटा संपर्क फ़ॉर्म, कुछ पंक्तियों की स्क्रिप्ट से जुड़ा, पहले सादा, फिर स्टाइल किया हुआ, लगभग 10 मिनट में।

शुरू करने से पहले

आपको Node.js और एक बंडलर या कोई भी सेटअप चाहिए जो बेयर मॉड्यूल इम्पोर्ट हल करे। कैटलॉग 661 में से 626 कॉम्पोनेंट को कवर करता है; टेबल के उप-एलिमेंट और कुछ सूची-आइटम परिवार छोड़े गए हैं, क्योंकि एक स्वायत्त कस्टम एलिमेंट <tr> या <li>की जगह नहीं ले सकता।

चरण 1 — इंस्टॉल और रजिस्टर करें

npm install @lilydesignsystem/web-components-headless
<script type="module">
  import "@lilydesignsystem/web-components-headless";
</script>

पैकेज इम्पोर्ट करते ही हर एलिमेंट परिभाषित हो जाता है, जिनका नाम lily- के बाद कॉम्पोनेंट का स्लग है: <lily-button>, <lily-text-input>, <lily-range-fieldset>।

चरण 2 — आपका पहला कॉम्पोनेंट

<lily-button type="submit">Send</lily-button>

एलिमेंट अपने भीतर एक असली <button class="button"> बनाता है, इसलिए Enter, Space और बटन की भूमिका नेटिव हैं। आप जो एट्रिब्यूट जोड़ते हैं वे उस भीतरी एलिमेंट तक पहुँचते हैं।

चरण 3 — एक छोटा फ़ॉर्म बनाएँ

<lily-form label="Contact us">
  <lily-field label="Full name" required>
    <lily-text-input label="Full name" name="name" autocomplete="name" required></lily-text-input>
  </lily-field>
  <lily-field label="Email" required>
    <lily-email-input label="Email" name="email" required></lily-email-input>
  </lily-field>
  <lily-button type="submit">Send</lily-button>
</lily-form>

<script type="module">
  const form = document.querySelector("lily-form form");
  form.addEventListener("submit", () => {
    const data = new FormData(form);
    console.log(Object.fromEntries(data));
  });
</script>

<lily-form> पेज नेविगेशन रोकता है और submit इवेंट को ऊपर जाने देता है, ताकि आपकी स्क्रिप्ट तय करे कि क्या हो। इनपुट असली फ़ॉर्म नियंत्रण हैं, इसलिए FormData उन्हें पढ़ता है।

अपना काम जाँचें: फ़ॉर्म में Tab दबाते हुए जाएँ, फिर सबमिट करें: कंसोल name और emailदिखाता है। कोई फ़ील्ड खाली छोड़ें तो ब्राउज़र की अपनी required जाँच सबमिट रोक देती है।

चरण 4 — स्टाइल दें

क्लास हुक भीतरी एलिमेंट पर हैं, इसलिए 63 थीम और आपका CSS उन्हें सादे HTML की तरह लक्ष्य करते हैं: 

<link rel="stylesheet" href="/themes/light.css" />

<style>
  .button { padding: 0.75rem 1.5rem; }
  lily-field { display: block; margin-block-end: 1rem; }
</style>

भेदने के लिए कोई shadow DOM नहीं है: आपकी स्टाइलशीट और सहायक तकनीक से कुछ भी छिपा नहीं।

चरण 5 — सब कुछ काम करते देखें

  • हर एलिमेंट की एक story है: pnpm run storybook में lily-design-system-web-components-headless।
  • हेल्पर भी कस्टम एलिमेंट के रूप में आते हैं: <lily-theme-picker>, डेटा ग्रिड, कैलेंडर और अन्य (@lilydesignsystem/web-components-*)।

अगले कदम

  • सुलभ फ़ॉर्म — त्रुटियाँ, त्रुटि-सारांश और फ़ोकस।
  • थीमिंग — चलते समय थीम बदलना।
  • कॉम्पोनेंट कैटलॉग — पूरा संदर्भ।
