## 0.1.0 — 2026-11-18

- First release. The Solid port of the Svelte helper. Solid Markdown editor: a textarea with a toolbar of rich-text buttons (bold, italic, link, headings, lists, quote, code) that write Markdown. Headless, SSR-safe, no CSS.
