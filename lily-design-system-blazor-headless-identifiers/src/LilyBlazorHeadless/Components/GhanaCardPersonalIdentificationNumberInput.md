# GhanaCardPersonalIdentificationNumberInput

A an input for entering Ghana's Ghana Card PIN.

See `components/ghana-card-personal-identification-number-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `ghana-card-personal-identification-number-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<GhanaCardPersonalIdentificationNumberInput Label="Ghana Card Personal Identification Number" />
```
