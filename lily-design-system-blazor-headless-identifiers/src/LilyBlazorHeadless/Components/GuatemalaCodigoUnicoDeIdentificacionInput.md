# GuatemalaCodigoUnicoDeIdentificacionInput

A an input for entering Guatemala's Código Único de Identificación (CUI).

See `components/guatemala-codigo-unico-de-identificacion-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `guatemala-codigo-unico-de-identificacion-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<GuatemalaCodigoUnicoDeIdentificacionInput Label="Guatemala Codigo Unico De Identificacion" />
```
