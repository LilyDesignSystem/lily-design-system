# BangladeshNationalIdentityCardInput

A an input for entering Bangladesh's National ID (NID) number.

See `components/bangladesh-national-identity-card-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `bangladesh-national-identity-card-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<BangladeshNationalIdentityCardInput Label="Bangladesh National Identity Card" />
```
