# MauritiusNationalIdentityCardNumberInput

A an input for entering Mauritius's National Identity Card number.

See `components/mauritius-national-identity-card-number-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `mauritius-national-identity-card-number-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<MauritiusNationalIdentityCardNumberInput Label="Mauritius National Identity Card Number" />
```
