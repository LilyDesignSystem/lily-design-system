# PeruDocumentoNacionalDeIdentidadInput

A an input for entering Peru's Documento Nacional de Identidad (DNI).

See `components/peru-documento-nacional-de-identidad-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `peru-documento-nacional-de-identidad-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<PeruDocumentoNacionalDeIdentidadInput Label="Peru Documento Nacional De Identidad" />
```
