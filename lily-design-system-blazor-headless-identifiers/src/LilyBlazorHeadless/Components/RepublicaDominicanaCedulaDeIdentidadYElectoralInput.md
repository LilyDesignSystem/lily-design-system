# RepublicaDominicanaCedulaDeIdentidadYElectoralInput

A an input for entering the Dominican Republic's Cédula de Identidad y Electoral.

See `components/republica-dominicana-cedula-de-identidad-y-electoral-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `republica-dominicana-cedula-de-identidad-y-electoral-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<RepublicaDominicanaCedulaDeIdentidadYElectoralInput Label="Republica Dominicana Cedula De Identidad Y Electoral" />
```
