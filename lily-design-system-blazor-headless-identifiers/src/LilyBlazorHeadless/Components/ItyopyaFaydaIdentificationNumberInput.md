# ItyopyaFaydaIdentificationNumberInput

A an input for entering Ethiopia's Fayda Identification Number (FIN).

See `components/ityopya-fayda-identification-number-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `ityopya-fayda-identification-number-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<ItyopyaFaydaIdentificationNumberInput Label="Ityopya Fayda Identification Number" />
```
