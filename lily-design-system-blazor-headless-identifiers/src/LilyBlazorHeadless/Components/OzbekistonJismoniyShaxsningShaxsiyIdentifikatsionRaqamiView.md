# OzbekistonJismoniyShaxsningShaxsiyIdentifikatsionRaqamiView

A a read-only display of Uzbekistan's Personal identification number (JShShIR / PINFL).

See `components/ozbekiston-jismoniy-shaxsning-shaxsiy-identifikatsion-raqami-view/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `ozbekiston-jismoniy-shaxsning-shaxsiy-identifikatsion-raqami-view`
- `ChildContent`: RenderFragment — component content
- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<OzbekistonJismoniyShaxsningShaxsiyIdentifikatsionRaqamiView Label="Ozbekiston Jismoniy Shaxsning Shaxsiy Identifikatsion Raqami">...</OzbekistonJismoniyShaxsningShaxsiyIdentifikatsionRaqamiView>
```
