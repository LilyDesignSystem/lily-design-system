# CostaRicaCedulaDeIdentidadInput

A an input for entering Costa Rica's Cédula de Identidad.

See `components/costa-rica-cedula-de-identidad-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `costa-rica-cedula-de-identidad-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<CostaRicaCedulaDeIdentidadInput Label="Costa Rica Cedula De Identidad" />
```
