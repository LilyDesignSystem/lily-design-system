# AlImaratRaqmAlHuwiyahInput

A an input for entering the United Arab Emirates' Emirates ID number.

See `components/al-imarat-raqm-al-huwiyah-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `al-imarat-raqm-al-huwiyah-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<AlImaratRaqmAlHuwiyahInput Label="Al Imarat Raqm Al Huwiyah" />
```
