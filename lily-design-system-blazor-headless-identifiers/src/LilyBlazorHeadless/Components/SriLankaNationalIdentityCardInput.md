# SriLankaNationalIdentityCardInput

A an input for entering Sri Lanka's National Identity Card (NIC) number.

See `components/sri-lanka-national-identity-card-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `sri-lanka-national-identity-card-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<SriLankaNationalIdentityCardInput Label="Sri Lanka National Identity Card" />
```
