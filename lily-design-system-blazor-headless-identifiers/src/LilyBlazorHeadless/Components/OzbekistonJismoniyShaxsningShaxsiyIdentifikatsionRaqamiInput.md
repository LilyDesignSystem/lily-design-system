# OzbekistonJismoniyShaxsningShaxsiyIdentifikatsionRaqamiInput

A an input for entering Uzbekistan's Personal identification number (JShShIR / PINFL).

See `components/ozbekiston-jismoniy-shaxsning-shaxsiy-identifikatsion-raqami-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `ozbekiston-jismoniy-shaxsning-shaxsiy-identifikatsion-raqami-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<OzbekistonJismoniyShaxsningShaxsiyIdentifikatsionRaqamiInput Label="Ozbekiston Jismoniy Shaxsning Shaxsiy Identifikatsion Raqami" />
```
