# QazaqstanZhekeSaikestendiruNomiriInput

A an input for entering Kazakhstan's Individual Identification Number (IIN).

See `components/qazaqstan-zheke-saikestendiru-nomiri-input/index.md` for canonical documentation.

## Parameters

- `Label`: string (required) — accessible label set on `aria-label`
- `CssClass`: string — extra CSS classes appended to `qazaqstan-zheke-saikestendiru-nomiri-input`

- `AdditionalAttributes`: catches unmatched HTML attributes

## Usage

```razor
<QazaqstanZhekeSaikestendiruNomiriInput Label="Qazaqstan Zheke Saikestendiru Nomiri" />
```
