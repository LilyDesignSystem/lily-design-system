# Changelog — LilyDesignSystem.Blazor.Headless.Identifiers

The format is loosely based on [Keep a Changelog](https://keepachangelog.com/)
and the package follows [Semantic Versioning](https://semver.org/).

## 0.1.0 — 2026-11-18

- First release: the 164 national personal identifier components of the Lily Design System catalog for Blazor, an
  `-input` and a `-view` for each of 82 identifier types across more than 50 countries, moved here unchanged from
  `LilyDesignSystem.Blazor.Headless` 0.10.0 (spec/headless-identifiers). It depends on `LilyDesignSystem.Blazor.Headless`,
  whose `ValueInputBase` every identifier input extends.
