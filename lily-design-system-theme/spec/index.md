# Theme Skill — Specification

## Role

A playbook for consumer styling and repository reference-theme authoring
(tasks.md P22-T7), grounded in the DTCG token source and accessibility gates.

## Acceptance criteria

- [x] The description names styling, tokens, theme creation, and contrast triggers.
- [x] Consumer overrides and canonical theme changes are separate workflows.
- [x] Canonical edits use token JSON and regenerate CSS.
- [x] Contrast, token, provenance, and full-repository checks are named.

Project-wide skill rules: [spec/agent-skills](../../spec/agent-skills/index.md).
