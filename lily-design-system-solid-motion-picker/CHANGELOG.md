# Changelog — @lilydesignsystem/solid-motion-picker

The format is loosely based on [Keep a Changelog](https://keepachangelog.com/)
and the package follows [Semantic Versioning](https://semver.org/).

## 0.1.0 — unreleased

- First release, for Solid 2.0 (`solid-js` and `@solidjs/web` ^2.0.0 as peers): motion (reduced-motion) picker: an icon button opening an APG listbox that sets data-motion on the document, defaulting to the OS's own prefers-reduced-motion signal. Headless, SSR-safe, no CSS.
- Ported from [`@lilydesignsystem/react-motion-picker`](../lily-design-system-react-motion-picker/) with its tests, to the contract in
  [spec/index.md](./spec/index.md); the same markup, class hooks, keyboard and ARIA as the other catalogs.
- The monorepo [CHANGELOG](../CHANGELOG.md) has the detail.
