# Changelog — ColorPicker (Svelte)

All notable changes to this helper are documented in this file. The format is loosely based on
[Keep a Changelog](https://keepachangelog.com/) and the project follows [Semantic Versioning](https://semver.org/).

## 0.1.0 — 2026-11-15

- First version: recent colours, a separator, a palette of 8 rows of 10 swatches with a Transparent button, a separator, and
  entry by hex, CSS (X11) colour name, and HSL, HSB, RGB and CMYK groups. Native radios, Up and Down by row, form submission and
  reset, no English, no CSS.
