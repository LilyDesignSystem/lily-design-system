# ConvertIntoValueDiv

The converted value, such as a text input showing the number of euros.

## Props

- `className`: string (optional) -- CSS class appended to `convert-into-value-div`
- `children`: ReactNode (optional) -- the content
- `...restProps`: unknown -- additional attributes spread onto the root

## Usage

```tsx
<ConvertIntoValueDiv>...</ConvertIntoValueDiv>
```
