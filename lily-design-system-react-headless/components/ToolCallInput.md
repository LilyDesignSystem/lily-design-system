# ToolCallInput

A headless wrapper for the input or arguments passed to a tool in a tool call.

## Canonical documentation

See [components/tool-call-input/index.md](../../components/tool-call-input/index.md) for the full component documentation: ARIA, behaviour, props and guidance.

## Usage

```tsx
<ToolCallInput>…</ToolCallInput>
```

## Contract

The input or arguments passed to the tool. A `<div>` that becomes a named group when `label` is given; the consumer puts a `<pre>` or formatted arguments inside.
