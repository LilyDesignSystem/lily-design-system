# ConvertIntoUnitDiv

The unit to convert into, such as a select box of currencies or lengths.

## Props

- `className`: string (optional) -- CSS class appended to `convert-into-unit-div`
- `children`: ReactNode (optional) -- the content
- `...restProps`: unknown -- additional attributes spread onto the root

## Usage

```tsx
<ConvertIntoUnitDiv>...</ConvertIntoUnitDiv>
```
