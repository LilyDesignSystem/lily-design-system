# PilipinasPhilhealthIdentificationNumberView

A headless read-only display for the Philippines's PhilHealth Identification Number (PIN). Format: Twelve-digit number assigned by the Philippine Health Insurance Corporation (PhilHealth) to every enrolled member, commonly displayed grouped as NN-NNNNNNNNN-N. No published check-digit algorithm; correctness is confirmed against PhilHealth's own membership records.

## What it is

A React 19 component that renders an inline `<span>` for displaying the Philippines's PhilHealth Identification Number (PIN) read-only.

## When to use it

- Displaying a PhilHealth Identification Number for the Philippines.

## When not to use it

- Use `PilipinasPhilhealthIdentificationNumberInput` for the editable input counterpart.
