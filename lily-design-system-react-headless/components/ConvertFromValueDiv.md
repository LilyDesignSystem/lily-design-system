# ConvertFromValueDiv

The value to convert from, such as a text input holding the number of dollars.

## Props

- `className`: string (optional) -- CSS class appended to `convert-from-value-div`
- `children`: ReactNode (optional) -- the content
- `...restProps`: unknown -- additional attributes spread onto the root

## Usage

```tsx
<ConvertFromValueDiv>...</ConvertFromValueDiv>
```
