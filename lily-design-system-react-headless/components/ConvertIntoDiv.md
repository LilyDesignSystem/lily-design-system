# ConvertIntoDiv

The target side of a conversion, holding the value and unit to convert into.

## Props

- `className`: string (optional) -- CSS class appended to `convert-into-div`
- `children`: ReactNode (optional) -- the content
- `...restProps`: unknown -- additional attributes spread onto the root

## Usage

```tsx
<ConvertIntoDiv>...</ConvertIntoDiv>
```
