# ColombiaCedulaDeCiudadaniaView

A headless read-only display for Colombia's Cedula de Ciudadania Number. Format: Six to ten digits, usually written with dots as thousands separators (1.020.304.050). Newer cards carry the ten-digit Número Único de Identificación Personal (NUIP). There is no check digit.

## What it is

A React 19 component that renders an inline `<span>` for displaying Colombia's Cedula de Ciudadania Number read-only.

## When to use it

- Displaying a Colombia Cedula de Ciudadania Number. Printed on the Cédula de Ciudadanía issued by the Registraduría Nacional del Estado Civil, and asked for by EPS health-insurance providers, banks and government services.

## When not to use it

- Use `ColombiaCedulaDeCiudadaniaInput` for the editable input counterpart.
