# ConvertFromUnitDiv

The unit to convert from, such as a select box of currencies or lengths.

## Props

- `className`: string (optional) -- CSS class appended to `convert-from-unit-div`
- `children`: ReactNode (optional) -- the content
- `...restProps`: unknown -- additional attributes spread onto the root

## Usage

```tsx
<ConvertFromUnitDiv>...</ConvertFromUnitDiv>
```
