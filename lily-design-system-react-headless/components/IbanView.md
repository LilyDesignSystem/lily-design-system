# IbanView

A headless read-only display for an International Bank Account Number (IBAN). Format: Up to 34 letters and digits: a two-letter country code, two check digits, then the national account number.

## What it is

A React 19 component that renders an inline `<span>` for displaying an International Bank Account Number (IBAN) read-only.

## When to use it

- Displaying an IBAN.

## When not to use it

- Use `IbanInput` for the editable input counterpart.
