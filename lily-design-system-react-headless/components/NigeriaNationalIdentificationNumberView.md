# NigeriaNationalIdentificationNumberView

A headless read-only display for Nigeria's National Identification Number (NIN). Format: Eleven digits issued by the National Identity Management Commission (NIMC). No check-digit algorithm is published, so only the length and digits can be checked.

## What it is

A React 19 component that renders an inline `<span>` for displaying Nigeria's National Identification Number (NIN) read-only.

## When to use it

- Displaying a Nigeria National Identification Number (NIN). Shown on the NIN slip and in the NIMC mobile app, and asked for when registering a SIM card, opening a bank account or applying for a passport.

## When not to use it

- Use `NigeriaNationalIdentificationNumberInput` for the editable input counterpart.
