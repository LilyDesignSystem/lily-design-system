# NigeriaNationalIdentificationNumberInput

A headless input for Nigeria's National Identification Number (NIN). Format: Eleven digits issued by the National Identity Management Commission (NIMC). No check-digit algorithm is published, so only the length and digits can be checked.

## What it is

A React 19 component that renders a native `<input type="text">` for entering Nigeria's National Identification Number (NIN).

## When to use it

- Forms collecting a Nigeria National Identification Number (NIN). Shown on the NIN slip and in the NIMC mobile app, and asked for when registering a SIM card, opening a bank account or applying for a passport.

## When not to use it

- Use `NigeriaNationalIdentificationNumberView` for the read-only display counterpart.
