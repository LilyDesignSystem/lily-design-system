# IbanInput

A headless input for an International Bank Account Number (IBAN). Format: Up to 34 letters and digits: a two-letter country code, two check digits, then the national account number.

## What it is

A React 19 component that renders a native `<input type="text">` for entering an International Bank Account Number (IBAN).

## When to use it

- Forms collecting an IBAN.

## When not to use it

- Use `IbanView` for the read-only display counterpart.
