## P56-T2a · Review the Welsh words at the point where the user needs them

The content designer lists the exact wording for each scenario, including page titles, error summaries, field errors, change links and hidden prefixes. Uncertain Welsh is visibly marked for translation. The wireframe test counts marked strings still awaiting translation; its language-switch check can pass with placeholders. A successful switch demonstrates the wiring. A Welsh-language reviewer must still assess the meaning of the words. [Content role](https://github.com/DHCW-Digital-Health-and-Care-Wales/dhcw-design-system-factory/blob/44adb5c848efd4060a75e41767cf95abaa892eb3/.claude/agents/carys-copy.md) · [Wireframe checks](https://github.com/DHCW-Digital-Health-and-Care-Wales/dhcw-design-system-factory/blob/44adb5c848efd4060a75e41767cf95abaa892eb3/templates/wireframe/test.js)

Extend P56-T1/T2 with a short English/Welsh wording table for **one booking validation state**. Include the field label, inline error, error-summary link and recovery action. Record which words the service owns, which come from a label pack, and whether the Welsh is awaiting review or has been reviewed by a named reviewer on a recorded date. Check that the two error locations give the same instruction and the link reaches the field. Keep provisional copy in the review artifact. P41-T1 already owns review of the reusable Welsh pack; this task covers the service-specific words read together during an error.
