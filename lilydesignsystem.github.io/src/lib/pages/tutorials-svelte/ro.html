Tutorial Svelte

Biblioteca Svelte a Lily este implementarea canonică: runes Svelte 5, props tipizate, distribuire a props rămase și legare bidirecțională cu bind:value.

Ce vei construi

Un mic formular de contact — câmp cu etichetă, buton de trimitere, legare bidirecțională, comportament real al tastaturii și al cititorului de ecran — mai întâi simplu, apoi stilizat, în aproximativ 10 minute.

Înainte să începi

Ai nevoie de git, Node 22 sau mai nou și pnpm 10 sau mai nou. Orice proiect Svelte 5 merge — o aplicație npx sv create nouă este suficientă.

Pasul 1 — Obține codul

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-headless
pnpm install
pnpm test        # vitest — thousands of component cases
pnpm run storybook   # browse all 571 components

Componentele se află în src/lib/components/{Name}/, un director pe componentă cu fișierul .svelte , testele, story-urile și documentația sa alături. Copiază directoarele de care ai nevoie în aplicația ta sau depinde de depozit și importă direct.

Pasul 2 — Prima ta componentă

<script>
  import Button from "#lib/components/Button/Button.svelte";

  function save() { console.log("saved"); }
</script>

<Button onclick={save}>Save</Button>

Randează <button class="button" type="button">. Props sunt tipizate: type, disabled, pressed (randează aria-pressed (randează label (un aria-label pentru butoane comutatoare),

Pasul 4 — Stilizează-l

Tot ce e mai sus se randează ca structură pură, gata pentru stilurile tale. Stilizează cârligele de clasă — .button, .text-input, .label, .field — în foaia ta de stil globală sau leagă o temă gata făcută în app.html: 

<link rel="stylesheet" href="/themes/dark.css" />

Ajustările pe instanță trec prin prop-ul class care se adaugă la cârligul de bază: <Button class="wide"> randează class="button wide".

Pasul 5 — Vezi totul funcționând

Aplicația-exemplu SvelteKit este același catalog complet stilizat, cu demonstrații live, teste Playwright e2e și o linie de bază de accesibilitate axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-sveltekit-examples
pnpm install && pnpm run dev
