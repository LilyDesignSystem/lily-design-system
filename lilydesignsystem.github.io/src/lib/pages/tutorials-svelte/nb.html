Svelte-veiledning

Lilys Svelte-bibliotek er den kanoniske implementasjonen: Svelte 5 runes, typede egenskaper, rest-prop-spredning og toveis binding med bind:value.

Hva du skal bygge

Et lite kontaktskjema — et inndatafelt med etikett, en send-knapp, toveis binding, ekte tastatur- og skjermleseroppførsel — først bart, så stilet, på omtrent 10 minutter.

Før du begynner

Du trenger git, Node 22 eller nyere og pnpm 10 eller nyere. Ethvert Svelte 5-prosjekt fungerer — en ny npx sv create app holder.

Steg 1 — Hent koden

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-headless
pnpm install
pnpm test        # vitest — thousands of component cases
pnpm run storybook   # browse all 571 components

Komponentene bor i src/lib/components/{Name}/, én katalog per komponent med .svelte -filen, testene, storiene og dokumentasjonen side om side. Kopier katalogene du trenger inn i appen din, eller avhenge av repoet og importer direkte.

Steg 2 — Din første komponent

<script>
  import Button from "#lib/components/Button/Button.svelte";

  function save() { console.log("saved"); }
</script>

<Button onclick={save}>Save</Button>

Gjengir <button class="button" type="button">. Egenskapene er typet: type, disabled, pressed (gjengir aria-pressed for veksleknapper), label (en aria-label overstyring), og ethvert ekstra attributt spres på roten.

Steg 3 — Sett sammen et lite skjema

<script>
  import Form from "#lib/components/Form/Form.svelte";
  import Field from "#lib/components/Field/Field.svelte";
  import TextInput from "#lib/components/TextInput/TextInput.svelte";
  import Button from "#lib/components/Button/Button.svelte";

  let name = $state("");
</script>

<Form label="Contact form" onsubmit={handleSubmit}>
  <Field label="Full name" required>
    <TextInput id="name" label="Full name" bind:value={name} required />
  </Field>
  <Button type="submit">Save</Button>
</Form>

Field tar den synlige label som sin egen egenskap i stedet for en nøstet etikettkomponent — send den inn én gang, på Fieldog TextInputpå label gir det tilgjengelige navnet. TextInput's value er en $bindable rune-egenskap, så bind:value gir deg toveis binding med en gang.

Verifisert 2026-08-29: akkurat denne snutten ble kompilert via svelte/server og sjekket for én, korrekt lenket <label for> — et tidligere utkast nøstet en separat Label inni Field, som gjengav to etiketter (én tom) fordi Field allerede gjengir sin egen fra label egenskap. Den sammensatte kontaktskjema-ruten er det samme mønsteret, prøvd med ekte e2e- og axe-tester.

Sjekk arbeidet ditt: kjør appen, og skjemaet ser enkelt ut — akkurat som tiltenkt: stilingen ligger fortsatt foran. Trykk Tab: fokus beveger seg gjennom hver kontroll, etiketten kunngjøres og innsending fungerer. Oppførselen er ferdig; utseendet er ditt og er neste.

Steg 4 — Stil det

Alt ovenfor gjengis som ren struktur, klar for stilene dine. Stil klassekrokene — .button, .text-input, .label, .field — i det globale stilarket ditt, eller lenk et ferdig tema i app.html: 

<link rel="stylesheet" href="/themes/dark.css" />

Justeringer per forekomst går gjennom class -egenskapen, som føyes til basekroken: <Button class="wide"> gjengir class="button wide".

Steg 5 — Se alt fungere

SvelteKit-eksempelappen er den samme katalogen fullt stilet, med levende demoer, Playwright e2e-tester og en axe-core-tilgjengelighetsbaseline: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-sveltekit-examples
pnpm install && pnpm run dev

Neste steg

  • Tema — bytte ved kjøretid med Svelte theme-picker-hjelperen.
  • Preferansehjelpere — språk og tekststørrelse.
  • Komponentkatalog — egenskaper, ARIA og tastatur per komponent.

Spørsmål underveis? hjelpesiden er full av svar — og hvis et steg kan bli tydeligere, fortell oss så forbedrer vi gjerne veiledningen.
