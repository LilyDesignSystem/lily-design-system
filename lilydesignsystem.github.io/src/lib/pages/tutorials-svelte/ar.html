دليل Svelte

مكتبة Svelte من Lily هي التنفيذ المرجعي: runes في Svelte 5، وخصائص مُنمَّطة، ونشر الخصائص المتبقية، وربط ثنائي الاتجاه مع bind:value.

ما الذي ستبنيه

نموذج اتصال صغير — حقل بتسمية، زر إرسال، ربط ثنائي الاتجاه، سلوك حقيقي للوحة المفاتيح وقارئ الشاشة — عاريًا أولًا ثم منسَّقًا، في نحو 10 دقائق.

قبل أن تبدأ

تحتاج إلى git وNode 22 أو أحدث وpnpm 10 أو أحدث. يصلح أي مشروع Svelte 5 — يكفي تطبيق جديد npx sv create تمامًا.

الخطوة 1 — احصل على الشيفرة

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-headless
pnpm install
pnpm test        # vitest — thousands of component cases
pnpm run storybook   # browse all 571 components

توجد المكوّنات في src/lib/components/{Name}/، مجلد لكل مكوّن فيه ملف .svelte واختباراته وstories ووثائقه جنبًا إلى جنب. انسخ المجلدات التي تحتاجها إلى تطبيقك، أو اعتمد على المستودع واستورد مباشرة.

الخطوة 2 — مكوّنك الأول

<script>

  function save() { console.log("saved"); }

<Button onclick={save}>Save</Button>

تحقق من عملك: شغّل التطبيق فيبدو النموذج بسيطًا — تمامًا كما هو مقصود: التنسيق لا يزال قادمًا. اضغط Tab: ينتقل التركيز عبر كل عنصر تحكم، وتُعلن التسمية، ويعمل الإرسال. السلوك مكتمل؛ والمظهر لك وهو الخطوة التالية.

الخطوة 4 — نسِّقه

كل ما سبق يُعرض كبنية خالصة، جاهزة لأنماطك. نسِّق خطّافات الأصناف — .button, .text-input, .label, .field — في ورقة الأنماط العامة لديك، أو اربط سمة جاهزة في app.html: 

<link rel="stylesheet" href="/themes/dark.css" />

تمرّ التعديلات لكل نسخة عبر الخاصية class التي تُلحق بالخطّاف الأساسي: <Button class="wide"> يعرض class="button wide".

الخطوة 5 — شاهد كل شيء يعمل

تطبيق المثال SvelteKit هو الفهرس نفسه منسَّقًا بالكامل، مع عروض حيّة واختبارات Playwright e2e وخط أساس إمكانية الوصول axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-sveltekit-examples
pnpm install && pnpm run dev
