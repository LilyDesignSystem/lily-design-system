Svelte-Tutorial

Lilys Svelte-Bibliothek ist die kanonische Implementierung: Svelte-5-Runes, typisierte Props, Rest-Prop-Spread und Zwei-Wege-Bindung mit bind:value.

Was du baust

Ein kleines Kontaktformular — beschriftetes Eingabefeld, Absenden-Schaltfläche, Zwei-Wege-Bindung, echtes Tastatur- und Screenreader-Verhalten — zuerst nackt, dann gestaltet, in etwa 10 Minuten.

Bevor du anfängst

Du brauchst git, Node 22 oder neuer und pnpm 10 oder neuer. Jedes Svelte-5-Projekt funktioniert — eine frische npx sv create -App reicht.

Schritt 1 — Den Code holen

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-headless
pnpm install
pnpm test        # vitest — thousands of component cases
pnpm run storybook   # browse all 571 components

Die Komponenten liegen in src/lib/components/{Name}/, ein Verzeichnis pro Komponente mit der .svelte -Datei, ihren Tests, ihren Stories und ihrer Dokumentation nebeneinander. Kopiere die benötigten Verzeichnisse in deine App, oder hänge dich ans Repo und importiere direkt.

Schritt 2 — Deine erste Komponente

<script>
  import Button from "#lib/components/Button/Button.svelte";

  function save() { console.log("saved"); }
</script>

<Button onclick={save}>Save</Button>

Schritt 4 — Gestalten

Alles oben wird als reine Struktur gerendert, bereit für deine Styles. Gestalte die Klassen-Hooks — .button, .text-input, .label, .field — in deinem globalen Stylesheet, oder binde ein fertiges Theme ein in app.html: 

<link rel="stylesheet" href="/themes/dark.css" />

Anpassungen pro Instanz laufen über die class -Prop, die an den Basis-Hook angehängt wird: <Button class="wide"> rendert class="button wide".
