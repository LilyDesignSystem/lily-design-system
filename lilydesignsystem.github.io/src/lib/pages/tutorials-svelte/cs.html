Návod pro Svelte

Knihovna Svelte od Lily je kanonická implementace: runy Svelte 5, typované props, rozprostírání zbývajících props a obousměrná vazba s bind:value.

Co vytvoříte

Malý kontaktní formulář — pole se štítkem, tlačítko odeslat, obousměrná vazba, skutečné chování klávesnice a čtečky obrazovky — nejprve holý, potom ostylovaný, zhruba za 10 minut.

Než začnete

Potřebujete git, Node 22 nebo novější a pnpm 10 nebo novější. Hodí se jakýkoli projekt Svelte 5 — stačí nová npx sv create aplikace.

Krok 1 — Získejte kód

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-headless
pnpm install
pnpm test        # vitest — thousands of component cases
pnpm run storybook   # browse all 571 components

Komponenty jsou v src/lib/components/{Name}/, jeden adresář na komponentu se souborem .svelte , jeho testy, story a dokumentací vedle sebe. Zkopírujte potřebné adresáře do své aplikace, nebo se na repozitáři závislejte a importujte přímo.

Krok 2 — Vaše první komponenta

<script>
  import Button from "#lib/components/Button/Button.svelte";

  function save() { console.log("saved"); }
</script>

<Button onclick={save}>Save</Button>

Vykresluje <button class="button" type="button">. Props jsou typované: type, disabled, pressed (vykresluje aria-pressed (vykresluje label ( aria-label pro přepínací tlačítka),

Krok 4 — Ostylujte ho

Vše výše se vykresluje jako čistá struktura, připravená na vaše styly. Ostylujte třídní háčky — .button, .text-input, .label, .field — v globálním stylopisu, nebo připojte hotové téma v app.html: 

<link rel="stylesheet" href="/themes/dark.css" />

Úpravy pro jednotlivou instanci procházejí přes class prop, který se připojí k základnímu háčku: <Button class="wide"> vykresluje class="button wide".

Krok 5 — Podívejte se, jak to celé funguje

Ukázková aplikace SvelteKit je stejný katalog plně ostylovaný, s živými ukázkami, testy Playwright e2e a základní linií přístupnosti axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-sveltekit-examples
pnpm install && pnpm run dev
