Svelte-opas

Lilyn Svelte-kirjasto on kanoninen toteutus: Svelte 5 -runet, tyypitetyt propit, jäljellä olevien proppien levitys ja kaksisuuntainen sidonta bind:value.

Mitä rakennat

Pieni yhteydenottolomake — nimiöity kenttä, lähetyspainike, kaksisuuntainen sidonta, aito näppäimistö- ja ruudunlukijakäyttäytyminen — ensin paljaana, sitten tyylitellen, noin 10 minuutissa.

Ennen kuin aloitat

Tarvitset gitin, Node 22:n tai uudemman ja pnpm 10:n tai uudemman. Mikä tahansa Svelte 5 -projekti kelpaa — aivan uusi npx sv create -sovellus riittää.

Vaihe 1 — Hae koodi

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-headless
pnpm install
pnpm test        # vitest — thousands of component cases
pnpm run storybook   # browse all 581 components

Komponentit sijaitsevat hakemistossa src/lib/components/{Name}/, yksi hakemisto komponenttia kohden, jossa .svelte -tiedosto, sen testit, storyt ja dokumentaatio vierekkäin. Kopioi tarvitsemasi hakemistot sovellukseesi tai riipu reposta ja tuo suoraan.

Vaihe 4 — Tyylittele se

Kaikki yllä renderöityy puhtaana rakenteena, valmiina tyyleillesi. Tyylittele luokkakoukut — .button, .text-input, .label, .field — globaalissa tyylitiedostossasi, tai linkitä valmis teema tiedostossa app.html: 

<link rel="stylesheet" href="/themes/dark.css" />

Instanssikohtaiset säädöt kulkevat class -propin kautta, joka lisätään peruskoukkuun: <Button class="wide"> renderöi class="button wide".

Vaihe 5 — Katso kaiken toimivan

SvelteKit-esimerkkisovellus on sama luettelo täysin tyyliteltynä, live-demoineen, Playwright e2e -testeineen ja axe-core-saavutettavuuslähtötasoineen: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-sveltekit-examples
pnpm install && pnpm run dev

Seuraavat askeleet

  • Teemat — vaihto ajon aikana Sveltellä theme-picker-apuvälineellä.
  • Asetusapuvälineet — kieli ja tekstikoko.
  • Komponenttiluettelo — ominaisuudet, ARIA ja näppäimistö komponenteittain.
