Svelte-vejledning

Lilys Svelte-bibliotek er den kanoniske implementering: Svelte 5-runes, typede props, spredning af resterende props og tovejsbinding med bind:value.

Det her bygger du

En lille kontaktformular — felt med etiket, send-knap, tovejsbinding, ægte tastatur- og skærmlæseradfærd — først nøgen, derefter formgivet, på omkring 10 minutter.

Før du går i gang

Du skal bruge git, Node 22 eller nyere og pnpm 10 eller nyere. Ethvert Svelte 5-projekt virker — en splinterny npx sv create -app er nok.

Trin 1 — Hent koden

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-headless
pnpm install
pnpm test        # vitest — thousands of component cases
pnpm run storybook   # browse all 581 components

Komponenterne ligger i src/lib/components/{Name}/, én mappe pr. komponent med .svelte -filen, dens tests, dens stories og dens dokumentation side om side. Kopiér de mapper, du har brug for, ind i din app, eller afhæng af repoet og importér direkte.

Trin 4 — Giv den stil

Alt ovenfor gengives som ren struktur, klar til dine stilarter. Formgiv klassekrogene — .button, .text-input, .label, .field — i dit globale typografiark, eller link et færdigt tema i app.html: 

<link rel="stylesheet" href="/themes/dark.css" />

Justeringer pr. instans går via class -propen, som tilføjes til basekrogen: <Button class="wide"> gengiver class="button wide".

Trin 5 — Se det hele virke

SvelteKit eksempelapp er det samme katalog fuldt formgivet, med levende demoer, Playwright e2e-tests og en axe-core-tilgængelighedsbaseline: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-sveltekit-examples
pnpm install && pnpm run dev

Næste skridt

  • Temaer — skift under kørsel med Svelte-hjælperen theme-picker.
  • Indstillingshjælpere — sprog og tekststørrelse.
  • Komponentkatalog — egenskaber, ARIA og tastatur pr. komponent.
