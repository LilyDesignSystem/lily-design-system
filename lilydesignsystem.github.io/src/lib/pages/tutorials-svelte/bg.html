Ръководство за Svelte

Svelte библиотеката на Lily е каноничната имплементация: runes на Svelte 5, типизирани props, разпръскване на останалите props и двупосочно свързване с bind:value.

Какво ще изградите

Малка форма за контакт — поле с етикет, бутон за изпращане, двупосочно свързване, истинско поведение на клавиатурата и екранния четец — първо гола, после стилизирана, за около 10 минути.

Преди да започнете

Нужни са ви git, Node 22 или по-нов и pnpm 10 или по-нов. Подходящ е всеки проект на Svelte 5 — съвсем ново npx sv create приложение е достатъчно.

Стъпка 1 — Вземете кода

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-headless
pnpm install
pnpm test        # vitest — thousands of component cases
pnpm run storybook   # browse all 581 components

Компонентите се намират в src/lib/components/{Name}/, по една директория на компонент с файла .svelte , неговите тестове, story-та и документация един до друг. Копирайте нужните директории в приложението си или зависете от хранилището и импортирайте директно.

Стъпка 2 — Първият ви компонент

<script>
  import Button from "#lib/components/Button/Button.svelte";

  function save() { console.log("saved"); }
</script>

<Button onclick={save}>Save</Button>

Стъпка 4 — Стилизирайте го

Всичко по-горе се рендира като чиста структура, готова за вашите стилове. Стилизирайте класовите куки — .button, .text-input, .label, .field — във вашата глобална таблица със стилове или свържете готова тема в app.html: 

<link rel="stylesheet" href="/themes/dark.css" />

Настройките за отделен екземпляр минават през class prop, който се добавя към базовата кука: <Button class="wide"> рендира class="button wide".

Стъпка 5 — Вижте всичко в действие

Примерното приложение SvelteKit е същият каталог напълно стилизиран, с демонстрации на живо, Playwright e2e тестове и базова линия за достъпност axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-sveltekit-examples
pnpm install && pnpm run dev
