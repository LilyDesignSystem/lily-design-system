Tutorial de Svelte

A biblioteca Svelte da Lily é a implementação canónica: runes do Svelte 5, props tipadas, espalhamento das props restantes e ligação bidirecional com bind:value.

O que vai construir

Um pequeno formulário de contacto — campo com etiqueta, botão de envio, ligação bidirecional, comportamento real de teclado e leitor de ecrã — primeiro simples, depois estilizado, em cerca de 10 minutos.

Antes de começar

Precisa de git, Node 22 ou posterior e pnpm 10 ou posterior. Qualquer projeto Svelte 5 serve — uma aplicação novinha npx sv create chega.

Passo 1 — Obter o código

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-headless
pnpm install
pnpm test        # vitest — thousands of component cases
pnpm run storybook   # browse all 581 components

Os componentes vivem em src/lib/components/{Name}/, um diretório por componente com o ficheiro .svelte , os seus testes, as suas stories e a sua documentação lado a lado. Copie os diretórios de que precisa para a sua aplicação, ou dependa do repositório e importe diretamente.

Passo 4 — Estilize-o

Tudo o que está acima é renderizado como estrutura pura, pronta para os seus estilos. Estilize os ganchos de classe — .button, .text-input, .label, .field — na sua folha de estilos global, ou ligue um tema pronto em app.html: 

<link rel="stylesheet" href="/themes/dark.css" />

Os ajustes por instância passam pela class prop, que é acrescentada ao gancho base: <Button class="wide"> renderiza class="button wide".

Passo 5 — Veja tudo a funcionar

A aplicação de exemplo SvelteKit é o mesmo catálogo totalmente estilizado, com demonstrações em direto, testes Playwright e2e e uma linha de base de acessibilidade axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-sveltekit-examples
pnpm install && pnpm run dev

Passos seguintes

  • Temas — alternância em tempo de execução com o auxiliar theme-picker do Svelte.
  • Auxiliares de preferências — idioma e tamanho do texto.
  • Catálogo de componentes — propriedades, ARIA e teclado por componente.
