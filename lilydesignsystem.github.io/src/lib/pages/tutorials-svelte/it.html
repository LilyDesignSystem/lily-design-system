Tutorial Svelte

La libreria Svelte di Lily è l'implementazione canonica: rune di Svelte 5, prop tipizzate, propagazione delle prop restanti e binding bidirezionale con bind:value.

Cosa costruirai

Un piccolo modulo di contatto — campo con etichetta, pulsante di invio, binding bidirezionale, comportamento reale di tastiera e screen reader — prima spoglio, poi stilizzato, in circa 10 minuti.

Prima di iniziare

Servono git, Node 22 o successivo e pnpm 10 o successivo. Va bene qualsiasi progetto Svelte 5 — una nuova npx sv create app va benissimo.

Passo 1 — Ottieni il codice

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-headless
pnpm install
pnpm test        # vitest — thousands of component cases
pnpm run storybook   # browse all 581 components

I componenti si trovano in src/lib/components/{Name}/, una directory per componente con il file .svelte i suoi test, le sue story e la sua documentazione affiancati. Copia le directory che ti servono nella tua app, oppure dipendi dal repository e importa direttamente.

Passo 2 — Il tuo primo componente

<script>
  import Button from "#lib/components/Button/Button.svelte";

  function save() { console.log("saved"); }
</script>

<Button onclick={save}>Save</Button>

Controlla il lavoro: avvia l'app e il modulo appare spoglio — esattamente come previsto: lo stile deve ancora venire. Premi Tab: il focus si sposta su ogni controllo, l'etichetta viene annunciata e l'invio funziona. Il comportamento è fatto; l'aspetto è tuo, ed è il prossimo passo.

Passo 4 — Dagli uno stile

Tutto quanto sopra viene reso come pura struttura, pronta per i tuoi stili. Stilizza gli hook di classe — .button, .text-input, .label, .field — nel tuo foglio di stile globale, oppure collega un tema pronto in app.html: 

<link rel="stylesheet" href="/themes/dark.css" />

Le modifiche per singola istanza passano per la class prop, che si aggiunge all'hook di base: <Button class="wide"> rende class="button wide".

Passo 5 — Guarda tutto in funzione

App di esempio SvelteKit è lo stesso catalogo completamente stilizzato, con demo dal vivo, test e2e Playwright e una baseline di accessibilità axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-sveltekit-examples
pnpm install && pnpm run dev

Prossimi passi

  • Temi — cambio a runtime con l'helper theme-picker per Svelte.
  • Helper delle preferenze — lingua e dimensione del testo.
  • Catalogo dei componenti — proprietà, ARIA e tastiera per ogni componente.
