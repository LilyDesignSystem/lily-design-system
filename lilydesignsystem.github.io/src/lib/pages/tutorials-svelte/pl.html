Samouczek Svelte

Biblioteka Svelte Lily jest implementacją kanoniczną: runy Svelte 5, typowane propsy, rozsmarowywanie pozostałych propsów i wiązanie dwukierunkowe z bind:value.

Co zbudujesz

Mały formularz kontaktowy — pole z etykietą, przycisk wysyłania, wiązanie dwukierunkowe, prawdziwe działanie klawiatury i czytnika ekranu — najpierw surowy, potem ostylowany, w około 10 minut.

Zanim zaczniesz

Potrzebujesz gita, Node 22 lub nowszego i pnpm 10 lub nowszego. Dowolny projekt Svelte 5 się nadaje — świeża npx sv create aplikacja wystarczy.

Krok 1 — Pobierz kod

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-headless
pnpm install
pnpm test        # vitest — thousands of component cases
pnpm run storybook   # browse all 571 components

Komponenty znajdują się w src/lib/components/{Name}/, po jednym katalogu na komponent z plikiem .svelte , jego testami, story i dokumentacją obok siebie. Skopiuj potrzebne katalogi do aplikacji albo zależ od repozytorium i importuj bezpośrednio.

Krok 2 — Twój pierwszy komponent

<script>
  import Button from "#lib/components/Button/Button.svelte";

  function save() { console.log("saved"); }
</script>

<Button onclick={save}>Save</Button>

Krok 4 — Ostyluj go

Wszystko powyżej renderuje się jako czysta struktura, gotowa na twoje style. Ostyluj haczyki klas — .button, .text-input, .label, .field — w globalnym arkuszu stylów lub podlinkuj gotowy motyw w app.html: 

<link rel="stylesheet" href="/themes/dark.css" />

Dostosowania dla pojedynczej instancji przechodzą przez class props, który dopisuje się do haczyka bazowego: <Button class="wide"> renderuje class="button wide".

Krok 5 — Zobacz, jak to wszystko działa

Aplikacja przykładowa SvelteKit to ten sam katalog w pełni ostylowany, z demami na żywo, testami Playwright e2e i punktem odniesienia dostępności axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-sveltekit-examples
pnpm install && pnpm run dev

Następne kroki

  • Motywy — przełączanie w czasie działania pomocnikiem theme-picker dla Svelte.
  • Pomocniki preferencji — język i rozmiar tekstu.
  • Katalog komponentów — właściwości, ARIA i klawiatura dla każdego komponentu.
