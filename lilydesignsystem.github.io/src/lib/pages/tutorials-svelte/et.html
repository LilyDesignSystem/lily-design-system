Svelte'i õpetus

Lily Svelte'i teek on kanooniline teostus: Svelte 5 runed, tüübitud propid, ülejäänud proppide laiali jagamine ja kahesuunaline sidumine bind:value.

Mida sa ehitad

Väike kontaktivorm — sildiga väli, saatmisnupp, kahesuunaline sidumine, tõeline klaviatuuri- ja ekraanilugeja käitumine — esmalt paljas, seejärel kujundatud, umbes 10 minutiga.

Enne alustamist

Vaja on gitti, Node 22 või uuemat ja pnpm 10 või uuemat. Sobib iga Svelte 5 projekt — täiesti uus npx sv create rakendus on piisav.

Samm 1 — Hangi kood

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-headless
pnpm install
pnpm test        # vitest — thousands of component cases
pnpm run storybook   # browse all 571 components

Komponendid asuvad kaustas src/lib/components/{Name}/, üks kaust komponendi kohta koos .svelte failiga, selle testide, storyde ja dokumentatsiooniga kõrvuti. Kopeeri vajalikud kaustad oma rakendusse või sõltu repost ja impordi otse.

Samm 4 — Kujunda see

Kõik ülaltoodu renderdatakse puhta struktuurina, valmis sinu stiilidele. Kujunda klassikonksud — .button, .text-input, .label, .field — oma globaalses laadilehes või lingi valmis teema failis app.html: 

<link rel="stylesheet" href="/themes/dark.css" />

Instantsipõhised kohandused käivad läbi class propi, mis lisatakse baaskonksule: <Button class="wide"> renderdab class="button wide".

Samm 5 — Vaata kõike töötamas

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-sveltekit-examples
pnpm install && pnpm run dev
