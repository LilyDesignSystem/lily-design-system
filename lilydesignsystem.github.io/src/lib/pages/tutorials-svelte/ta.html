Svelte பயிற்சி

Lily இன் Svelte நூலகம் நியம செயலாக்கம்: Svelte 5 runes, வகைப்படுத்தப்பட்ட props, மீதமுள்ள props பரவல், மற்றும் இதனுடன் இருவழி பிணைப்பு bind:value.

நீங்கள் என்ன உருவாக்குவீர்கள்

ஒரு சிறிய தொடர்புப் படிவம் — லேபிளுடன் கூடிய புலம், சமர்ப்பிக்கும் பொத்தான், இருவழி பிணைப்பு, உண்மையான விசைப்பலகை மற்றும் திரை வாசிப்பான் நடத்தை — முதலில் வெறுமையாக, பிறகு பாணியுடன், சுமார் 10 நிமிடங்களில்.

தொடங்குவதற்கு முன்

உங்களுக்கு git, Node 22 அல்லது புதியது, மற்றும் pnpm 10 அல்லது புதியது தேவை. எந்த Svelte 5 திட்டமும் வேலை செய்யும் — புத்தம் புதிய npx sv create பயன்பாடு போதும்.

படி 1 — குறியீட்டைப் பெறுங்கள்

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-headless
pnpm install
pnpm test        # vitest — thousands of component cases
pnpm run storybook   # browse all 571 components

கூறுகள் இங்கே உள்ளன: src/lib/components/{Name}/, ஒவ்வொரு கூறுக்கும் ஒரு அடைவு, அதில் .svelte கோப்பு, அதன் சோதனைகள், story கள் மற்றும் ஆவணங்கள் அருகருகே. தேவையான அடைவுகளை உங்கள் பயன்பாட்டில் நகலெடுங்கள், அல்லது களஞ்சியத்தைச் சார்ந்து நேரடியாக இறக்குமதி செய்யுங்கள்.

படி 2 — உங்கள் முதல் கூறு

<script>
  import Button from "#lib/components/Button/Button.svelte";

  function save() { console.log("saved"); }
</script>

<Button onclick={save}>Save</Button>

இது வழங்குகிறது <button class="button" type="button">. Props வகைப்படுத்தப்பட்டுள்ளன: type, disabled, pressed (வழங்குகிறது aria-pressed (வழங்குகிறது label (ஒரு aria-label மாற்றுப் பொத்தான்களுக்கு),

படி 3 — ஒரு சிறிய படிவத்தை உருவாக்குங்கள்

<script>
  import Form from "#lib/components/Form/Form.svelte";
  import Field from "#lib/components/Field/Field.svelte";
  import TextInput from "#lib/components/TextInput/TextInput.svelte";
  import Button from "#lib/components/Button/Button.svelte";

  let name = $state("");
</script>

<Form label="Contact form" onsubmit={handleSubmit}>
  <Field label="Full name" required>
    <TextInput id="name" label="Full name" bind:value={name} required />
  </Field>
  <Button type="submit">Save</Button>
</Form>

Field தெரியும் label அதன் சொந்த prop ஆக, உள்ளமைந்த லேபிள் கூறாக அல்ல — அதை ஒருமுறை கொடுங்கள், மீது Fieldமற்றும் TextInputஇன் label அணுகத்தக்க பெயரை வழங்குகிறது. TextInput's value மேலெழுத), மற்றும் கூடுதல் பண்பு எதுவும் வேரில் பரவுகிறது. $bindable ஒரு bind:value rune prop, எனவே

2026-08-29 அன்று சரிபார்க்கப்பட்டது: உங்களுக்கு உடனே இருவழி பிணைப்பைத் தருகிறது. svelte/server இந்தத் துணுக்கு இதன் வழியாகத் தொகுக்கப்பட்டது <label for> மற்றும் ஒரே ஒரு, சரியாக இணைக்கப்பட்ட லேபிளுக்காகச் சோதிக்கப்பட்டது Label உள்ளே Field— முந்தைய வரைவு தனி இரண்டு லேபிள்கள் (ஒன்று காலி) வழங்கப்பட்டன, ஏனெனில் Field ஏற்கனவே தன் சொந்தத்தை label உள்ளே வைத்தது, அது வழங்கியது இணைந்த தொடர்புப் படிவ வழி அதே முறைதான், உண்மையான e2e மற்றும் axe சோதனைகளால் சோதிக்கப்பட்டது.

உங்கள் வேலையைச் சரிபார்க்கவும்: பயன்பாட்டை இயக்குங்கள், படிவம் வெறுமையாகத் தெரிகிறது — சரியாக நோக்கப்பட்டபடி: பாணியிடல் இன்னும் வரவுள்ளது. அழுத்துங்கள் Tab: குவியம் ஒவ்வொரு கட்டுப்பாட்டின் வழியாகவும் செல்கிறது, லேபிள் அறிவிக்கப்படுகிறது, சமர்ப்பிப்பு வேலை செய்கிறது. நடத்தை முடிந்தது; தோற்றம் உங்களுடையது, அடுத்த படி அதுவே.

படி 4 — பாணியிடுங்கள்

மேலுள்ள அனைத்தும் தூய கட்டமைப்பாக ரெண்டர் ஆகின்றன, உங்கள் பாணிகளுக்குத் தயாராக. வகுப்புக் கொக்கிகளுக்குப் பாணியிடுங்கள் — .button, .text-input, .label, .field — உங்கள் உலகளாவிய நடைத்தாளில், அல்லது தயார் தீமை இங்கே இணைக்கவும் app.html: 

<link rel="stylesheet" href="/themes/dark.css" />

ஒவ்வொரு நிகழ்வுக்கான மாற்றங்களும் இதன் வழியாகச் செல்கின்றன class prop, இது அடிப்படைக் கொக்கியில் சேர்க்கப்படுகிறது: <Button class="wide"> வழங்குகிறது class="button wide".

படி 5 — எல்லாம் வேலை செய்வதைப் பாருங்கள்

SvelteKit எடுத்துக்காட்டுப் பயன்பாடு அதே பட்டியல் முழுமையாகப் பாணியிடப்பட்டு, நேரடி செயல்விளக்கங்கள், Playwright e2e சோதனைகள் மற்றும் axe-core அணுகல் அடிப்படையுடன்: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-sveltekit-examples
pnpm install && pnpm run dev

அடுத்த படிகள்

  • தீம்கள் — Svelte theme-picker உதவியாளருடன் இயங்கும் போதே மாற்றுதல்.
  • விருப்ப உதவியாளர்கள் — மொழி மற்றும் உரை அளவு.
  • கூறுப் பட்டியல் — ஒவ்வொரு கூறுக்கும் பண்புகள், ARIA மற்றும் விசைப்பலகை.

வழியில் கேள்விகளா? உதவிப் பக்கம் பதில்களால் நிறைந்தது — ஒரு படி இன்னும் தெளிவாக இருக்க முடிந்தால், எங்களிடம் சொல்லுங்கள் நாங்கள் மகிழ்ச்சியுடன் பயிற்சியை மேம்படுத்துவோம்.
