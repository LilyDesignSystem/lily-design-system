Руководство по Svelte

Библиотека Svelte от Lily — эталонная реализация: руны Svelte 5, типизированные props, разворачивание остальных props и двусторонняя привязка с bind:value.

Что вы построите

Небольшая контактная форма — поле с меткой, кнопка отправки, двусторонняя привязка, реальное поведение клавиатуры и программы чтения с экрана — сначала голая, затем оформленная, примерно за 10 минут.

Прежде чем начать

Вам понадобятся git, Node 22 или новее и pnpm 10 или новее. Подойдёт любой проект Svelte 5 — достаточно совершенно нового npx sv create приложения.

Шаг 1 — Получите код

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-headless
pnpm install
pnpm test        # vitest — thousands of component cases
pnpm run storybook   # browse all 581 components

Компоненты находятся в src/lib/components/{Name}/, по одному каталогу на компонент с файлом .svelte , его тестами, историями и документацией рядом. Скопируйте нужные каталоги в своё приложение или зависьте от репозитория и импортируйте напрямую.

Шаг 2 — Ваш первый компонент

Шаг 4 — Оформите её

Всё вышеперечисленное отображается как чистая структура, готовая для ваших стилей. Оформите крючки классов — .button, .text-input, .label, .field — в вашей глобальной таблице стилей, или подключите готовую тему в app.html: 

<link rel="stylesheet" href="/themes/dark.css" />

Настройки для отдельного экземпляра проходят через class prop, который добавляется к базовому крючку: <Button class="wide"> отображает class="button wide".
