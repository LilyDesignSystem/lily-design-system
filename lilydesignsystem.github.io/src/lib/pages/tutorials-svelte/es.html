Tutorial de Svelte

La biblioteca Svelte de Lily es la implementación canónica: runas de Svelte 5, props tipadas, esparcido de props restantes y enlace bidireccional con bind:value.

Qué vas a construir

Un pequeño formulario de contacto: campo con etiqueta, botón de envío, enlace bidireccional, comportamiento real de teclado y lector de pantalla; primero desnudo, luego con estilo, en unos 10 minutos.

Antes de empezar

Necesitas git, Node 22 o posterior y pnpm 10 o posterior. Sirve cualquier proyecto de Svelte 5: basta una aplicación nueva npx sv create .

Paso 1: Obtén el código

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-headless
pnpm install
pnpm test        # vitest — thousands of component cases
pnpm run storybook   # browse all 571 components

Los componentes viven en src/lib/components/{Name}/, un directorio por componente con el archivo .svelte , sus pruebas, sus stories y su documentación lado a lado. Copia los directorios que necesites en tu aplicación, o depende del repositorio e importa directamente.

Paso 2: Tu primer componente

<script>
  import Button from "#lib/components/Button/Button.svelte";

  function save() { console.log("saved"); }
</script>

<Button onclick={save}>Save</Button>

Paso 4: Dale estilo

Todo lo anterior se renderiza como estructura pura, lista para tus estilos. Da estilo a los ganchos de clase: .button, .text-input, .label, .field , en tu hoja de estilos global, o enlaza un tema ya hecho en app.html: 

<link rel="stylesheet" href="/themes/dark.css" />

Los ajustes por instancia pasan por la class prop, que se añade al gancho base: <Button class="wide"> renderiza class="button wide".

Paso 5: Míralo todo funcionando

La aplicación de ejemplo SvelteKit es el mismo catálogo con estilo completo, con demostraciones en vivo, pruebas Playwright e2e y una línea base de accesibilidad de axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-sveltekit-examples
pnpm install && pnpm run dev
