Svelte-handledning

Lilys Svelte-bibliotek är den kanoniska implementationen: Svelte 5-runes, typade props, spridning av övriga props och tvåvägsbindning med bind:value.

Det här bygger du

Ett litet kontaktformulär — fält med etikett, skicka-knapp, tvåvägsbindning, verkligt tangentbords- och skärmläsarbeteende — först naket, sedan formgivet, på ungefär 10 minuter.

Innan du börjar

Du behöver git, Node 22 eller senare och pnpm 10 eller senare. Alla Svelte 5-projekt fungerar — en alldeles ny npx sv create -app räcker.

Steg 1 — Hämta koden

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-headless
pnpm install
pnpm test        # vitest — thousands of component cases
pnpm run storybook   # browse all 571 components

Komponenterna finns i src/lib/components/{Name}/, en katalog per komponent med .svelte -filen, dess tester, dess stories och dess dokumentation sida vid sida. Kopiera de kataloger du behöver till din app, eller beror på förvaret och importera direkt.

Steg 4 — Formge det

Allt ovan renderas som ren struktur, redo för dina stilar. Formge klasskrokarna — .button, .text-input, .label, .field — i din globala stilmall, eller länka ett färdigt tema i app.html: 

<link rel="stylesheet" href="/themes/dark.css" />

Justeringar per instans går via class -propen, som läggs till på baskroken: <Button class="wide"> renderar class="button wide".

Steg 5 — Se allt fungera

Exempelappen SvelteKit är samma katalog fullt formgiven, med levande demos, Playwright e2e-tester och en axe-core-tillgänglighetsbaslinje: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-sveltekit-examples
pnpm install && pnpm run dev

Nästa steg

  • Teman — byte under körning med Svelte-hjälparen theme-picker.
  • Inställningshjälpare — språk och textstorlek.
  • Komponentkatalog — egenskaper, ARIA och tangentbord per komponent.

Frågor på vägen? Hjälpsidan är full av svar — och om ett steg kan bli tydligare, berätta för oss så förbättrar vi gärna handledningen.
