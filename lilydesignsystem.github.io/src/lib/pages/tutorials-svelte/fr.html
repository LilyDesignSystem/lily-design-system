Tutoriel Svelte

La bibliothèque Svelte de Lily est l'implémentation canonique : runes Svelte 5, props typées, répartition des props restantes et liaison bidirectionnelle avec bind:value.

Ce que vous allez construire

Un petit formulaire de contact — champ avec étiquette, bouton d'envoi, liaison bidirectionnelle, vrai comportement clavier et lecteur d'écran — d'abord nu, puis stylé, en 10 minutes environ.

Avant de commencer

Il vous faut git, Node 22 ou plus récent et pnpm 10 ou plus récent. Tout projet Svelte 5 convient — une toute nouvelle npx sv create application suffit.

Étape 1 — Récupérer le code

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-headless
pnpm install
pnpm test        # vitest — thousands of component cases
pnpm run storybook   # browse all 581 components

Les composants se trouvent dans src/lib/components/{Name}/, un répertoire par composant avec le fichier .svelte , ses tests, ses stories et sa documentation côte à côte. Copiez les répertoires dont vous avez besoin dans votre application, ou dépendez du dépôt et importez directement.

Étape 4 — Le styler

Tout ce qui précède est rendu comme de la structure pure, prête pour vos styles. Stylez les crochets de classe — .button, .text-input, .label, .field — dans votre feuille de style globale, ou liez un thème prêt à l'emploi dans app.html: 

<link rel="stylesheet" href="/themes/dark.css" />

Les ajustements par instance passent par la class prop, qui s'ajoute au crochet de base : <Button class="wide"> rend class="button wide".

Étape 5 — Voir le tout fonctionner

L'application d'exemple SvelteKit est le même catalogue entièrement stylé, avec des démos en direct, des tests Playwright e2e et une référence d'accessibilité axe-core : 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-sveltekit-examples
pnpm install && pnpm run dev
