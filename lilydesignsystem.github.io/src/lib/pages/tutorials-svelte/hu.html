Svelte oktatóanyag

A Lily Svelte-könyvtára a kanonikus megvalósítás: Svelte 5 runák, típusos propok, a maradék propok szórása és kétirányú kötés ezzel: bind:value.

Mit fogsz építeni

Egy kis kapcsolatfelvételi űrlap — címkézett mező, küldés gomb, kétirányú kötés, valódi billentyűzet- és képernyőolvasó-viselkedés — először csupaszon, aztán stílusosan, nagyjából 10 perc alatt.

Mielőtt elkezdenéd

Szükséged van gitre, Node 22-re vagy újabbra és pnpm 10-re vagy újabbra. Bármelyik Svelte 5 projekt megfelel — egy vadonatúj npx sv create alkalmazás is elég.

1. lépés — Szerezd meg a kódot

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-headless
pnpm install
pnpm test        # vitest — thousands of component cases
pnpm run storybook   # browse all 581 components

A komponensek itt vannak: src/lib/components/{Name}/, komponensenként egy könyvtár a .svelte fájllal, a tesztjeivel, a story-jaival és a dokumentációjával egymás mellett. Másold a szükséges könyvtárakat az alkalmazásodba, vagy függj a tárolótól, és importálj közvetlenül.

2. lépés — Az első komponensed

<script>
  import Button from "#lib/components/Button/Button.svelte";

  function save() { console.log("saved"); }
</script>

<Button onclick={save}>Save</Button>

4. lépés — Stílus hozzá

Minden fent tiszta szerkezetként renderelődik, készen a stílusaidra. Stílusozd az osztálykampókat — .button, .text-input, .label, .field — a globális stíluslapodban, vagy hivatkozz egy kész témára itt: app.html: 

<link rel="stylesheet" href="/themes/dark.css" />

A példányonkénti finomhangolások a class propon keresztül mennek, amely hozzáfűződik az alapkampóhoz: <Button class="wide"> ezt rendereli: class="button wide".

5. lépés — Nézd meg, ahogy az egész működik

A SvelteKit példaalkalmazás ugyanez a katalógus teljesen stílusosan, élő demókkal, Playwright e2e tesztekkel és axe-core akadálymentességi alapvonallal: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-sveltekit-examples
pnpm install && pnpm run dev

További lépések

  • Témák — váltás futásidőben a Svelte theme-picker segédjével.
  • Beállítási segédek — nyelv és szövegméret.
  • Komponenskatalógus — tulajdonságok, ARIA és billentyűzet komponensenként.
