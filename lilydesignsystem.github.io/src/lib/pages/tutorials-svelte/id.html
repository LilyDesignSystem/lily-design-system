Tutorial Svelte

Pustaka Svelte Lily adalah implementasi kanonis: rune Svelte 5, props bertipe, penyebaran props sisa, dan pengikatan dua arah dengan bind:value.

Apa yang akan Anda bangun

Formulir kontak kecil — kolom berlabel, tombol kirim, pengikatan dua arah, perilaku papan ketik dan pembaca layar yang nyata — pertama polos, lalu bergaya, dalam sekitar 10 menit.

Sebelum memulai

Anda memerlukan git, Node 22 atau lebih baru, dan pnpm 10 atau lebih baru. Proyek Svelte 5 mana pun bisa — aplikasi baru npx sv create sudah cukup.

Langkah 1 — Dapatkan kodenya

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-headless
pnpm install
pnpm test        # vitest — thousands of component cases
pnpm run storybook   # browse all 581 components

Komponen berada di src/lib/components/{Name}/, satu direktori per komponen dengan berkas .svelte , pengujian, story, dan dokumentasinya berdampingan. Salin direktori yang Anda perlukan ke aplikasi Anda, atau bergantung pada repositori dan impor langsung.

Langkah 4 — Beri gaya

Semua di atas dirender sebagai struktur murni, siap untuk gaya Anda. Beri gaya pada kait kelas — .button, .text-input, .label, .field — di lembar gaya global Anda, atau tautkan tema siap pakai di app.html: 

<link rel="stylesheet" href="/themes/dark.css" />

Penyesuaian per instans melalui prop class , yang ditambahkan ke kait dasar: <Button class="wide"> merender class="button wide".

Langkah 5 — Lihat semuanya bekerja

Aplikasi contoh SvelteKit adalah katalog yang sama dengan gaya lengkap, dengan demo langsung, pengujian Playwright e2e, dan garis dasar aksesibilitas axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-sveltekit-examples
pnpm install && pnpm run dev

Langkah berikutnya

  • Tema — pengalihan saat berjalan dengan pembantu theme-picker Svelte.
  • Pembantu preferensi — bahasa dan ukuran teks.
  • Katalog komponen — properti, ARIA, dan papan ketik per komponen.
