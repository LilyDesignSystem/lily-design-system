Svelte-handleiding

Lily's Svelte-bibliotheek is de canonieke implementatie: Svelte 5-runes, getypeerde props, rest-prop-spreiding en tweerichtingsbinding met bind:value.

Wat je gaat bouwen

Een klein contactformulier — invoerveld met label, verzendknop, tweerichtingsbinding, echt toetsenbord- en schermlezergedrag — eerst kaal, dan vormgegeven, in ongeveer 10 minuten.

Voordat je begint

Je hebt git, Node 22 of nieuwer en pnpm 10 of nieuwer nodig. Elk Svelte 5-project werkt — een gloednieuwe npx sv create -app is genoeg.

Stap 1 — Haal de code op

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-headless
pnpm install
pnpm test        # vitest — thousands of component cases
pnpm run storybook   # browse all 581 components

De componenten staan in src/lib/components/{Name}/, één map per component met het .svelte -bestand, zijn tests, zijn stories en zijn documentatie naast elkaar. Kopieer de mappen die je nodig hebt naar je app, of hang aan de repo en importeer rechtstreeks.

Stap 2 — Je eerste component

<script>
  import Button from "#lib/components/Button/Button.svelte";

  function save() { console.log("saved"); }
</script>

<Button onclick={save}>Save</Button>

Stap 3 — Stel een klein formulier samen

<script>
  import Form from "#lib/components/Form/Form.svelte";
  import Field from "#lib/components/Field/Field.svelte";
  import TextInput from "#lib/components/TextInput/TextInput.svelte";
  import Button from "#lib/components/Button/Button.svelte";

  let name = $state("");
</script>

<Form label="Contact form" onsubmit={handleSubmit}>
  <Field label="Full name" required>
    <TextInput id="name" label="Full name" bind:value={name} required />
  </Field>
  <Button type="submit">Save</Button>
</Form>

Controleer je werk: start de app en het formulier ziet er kaal uit — precies zoals bedoeld: de vormgeving komt nog. Druk op Tab: de focus beweegt door elk bedieningselement, het label wordt voorgelezen en verzenden werkt. Het gedrag is klaar; het uiterlijk is aan jou en komt hierna.

Stap 4 — Geef het vorm

Alles hierboven wordt als pure structuur gerenderd, klaar voor je stijlen. Geef de klassehaken vorm — .button, .text-input, .label, .field — in je globale stylesheet, of koppel een kant-en-klaar thema in app.html: 

<link rel="stylesheet" href="/themes/dark.css" />

Aanpassingen per instantie lopen via de class -prop, die aan de basishaak wordt toegevoegd: <Button class="wide"> rendert class="button wide".

Stap 5 — Zie alles werken

cd lily-design-system/lily-design-system-svelte-sveltekit-examples
pnpm install && pnpm run dev
