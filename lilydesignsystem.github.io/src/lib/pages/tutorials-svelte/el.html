Οδηγός Svelte

Η βιβλιοθήκη Svelte της Lily είναι η κανονική υλοποίηση: runes του Svelte 5, τυποποιημένα props, διασπορά των υπόλοιπων props και αμφίδρομη δέσμευση με bind:value.

Τι θα φτιάξετε

Μια μικρή φόρμα επικοινωνίας — πεδίο με ετικέτα, κουμπί υποβολής, αμφίδρομη δέσμευση, πραγματική συμπεριφορά πληκτρολογίου και προγράμματος ανάγνωσης οθόνης — πρώτα γυμνή, μετά μορφοποιημένη, σε περίπου 10 λεπτά.

Πριν ξεκινήσετε

Χρειάζεστε git, Node 22 ή νεότερο και pnpm 10 ή νεότερο. Κάθε έργο Svelte 5 κάνει — μια ολοκαίνουργια npx sv create εφαρμογή αρκεί.

Βήμα 1 — Πάρτε τον κώδικα

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-headless
pnpm install
pnpm test        # vitest — thousands of component cases
pnpm run storybook   # browse all 581 components

Τα στοιχεία βρίσκονται στο src/lib/components/{Name}/, ένας κατάλογος ανά στοιχείο με το αρχείο .svelte , τις δοκιμές, τα stories και την τεκμηρίωσή του δίπλα δίπλα. Αντιγράψτε τους καταλόγους που χρειάζεστε στην εφαρμογή σας ή εξαρτηθείτε από το αποθετήριο και εισαγάγετε απευθείας.

Ελέγξτε τη δουλειά σας: τρέξτε την εφαρμογή και η φόρμα φαίνεται γυμνή — ακριβώς όπως προβλέπεται: η μορφοποίηση έρχεται μετά. Πατήστε Tab: η εστίαση περνά από κάθε στοιχείο ελέγχου, η ετικέτα ανακοινώνεται και η υποβολή δουλεύει. Η συμπεριφορά είναι έτοιμη· η εμφάνιση είναι δική σας και είναι το επόμενο βήμα.

Βήμα 4 — Μορφοποιήστε την

Όλα τα παραπάνω αποδίδονται ως καθαρή δομή, έτοιμη για τα στυλ σας. Μορφοποιήστε τα αγκίστρια κλάσης — .button, .text-input, .label, .field — στο καθολικό φύλλο στυλ σας, ή συνδέστε ένα έτοιμο θέμα στο app.html: 

<link rel="stylesheet" href="/themes/dark.css" />

Οι προσαρμογές ανά στιγμιότυπο περνούν από το class prop, που προστίθεται στο βασικό αγκίστρι: <Button class="wide"> αποδίδει class="button wide".

Βήμα 5 — Δείτε τα πάντα να δουλεύουν

Η εφαρμογή-παράδειγμα SvelteKit είναι ο ίδιος κατάλογος πλήρως μορφοποιημένος, με ζωντανές επιδείξεις, δοκιμές Playwright e2e και βάση αναφοράς προσβασιμότητας axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-sveltekit-examples
pnpm install && pnpm run dev
