មេរៀន HTML

ការចាប់ផ្តើមសាមញ្ញបំផុតដែលអាចធ្វើបាន៖ ចម្លង HTML ន័យវិទ្យាជាមួយ class hook របស់ Lily បន្ថែមសន្លឹករចនាប័ទ្មមួយ ដឹកជញ្ជូន។ ឯកសារធម្មតាដែលដំណើរការគ្រប់ទីកន្លែងដែល HTML ដំណើរការ។

អ្វីដែលអ្នកនឹងសាងសង់

ទម្រង់ទំនាក់ទំនងតូចមួយ — វាលបញ្ចូលដែលមានស្លាក ប៊ូតុងដាក់ស្នើ អាកប្បកិរិយាក្តារចុច និងកម្មវិធីអានអេក្រង់ពិតប្រាកដ — ដំបូងទទេស្អាត បន្ទាប់មកមានរចនាប័ទ្ម ក្នុងរយៈពេលប្រហែល ១០ នាទី។

មុនពេលអ្នកចាប់ផ្តើម

អ្នកត្រូវការកម្មវិធីរុករក និងកម្មវិធីកែអត្ថបទ។ ប៉ុណ្ណឹងហើយ។ (git ជួយក្នុងការយកឯកសារសមាសភាគ ប៉ុន្តែអ្នកក៏អាចចម្លងវាពី GitHub ក្នុងកម្មវិធីរុករកផងដែរ។)

ជំហាន ១ — យកកូដ

git clone https://github.com/LilyDesignSystem/lily-design-system

  Save

ពិនិត្យការងាររបស់អ្នក៖ បើកទំព័រក្នុងកម្មវិធីរុករក។ វាមើលទៅធម្មតា — ដូចដែលបានគ្រោងទុក៖ រចនាប័ទ្មនៅខាងមុខ។ ចុច Tab៖ ការផ្តោតផ្លាស់ទីតាមការគ្រប់គ្រងនីមួយៗ ស្លាកត្រូវបានប្រកាស ហើយការដាក់ស្នើដំណើរការ។ អាកប្បកិរិយាបានចប់; រូបរាងជារបស់អ្នក ហើយជាជំហានបន្ទាប់។
