AI એજન્ટ પરના કૌશલ્યો Lily ને વધુ સરળ બનાવે છે

Lily કેન્દ્રિત કૌશલ્યો આપે છે — સામાન્ય, ફ્રેમવર્ક-દીઠ અને ઉપ-પ્રોજેક્ટ-દીઠ — જેથી એજન્ટ બરાબર તેને જોઈતો સંદર્ભ લોડ કરે અને જે જોઈતું નથી તે નહીં.

તમને કયું કૌશલ્ય જોઈએ છે?

દરેક સ્તર અલગ પ્રશ્નનો જવાબ આપે છે. તમે Lily ને હજુ જાણતા ન હો ત્યારે સામાન્ય કૌશલ્ય લોડ કરો. તમે તમારું ફ્રેમવર્ક જાણો છો પણ કયો ઉપ-પ્રોજેક્ટ જોઈએ તે નથી જાણતા ત્યારે ફ્રેમવર્ક કૌશલ્ય લોડ કરો. તમે શેના પર કામ કરી રહ્યા છો તે બરાબર જાણો ત્યારે headless-skill અથવા helpers-skill સીધું લોડ કરો.

  • સામાન્ય / જાળવનાર — “Lily શું છે?” / “આ મોનોરેપો કેવી રીતે ગોઠવાયેલો છે?” — lily-design-system-skill, lily-design-system-maintainer-skill
  • ફ્રેમવર્ક છત્ર — “{framework} માટે શું ઉપલબ્ધ છે, અને મને કયો ભાગ જોઈએ?” — 8, દરેક માટે એક {framework}-skill
  • હેડલેસ / સહાયકો — “હું {framework} ના ઘટકો / *-picker સહાયકો બરાબર કેવી રીતે વાપરું?” — 16, દરેક માટે એક {framework}-headless-skill અને એક {framework}-helpers-skill

આઠ ફ્રેમવર્ક

દરેક ફ્રેમવર્કને એ જ ત્રણ-સ્તરીય સ્ટેક મળે છે. છત્ર કૌશલ્ય તે ફ્રેમવર્કના બધા વાસ્તવિક ઉપ-પ્રોજેક્ટનો નકશો બનાવે છે — ઉદાહરણ એપ સહિત, જેને તેના બંને ભાઈ-બહેન કૌશલ્યોમાંથી એક પણ આવરતું નથી — અને તેમના કરારો પુનરાવર્તિત કરવાને બદલે તેમની તરફ નીચે નિર્દેશ કરે છે.

Web Components કૌશલ્ય કૌશલ્ય (546/581) કૌશલ્ય

Web Components બંને દિશામાં એકમાત્ર અપવાદ છે: તેનો હેડલેસ કેટલોગ 581 માંથી 546 નો ઇરાદાપૂર્વકનો વ્યાપ ધરાવે છે (મૂળ કસ્ટમ એલિમેન્ટ, કોઈ ફ્રેમવર્ક રનટાઇમ નથી; બાકીના 35 ઘટકો કાયમી રીતે બાકાત છે), અને હજુ Web Components ઉદાહરણ એપ નથી — તેનું છત્ર કૌશલ્ય એક છે એવો સંકેત આપવાને બદલે આ કહે છે.

એક કૌશલ્ય ઉમેરો

દરેક કૌશલ્ય એક SKILL.md ફાઇલ છે — ઉપરાંત સહાયક ફાઇલો, બિલ્ડ પગલું નથી. તમારું Claude Code સેટઅપ જ્યાંથી કૌશલ્યો લોડ કરે છે ત્યાં તમને જોઈતું ક્લોન કરો (તમારા પ્રોજેક્ટ અથવા ખાતાની કૌશલ્ય ડિરેક્ટરી માટે ઉપર લિંક કરેલા અધિકૃત દસ્તાવેજો જુઓ): 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-skill

ઘણા ફ્રેમવર્કમાં, અથવા મોનોરેપો પર જ કામ કરો છો? તેના બદલે પ્રમાણભૂત મોનોરેપો ક્લોન કરો — બધા 27 કૌશલ્યો પહેલેથી તેના રૂટ પર છે, જે હેડલેસ લાઇબ્રેરીઓ, સહાયક કેટલોગ અને ઉદાહરણ એપ્સનું તે વર્ણન કરે છે તેમની બાજુમાં.
