Skians war ahentys AI a wra Lily hwath hweth esya

Lily a dhanvon skians fokusys — kenedhlek, dre bub framwyth, ha dre bub isravel — may hyllo ahent kargya an kettermyn pur a'n jeves othom hag a dra na'n jeves othom anodho.

Pyth skians a vynnowgh?

Pub gradh a worthyp dhe wovynn dyffrans. Kargewgh an skians kenedhlek pan na aswonnowgh Lily hwath. Kargewgh skians framwyth pan aswonnowgh dha framwyth mes ny wodhowgh pyth isravel a'n jeves othom. Kargewgh headless-skill po helpers-skill yn tevri pan wodhowgh seulajys pyth a obereth.

  • Kenedhlek / gwithyer — “Pyth yw Lily?” / “Fatell yw an monorepo ma kesstrewys?” — lily-design-system-skill, lily-design-system-maintainer-skill
  • Kudh framwyth — “Pyth yw dhe-les rag {framework}, ha pyth darn yw othom dhymm?” — 8, unn {framework}-skill pub onan
  • Heb pen / gweresoryon — “Fatell usyav yn tevri darnow / gweresoryon *-picker {framework}?” — 16, unn {framework}-headless-skill ha unn {framework}-helpers-skill pub onan

An eth framwyth

Keworrewgh unn skians

Pub skians yw restren SKILL.md — ha restrennow skoodhya, heb kamm drehevel. Klonewgh an unn a'n jeves othom dhe le may kargh dha settyans Claude Code skians (gwelewgh an dhogynnans ofisek kevrys a-ugh rag kuntelleth skians dha raglen po dha gontow): 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-skill

Ow ’oberi dres lies framwyth, po war an monorepo y honan? Klonewgh an monorepo kenedhlek yn le henna — an 27 skians a drig seulajys orth y wreydh, ryb an lyvervaow heb pen, rolyansow gweresoryon, ha'n appys ensampel a dhisplettyans.
