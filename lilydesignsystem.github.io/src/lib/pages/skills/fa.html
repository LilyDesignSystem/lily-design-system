مهارت‌ها روی عامل‌های هوش مصنوعی Lily را باز هم آسان‌تر می‌کنند

Lily مهارت‌های متمرکز عرضه می‌کند — عمومی، برای هر چارچوب و برای هر زیرپروژه — تا عامل دقیقاً همان بافتاری را بارگذاری کند که نیاز دارد و هیچ چیز اضافه‌ای را نه.

کدام مهارت را می‌خواهید؟

هر سطح به پرسش دیگری پاسخ می‌دهد. وقتی هنوز Lily را نمی‌شناسید مهارت عمومی را بارگذاری کنید. وقتی چارچوبتان را می‌شناسید اما نمی‌دانید کدام زیرپروژه لازم است، مهارت چارچوب را بارگذاری کنید. وقتی دقیقاً می‌دانید روی چه کار می‌کنید، headless-skill یا helpers-skill را مستقیماً بارگذاری کنید.

  • عمومی / نگهدار — «Lily چیست؟» / «این مونورپو چگونه ساخته شده؟» — lily-design-system-skill, lily-design-system-maintainer-skill
  • چتر چارچوب — «برای {framework} چه چیزی موجود است و کدام بخش را لازم دارم؟» — ۸ مورد، به‌ازای هر کدام یک {framework}-skill
  • بدون‌سر / یاریگرها — «دقیقاً چگونه از مؤلفه‌ها / یاریگرهای *-picker چارچوب {framework} استفاده کنم؟» — ۱۶ مورد، به‌ازای هر کدام یک {framework}-headless-skill و یک {framework}-helpers-skill

هشت چارچوب

هر چارچوب همان پشتهٔ سه‌لایه را دارد. مهارت چتر همهٔ زیرپروژه‌های واقعی آن چارچوب را نقشه‌برداری می‌کند — از جمله برنامهٔ نمونه، که هیچ‌یک از دو مهارت هم‌نیایش پوشش نمی‌دهد — و به‌جای تکرار قراردادهایشان، به پایین به آن‌ها اشاره می‌کند.

Web Components تنها استثنا در هر دو جهت است: فهرست بدون‌سر آن عمداً دامنه‌ای ۵۳۶ از ۵۷۱ دارد (عناصر سفارشی بومی، بدون زمان اجرای چارچوب؛ ۳۵ مؤلفهٔ دیگر برای همیشه کنار گذاشته شده‌اند)، و هنوز برنامهٔ نمونهٔ Web Components وجود ندارد — مهارت چتر آن به‌جای اشارهٔ ضمنی به وجود چنین چیزی، همین را می‌گوید.

یک مهارت اضافه کنید

هر مهارت یک فایل SKILL.md است — به‌علاوهٔ فایل‌های پشتیبان، بدون گام ساخت. آنچه نیاز دارید به جایی کلون کنید که تنظیمات Claude Code شما مهارت‌ها را از آن بارگذاری می‌کند (برای پوشهٔ مهارت‌های پروژه یا حساب‌تان مستندات رسمی پیوندشده در بالا را ببینید): 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-skill

روی چند چارچوب کار می‌کنید، یا روی خود مونورپو؟ به‌جای آن مونورپوی متعارف را کلون کنید — هر ۲۶ مهارت از قبل در ریشهٔ آن‌اند، در کنار کتابخانه‌های بدون‌سر، فهرست‌های یاریگر و برنامه‌های نمونه‌ای که توصیف می‌کنند.
