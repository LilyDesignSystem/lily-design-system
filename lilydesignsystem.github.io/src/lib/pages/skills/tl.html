Ginagawang mas madali ng mga skill sa mga AI agent ang Lily

Nagpapadala ang Lily ng mga nakatutok na skill — pangkalahatan, bawat framework, at bawat subproject — para mai-load ng agent ang eksaktong kontekstong kailangan nito at wala nang iba.

Anong skill ang gusto mo?

Bawat antas ay sumasagot sa ibang tanong. I-load ang pangkalahatang skill kapag hindi mo pa kilala ang Lily. I-load ang skill ng framework kapag kilala mo ang framework mo pero hindi mo alam kung aling subproject ang kailangan mo. I-load nang direkta ang headless-skill o helpers-skill kapag alam mo na nang eksakto kung ano ang ginagawa mo.

  • Pangkalahatan / maintainer — “Ano ang Lily?” / “Paano binuo ang monorepo na ito?” — lily-design-system-skill, lily-design-system-maintainer-skill
  • Payong ng framework — “Ano ang available para sa {framework}, at aling piraso ang kailangan ko?” — 8, tig-isang {framework}-skill
  • Headless / mga helper — “Paano eksaktong gagamitin ang mga component / *-picker helper ng {framework}?” — 16, tig-isang {framework}-headless-skill at {framework}-helpers-skill

Ang walong framework

Nakakakuha ang bawat framework ng parehong tatlong-antas na stack. Imamapa ng payong na skill ang lahat ng tunay na subproject ng framework na iyon — kasama ang halimbawang app, na hindi sinasaklaw ng alinman sa dalawang kapatid nitong skill — at tutukoy pababa sa mga ito sa halip na ulitin ang kanilang mga kontrata.

Ang Web Components ang nag-iisang eksepsiyon sa magkabilang direksyon: ang headless na catalog nito ay sadyang saklaw na 536 sa 571 (mga native na custom element, walang framework runtime; ang iba pang 35 component ay permanenteng hindi kasama), at wala pang halimbawang app ng Web Components — sinasabi iyon ng payong na skill nito sa halip na ipahiwatig na mayroon.

Magdagdag ng isang skill

Ang bawat skill ay isang SKILL.md na file — kasama ang mga sumusuportang file, walang build step. I-clone ang kailangan mo sa kahit saan nilo-load ng iyong setup ng Claude Code ang mga skill (tingnan ang opisyal na dokumentong naka-link sa itaas para sa direktoryo ng skill ng iyong proyekto o account): 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-skill

Nagtatrabaho sa ilang framework, o sa monorepo mismo? I-clone na lang ang canonical na monorepo — ang lahat ng 26 na skill ay nasa root na nito, katabi ng mga headless na library, catalog ng mga helper, at halimbawang app na inilalarawan nila.
