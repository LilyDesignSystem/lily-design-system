Dovednosti u AI agentů dělají Lily ještě snazší

Lily dodává cílené dovednosti — obecné, pro každý framework a pro každý podprojekt — takže agent načte přesně ten kontext, který potřebuje, a nic navíc.

Jakou dovednost chcete?

Každá úroveň odpovídá na jinou otázku. Načtěte obecnou dovednost, když Lily ještě neznáte. Načtěte dovednost frameworku, když znáte svůj framework, ale nevíte, který podprojekt potřebujete. Načtěte přímo headless-skill nebo helpers-skill, když už přesně víte, na čem pracujete.

  • Obecná / správce — „Co je Lily?” / „Jak je tento monorepozitář sestaven?” — lily-design-system-skill, lily-design-system-maintainer-skill
  • Zastřešení frameworku — „Co je k dispozici pro {framework} a kterou část potřebuji?” — 8, vždy jedna {framework}-skill
  • Bezhlavé / pomocníci — „Jak přesně používám komponenty / pomocníky *-picker pro {framework}?” — 16, vždy jedna {framework}-headless-skill a jedna {framework}-helpers-skill

Osm frameworků

Každý framework dostává stejný třívrstvý stack. Zastřešující dovednost mapuje všechny skutečné podprojekty daného frameworku — včetně ukázkové aplikace, kterou nepokrývá žádná z jejích dvou sesterských dovedností — a odkazuje na ně dolů, místo aby opakovala jejich smlouvy.

Přidejte jednu dovednost

Každá dovednost je soubor SKILL.md — plus podpůrné soubory, žádný krok sestavení. Naklonujte tu, kterou potřebujete, tam, odkud vaše nastavení Claude Code načítá dovednosti (viz oficiální dokumentace odkázaná výše pro adresář dovedností vašeho projektu nebo účtu): 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-skill

Pracujete napříč několika frameworky, nebo na samotném monorepozitáři? Naklonujte místo toho kanonický monorepozitář — všech 26 dovedností už leží v jeho kořeni, vedle bezhlavých knihoven, katalogů pomocníků a ukázkových aplikací, které popisují.
