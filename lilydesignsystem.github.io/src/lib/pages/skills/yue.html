AI 代理嘅技能令 Lily 更容易用

Lily 附帶專注嘅技能 — 通用、每個框架同每個子項目 — 等代理載入佢真正需要嘅上下文,唔多唔少。

你想要邊個技能?

每一層回答唔同嘅問題。唔識 Lily 嘅時候載入通用技能。識你嘅框架但唔知需要邊個子項目嘅時候載入框架技能。已經清楚知道自己做緊乜嘅時候,直接載入 headless-skill 或 helpers-skill。

  • 通用 / 維護者 — 「Lily 係乜?」/「呢個單一倉庫係點組成嘅?」— lily-design-system-skill, lily-design-system-maintainer-skill
  • 框架總覽 — 「{framework} 有啲乜,我需要邊一部分?」— 8 個,每個框架一個 {framework}-skill
  • 無頭 / 輔助工具 — 「{framework} 嘅元件 / *-picker 輔助工具到底點用?」— 16 個,每個框架一個 {framework}-headless-skill 同一個 {framework}-helpers-skill

八個框架

每個框架都有同樣嘅三層結構。總覽技能映射該框架所有真實嘅子項目 — 包括範例應用程式,呢個係兩個兄弟技能都冇覆蓋嘅 — 並指向下層,而唔係重複佢哋嘅合約。

加入一個技能

每個技能都係一個 SKILL.md 檔案 — 加上輔助檔案,冇建置步驟。將你需要嘅複製到你嘅 Claude Code 設定載入技能嘅位置(睇上面連結嘅官方文件,了解你項目或帳戶嘅技能目錄): 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-skill

跨幾個框架工作,或者喺單一倉庫本身工作?改為複製標準單一倉庫 — 全部 27 個技能已經喺佢嘅根部,同佢哋描述嘅無頭函式庫、輔助工具目錄同範例應用程式放埋一齊。
