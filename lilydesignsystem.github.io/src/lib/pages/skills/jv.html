Kaprigelan ing agèn AI ndadèkaké Lily luwih gampang

Lily nyedhiyakaké kaprigelan sing fokus — umum, saben framework, lan saben subproyèk — supaya agèn mung muat konteks sing dibutuhaké lan ora ana liyané.

Kaprigelan apa sing sampéyan karepake?

Saben tingkat njawab pitakon sing béda. Muat kaprigelan umum nalika sampéyan durung ngerti Lily. Muat kaprigelan framework nalika sampéyan ngerti framework sampéyan nanging ora ngerti subproyèk endi sing dibutuhaké. Muat headless-skill utawa helpers-skill langsung nalika sampéyan wis ngerti persis apa sing lagi dikerjakaké.

  • Umum / pangreksa — “Apa kuwi Lily?” / “Kepriyé monorepo iki disusun?” — lily-design-system-skill, lily-design-system-maintainer-skill
  • Payung framework — “Apa sing kasedhiya kanggo {framework}, lan bagéan endi sing dibutuhaké?” — 8, siji {framework}-skill saben siji
  • Tanpa sirah / pembantu — “Kepriyé carané nggunakaké komponèn / pembantu *-picker {framework} kanthi pas?” — 16, siji {framework}-headless-skill lan siji {framework}-helpers-skill saben siji

Wolung framework

Saben framework entuk tumpukan telung tingkat sing padha. Kaprigelan payung mapakaké kabèh subproyèk nyata saka framework kuwi — kalebu aplikasi conto, sing ora dicakup salah siji saka rong kaprigelan sedulurné — lan nuding mudhun menyang kuwi tinimbang ngulang kontraké.

Tambahna siji kaprigelan

Saben kaprigelan iku berkas SKILL.md — ditambah berkas pendukung, ora ana langkah build. Kloning sing sampéyan butuhaké menyang panggonan sing dienggo persiyapan Claude Code sampéyan kanggo muat kaprigelan (delengen dokumentasi resmi sing ditautaké ing ndhuwur kanggo direktori kaprigelan proyèk utawa akun sampéyan): 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-skill

Makarya ing pirang-pirang framework, utawa ing monorepo dhéwé? Kloning monorepo kanonik waé — kabèh 27 kaprigelan wis ana ing oyodé, jejer karo pustaka tanpa sirah, katalog pembantu, lan aplikasi conto sing diterangaké.
