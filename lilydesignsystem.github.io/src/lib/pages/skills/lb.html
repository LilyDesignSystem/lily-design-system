Skills op KI-Agenten maachen Lily nach méi einfach

Lily liwwert fokusséiert Skills — allgemeng, pro Framework a pro Ënnerprojet — sou dass en Agent genee de Kontext luet, deen en brauch, an näischt, wat en net brauch.

Wéi eng Skill wëllt Dir?

All Niveau beäntwert eng aner Fro. Lued déi allgemeng Skill, wann Dir Lily nach net kennt. Lued eng Framework-Skill, wann Dir Äre Framework kennt, awer net wësst, wéi en Ënnerprojet Dir braucht. Lued eng headless-skill oder helpers-skill direkt, wann Dir scho genee wësst, un wat Dir schafft.

  • Allgemeng / Maintainer — „Wat ass Lily?” / „Wéi ass dës Monorepo opgebaut?” — lily-design-system-skill, lily-design-system-maintainer-skill
  • Framework-Schierm — „Wat ass fir {framework} verfügbar, a wéi en Deel brauch ech?” — 8, jeweils eng {framework}-skill
  • Headless / Helfer — „Wéi benotzen ech genee d’Komponenten / *-picker-Helfer vu {framework}?” — 16, jeweils eng {framework}-headless-skill an eng {framework}-helpers-skill

Déi aacht Frameworken

All Framework kritt dee selwechten Dräi-Niveau-Stack. D’Schierm-Skill mapt all déi richteg Ënnerprojete vun deem Framework — dorënner d’Beispillapplikatioun, déi keng vu senge zwou Schwësterskills ofdeckt — a weist no ënnen op se, amplaz hir Kontrakter ze widderhuelen.

Web Components ass déi eenzeg Ausnam a béid Richtungen: säi Headless-Katalog huet en bewosst Ëmfang vu 536 vun 571 (native Custom Elements, keng Framework-Runtime; déi aner 35 Komponente sinn dauerhaft ausgeschloss), an et gëtt nach keng Web-Components-Beispillapplikatioun — seng Schierm-Skill seet dat, amplaz unzedeuten, datt et eng gëtt.

Eng Skill derbäisetzen

All Skill ass eng SKILL.md-Datei — plus Ënnerstëtzungsdateien, kee Build-Schrëtt. Klonéiert déi, déi Dir braucht, dohin, wou Är Claude-Code-Astellung Skills luet (kuckt déi uewe verlinkt offiziell Dokumentatioun fir de Skills-Verzeechnes vun Ärem Projet oder Kont): 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-skill

Schafft Dir iwwer méi Frameworken ewech, oder un der Monorepo selwer? Klonéiert amplaz déi kanonesch Monorepo — all 26 Skills sinn do schonn op hirer Wuerzel, niewent den Headless-Bibliothéiken, den Helferkatalogen an de Beispillapplikatiounen, déi se beschreiwen.
