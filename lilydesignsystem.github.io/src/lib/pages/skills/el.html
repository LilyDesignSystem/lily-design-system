Οι δεξιότητες στους πράκτορες AI κάνουν το Lily ακόμη πιο εύκολο

Το Lily παρέχει εστιασμένες δεξιότητες — γενικές, ανά πλαίσιο και ανά υποέργο — ώστε ένας πράκτορας να φορτώνει ακριβώς το πλαίσιο που χρειάζεται και τίποτα που δεν χρειάζεται.

Ποια δεξιότητα θέλεις;

Κάθε επίπεδο απαντά σε διαφορετική ερώτηση. Φόρτωσε τη γενική δεξιότητα όταν δεν γνωρίζεις ακόμη το Lily. Φόρτωσε μια δεξιότητα πλαισίου όταν γνωρίζεις το πλαίσιό σου αλλά όχι ποιο υποέργο χρειάζεσαι. Φόρτωσε απευθείας μια headless-skill ή helpers-skill όταν ήδη ξέρεις ακριβώς με τι δουλεύεις.

  • Γενική / συντηρητής — «Τι είναι το Lily;» / «Πώς είναι δομημένο αυτό το monorepo;» — lily-design-system-skill, lily-design-system-maintainer-skill
  • Ομπρέλα πλαισίου — «Τι διατίθεται για το {framework} και ποιο κομμάτι χρειάζομαι;» — 8, μία {framework}-skill για το καθένα
  • Κεφαλοχωρίς / βοηθοί — «Πώς ακριβώς χρησιμοποιώ τα στοιχεία / τους βοηθούς *-picker του {framework};» — 16, μία {framework}-headless-skill και μία {framework}-helpers-skill για το καθένα

Τα οκτώ πλαίσια

Κάθε πλαίσιο παίρνει την ίδια στοίβα τριών επιπέδων. Η δεξιότητα-ομπρέλα χαρτογραφεί όλα τα πραγματικά υποέργα του εν λόγω πλαισίου — συμπεριλαμβανομένης της εφαρμογής-παραδείγματος, που καμία από τις δύο αδελφές της δεξιότητες δεν καλύπτει — και δείχνει προς τα κάτω σε αυτά αντί να επαναλαμβάνει τα συμβόλαιά τους.

Το Web Components είναι η μοναδική εξαίρεση προς τις δύο κατευθύνσεις: ο κεφαλοχωρίς κατάλογός του έχει σκόπιμο εύρος 536 από 571 (εγγενή προσαρμοσμένα στοιχεία, χωρίς χρόνο εκτέλεσης πλαισίου· τα υπόλοιπα 35 στοιχεία αποκλείονται μόνιμα), και δεν υπάρχει ακόμη εφαρμογή-παράδειγμα Web Components — η δεξιότητα-ομπρέλα του το λέει αντί να υπονοεί ότι υπάρχει.

Πρόσθεσε μία δεξιότητα

Κάθε δεξιότητα είναι ένα αρχείο SKILL.md — συν αρχεία υποστήριξης, χωρίς βήμα δόμησης. Κλωνοποίησε αυτήν που χρειάζεσαι εκεί από όπου η ρύθμιση του Claude Code σου φορτώνει δεξιότητες (δες την επίσημη τεκμηρίωση που συνδέεται παραπάνω για τον κατάλογο δεξιοτήτων του έργου ή του λογαριασμού σου): 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-skill

Δουλεύεις σε πολλά πλαίσια ή στο ίδιο το monorepo; Κλωνοποίησε αντί γι' αυτό το κανονικό monorepo — και οι 26 δεξιότητες βρίσκονται ήδη στη ρίζα του, δίπλα στις κεφαλοχωρίς βιβλιοθήκες, τους καταλόγους βοηθών και τις εφαρμογές-παραδείγματα που περιγράφουν.
