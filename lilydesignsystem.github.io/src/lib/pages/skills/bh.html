AI एजेंट पर कौशल Lily के अउर आसान बना देलें

Lily केंद्रित कौशल देला — सामान्य, फ्रेमवर्क-वार, आ उप-परियोजना-वार — ताकि एजेंट ठीक ओहि संदर्भ के लोड करे जे ओकरा के चाहीं आ कुछुओ अइसन ना जे ना चाहीं।

रउआ के कवन कौशल चाहीं?

हर स्तर अलग सवाल के जवाब देला। जब रउआ Lily के अबहीं ना जानीले त सामान्य कौशल लोड करीं। जब रउआ आपन फ्रेमवर्क जानीले बाकिर ना जानीले कि कवन उप-परियोजना चाहीं त फ्रेमवर्क कौशल लोड करीं। जब रउआ ठीक-ठीक जानीले कि का पर काम कर रहल बानी त headless-skill भा helpers-skill सीधे लोड करीं।

  • सामान्य / अनुरक्षक — “Lily का ह?” / “ई मोनोरेपो कइसे बनल बा?” — lily-design-system-skill, lily-design-system-maintainer-skill
  • फ्रेमवर्क छतरी — “{framework} खातिर का उपलब्ध बा, आ हमरा कवन हिस्सा चाहीं?” — 8, हर एक खातिर एगो {framework}-skill
  • हेडलेस / सहायक — “हम {framework} के घटक / *-picker सहायक के ठीक-ठीक कइसे प्रयोग करीं?” — 16, हर एक खातिर एगो {framework}-headless-skill आ एगो {framework}-helpers-skill

आठ फ्रेमवर्क

हर फ्रेमवर्क के उहे तीन-स्तरीय स्टैक मिलेला। छतरी कौशल ओह फ्रेमवर्क के सब असली उप-परियोजना के नक्शा बनावेला — उदाहरण ऐप समेत, जेकरा के एकरा दूनो सहोदर कौशल में से कवनो कवर ना करेला — आ उनहन के करार दोहरावे के बदले उनहन के ओर नीचे इशारा करेला।

हर कौशल एगो SKILL.md फाइल ह — संगे सहायक फाइल, बिल्ड कदम ना। जवन रउआ के चाहीं ऊ ओहिजा क्लोन करीं जहाँ से रउआ के Claude Code सेटअप कौशल लोड करेला (रउआ के परियोजना भा खाता के कौशल डायरेक्टरी खातिर ऊपर जोड़ल आधिकारिक दस्तावेज देखीं): 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-skill
