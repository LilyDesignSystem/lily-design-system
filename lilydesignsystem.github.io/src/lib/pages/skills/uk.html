Навички для ШІ-агентів роблять Lily ще простішою

Lily постачає сфокусовані навички — загальні, для кожного фреймворку та для кожного підпроєкту, — щоб агент завантажував рівно той контекст, який йому потрібен, і нічого зайвого.

Яка навичка вам потрібна?

Кожен рівень відповідає на інше запитання. Завантажте загальну навичку, коли ще не знаєте Lily. Завантажте навичку фреймворку, коли знаєте свій фреймворк, але не знаєте, який підпроєкт вам потрібен. Завантажте headless-skill або helpers-skill напряму, коли вже точно знаєте, над чим працюєте.

  • Загальна / для супровідника — «Що таке Lily?» / «Як влаштовано цей монорепозиторій?» — lily-design-system-skill, lily-design-system-maintainer-skill
  • Парасолькова для фреймворку — «Що доступно для {framework} і який елемент мені потрібен?» — 8, по одній {framework}-skill на кожен
  • «Безголова» / допоміжні засоби — «Як саме користуватися компонентами / допоміжними засобами *-picker для {framework}?» — 16, по одній {framework}-headless-skill і одній {framework}-helpers-skill на кожен

Вісім фреймворків

Кожен фреймворк отримує той самий триглибинний стек. Парасолькова навичка зіставляє всі справжні підпроєкти цього фреймворку — включно з прикладом застосунку, якого не охоплює жодна з двох сусідніх навичок — і вказує вниз на них, а не повторює їхні контракти.

Додайте одну навичку

Кожна навичка — це файл SKILL.md плюс допоміжні файли, без кроку збирання. Клонуйте потрібну туди, звідки ваше налаштування Claude Code завантажує навички (див. офіційну документацію за посиланням вище щодо каталогу навичок вашого проєкту чи облікового запису): 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-skill

Працюєте з кількома фреймворками чи над самим монорепозиторієм? Клонуйте натомість канонічний монорепозиторій — усі 26 навичок уже лежать у його корені поруч із «безголовими» бібліотеками, каталогами допоміжних засобів і прикладами застосунків, які вони описують.
