Skill pada agen AI membuat Lily semakin mudah

Lily menyertakan skill yang terfokus — umum, per framework, dan per subproyek — sehingga agen memuat persis konteks yang dibutuhkan dan tidak lebih.

Skill apa yang Anda inginkan?

Setiap tingkat menjawab pertanyaan yang berbeda. Muat skill umum saat Anda belum mengenal Lily. Muat skill framework saat Anda mengenal framework Anda tetapi belum tahu subproyek mana yang Anda butuhkan. Muat skill headless atau skill asisten langsung saat Anda sudah tahu persis apa yang sedang dikerjakan.

  • Umum / pemelihara — “Apa itu Lily?” / “Bagaimana monorepo ini disusun?” — lily-design-system-skill, lily-design-system-maintainer-skill
  • Payung framework — “Apa yang tersedia untuk {framework}, dan bagian mana yang saya butuhkan?” — 8, masing-masing satu {framework}-skill
  • Headless / asisten — “Bagaimana tepatnya saya memakai komponen / asisten *-picker {framework}?” — 16, masing-masing satu {framework}-headless-skill dan satu {framework}-helpers-skill

Kedelapan framework

Setiap framework mendapat tumpukan tiga lapis yang sama. Skill payung memetakan semua subproyek nyata framework itu — termasuk aplikasi contoh, yang tidak dicakup oleh kedua skill saudaranya — dan menunjuk ke bawah ke dalamnya alih-alih mengulang kontraknya.

Web Components adalah satu-satunya pengecualian di kedua arah: katalog headless-nya memiliki cakupan yang disengaja yaitu 536 dari 571 (elemen kustom native, tanpa runtime framework; 35 komponen lainnya dikecualikan secara permanen), dan belum ada aplikasi contoh Web Components — skill payungnya menyatakan hal itu alih-alih menyiratkan adanya aplikasi tersebut.

Tambahkan satu skill

Setiap skill adalah berkas SKILL.md beserta berkas pendukung, tanpa langkah build. Klon yang Anda butuhkan ke lokasi tempat penyiapan Claude Code Anda memuat skill (lihat dokumentasi resmi yang ditautkan di atas untuk direktori skill proyek atau akun Anda):

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-skill

Bekerja dengan beberapa framework, atau pada monorepo itu sendiri? Klon monorepo kanonis saja — ke-26 skill sudah ada di akarnya, bersama pustaka headless, katalog asisten, dan aplikasi contoh yang mereka jelaskan.
