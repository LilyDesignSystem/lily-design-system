AI এজেন্টের স্কিল Lily-কে আরও সহজ করে

Lily কেন্দ্রীভূত স্কিল নিয়ে আসে — সাধারণ, প্রতি-ফ্রেমওয়ার্ক ও প্রতি-উপপ্রকল্প — যাতে একজন এজেন্ট ঠিক যে প্রেক্ষাপট দরকার তাই লোড করে, তার বেশি কিছু নয়।

আপনি কোন স্কিল চান?

প্রতিটি স্তর একটি আলাদা প্রশ্নের উত্তর দেয়। আপনি যখন এখনো Lily চেনেন না তখন সাধারণ স্কিল লোড করুন। আপনার ফ্রেমওয়ার্ক জানেন কিন্তু কোন উপপ্রকল্প লাগবে তা জানেন না তখন ফ্রেমওয়ার্ক স্কিল লোড করুন। আপনি ঠিক কী নিয়ে কাজ করছেন তা জানলে সরাসরি headless স্কিল বা সহায়ক স্কিল লোড করুন।

  • সাধারণ / রক্ষণাবেক্ষণ — «Lily কী?» / «এই মনোরিপো কীভাবে সাজানো?» — lily-design-system-skill, lily-design-system-maintainer-skill
  • ফ্রেমওয়ার্ক ছাতা — «{framework}-এর জন্য কী পাওয়া যায়, আর আমার কোন অংশটি লাগবে?» — ৮টি, প্রতিটির জন্য একটি {framework}-skill
  • Headless / সহায়ক — «আমি {framework}-এর কম্পোনেন্ট / *-picker সহায়ক ঠিক কীভাবে ব্যবহার করব?» — ১৬টি, প্রতিটির জন্য একটি {framework}-headless-skill ও একটি {framework}-helpers-skill

আটটি ফ্রেমওয়ার্ক

প্রতিটি ফ্রেমওয়ার্ক একই তিন-স্তরের কাঠামো পায়। ছাতা স্কিল সেই ফ্রেমওয়ার্কের সব আসল উপপ্রকল্পের মানচিত্র আঁকে — উদাহরণ অ্যাপসহ, যা তার দুই সহোদর স্কিলের কোনোটিই কভার করে না — এবং তাদের চুক্তি পুনরাবৃত্তি না করে সেগুলোর দিকে নির্দেশ করে।

Web Components দুই দিকেই একমাত্র ব্যতিক্রম: এর headless ক্যাটালগের পরিধি ইচ্ছাকৃতভাবে ৫৭১-এর মধ্যে ৫৩৬ (নেটিভ কাস্টম এলিমেন্ট, কোনো ফ্রেমওয়ার্ক রানটাইম নেই; বাকি ৩৫টি কম্পোনেন্ট স্থায়ীভাবে বাদ), এবং এখনো কোনো Web Components উদাহরণ অ্যাপ নেই — এর ছাতা স্কিল একটি আছে বলে আভাস না দিয়ে সেটাই জানিয়ে দেয়।

একটি স্কিল যোগ করুন

প্রতিটি স্কিল একটি SKILL.md ফাইল এবং সহায়ক ফাইলও, কোনো বিল্ড ধাপ ছাড়াই। আপনার যেটি দরকার সেটি সেখানে ক্লোন করুন যেখান থেকে আপনার Claude Code সেটআপ স্কিল লোড করে (আপনার প্রকল্প বা অ্যাকাউন্টের স্কিল ডিরেক্টরির জন্য উপরে যুক্ত সরকারি নথি দেখুন):

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-skill

একাধিক ফ্রেমওয়ার্কে কাজ করছেন, বা মনোরিপো নিজেই? তার বদলে আদর্শ মনোরিপো ক্লোন করুন — সব ২৬টি স্কিল ইতিমধ্যেই তার মূলে আছে, সঙ্গে সেই headless লাইব্রেরি, সহায়ক ক্যাটালগ ও উদাহরণ অ্যাপ যেগুলোর তারা বর্ণনা দেয়।
