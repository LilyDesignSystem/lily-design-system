Habilidades em agentes de IA tornam a Lily ainda mais fácil

A Lily traz habilidades focadas — gerais, por framework e por subprojeto — para que um agente carregue exatamente o contexto de que precisa e nada além disso.

Qual habilidade você quer?

Cada nível responde a uma pergunta diferente. Carregue a habilidade geral quando ainda não conhecer a Lily. Carregue uma habilidade de framework quando conhecer seu framework, mas não souber de qual subprojeto precisa. Carregue diretamente uma habilidade headless ou de assistentes quando já souber exatamente em que está trabalhando.

  • Geral / manutenção — “O que é a Lily?” / “Como este monorrepositório é organizado?” — lily-design-system-skill, lily-design-system-maintainer-skill
  • Guarda-chuva de framework — “O que existe para {framework}, e de qual peça eu preciso?” — 8, uma {framework}-skill cada
  • Headless / assistentes — “Como exatamente uso os componentes / assistentes *-picker de {framework}?” — 16, uma {framework}-headless-skill e uma {framework}-helpers-skill cada

Os oito frameworks

Cada framework recebe a mesma pilha de três níveis. A habilidade guarda-chuva mapeia todos os subprojetos reais desse framework — incluindo o aplicativo de exemplo, que nenhuma das duas habilidades irmãs cobre — e aponta para eles em vez de repetir seus contratos.

O Web Components é a única exceção nos dois sentidos: seu catálogo headless tem um escopo deliberado de 536 de 571 (elementos personalizados nativos, sem runtime de framework; os outros 35 componentes estão excluídos permanentemente), e ainda não existe um aplicativo de exemplo de Web Components — sua habilidade guarda-chuva diz isso em vez de sugerir que exista.

Adicione uma habilidade

Cada habilidade é um arquivo SKILL.md mais arquivos de apoio, sem etapa de build. Clone a que você precisa para onde a sua configuração do Claude Code carrega habilidades (consulte a documentação oficial linkada acima para o diretório de habilidades do seu projeto ou conta):

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-skill

Trabalha com vários frameworks, ou no próprio monorrepositório? Clone o monorrepositório canônico — as 26 habilidades já estão na raiz, junto com as bibliotecas headless, os catálogos de assistentes e os aplicativos de exemplo que elas descrevem.
