Skills für KI-Agenten machen Lily noch einfacher

Lily liefert fokussierte Skills – allgemein, je Framework und je Teilprojekt –, damit ein Agent genau den Kontext lädt, den er braucht, und nichts, was er nicht braucht.

Welche Skill möchten Sie?

Jede Ebene beantwortet eine andere Frage. Laden Sie die allgemeine Skill, wenn Sie Lily noch nicht kennen. Laden Sie eine Framework-Skill, wenn Sie Ihr Framework kennen, aber nicht wissen, welches Teilprojekt Sie brauchen. Laden Sie eine headless-skill oder helpers-skill direkt, wenn Sie schon genau wissen, woran Sie arbeiten.

  • Allgemein / Maintainer – „Was ist Lily?” / „Wie ist dieses Monorepo aufgebaut?” – lily-design-system-skill, lily-design-system-maintainer-skill
  • Framework-Dach – „Was gibt es für {framework}, und welches Teil brauche ich?” – 8, jeweils eine {framework}-skill
  • Headless / Helfer – „Wie genau verwende ich die Komponenten / *-picker-Helfer von {framework}?” – 16, jeweils eine {framework}-headless-skill und eine {framework}-helpers-skill

Die acht Frameworks

Jedes Framework erhält denselben dreistufigen Aufbau. Die Dach-Skill bildet alle echten Teilprojekte dieses Frameworks ab – einschließlich der Beispiel-App, die keine ihrer beiden Schwester-Skills abdeckt – und verweist nach unten auf sie, statt ihre Verträge zu wiederholen.

Web Components ist die einzige Ausnahme in beide Richtungen: Der Headless-Katalog hat einen bewussten Umfang von 546 von 581 (native Custom Elements, keine Framework-Laufzeit; die übrigen 35 Komponenten sind dauerhaft ausgeschlossen), und es gibt noch keine Web-Components-Beispiel-App – die Dach-Skill sagt das, statt anzudeuten, es gäbe eine.

Eine Skill hinzufügen

Jede Skill ist eine SKILL.md-Datei – plus Hilfsdateien, kein Build-Schritt. Klonen Sie die gewünschte dorthin, wo Ihre Claude-Code-Einrichtung Skills lädt (siehe die oben verlinkte offizielle Dokumentation für das Skills-Verzeichnis Ihres Projekts oder Kontos): 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-skill

Arbeiten Sie über mehrere Frameworks hinweg oder am Monorepo selbst? Klonen Sie stattdessen das kanonische Monorepo – alle 27 Skills liegen bereits in dessen Root, neben den Headless-Bibliotheken, den Helferkatalogen und den Beispiel-Apps, die sie beschreiben.
