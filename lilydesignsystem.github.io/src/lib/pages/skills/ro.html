Competențele agenților AI fac Lily și mai ușor de folosit

Lily livrează competențe țintite — generale, pe framework și pe subproiect — astfel încât un agent încarcă exact contextul de care are nevoie și nimic în plus.

Ce competență vrei?

Fiecare nivel răspunde la o altă întrebare. Încarcă competența generală când nu cunoști încă Lily. Încarcă o competență de framework când îți cunoști framework-ul, dar nu știi ce subproiect îți trebuie. Încarcă direct un headless-skill sau helpers-skill când știi deja exact la ce lucrezi.

  • General / responsabil — „Ce este Lily?” / „Cum este alcătuit acest monorepo?” — lily-design-system-skill, lily-design-system-maintainer-skill
  • Umbrelă de framework — „Ce este disponibil pentru {framework} și de ce parte am nevoie?” — 8, câte un {framework}-skill
  • Headless / ajutoare — „Cum folosesc exact componentele / ajutoarele *-picker ale {framework}?” — 16, câte un {framework}-headless-skill și un {framework}-helpers-skill

Cele opt framework-uri

Fiecare framework primește aceeași stivă pe trei niveluri. Competența-umbrelă cartografiază toate subproiectele reale ale acelui framework — inclusiv aplicația-exemplu, pe care niciuna dintre cele două competențe surori nu o acoperă — și indică în jos către ele, în loc să le repete contractele.

Adaugă o competență

Fiecare competență este un fișier SKILL.md — plus fișiere de suport, fără pas de build. Clonează-o pe cea de care ai nevoie acolo de unde configurația ta Claude Code încarcă competențele (vezi documentația oficială legată mai sus pentru directorul de competențe al proiectului sau al contului tău): 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-skill

Lucrezi pe mai multe framework-uri sau pe monorepo-ul însuși? Clonează în schimb monorepo-ul canonic — toate cele 27 de competențe se află deja la rădăcina lui, alături de bibliotecile headless, cataloagele de ajutoare și aplicațiile-exemplu pe care le descriu.
