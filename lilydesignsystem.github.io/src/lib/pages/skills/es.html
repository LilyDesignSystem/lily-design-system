Las habilidades en agentes de IA hacen Lily aún más fácil

Lily incluye habilidades específicas —generales, por framework y por subproyecto— para que un agente cargue exactamente el contexto que necesita y nada más.

¿Qué habilidad quieres?

Cada nivel responde a una pregunta distinta. Carga la habilidad general cuando aún no conozcas Lily. Carga una habilidad de framework cuando conozcas tu framework pero no sepas qué subproyecto necesitas. Carga directamente una habilidad headless o de asistentes cuando ya sepas exactamente en qué estás trabajando.

  • General / mantenimiento — «¿Qué es Lily?» / «¿Cómo está organizado este monorrepositorio?» — lily-design-system-skill, lily-design-system-maintainer-skill
  • Paraguas de framework — «¿Qué hay disponible para {framework} y qué pieza necesito?» — 8, una {framework}-skill cada uno
  • Headless / asistentes — «¿Cómo uso exactamente los componentes / asistentes *-picker de {framework}?» — 16, una {framework}-headless-skill y una {framework}-helpers-skill cada uno

Los ocho frameworks

Cada framework recibe la misma pila de tres niveles. La habilidad paraguas mapea todos los subproyectos reales de ese framework —incluida la aplicación de ejemplo, que ninguna de sus dos habilidades hermanas cubre— y remite a ellos en lugar de repetir sus contratos.

Web Components es la única excepción en ambos sentidos: su catálogo headless tiene un alcance deliberado de 536 de 571 (elementos personalizados nativos, sin entorno de ejecución de framework; los otros 35 componentes quedan excluidos de forma permanente), y todavía no existe una aplicación de ejemplo de Web Components: su habilidad paraguas lo dice en lugar de dar a entender que existe una.

Añade una habilidad

Cada habilidad es un archivo SKILL.md más archivos de apoyo, sin paso de compilación. Clona la que necesites en el lugar desde donde tu configuración de Claude Code carga las habilidades (consulta la documentación oficial enlazada arriba para ver el directorio de habilidades de tu proyecto o de tu cuenta):

git clone https://github.com/LilyDesignSystem/lily-design-system-svelte-skill

¿Trabajas con varios frameworks, o en el propio monorrepositorio? Clona en su lugar el monorrepositorio canónico: las 26 habilidades ya viven en su raíz, junto con las bibliotecas headless, los catálogos de asistentes y las aplicaciones de ejemplo que describen.
