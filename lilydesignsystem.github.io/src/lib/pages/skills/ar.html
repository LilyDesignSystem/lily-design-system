المهارات على وكلاء الذكاء الاصطناعي تجعل Lily أسهل

يأتي Lily بمهارات مركّزة — عامة ولكل إطار عمل ولكل مشروع فرعي — ليحمّل الوكيل بالضبط السياق الذي يحتاج إليه ولا شيء غيره.

أي مهارة تريد؟

يجيب كل مستوى عن سؤال مختلف. حمّل المهارة العامة حين لا تعرف Lily بعد. وحمّل مهارة إطار العمل حين تعرف إطار عملك لكنك لا تعرف أي مشروع فرعي تحتاج إليه. وحمّل مهارة headless أو مهارة المساعدات مباشرة حين تعرف بالضبط ما تعمل عليه.

  • عامة / صيانة — «ما هو Lily؟» / «كيف يتألف هذا المستودع الأحادي؟» — lily-design-system-skill، lily-design-system-maintainer-skill
  • مظلة إطار العمل — «ما المتاح لـ {framework}، وأي قطعة أحتاج؟» — 8، واحدة {framework}-skill لكل إطار
  • Headless / مساعدات — «كيف أستخدم بالضبط مكوّنات / مساعدات *-picker الخاصة بـ {framework}؟» — 16، واحدة {framework}-headless-skill وواحدة {framework}-helpers-skill لكل إطار

أطر العمل الثمانية

يحصل كل إطار عمل على الحزمة الثلاثية المستويات نفسها. وترسم مهارة المظلة جميع المشاريع الفرعية الحقيقية لذلك الإطار — بما فيها تطبيق المثال الذي لا تغطيه أي من مهارتيه الشقيقتين — وتشير إليها بدل تكرار عقودها.

أضف مهارة واحدة

كل مهارة هي ملف SKILL.md مع ملفات داعمة، بلا خطوة بناء. انسخ المهارة التي تحتاج إليها إلى المكان الذي يحمّل منه إعداد Claude Code الخاص بك المهارات (راجع الوثائق الرسمية المرتبطة أعلاه لمعرفة دليل المهارات لمشروعك أو حسابك):

git clone https://github.com/LilyDesignSystem/lily-design-system-svelte-skill

تعمل عبر عدة أطر عمل، أو على المستودع الأحادي نفسها؟ انسخ بدلًا من ذلك المستودع الأحادي المعتمد — فالمهارات الـ 26 كلها موجودة في جذرها، إلى جانب مكتبات headless وفهارس المساعدات وتطبيقات الأمثلة التي تصفها.
