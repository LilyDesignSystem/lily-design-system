AI ಏಜೆಂಟ್‌ಗಳಲ್ಲಿ ಕೌಶಲ್ಯಗಳು Lily ಯನ್ನು ಇನ್ನೂ ಸುಲಭಗೊಳಿಸುತ್ತವೆ

Lily ಕೇಂದ್ರೀಕೃತ ಕೌಶಲ್ಯಗಳನ್ನು ಕಳುಹಿಸುತ್ತದೆ — ಸಾಮಾನ್ಯ, ಪ್ರತಿ ಫ್ರೇಮ್‌ವರ್ಕ್‌ಗೆ ಮತ್ತು ಪ್ರತಿ ಉಪಯೋಜನೆಗೆ — ಹೀಗಾಗಿ ಏಜೆಂಟ್ ತನಗೆ ಬೇಕಾದ ಸಂದರ್ಭವನ್ನು ಮಾತ್ರ ಲೋಡ್ ಮಾಡುತ್ತದೆ, ಬೇಡದ್ದನ್ನು ಅಲ್ಲ.

ನಿಮಗೆ ಯಾವ ಕೌಶಲ್ಯ ಬೇಕು?

ಪ್ರತಿ ಹಂತವೂ ಬೇರೆ ಪ್ರಶ್ನೆಗೆ ಉತ್ತರಿಸುತ್ತದೆ. Lily ಯನ್ನು ಇನ್ನೂ ತಿಳಿಯದಿದ್ದಾಗ ಸಾಮಾನ್ಯ ಕೌಶಲ್ಯವನ್ನು ಲೋಡ್ ಮಾಡಿ. ನಿಮ್ಮ ಫ್ರೇಮ್‌ವರ್ಕ್ ತಿಳಿದಿದ್ದು ಯಾವ ಉಪಯೋಜನೆ ಬೇಕೆಂದು ತಿಳಿಯದಿದ್ದಾಗ ಫ್ರೇಮ್‌ವರ್ಕ್ ಕೌಶಲ್ಯವನ್ನು ಲೋಡ್ ಮಾಡಿ. ನೀವು ಏನು ಮಾಡುತ್ತಿದ್ದೀರಿ ಎಂದು ನಿಖರವಾಗಿ ತಿಳಿದಿರುವಾಗ headless-skill ಅಥವಾ helpers-skill ಅನ್ನು ನೇರವಾಗಿ ಲೋಡ್ ಮಾಡಿ.

  • ಸಾಮಾನ್ಯ / ನಿರ್ವಾಹಕ — “Lily ಎಂದರೇನು?” / “ಈ ಮೊನೊರೆಪೊ ಹೇಗೆ ಜೋಡಿಸಲ್ಪಟ್ಟಿದೆ?” — lily-design-system-skill, lily-design-system-maintainer-skill
  • ಫ್ರೇಮ್‌ವರ್ಕ್ ಛತ್ರಿ — “{framework} ಗೆ ಏನಿದೆ, ಮತ್ತು ನನಗೆ ಯಾವ ಭಾಗ ಬೇಕು?” — 8, ತಲಾ ಒಂದು {framework}-skill
  • ಹೆಡ್‌ಲೆಸ್ / ಸಹಾಯಕಗಳು — “{framework} ನ ಘಟಕಗಳು / *-picker ಸಹಾಯಕಗಳನ್ನು ನಿಖರವಾಗಿ ಹೇಗೆ ಬಳಸುವುದು?” — 16, ತಲಾ ಒಂದು {framework}-headless-skill ಮತ್ತು ಒಂದು {framework}-helpers-skill

ಎಂಟು ಫ್ರೇಮ್‌ವರ್ಕ್‌ಗಳು

ಪ್ರತಿ ಫ್ರೇಮ್‌ವರ್ಕ್‌ಗೂ ಅದೇ ಮೂರು-ಆಳದ ಸ್ಟ್ಯಾಕ್ ಸಿಗುತ್ತದೆ. ಛತ್ರಿ ಕೌಶಲ್ಯವು ಆ ಫ್ರೇಮ್‌ವರ್ಕ್‌ನ ಎಲ್ಲಾ ನಿಜವಾದ ಉಪಯೋಜನೆಗಳನ್ನು — ಅದರ ಎರಡೂ ಸಹೋದರ ಕೌಶಲ್ಯಗಳು ಒಳಗೊಳ್ಳದ ಉದಾಹರಣೆ ಅಪ್ಲಿಕೇಶನ್ ಸೇರಿದಂತೆ — ನಕ್ಷೆ ಮಾಡುತ್ತದೆ ಮತ್ತು ಅವುಗಳ ಒಪ್ಪಂದಗಳನ್ನು ಪುನರಾವರ್ತಿಸುವ ಬದಲು ಅವುಗಳತ್ತ ಕೆಳಮುಖವಾಗಿ ಸೂಚಿಸುತ್ತದೆ.

Web Components ಎರಡೂ ದಿಕ್ಕುಗಳಲ್ಲಿ ಏಕೈಕ ಅಪವಾದ: ಅದರ ಹೆಡ್‌ಲೆಸ್ ಕ್ಯಾಟಲಾಗ್ ಉದ್ದೇಶಪೂರ್ವಕ 581 ರಲ್ಲಿ 546 ವ್ಯಾಪ್ತಿ (ಸ್ಥಳೀಯ ಕಸ್ಟಮ್ ಎಲಿಮೆಂಟ್‌ಗಳು, ಫ್ರೇಮ್‌ವರ್ಕ್ ರನ್‌ಟೈಮ್ ಇಲ್ಲ; ಉಳಿದ 35 ಘಟಕಗಳು ಶಾಶ್ವತವಾಗಿ ಹೊರಗಿವೆ), ಮತ್ತು ಇನ್ನೂ Web Components ಉದಾಹರಣೆ ಅಪ್ಲಿಕೇಶನ್ ಇಲ್ಲ — ಅದರ ಛತ್ರಿ ಕೌಶಲ್ಯ ಒಂದಿದೆ ಎಂದು ಸೂಚಿಸುವ ಬದಲು ಹಾಗೆಂದು ಹೇಳುತ್ತದೆ.
