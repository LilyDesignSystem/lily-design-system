מיומנויות לסוכני בינה מלאכותית הופכות את Lily לקלה עוד יותר

Lily שולחת מיומנויות ממוקדות — כלליות, לכל מסגרת ולכל תת-פרויקט — כדי שסוכן יטען בדיוק את ההקשר שהוא צריך ולא יותר.

איזו מיומנות אתם רוצים?

כל שכבה עונה על שאלה אחרת. טענו את המיומנות הכללית כשאתם עדיין לא מכירים את Lily. טענו מיומנות מסגרת כשאתם מכירים את המסגרת שלכם אך לא יודעים איזה תת-פרויקט אתם צריכים. טענו headless-skill או helpers-skill ישירות כשאתם כבר יודעים בדיוק על מה אתם עובדים.

שמונה המסגרות

כל מסגרת מקבלת אותה ערימה תלת-שכבתית. מיומנות המטרייה ממפה את כל תתי-הפרויקטים האמיתיים של אותה מסגרת — כולל אפליקציית הדוגמה, שאף אחת משתי מיומנויות האחיות אינה מכסה — ומצביעה כלפי מטה אליהם במקום לחזור על החוזים שלהם.

הוסיפו מיומנות אחת

כל מיומנות היא קובץ SKILL.md — בתוספת קבצי תמיכה, ללא שלב בנייה. שכפלו את זו שאתם צריכים אל המקום שממנו ההתקנה של Claude Code שלכם טוענת מיומנויות (ראו את התיעוד הרשמי שקושר לעיל עבור ספריית המיומנויות של הפרויקט או החשבון שלכם): 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-skill

עובדים על כמה מסגרות, או על המונוריפו עצמו? שכפלו במקום זאת את המונוריפו הקנוני — כל 27 המיומנויות כבר יושבות בשורשו, לצד הספריות ללא הראש, קטלוגי העוזרים ואפליקציות הדוגמה שהן מתארות.
