Le skill sugli agenti IA rendono Lily ancora più semplice

Lily include skill mirate – generali, per framework e per sottoprogetto – così un agente carica esattamente il contesto di cui ha bisogno e nulla di superfluo.

Quale skill vuoi?

Ogni livello risponde a una domanda diversa. Carica la skill generale quando non conosci ancora Lily. Carica una skill di framework quando conosci il tuo framework ma non sai quale sottoprogetto ti serve. Carica direttamente una headless-skill o una helpers-skill quando sai già esattamente su cosa stai lavorando.

  • Generale / maintainer – «Cos'è Lily?» / «Com'è organizzato questo monorepo?» – lily-design-system-skill, lily-design-system-maintainer-skill
  • Ombrello di framework – «Cosa c'è per {framework} e quale parte mi serve?» – 8, una {framework}-skill ciascuno
  • Headless / helper – «Come uso esattamente i componenti / gli helper *-picker di {framework}?» – 16, una {framework}-headless-skill e una {framework}-helpers-skill ciascuno

Gli otto framework

Ogni framework ha la stessa pila a tre livelli. La skill ombrello mappa tutti i sottoprogetti reali di quel framework – compresa l'app di esempio, che nessuna delle sue due skill sorelle copre – e rimanda a essi invece di ripetere i loro contratti.

Web Components è l'unica eccezione in entrambe le direzioni: il suo catalogo headless ha un ambito volutamente di 546 su 581 (custom element nativi, nessun runtime di framework; gli altri 35 componenti sono esclusi in modo permanente), e non esiste ancora un'app di esempio Web Components – la sua skill ombrello lo dice invece di lasciar intendere che ce ne sia una.

Aggiungi una skill

Ogni skill è un file SKILL.md – più i file di supporto, senza passaggi di build. Clona quella che ti serve nel punto da cui la tua configurazione di Claude Code carica le skill (vedi la documentazione ufficiale collegata sopra per la directory delle skill del tuo progetto o account): 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-skill

Lavori su più framework o sul monorepo stesso? Clona invece il monorepo canonico – tutte e 27 le skill sono già nella sua radice, accanto alle librerie headless, ai cataloghi helper e alle app di esempio che descrivono.
