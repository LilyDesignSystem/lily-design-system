Навыки для ИИ-агентов делают Lily ещё проще

Lily поставляется с целевыми навыками — общими, по фреймворкам и по подпроектам, — чтобы агент загружал ровно тот контекст, который ему нужен, и ничего лишнего.

Какой навык вам нужен?

Каждый уровень отвечает на свой вопрос. Загрузите общий навык, если вы ещё не знаете Lily. Загрузите навык фреймворка, если вы знаете свой фреймворк, но не знаете, какой подпроект вам нужен. Загрузите навык headless или навык помощников напрямую, если вы точно знаете, над чем работаете.

  • Общий / сопровождение — «Что такое Lily?» / «Как устроен этот монорепозиторий?» — lily-design-system-skill, lily-design-system-maintainer-skill
  • Обзорный навык фреймворка — «Что доступно для {framework} и какая часть мне нужна?» — 8, по одному {framework}-skill на фреймворк
  • Headless / помощники — «Как именно использовать компоненты / помощники *-picker для {framework}?» — 16, по одному {framework}-headless-skill и одному {framework}-helpers-skill на фреймворк

Восемь фреймворков

Каждый фреймворк получает один и тот же трёхуровневый набор. Обзорный навык отображает все настоящие подпроекты этого фреймворка — включая пример приложения, которого не охватывает ни один из двух соседних навыков, — и отсылает к ним, а не повторяет их контракты.

Добавьте один навык

Каждый навык — это файл SKILL.md плюс вспомогательные файлы, без этапа сборки. Клонируйте нужный туда, откуда ваша установка Claude Code загружает навыки (каталог навыков вашего проекта или учётной записи см. в официальной документации по ссылке выше):

git clone https://github.com/LilyDesignSystem/lily-design-system-svelte-skill

Работаете с несколькими фреймворками или над самим монорепозиторием? Клонируйте вместо этого канонический монорепозиторий — все 26 навыков уже лежат в его корне вместе с headless-библиотеками, каталогами помощников и примерами приложений, которые они описывают.
