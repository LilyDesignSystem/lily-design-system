Skills on AI agents mak Lily even easier

Lily ships focused skills — general, per-framework, an per-subproject — sae an agent loads exactly the context it needs an naething it disnae.

Whit skill dae ye want?

Ilka tier answers a different question. Load the general skill whan ye dinnae ken Lily yet. Load a framework skill whan ye ken yer framework but no whit subproject ye need. Load a headless-skill or helpers-skill directly whan ye aareadies ken exactly whit ye're wirkin on.

  • General / maintainer — “Whit is Lily?” / “Hoo is this monorepo pit thegither?” — lily-design-system-skill, lily-design-system-maintainer-skill
  • Framework umbrella — “Whit's available for {framework}, an whit piece dae I need?” — 8, ane {framework}-skill ilkane
  • Headless / helpers — “Hoo exactly dae I uise {framework}'s components / *-picker helpers?” — 16, ane {framework}-headless-skill an ane {framework}-helpers-skill ilkane

Add ae skill

Ilka skill is a SKILL.md file — plus supportin files, nae build step. Clone the ane ye need intae whaurever yer Claude Code setup loads skills frae (see the official docs linkit abune for yer project's or account's skills directory): 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-skill

Wirkin athort several frameworks, or on the monorepo itsel? Clone the canonical monorepo insteid — ilka ane o the 27 skills aareadies lives at its root, alangside the headless libraries, the helpers catalogs, an the example apps they describe.
