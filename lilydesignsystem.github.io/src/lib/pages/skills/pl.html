Umiejętności agentów AI jeszcze bardziej ułatwiają Lily

Lily dostarcza umiejętności o wąskim zakresie — ogólne, dla każdego frameworka i dla każdego podprojektu — dzięki czemu agent ładuje dokładnie ten kontekst, którego potrzebuje, i nic ponad to.

Jakiej umiejętności potrzebujesz?

Każdy poziom odpowiada na inne pytanie. Załaduj umiejętność ogólną, gdy jeszcze nie znasz Lily. Załaduj umiejętność frameworka, gdy znasz swój framework, ale nie wiesz, którego podprojektu potrzebujesz. Załaduj headless-skill lub helpers-skill bezpośrednio, gdy już dokładnie wiesz, nad czym pracujesz.

  • Ogólna / opiekun — „Czym jest Lily?” / „Jak jest zbudowane to monorepozytorium?” — lily-design-system-skill, lily-design-system-maintainer-skill
  • Parasol frameworka — „Co jest dostępne dla {framework} i której części potrzebuję?” — 8, po jednej {framework}-skill
  • Bezgłowa / pomocnicy — „Jak dokładnie używać komponentów / pomocników *-picker dla {framework}?” — 16, po jednej {framework}-headless-skill i jednej {framework}-helpers-skill

Osiem frameworków

Każdy framework ma ten sam trzypoziomowy stos. Umiejętność parasolowa mapuje wszystkie rzeczywiste podprojekty tego frameworka — w tym aplikację przykładową, której nie obejmuje żadna z dwóch umiejętności siostrzanych — i wskazuje w dół na nie, zamiast powtarzać ich kontrakty.

Dodaj jedną umiejętność

Każda umiejętność to plik SKILL.md — plus pliki pomocnicze, bez kroku budowania. Sklonuj potrzebną tam, skąd twoja konfiguracja Claude Code ładuje umiejętności (zobacz oficjalną dokumentację podlinkowaną powyżej, aby znaleźć katalog umiejętności projektu lub konta): 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-skill

Pracujesz z wieloma frameworkami lub nad samym monorepozytorium? Sklonuj zamiast tego kanoniczne monorepozytorium — wszystkie 27 umiejętności leżą już w jego korzeniu, obok bibliotek bezgłowych, katalogów pomocników i aplikacji przykładowych, które opisują.
