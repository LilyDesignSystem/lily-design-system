Zručnosti pri AI agentoch robia Lily ešte jednoduchším

Lily dodáva cielené zručnosti — všeobecné, pre každý framework a pre každý podprojekt — takže agent načíta presne ten kontext, ktorý potrebuje, a nič navyše.

Akú zručnosť chcete?

Každá úroveň odpovedá na inú otázku. Načítajte všeobecnú zručnosť, keď Lily ešte nepoznáte. Načítajte zručnosť frameworku, keď poznáte svoj framework, ale neviete, ktorý podprojekt potrebujete. Načítajte priamo headless-skill alebo helpers-skill, keď už presne viete, na čom pracujete.

  • Všeobecná / správca — „Čo je Lily?” / „Ako je tento monorepozitár zostavený?” — lily-design-system-skill, lily-design-system-maintainer-skill
  • Zastrešenie frameworku — „Čo je k dispozícii pre {framework} a ktorú časť potrebujem?” — 8, vždy jedna {framework}-skill
  • Bezhlavé / pomocníci — „Ako presne používam komponenty / pomocníkov *-picker pre {framework}?” — 16, vždy jedna {framework}-headless-skill a jedna {framework}-helpers-skill

Osem frameworkov

Každý framework dostáva rovnaký trojvrstvový stack. Zastrešujúca zručnosť mapuje všetky skutočné podprojekty daného frameworku — vrátane ukážkovej aplikácie, ktorú nepokrýva žiadna z jej dvoch sesterských zručností — a odkazuje na ne nadol, namiesto aby opakovala ich zmluvy.

Pridajte jednu zručnosť

Každá zručnosť je súbor SKILL.md — plus podporné súbory, žiadny krok zostavenia. Naklonujte tú, ktorú potrebujete, tam, odkiaľ vaše nastavenie Claude Code načítava zručnosti (pozrite oficiálnu dokumentáciu prepojenú vyššie pre adresár zručností vášho projektu alebo účtu): 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-skill

Pracujete naprieč viacerými frameworkmi, alebo na samotnom monorepozitári? Naklonujte namiesto toho kanonický monorepozitár — všetkých 26 zručností už leží v jeho koreni, vedľa bezhlavých knižníc, katalógov pomocníkov a ukážkových aplikácií, ktoré opisujú.
