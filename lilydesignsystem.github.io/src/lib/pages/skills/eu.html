IA agenteetako trebetasunek Lily are errazago egiten dute

Lilyk trebetasun fokatuak bidaltzen ditu — orokorrak, framework bakoitzekoak eta azpiproiektu bakoitzekoak — agente batek behar duen testuingurua eta ez besterik kargatu dezan.

Zein trebetasun nahi duzu?

Maila bakoitzak galdera desberdin bati erantzuten dio. Kargatu trebetasun orokorra Lily oraindik ezagutzen ez duzunean. Kargatu framework-trebetasun bat zure framework-a ezagutzen duzunean baina ez dakizunean zein azpiproiektu behar duzun. Kargatu headless-skill edo helpers-skill zuzenean zehazki zertan ari zaren badakizunean.

  • Orokorra / mantentzailea — “Zer da Lily?” / “Nola dago monorepo hau antolatuta?” — lily-design-system-skill, lily-design-system-maintainer-skill
  • Framework-sakabanatzailea — “Zer dago eskuragarri {framework}-erako, eta zein pieza behar dut?” — 8, {framework}-skill bana
  • Buru gabea / laguntzaileak — “Nola erabili zehazki {framework}-en osagaiak / *-picker laguntzaileak?” — 16, {framework}-headless-skill bat eta {framework}-helpers-skill bat bakoitzeko

Zortzi framework-ak

Framework bakoitzak hiru mailako stack bera du. Sakabanatzaile-trebetasunak framework horren azpiproiektu errealak mapatzen ditu — adibide-aplikazioa barne, bere bi trebetasun-ahizpek estaltzen ez dutena — eta beheranzko seinalatzen ditu, haien kontratuak errepikatu beharrean.

Gehitu trebetasun bat

Trebetasun bakoitza SKILL.md fitxategi bat da — gehi laguntza-fitxategiak, eraikitze-pausorik gabe. Klonatu behar duzuna zure Claude Code konfigurazioak trebetasunak kargatzen dituen tokira (ikusi goiko dokumentazio ofiziala zure proiektuaren edo kontuaren trebetasun-direktorioa jakiteko): 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-skill

Framework ugaritan ari zara lanean, edo monorepoan bertan? Klonatu monorepo kanonikoa — 26 trebetasunak jada bere erroan daude, deskribatzen dituzten liburutegi buru gabeekin, laguntzaile-katalogoekin eta adibide-aplikazioekin batera.
