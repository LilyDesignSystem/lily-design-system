ជំនួយការចំណូលចិត្ត

កញ្ចប់តូចៗប្រាំពីរក្នុងមួយក្របខណ្ឌ នីមួយៗជាម្ចាស់ការងារអ្នកប្រើមួយពីដើមដល់ចប់ បូករបារដែលផ្គុំប្រាំក្នុងចំណោមពួកវា។ អ្នកបានជួប theme-pickerរួចហើយ; នេះគឺ locale-picker, text-size-picker និង motion-picker (ចំណូលចិត្ត), share-picker និង search-picker (សកម្មភាព), date-time-picker (តម្លៃទម្រង់) និង picker-bar។

អ្វីដែលអ្នកនឹងសាងសង់

បន្ទះការកំណត់ដែលអ្នកប្រើជ្រើសរើសភាសា និងទំហំអក្សររបស់ពួកគេ — ជម្រើសដែលអនុវត្តលើឯកសារទាំងមូល ស្ថិតស្ថេររវាងការទស្សនា និងអស់សមាសភាគពីរ និង CSS ប៉ុន្មានជួរ។ ប្រហែល ១៥ នាទី។

មុនពេលអ្នកចាប់ផ្តើម

បញ្ចប់ មេរៀនក្របខណ្ឌ សម្រាប់ស្ទែករបស់អ្នក។ គំរូខាងក្រោមជា Svelte; ជំនួយការ React, Vue, Angular, HTML, Nunjucks និង Blazor ត្រូវគ្នាកិច្ចសន្យាដោយកិច្ចសន្យា។

រូបរាងដែលពួកវាចែករំលែក

  • ប៊ូតុងរូបតំណាងគ្មានក្បាលដែលបើកប្រអប់បញ្ជី WAI-ARIA APG (ឬសម្រាប់ date-time-picker ប្រអប់ជ្រើសកាលបរិច្ឆេទ) — គ្មានដើម <select>ដូច្នេះក្របខណ្ឌនីមួយៗទទួលបានអាកប្បកិរិយាក្តារចុច និង hook រចនាប័ទ្មដូចគ្នា។
  • class hook មួយក្នុងមួយកញ្ចប់ (.locale-picker, .text-size-picker, .share-picker, .date-time-picker), CSS សូន្យត្រូវបានដឹកជញ្ជូន។
  • សុវត្ថិភាព SSR៖ ការសរសេរ DOM កើតឡើងតែក្នុងវដ្តជីវិត mount/effect ប៉ុណ្ណោះ។
  • ស្អាតចំពោះ i18n៖ អក្សរនីមួយៗដែលអ្នកប្រើមើលឃើញជាលក្ខណៈសម្បត្តិ។
  • មានសម្រាប់ Svelte (ស្តង់ដារ) React, Vue, Angular, ធាតុផ្ទាល់ខ្លួន HTML, Nunjucks និង Blazor — កិច្ចសន្យាដូចគ្នាក្នុងនីមួយៗ។

theme-picker, locale-picker និង text-size-picker នីមួយៗជាម្ចាស់ ចំណូលចិត្ត អ្នកប្រើមួយពីដើមដល់ចប់ (ការជ្រើសរើស ការអនុវត្ត DOM ជាជម្រើស localStorage ភាពស្ថិតស្ថេរ storageKey តាមរយៈលក្ខណៈសម្បត្តិ)។ share-picker និង date-time-picker ខុសគ្នាក្នុងប្រភេទ៖ share-picker ជាម្ចាស់ សកម្មភាព — វាមិនអនុវត្តអ្វីលើឯកសារ ហើយមិនរក្សាទុកអ្វី — ហើយ date-time-picker ជាម្ចាស់ តម្លៃទម្រង់ពីព្រោះកាលបរិច្ឆេទក្នុងទម្រង់ជាទិន្នន័យ មិនមែនជាចំណូលចិត្តទេ។

locale-picker — ភាសា និងទិស

អនុញ្ញាតឱ្យអ្នកប្រើជ្រើសរើសតំបន់ភាសា បន្ទាប់មកសរសេរ lang និង dir ទៅឫសឯកសារ ដើម្បីឱ្យបណ្ណាល័យ i18n CSS និងបច្ចេកវិទ្យាជំនួយរបស់អ្នកទាំងអស់តាម។ RTL ត្រូវបានរកឃើញដោយស្វ័យប្រវត្តិសម្រាប់អារ៉ាប់ ហេព្រើរ និងអក្សរស្តាំទៅឆ្វេងផ្សេងទៀត។ វាផ្តោតតែលើការផ្តល់សញ្ញា — បណ្ណាល័យ i18n របស់អ្នកគ្រប់គ្រងការបកប្រែ។ 

<script>
  import LocalePicker from "@lilydesignsystem/svelte-locale-picker";

  let locale = $state("en-US");
</script>

<LocalePicker
  label="Language"
  locales={["en-US", "fr", "ar", "he", "ja"]}
  bind:value={locale}
  storageKey="my-app-locale"
/>

ជម្រើសត្រូវបានដាក់ស្លាកពីតារាងដែលភ្ជាប់មកស្រាប់នៃឈ្មោះតំបន់ភាសា (អាចបដិសេធតាមរយៈ localeLabels) ជម្រើសនីមួយៗមាន lang គុណលក្ខណៈផ្ទាល់ខ្លួន ដើម្បីឱ្យកម្មវិធីអានអេក្រង់បញ្ចេញសំឡេង “Français” ជាភាសាបារាំង ហើយកូដដែលមានសញ្ញាគូសបន្ទាត់ក្រោមដូចជា en_US ធ្វើដំណើរទៅមកដោយគ្មានការបាត់បង់ទៅ BCP 47 en-US។ ភ្ជាប់ onChange (ឬតម្លៃដែលចង) ទៅ i18next, Paraglide, vue-i18n ឬអ្វីដែលអ្នកប្រើ។

text-size-picker — ទំហំដែលអ្នកអានគ្រប់គ្រង

ជ័យជម្នះភាពងាយស្រួលចូលប្រើដែលចំណាយពេលតែប៉ុន្មាននាទី៖ ជំនួយការកំណត់ data-text-size="{slug}" នៅលើឫសឯកសារ ហើយ CSS របស់អ្នកផ្គូផ្គងតម្លៃនីមួយៗទៅទំហំ។ 

<script>
  import TextSizePicker from "@lilydesignsystem/svelte-text-size-picker";
</script>

<TextSizePicker
  label="Text size"
  sizes={["small", "medium", "large", "x-large"]}
  storageKey="my-app-text-size"
/>
:root[data-text-size="small"]   { font-size: 87.5%; }
:root[data-text-size="medium"]  { font-size: 100%; }
:root[data-text-size="large"]   { font-size: 112.5%; }
:root[data-text-size="x-large"] { font-size: 125%; }

កំណត់ទំហំប្លង់របស់អ្នកក្នុង rem ហើយកម្មវិធីទាំងមូលធ្វើមាត្រដ្ឋានតាមជម្រើសរបស់អ្នកប្រើ។ ស្លាកត្រូវបានធ្វើជាអក្សរធំពី slug (“X Large”) ឬបដិសេធដោយ sizeLabels.

ពិនិត្យការងាររបស់អ្នក៖ ជ្រើស “Large” ពីឧបករណ៍ជ្រើសរើស ហើយអត្ថបទទំព័រលូតលាស់។ ផ្ទុកឡើងវិញ — វានៅតែធំ៖ ជម្រើសត្រូវបានរក្សាទុកទៅ localStorage។ ប្តូរឧបករណ៍ជ្រើសភាសារបស់អ្នកទៅអារ៉ាប់ ហើយ dir="rtl" ចុះចតលើឯកសារដោយស្វ័យប្រវត្តិ។

share-picker — ផ្ញើទំព័រនេះ

ប៊ូតុងអក្សរតែមួយដែលបើកសន្លឹកចែករំលែកដើមរបស់ឧបករណ៍ កន្លែងដែលមាន ហើយបើមិនដូច្នោះទេ ត្រឡប់ទៅបញ្ជីគោលដៅដែលអ្នកផ្តល់ បូកសកម្មភាពចម្លង URL។ វាមិនដឹកជញ្ជូន URL បណ្តាញសង្គមទេ — បណ្តាញណាដែលជារបស់ផលិតផលរបស់អ្នក ជាការហៅរបស់អ្នក មិនមែនរបស់ប្រព័ន្ធរចនាទេ។

      href: (url, title) => `mailto:?subject=${encodeURIComponent(title)}&body=${encodeURIComponent(url)}`, newTab: false },

<SharePicker

date-time-picker — កាលបរិច្ឆេទ ពេលវេលា ឬទាំងពីរ

វាលអត្ថបទដែលអ្នកអាចវាយ បូកប៊ូតុងរូបតំណាងដែលបើកប្រអប់ជ្រើសកាលបរិច្ឆេទ WAI-ARIA APG។ ត្រឹមត្រូវតាមតំបន់ភាសាតាមការរចនា — ឈ្មោះខែ ឈ្មោះថ្ងៃក្នុងសប្តាហ៍ ថ្ងៃដំបូងនៃសប្តាហ៍ និងនាឡិកា ១២ ឬ ២៤ ម៉ោង ទាំងអស់មកពី Intl — ហើយតម្លៃគឺជាខ្សែអក្សរ ISO ដែលអាចតម្រៀបបាន គ្មានល្វែងម៉ោងជានិច្ច៖ "2026-03-15" សម្រាប់ mode="date", "09:30" សម្រាប់ mode="time", "2026-03-15T09:30" សម្រាប់ mode="datetime".

motion-picker — គោរពចលនាថយចុះ

search-picker — ប្រអប់ស្វែងរកដែលចៀសចេញពីផ្លូវ

  navigate={(href) => goto(href)}
/>

action ផ្លាស់ប្តូរផ្លូវ (/search?foo) និង navigate រក្សាការរុករកក្នុងកម្មវិធី; បើគ្មានវាទេ ជំនួយការហៅ location.assign.

picker-bar — ជួរក្បាលទំព័រទាំងមូលក្នុងពេលតែមួយ

ឧបករណ៍ជ្រើសរើសនីមួយៗបង្ហាញស្លាករបស់វាក្នុងព័ត៌មានជំនួយនៅពេលទស្សន៍ទ្រនិចសម្រាកលើប៊ូតុងរបស់វា ឬប៊ូតុងមានការផ្តោតក្តារចុច។ ព័ត៌មានជំនួយនៅតែមាននៅពេលទស្សន៍ទ្រនិចផ្លាស់ទីលើវា Escape បដិសេធវាទោះការផ្តោតនៅទីណាក៏ដោយ ហើយវាមិនដែលបង្ហាញនៅពេលផ្ទាំងលេចឡើងរបស់ឧបករណ៍ជ្រើសរើសបើកទេ។ វាមានអត្ថបទដូចគ្នានឹងឈ្មោះដែលអាចចូលប្រើបានរបស់ប៊ូតុង ដូច្នេះគ្មានអ្វីត្រូវកំណត់ ហើយគ្មានអ្វីត្រូវបកប្រែពីរដងទេ; ស្បែកយោងដាក់រចនាប័ទ្មវា។
