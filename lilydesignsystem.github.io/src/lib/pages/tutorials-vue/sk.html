Návod pre Vue

Jednosúborové komponenty Vue 3 s typovanými props, defineModel obojsmernou väzbou a prenášaním v-bind="$attrs" .

Čo vytvoríte

Malý kontaktný formulár — pole s popisom, tlačidlo odoslať, v-model väzba, skutočné správanie klávesnice a čítačky obrazovky — najprv holý, potom ostylovaný, približne za 10 minút.

Skôr než začnete

Potrebujete git, Node 22 alebo novší a pnpm 10 alebo novší. Hodí sa akýkoľvek projekt Vue 3 — Nuxt, Vite alebo čistý Vue.

Krok 1 — Získajte kód

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-vue-headless
pnpm install
pnpm test        # vitest + @testing-library/vue
pnpm run storybook   # browse all 581 components

Komponenty sú ploché súbory v components/ — Button.vue, TextInput.vue — každý s vlastným testom, story a dokumentáciou po boku. Skopírujte potrebné súbory, alebo si repozitár vezmite.

Krok 2 — Váš prvý komponent

<script setup>
import Button from "lily-design-system-vue-headless/components/Button.vue";
</script>

<template>
  <Button @click="save">Save</Button>
</template>

Vykresľuje <button class="button" type="button">. Props zodpovedajú ostatným frameworkom: type, disabled, pressed, label, plus prepúšťanie atribútov pre všetko ostatné.

Krok 3 — Zložte malý formulár

<script setup>
import { ref } from "vue";
import Form from ".../components/Form.vue";
import Field from ".../components/Field.vue";
import TextInput from ".../components/TextInput.vue";
import Button from ".../components/Button.vue";

const name = ref("");
</script>

<template>
  <Form @submit="handleSubmit">
    <Field label="Full name" required>
      <TextInput id="name" label="Full name" v-model="name" required />
    </Field>
    <Button type="submit">Save</Button>
  </Form>
</template>

Field prijíma viditeľný label ako vlastný prop namiesto vnoreného komponentu popisu — odovzdajte ho raz, pri Fielda TextInputz label poskytne prístupný názov.

Overené 2026-08-29: skorší koncept vnáral samostatný komponent Label vnútri Field, čo vykreslilo dva popisy (jeden prázdny), pretože Field už vykresľuje svoj vlastný zo vstupu label prop — zistené kompiláciou presnej ukážky. Trasa Zložená trasa kontaktného formulára je rovnaký vzor, preverený skutočnými testami e2e a axe.

TextInput používa defineModel, takže obyčajný v-model funguje hneď.

Skontrolujte svoju prácu: spustite aplikáciu a formulár vyzerá holo — presne podľa zámeru: štýlovanie ešte len príde. Stlačte Tab: fokus prechádza každým ovládacím prvkom, popis sa oznamuje a odoslanie funguje. Správanie je hotové; vzhľad je váš a je ďalším krokom.

Krok 4 — Ostylujte ho

Ostylujte triedne háčiky — .button, .text-input, .label, .field — vo svojej štýlovej šablóne, alebo pripojte hotovú tému v index.html / nuxt.config: 

<link rel="stylesheet" href="/themes/nord.css" />

Krok 5 — Pozrite sa, ako to celé funguje

Ukážková aplikácia Nuxt je celý katalóg ostylovaný a predvedený, s Playwright e2e a základnou líniou axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-vue-nuxt-examples
pnpm install && pnpm run dev

Ďalšie kroky

  • Témy — prepínanie za behu pomocníkom theme-picker pre Vue.
  • Pomocníci pre predvoľby — jazyk a veľkosť textu.
  • Katalóg komponentov — vlastnosti, ARIA a klávesnica pre každý komponent.

Otázky po ceste? Stránka pomocníka je plná odpovedí — a ak by niektorý krok mohol byť jasnejší, dajte nám vedieť a návod radi vylepšíme.
