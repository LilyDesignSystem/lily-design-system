Tutorial Vue

Komponen satu berkas Vue 3 dengan props bertipe, defineModel pengikatan dua arah, dan penerusan v-bind="$attrs" .

Apa yang akan Anda bangun

Formulir kontak kecil — kolom berlabel, tombol kirim, v-model pengikatan, perilaku papan ketik dan pembaca layar yang nyata — pertama polos, lalu bergaya, dalam sekitar 10 menit.

Sebelum memulai

Anda memerlukan git, Node 22 atau lebih baru, dan pnpm 10 atau lebih baru. Proyek Vue 3 mana pun bisa — Nuxt, Vite, atau Vue biasa.

Langkah 1 — Dapatkan kodenya

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-vue-headless
pnpm install
pnpm test        # vitest + @testing-library/vue
pnpm run storybook   # browse all 571 components

Komponen berupa berkas datar di components/ — Button.vue, TextInput.vue — masing-masing dengan pengujian, story, dan dokumentasinya di sampingnya. Salin berkas yang Anda perlukan, atau tarik repositori.

Langkah 2 — Komponen pertama Anda

<script setup>
import Button from "lily-design-system-vue-headless/components/Button.vue";
</script>

<template>
  <Button @click="save">Save</Button>
</template>

Merender <button class="button" type="button">. Props sesuai dengan kerangka kerja lain: type, disabled, pressed, label, ditambah penerusan atribut untuk yang lainnya.

Langkah 3 — Susun formulir kecil

<script setup>
import { ref } from "vue";
import Form from ".../components/Form.vue";
import Field from ".../components/Field.vue";
import TextInput from ".../components/TextInput.vue";
import Button from ".../components/Button.vue";

const name = ref("");
</script>

<template>
  <Form @submit="handleSubmit">
    <Field label="Full name" required>
      <TextInput id="name" label="Full name" v-model="name" required />
    </Field>
    <Button type="submit">Save</Button>
  </Form>
</template>

Field menerima label sebagai prop-nya sendiri, bukan komponen label bersarang — teruskan sekali, pada Fielddan TextInputyang cocok dari label memberikan nama yang dapat diakses.

Diverifikasi 2026-08-29: draf sebelumnya menyarangkan komponen Label di dalam Field, yang merender dua label (satu kosong) karena Field sudah merender labelnya sendiri dari input label prop — ditemukan dengan mengompilasi cuplikan yang persis. Rute Rute formulir kontak gabungan adalah pola yang sama, diuji dengan pengujian e2e dan axe yang nyata.

TextInput menggunakan defineModel, jadi v-model biasa langsung bekerja.

Periksa pekerjaan Anda: jalankan aplikasi dan formulir tampak polos — persis seperti yang dimaksudkan: penataan gaya masih akan datang. Tekan Tab: fokus berpindah melalui setiap kontrol, label diumumkan, dan pengiriman berfungsi. Perilakunya selesai; tampilan adalah milik Anda dan menjadi langkah berikutnya.

Langkah 4 — Beri gaya

Beri gaya pada kait kelas — .button, .text-input, .label, .field — di lembar gaya Anda, atau tautkan tema siap pakai di index.html / nuxt.config: 

<link rel="stylesheet" href="/themes/nord.css" />

Langkah 5 — Lihat semuanya bekerja

Aplikasi contoh Nuxt adalah katalog lengkap yang bergaya dan didemonstrasikan, dengan Playwright e2e dan garis dasar axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-vue-nuxt-examples
pnpm install && pnpm run dev

Langkah berikutnya

  • Tema — pengalihan saat berjalan dengan pembantu theme-picker Vue.
  • Pembantu preferensi — bahasa dan ukuran teks.
  • Katalog komponen — properti, ARIA, dan papan ketik per komponen.

Ada pertanyaan di tengah jalan? Halaman bantuan penuh jawaban — dan jika suatu langkah bisa lebih jelas, beri tahu kami dan kami dengan senang hati akan memperbaiki tutorial ini.
