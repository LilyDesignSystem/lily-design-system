Ръководство за Vue

Еднофайлови компоненти на Vue 3 с типизирани props, defineModel двупосочно свързване и преминаване на v-bind="$attrs" .

Какво ще изградите

Малка форма за контакт — поле с етикет, бутон за изпращане, v-model свързване, истинско поведение на клавиатурата и екранния четец — първо гола, после стилизирана, за около 10 минути.

Преди да започнете

Нужни са ви git, Node 22 или по-нов и pnpm 10 или по-нов. Подходящ е всеки проект на Vue 3 — Nuxt, Vite или чист Vue.

Стъпка 1 — Вземете кода

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-vue-headless
pnpm install
pnpm test        # vitest + @testing-library/vue
pnpm run storybook   # browse all 581 components

Компонентите са плоски файлове в components/ — Button.vue, TextInput.vue — всеки със свой тест, story и документация до него. Копирайте нужните файлове или вземете хранилището.

Стъпка 2 — Първият ви компонент

<script setup>
import Button from "lily-design-system-vue-headless/components/Button.vue";
</script>

<template>
  <Button @click="save">Save</Button>
</template>

Рендира <button class="button" type="button">. Props съответстват на останалите фреймуърци: type, disabled, pressed, label, плюс преминаване на атрибути за всичко останало.

Стъпка 3 — Съставете малка форма

<script setup>
import { ref } from "vue";
import Form from ".../components/Form.vue";
import Field from ".../components/Field.vue";
import TextInput from ".../components/TextInput.vue";
import Button from ".../components/Button.vue";

const name = ref("");
</script>

<template>
  <Form @submit="handleSubmit">
    <Field label="Full name" required>
      <TextInput id="name" label="Full name" v-model="name" required />
    </Field>
    <Button type="submit">Save</Button>
  </Form>
</template>

Field приема видимия label като свой собствен prop вместо вложен компонент за етикет — подайте го веднъж, на Fieldи TextInputот label осигурява достъпното име.

Проверено на 2026-08-29: по-ранна чернова влагаше отделен компонент Label вътре в Field, което рендираше два етикета (единият празен), защото Field вече рендира собствения си от входа label prop — открито чрез компилиране на точния фрагмент. Маршрутът Съставният маршрут на формата за контакт е същият модел, изпитан с истински e2e и axe тестове.

TextInput използва defineModel, така че обикновен v-model работи от кутията.

Проверете работата си: стартирайте приложението и формата изглежда гола — точно както е предвидено: стилизирането предстои. Натиснете Tab: фокусът минава през всеки контрол, етикетът се обявява и изпращането работи. Поведението е готово; външният вид е ваш и е следващата стъпка.

Стъпка 4 — Стилизирайте го

Стилизирайте класовите куки — .button, .text-input, .label, .field — във вашата таблица със стилове или свържете готова тема в index.html / nuxt.config: 

<link rel="stylesheet" href="/themes/nord.css" />

Стъпка 5 — Вижте всичко в действие

Примерното приложение Nuxt е целият каталог стилизиран и демонстриран, с Playwright e2e и базова линия axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-vue-nuxt-examples
pnpm install && pnpm run dev
