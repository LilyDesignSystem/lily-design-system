Vue-kennsluefni

Vue 3 einskrárhlutir með tegundabundnum props, defineModel tvíátta bindingu og v-bind="$attrs" gegnumflæði.

Það sem þú munt byggja

Lítið tengiliðaeyðublað — innsláttarreitur með merkimiða, sendihnappur, v-model binding, raunveruleg lyklaborðs- og skjálesarahegðun — fyrst ber, svo stílað, á um 10 mínútum.

Áður en þú byrjar

Þú þarft git, Node 22 eða nýrra og pnpm 10 eða nýrra. Hvaða Vue 3 verkefni sem er virkar — Nuxt, Vite eða hreint Vue.

Skref 1 — Náðu í kóðann

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-vue-headless
pnpm install
pnpm test        # vitest + @testing-library/vue
pnpm run storybook   # browse all 581 components

Íhlutirnir eru flatar skrár í components/ — Button.vue, TextInput.vue — hver með prófi, story og skjölum við hliðina. Afritaðu skrárnar sem þú þarft, eða taktu geymsluna inn.

Skref 2 — Fyrsti íhluturinn þinn

<script setup>
import Button from "lily-design-system-vue-headless/components/Button.vue";
</script>

<template>
  <Button @click="save">Save</Button>
</template>

Birtir <button class="button" type="button">. Props samsvara hinum römmunum: type, disabled, pressed, label, auk eigindagegnumflæðis fyrir allt annað.

Skref 3 — Settu saman lítið eyðublað

<script setup>
import { ref } from "vue";
import Form from ".../components/Form.vue";
import Field from ".../components/Field.vue";
import TextInput from ".../components/TextInput.vue";
import Button from ".../components/Button.vue";

const name = ref("");
</script>

<template>
  <Form @submit="handleSubmit">
    <Field label="Full name" required>
      <TextInput id="name" label="Full name" v-model="name" required />
    </Field>
    <Button type="submit">Save</Button>
  </Form>
</template>

Field tekur sýnilega label sem sinn eigin prop frekar en innfelldan merkimiðaíhlut — gefðu hann einu sinni, á Fieldog TextInputá label sér um aðgengilega heitið.

Staðfest 2026-08-29: fyrri drög innfeldu sérstakan Label inni í Field, sem birtir tvo merkimiða (annan tóman) því Field birtir þegar sinn eigin út frá label prop — uppgötvað með því að þýða nákvæmlega snifsið. Sá samsetta tengiliðaeyðublaðsleiðin er sama mynstur, prófað með raunverulegum e2e- og axe-prófum.

TextInput notar defineModel, svo einfalt v-model virkar strax.

Athugaðu verkið: keyrðu forritið og eyðublaðið lítur einfalt út — nákvæmlega eins og ætlað er: stíllinn er enn framundan. Ýttu á Tab: fókusinn færist í gegnum hverja stýringu, merkimiðinn er lesinn upp og sending virkar. Hegðunin er tilbúin; útlitið er þitt og er næst.

Skref 4 — Stílaðu það

Stílaðu klasakrókana — .button, .text-input, .label, .field — í stílblaðinu þínu, eða tengdu tilbúið þema í index.html / nuxt.config: 

<link rel="stylesheet" href="/themes/nord.css" />

Skref 5 — Sjáðu allt virka

Nuxt dæmaforritið er allt safnið stílað og sýnt, með Playwright e2e og axe-core grunnlínu: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-vue-nuxt-examples
pnpm install && pnpm run dev

Næstu skref

  • Þemu — skipti á keyrslutíma með Vue theme-picker hjálpartækinu.
  • Stillingahjálpartæki — tungumál og textastærð.
  • Íhlutasafn — eiginleikar, ARIA og lyklaborð fyrir hvern íhlut.

Spurningar á leiðinni? hjálparsíðan er full af svörum — og ef skref gæti verið skýrara, segðu okkur og við bætum kennsluefnið með ánægju.
