מדריך Vue

רכיבי קובץ יחיד של Vue 3 עם מאפיינים מוקלדים, defineModel קשירה דו-כיוונית, ו v-bind="$attrs" העברה דרך.

מה תבנו

טופס יצירת קשר קטן — קלט עם תווית, כפתור שליחה, v-model קשירה, התנהגות אמיתית של מקלדת וקורא מסך — קודם חשוף, אחר כך מעוצב, בכ-10 דקות.

לפני שמתחילים

אתם צריכים git, Node 22 ומעלה ו-pnpm 10 ומעלה. כל פרויקט Vue 3 מתאים — Nuxt, Vite או Vue פשוט.

שלב 1 — קבלו את הקוד

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-vue-headless
pnpm install
pnpm test        # vitest + @testing-library/vue
pnpm run storybook   # browse all 581 components

הרכיבים הם קבצים שטוחים ב- components/ — Button.vue, TextInput.vue — כל אחד עם הבדיקה, ה-story והתיעוד שלו לצדו. העתיקו את הקבצים שאתם צריכים, או עשו vendoring למאגר.

שלב 2 — הרכיב הראשון שלכם

<script setup>
import Button from "lily-design-system-vue-headless/components/Button.vue";
</script>

<template>
  <Button @click="save">Save</Button>
</template>

מציג <button class="button" type="button">. המאפיינים תואמים למסגרות האחרות: type, disabled, pressed, label, בתוספת העברת מאפיינים עבור כל השאר.

שלב 3 — הרכיבו טופס קטן

<script setup>
import { ref } from "vue";
import Form from ".../components/Form.vue";
import Field from ".../components/Field.vue";
import TextInput from ".../components/TextInput.vue";
import Button from ".../components/Button.vue";

const name = ref("");
</script>

<template>
  <Form @submit="handleSubmit">
    <Field label="Full name" required>
      <TextInput id="name" label="Full name" v-model="name" required />
    </Field>
    <Button type="submit">Save</Button>
  </Form>
</template>

Field לוקח את ה label כמאפיין משלו ולא כרכיב תווית מקונן — העבירו אותה פעם אחת, על Field, ו TextInputהתואם ב- label מספק את השם הנגיש.

אומת ב-2026-08-29: טיוטה מוקדמת קיננה רכיב נפרד Label בתוך Field, מה שהציג שתי תוויות (אחת ריקה) משום ש- Field כבר מציג תווית משלו מתוך label מאפיין — התגלה על ידי הידור הקטע המדויק. נתיב טופס יצירת הקשר המורכב הוא אותה תבנית, שנבדקה בבדיקות e2e ו-axe אמיתיות.

TextInput משתמש ב- defineModel, ולכן v-model פשוט עובד מהקופסה.

בדקו את העבודה שלכם: הריצו את האפליקציה והטופס נראה פשוט — בדיוק כמתוכנן: העיצוב עוד לפנינו. לחצו על Tab: המיקוד עובר בכל פקד, התווית מוכרזת והשליחה עובדת. ההתנהגות מוכנה; המראה שלכם והוא הבא בתור.

שלב 4 — עצבו אותו

עצבו את ווי המחלקה — .button, .text-input, .label, .field — בגיליון הסגנון שלכם, או קשרו ערכת נושא מוכנה ב- index.html / nuxt.config: 

<link rel="stylesheet" href="/themes/nord.css" />

שלב 5 — ראו הכול עובד

אפליקציית הדוגמה Nuxt היא הקטלוג המלא מעוצב ומודגם, עם Playwright e2e וקו בסיס axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-vue-nuxt-examples
pnpm install && pnpm run dev

השלבים הבאים

  • ערכות נושא — החלפה בזמן ריצה עם העוזר theme-picker של Vue.
  • עוזרי העדפות — שפה וגודל טקסט.
  • קטלוג הרכיבים — מאפיינים, ARIA ומקלדת לכל רכיב.

שאלות בדרך? עמוד העזרה מלא בתשובות — ואם שלב יכול להיות ברור יותר, ספרו לנו ונשמח לשפר את המדריך.
