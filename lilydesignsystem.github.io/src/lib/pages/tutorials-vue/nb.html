Vue-veiledning

Vue 3 enkeltfilkomponenter med typede egenskaper, defineModel toveis binding og v-bind="$attrs" gjennomstrømming.

Hva du skal bygge

Et lite kontaktskjema — et inndatafelt med etikett, en send-knapp, v-model binding, ekte tastatur- og skjermleseroppførsel — først bart, så stilet, på omtrent 10 minutter.

Før du begynner

Du trenger git, Node 22 eller nyere og pnpm 10 eller nyere. Ethvert Vue 3-prosjekt fungerer — Nuxt, Vite eller ren Vue.

Steg 1 — Hent koden

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-vue-headless
pnpm install
pnpm test        # vitest + @testing-library/vue
pnpm run storybook   # browse all 571 components

Komponentene er flate filer i components/ — Button.vue, TextInput.vue — hver med sin test, story og dokumentasjon ved siden av. Kopier filene du trenger, eller vendor repoet.

Steg 2 — Din første komponent

<script setup>
import Button from "lily-design-system-vue-headless/components/Button.vue";
</script>

<template>
  <Button @click="save">Save</Button>
</template>

Gjengir <button class="button" type="button">. Egenskapene samsvarer med de andre rammeverkene: type, disabled, pressed, label, pluss attributt-gjennomstrømming for alt annet.

Steg 3 — Sett sammen et lite skjema

<script setup>
import { ref } from "vue";
import Form from ".../components/Form.vue";
import Field from ".../components/Field.vue";
import TextInput from ".../components/TextInput.vue";
import Button from ".../components/Button.vue";

const name = ref("");
</script>

<template>
  <Form @submit="handleSubmit">
    <Field label="Full name" required>
      <TextInput id="name" label="Full name" v-model="name" required />
    </Field>
    <Button type="submit">Save</Button>
  </Form>
</template>

Field tar den synlige label som sin egen egenskap i stedet for en nøstet etikettkomponent — send den inn én gang, på Fieldog TextInputpå label gir det tilgjengelige navnet.

Verifisert 2026-08-29: et tidligere utkast nøstet en separat Label inni Field, som gjengir to etiketter (én tom) fordi Field allerede gjengir sin egen fra label egenskap — oppdaget ved å kompilere den nøyaktige snutten. Den sammensatte kontaktskjema-ruten er det samme mønsteret, prøvd med ekte e2e- og axe-tester.

TextInput bruker defineModel, så vanlig v-model fungerer rett ut av esken.

Sjekk arbeidet ditt: kjør appen, og skjemaet ser enkelt ut — akkurat som tiltenkt: stilingen ligger fortsatt foran. Trykk Tab: fokus beveger seg gjennom hver kontroll, etiketten kunngjøres og innsending fungerer. Oppførselen er ferdig; utseendet er ditt og er neste.

Steg 4 — Stil det

Stil klassekrokene — .button, .text-input, .label, .field — i stilarket ditt, eller lenk et ferdig tema i index.html / nuxt.config: 

<link rel="stylesheet" href="/themes/nord.css" />

Steg 5 — Se alt fungere

Nuxt-eksempelappen er hele katalogen stilet og demonstrert, med Playwright e2e og en axe-core-baseline: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-vue-nuxt-examples
pnpm install && pnpm run dev

Neste steg

  • Tema — bytte ved kjøretid med Vue theme-picker-hjelperen.
  • Preferansehjelpere — språk og tekststørrelse.
  • Komponentkatalog — egenskaper, ARIA og tastatur per komponent.

Spørsmål underveis? hjelpesiden er full av svar — og hvis et steg kan bli tydeligere, fortell oss så forbedrer vi gjerne veiledningen.
