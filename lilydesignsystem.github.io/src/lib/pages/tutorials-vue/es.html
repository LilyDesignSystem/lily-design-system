Tutorial de Vue

Componentes de archivo único de Vue 3 con props tipadas, defineModel enlace bidireccional y transferencia de v-bind="$attrs" .

Qué vas a construir

Un pequeño formulario de contacto: campo con etiqueta, botón de envío, v-model enlace, comportamiento real de teclado y lector de pantalla; primero desnudo, luego con estilo, en unos 10 minutos.

Antes de empezar

Necesitas git, Node 22 o posterior y pnpm 10 o posterior. Sirve cualquier proyecto de Vue 3: Nuxt, Vite o Vue simple.

Paso 1: Obtén el código

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-vue-headless
pnpm install
pnpm test        # vitest + @testing-library/vue
pnpm run storybook   # browse all 581 components

Los componentes son archivos planos en components/ — Button.vue, TextInput.vue ; cada uno con su prueba, su story y su documentación al lado. Copia los archivos que necesites, o trae el repositorio.

Paso 2: Tu primer componente

<script setup>
import Button from "lily-design-system-vue-headless/components/Button.vue";
</script>

<template>
  <Button @click="save">Save</Button>
</template>

Renderiza <button class="button" type="button">. Las props coinciden con los demás frameworks: type, disabled, pressed, label, más transferencia de atributos para todo lo demás.

Paso 3: Compón un formulario pequeño

<script setup>
import { ref } from "vue";
import Form from ".../components/Form.vue";
import Field from ".../components/Field.vue";
import TextInput from ".../components/TextInput.vue";
import Button from ".../components/Button.vue";

const name = ref("");
</script>

<template>
  <Form @submit="handleSubmit">
    <Field label="Full name" required>
      <TextInput id="name" label="Full name" v-model="name" required />
    </Field>
    <Button type="submit">Save</Button>
  </Form>
</template>

Field toma el label como su propia prop en lugar de un componente de etiqueta anidado: pásala una vez, en Fieldy TextInputcorrespondiente de label aporta el nombre accesible.

Verificado el 2026-08-29: un borrador anterior anidaba un componente Label dentro de Field, lo que renderizaba dos etiquetas (una vacía) porque Field ya renderiza la suya propia a partir de la entrada label prop; se detectó compilando el fragmento exacto. La ruta La ruta compuesta del formulario de contacto es el mismo patrón, ejercitado con pruebas e2e y axe reales.

TextInput usa defineModelasí que un v-model simple funciona de fábrica.

Comprueba tu trabajo: ejecuta la aplicación y el formulario se ve sencillo, tal como se pretendía: el estilo aún está por venir. Pulsa Tab: el foco recorre cada control, se anuncia la etiqueta y el envío funciona. El comportamiento está hecho; el aspecto es tuyo y es el siguiente paso.

Paso 4: Dale estilo

Da estilo a los ganchos de clase: .button, .text-input, .label, .field , en tu hoja de estilos, o enlaza un tema ya hecho en index.html / nuxt.config: 

<link rel="stylesheet" href="/themes/nord.css" />

Paso 5: Míralo todo funcionando

La aplicación de ejemplo Nuxt es el catálogo completo con estilo y demostrado, con Playwright e2e y una línea base de axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-vue-nuxt-examples
pnpm install && pnpm run dev
