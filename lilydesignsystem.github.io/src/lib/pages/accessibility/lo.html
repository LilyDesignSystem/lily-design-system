ການ “ຕັ້ງເປົ້າ WCAG 2.2 AAA” ໝາຍຄວາມວ່າແນວໃດທີ່ນີ້

ຄຳວ່າ ຕັ້ງເປົ້າ ຖືກເລືອກຢ່າງຕັ້ງໃຈ. ໜ້ານີ້ບອກຢ່າງແນ່ນອນວ່າສິ່ງໃດຖືກກວດສອບ, ດ້ວຍຫຍັງ, ສິ່ງໃດບໍ່ຖືກກວດສອບດ້ວຍຫຍັງເລີຍ, ແລະພວກເຮົາຕັ້ງໃຈເຮັດຫຍັງກັບຊ່ອງຫວ່າງນັ້ນ. Lily ບໍ່ເຄີຍອ້າງ “ການປະຕິບັດຕາມ” WCAG — ບໍ່ມີການກວດສອບໃດສະໜັບສະໜູນມັນ.

ກວດສອບຢ່າງຕໍ່ເນື່ອງ

  • ອົງປະກອບທີ່ມີຄວາມໝາຍມາດຕະຖານຂອງທຸກອົງປະກອບ, ຄຸນລັກສະນະ ARIA ແລະ class hook — ຢືນຢັນໂດຍຊຸດທົດສອບໜ່ວຍຕໍ່ເຟຣມເວີກ (ຫຼາຍກວ່າ 15,000 ກໍລະນີໃນເຈັດເຟຣມເວີກ).
  • ທຸກໜ້າສາທິດອົງປະກອບ 581 ໜ້າໃນແອັບຕົວຢ່າງ SvelteKit ສະອາດຈາກ axe (ຊຸດກົດ WCAG 2.0/2.1 A+AA ແລະ 2.2 AA) — ການກວາດແຄັດຕາລັອກເຕັມ, ກຳນົດ baseline ຄັ້ງທຳອິດ 2026-08-27 ແລະແລ່ນຄືນ 2026-10-06 — ບວກກັບ baseline ຕໍ່ແອັບໃນໜ້າຫຼັກ, ແຄັດຕາລັອກ ແລະເສັ້ນທາງປະກອບໃນທັງເຈັດແອັບຕົວຢ່າງ.
  • ສັນຍາແປ້ນພິມຕໍ່ອົງປະກອບແບບໂຕ້ຕອບ, ບັນທຶກໃນເມຕາດາຕາມາດຕະຖານຂອງທຸກອົງປະກອບ ແລະໃຊ້ໂດຍຊຸດທົດສອບ; ແພັກເກັດຕົວຊ່ວຍຍັງແລ່ນ Playwright spec ໃນບຣາວເຊີຈິງ.
  • ພື້ນຂະໜາດເປົ້າໝາຍ WCAG 2.2 ແລະຕົວປ້ອງກັນລົ້ນໃນທັງ 57 ຮູບແບບສີສັນ; ລິ້ງຂ້າມ, ຈຸດສັງເກດ ແລະບໍ່ມີການລົ້ນແນວນອນໃນສີ່ viewport ຕໍ່ແອັບ; lang/dir ການນຳໃຊ້ ແລະການພິກ RTL.

ບໍ່ຖືກກວດສອບດ້ວຍຫຍັງເລີຍ

  • ບໍ່ເຄີຍມີການກວດສອບຄວາມສອດຄ່ອງ. ບໍ່ມີ VPAT, ບໍ່ມີການຮັບຮອງ. ເຄື່ອງມືອັດຕະໂນມັດກວມເອົາສ່ວນນ້ອຍຂອງເກນຄວາມສຳເລັດ WCAG.
  • ເກນສະເພາະ AAA (ຄວາມຄົມຊັດທີ່ປັບປຸງ ແລະອື່ນໆ) ແມ່ນເຈດຕະນາການອອກແບບ, ບໍ່ແມ່ນຄຸນສົມບັດທີ່ກວດສອບແລ້ວ; ຊຸດກົດ axe ແລ່ນ A/AA. ຍັງບໍ່ມີຮູບແບບສີສັນຄວາມຄົມຊັດສູງສະເພາະ.
  • ພຶດຕິກຳໂປຣແກຣມອ່ານໜ້າຈໍສ່ວນໃຫຍ່ຍັງບໍ່ໄດ້ທົດສອບ. ຊຸດທົດສອບຢືນຢັນຄຸນລັກສະນະ ARIA, ບໍ່ແມ່ນສິ່ງທີ່ VoiceOver, NVDA ຫຼື JAWS ປະກາດ — ແລະໂຄງການນີ້ໄດ້ສົ່ງຊຸດທົດສອບສີຂຽວເໜືອຂໍ້ບົກພ່ອງຈິງຫຼາຍກວ່າໜຶ່ງຄັ້ງ, ແຕ່ລະອັນຖືກຂຽນໃນບັນທຶກການປ່ຽນແປງກໍເພາະຊຸດທົດສອບເບິ່ງບໍ່ເຫັນມັນ.

ພວກເຮົາຕັ້ງໃຈເຮັດຫຍັງກັບມັນ

ການກວດສອບການເຂົ້າເຖິງໄດ້ງ່າຍແບບເອກະລາດແມ່ນການນຳໃຊ້ທຳອິດທີ່ລະບຸຊື່ຂອງທຶນໂຄງການໃດໆ, ແລະຂອບເຂດທີ່ຜູ້ກວດສອບຕ້ອງການໄດ້ກະກຽມແລ້ວ. ຈົນກວ່າຈະເຖິງເວລານັ້ນ, ລາຍງານໂປຣແກຣມອ່ານໜ້າຈໍແມ່ນການປະກອບສ່ວນທີ່ໂຄງການນີ້ຕ້ອງການທີ່ສຸດ: “ອົງປະກອບ X ປະກາດ Y, ເຊິ່ງຜິດເພາະ Z” ປະຕິບັດໄດ້ໂດຍກົງ.
