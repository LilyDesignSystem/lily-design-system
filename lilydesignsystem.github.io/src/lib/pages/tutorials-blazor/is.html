Blazor-kennsluefni

Razor-klasasafnsíhlutir með færibreytum, ChildContent birtingarbrotum, eigindadreifingu og bUnit-prófi fyrir hvern íhlut.

Það sem þú munt byggja

Lítið tengiliðaeyðublað — innsláttarreitur með merkimiða, sendihnappur, @bind-Value binding, raunveruleg lyklaborðs- og skjálesarahegðun — fyrst ber, svo stílað, á um 10 mínútum.

Áður en þú byrjar

Þú þarft git og .NET SDK 8 eða nýrra. Hvaða Blazor verkefni sem er virkar — Blazor Web App, Server eða WebAssembly.

Skref 1 — Náðu í kóðann

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-blazor-headless
dotnet build
dotnet test      # bUnit — 1,400+ cases across the catalog

Íhlutirnir eru í src/LilyBlazorHeadless/Components/ — Button.razor, TextInput.razor — ein Razor-skrá hver. Vísaðu í verkefnið (eða afritaðu skrárnar) úr Blazor-forritinu þínu og bættu við @using LilyBlazorHeadless.Components í _Imports.razor.

Skref 2 — Fyrsti íhluturinn þinn

<Button OnClick="Save">Save</Button>

Birtir <button class="button">. Sameiginlegar færibreytuvenjur: Label ( aria-label yfirskrift), CssClass (bætt við grunnkrókinn), ChildContentog [Parameter(CaptureUnmatchedValues = true)] eigindadreifing svo að hvaða aukaeigind HTML sem er fari í gegn.

Skref 3 — Settu saman lítið eyðublað

<Form OnSubmit="HandleSubmit">
  <Field Label="Full name" Required="true">
    <TextInput Id="name" Label="Full name" @bind-Value="name" Required="true" />
  </Field>
  <Button Type="submit">Save</Button>
</Form>

@code {
  private string name = "";
}

Field tekur sýnilega Label sem sína eigin færibreytu frekar en innfelldan merkimiðaíhlut — gefðu hana einu sinni, á Fieldog TextInputá Label sér um aðgengilega heitið.

Staðfest 2026-08-29: fyrri drög innfeldu sérstakan Label íhlut inni í Field, sem birtir tvo merkimiða (annan tóman) því Field birtir þegar sinn eigin út frá Label færibreyta — uppgötvað með því að athuga frumkóða íhlutarins; Form hefur enga eigin Label færibreytu, svo notkun fyrri draga á <Form> var leiðrétt með því að sleppa henni frekar en að búa til eigind sem er ekki til. Sá samsetta tengiliðaeyðublaðsleiðin er sama mynstur, prófað með raunverulegum e2e- og axe-prófum.

Athugaðu verkið: keyrðu forritið og eyðublaðið lítur einfalt út — nákvæmlega eins og ætlað er: stíllinn er enn framundan. Ýttu á Tab: fókusinn færist í gegnum hverja stýringu, merkimiðinn er lesinn upp og sending virkar. Hegðunin er tilbúin; útlitið er þitt og er næst.

Skref 4 — Stílaðu það

Stílaðu klasakrókana — .button, .text-input, .label, .field — í app.css, eða tengdu tilbúið þema í App.razor / index.html: 

<link rel="stylesheet" href="themes/wireframe.css" />

Skref 5 — Sjáðu allt virka

Blazor Web dæmaforritið sýnir allt safnið stílað og sýnt, með Playwright e2e-prófum: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-blazor-web-examples
dotnet run --project src/LilyBlazorWebExamples

Næstu skref

  • Þemu — skipti á keyrslutíma með Blazor theme-picker hjálpartækinu (Razor-klasasafn á NuGet).
  • Stillingahjálpartæki — tungumál og textastærð.
  • Íhlutasafn — eiginleikar, ARIA og lyklaborð fyrir hvern íhlut.

Spurningar á leiðinni? hjálparsíðan er full af svörum — og ef skref gæti verið skýrara, segðu okkur og við bætum kennsluefnið með ánægju.
