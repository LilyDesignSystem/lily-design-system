Blazor ટ્યુટોરિયલ

પેરામીટર સાથેના Razor ક્લાસ લાઇબ્રેરી ઘટકો, ChildContent રેન્ડર ફ્રેગમેન્ટ, ગુણધર્મ ફેલાવો અને દરેક ઘટક માટે એક bUnit પરીક્ષણ.

તમે શું બનાવશો

એક નાનું સંપર્ક ફોર્મ — લેબલ સાથેનું ક્ષેત્ર, સબમિટ બટન, @bind-Value બાઇન્ડિંગ, સાચું કીબોર્ડ અને સ્ક્રીન-રીડર વર્તન — પહેલાં સાદું, પછી શૈલીબદ્ધ, લગભગ 10 મિનિટમાં.

શરૂ કરતા પહેલાં

તમને git અને .NET SDK 8 કે નવું જોઈએ. કોઈ પણ Blazor પ્રોજેક્ટ ચાલશે — Blazor Web App, Server અથવા WebAssembly.

પગલું 1 — કોડ મેળવો

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-blazor-headless
dotnet build
dotnet test      # bUnit — 1,400+ cases across the catalog

ઘટકો અહીં રહે છે: src/LilyBlazorHeadless/Components/ — Button.razor, TextInput.razor — દરેક માટે એક Razor ફાઇલ. તમારી Blazor એપમાંથી પ્રોજેક્ટનો સંદર્ભ આપો (અથવા ફાઇલો કૉપી કરો) અને ઉમેરો @using LilyBlazorHeadless.Components માં _Imports.razor.

પગલું 2 — તમારો પહેલો ઘટક

<Button OnClick="Save">Save</Button>

આ દર્શાવે છે <button class="button">. વહેંચાયેલા પેરામીટર નિયમો: Label (એક aria-label ઓવરરાઇડ કરવા), CssClass (મૂળ હૂકમાં ઉમેરાય છે), ChildContentઅને [Parameter(CaptureUnmatchedValues = true)] ગુણધર્મ ફેલાવો જેથી કોઈ પણ વધારાનો HTML ગુણધર્મ પસાર થાય.

પગલું 3 — એક નાનું ફોર્મ બનાવો

<Form OnSubmit="HandleSubmit">
  <Field Label="Full name" Required="true">
    <TextInput Id="name" Label="Full name" @bind-Value="name" Required="true" />
  </Field>
  <Button Type="submit">Save</Button>
</Form>

@code {
  private string name = "";
}

Field દેખાતા Label ને પોતાના પેરામીટર તરીકે લે છે, અંદર મૂકેલા લેબલ ઘટક તરીકે નહીં — તેને એક વાર આપો, પર Fieldઅને TextInputનું Label સુલભ નામ પૂરું પાડે છે.

2026-08-29 ના રોજ ચકાસ્યું: અગાઉના મુસદ્દાએ અલગ Label ઘટકને Fieldની અંદર મૂક્યો હતો, જેનાથી બે લેબલ (એક ખાલી) દેખાયા કારણ કે Field પહેલેથી પોતાનું Label પેરામીટર — ઘટકનો સ્રોત કોડ તપાસીને ખબર પડી; Form ને પોતાને Label પેરામીટર નથી, તેથી અગાઉના મુસદ્દાના <Form> ઉપયોગને તેને છોડીને સુધારવામાં આવ્યો, જે ગુણધર્મ અસ્તિત્વમાં નથી તે ઘડવાને બદલે. સંયુક્ત સંપર્ક-ફોર્મ રૂટ એ જ પેટર્ન છે, સાચા e2e અને axe પરીક્ષણોથી ચકાસાયેલ.

તમારું કામ તપાસો: એપ ચલાવો અને ફોર્મ સાદું દેખાય છે — બરાબર ધાર્યા મુજબ: શૈલી હજી આગળ છે. દબાવો Tab: ફોકસ દરેક નિયંત્રણમાંથી પસાર થાય છે, લેબલ જાહેર થાય છે અને સબમિટ કામ કરે છે. વર્તન પૂર્ણ છે; દેખાવ તમારો છે અને આગલું પગલું છે.

પગલું 4 — તેને શૈલી આપો

ક્લાસ હૂકને શૈલી આપો — .button, .text-input, .label, .field — આમાં app.css, અથવા તૈયાર થીમ અહીં લિંક કરો App.razor / index.html: 

<link rel="stylesheet" href="themes/wireframe.css" />

પગલું 5 — બધું કામ કરતું જુઓ

Blazor Web ઉદાહરણ એપ સંપૂર્ણ કેટલોગ શૈલીબદ્ધ અને નિદર્શન સાથે દર્શાવે છે, Playwright e2e પરીક્ષણો સાથે: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-blazor-web-examples
dotnet run --project src/LilyBlazorWebExamples

આગળનાં પગલાં

  • થીમ — Blazor theme-picker સહાયક સાથે ચાલતી વખતે બદલવું (NuGet પર Razor ક્લાસ લાઇબ્રેરી).
  • પસંદગી સહાયકો — ભાષા અને લખાણનું કદ.
  • ઘટક કેટલોગ — દરેક ઘટક માટે ગુણધર્મો, ARIA અને કીબોર્ડ.

રસ્તામાં પ્રશ્નો છે? મદદ પૃષ્ઠ જવાબોથી ભરેલું છે — અને જો કોઈ પગલું વધુ સ્પષ્ટ થઈ શકે, અમને કહો અને અમે ખુશીથી ટ્યુટોરિયલ સુધારીશું.
