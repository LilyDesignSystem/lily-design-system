Vodnik za Blazor

Komponente knjižnice razredov Razor s parametri, ChildContent fragmenti izrisovanja, razprševanje atributov in en test bUnit na komponento.

Kaj boste ustvarili

Majhen kontaktni obrazec — polje z oznako, gumb za pošiljanje, @bind-Value vezava, resnično vedenje tipkovnice in bralnika zaslona — najprej gol, nato oblikovan, v približno 10 minutah.

Preden začnete

Potrebujete git in .NET SDK 8 ali novejši. Primeren je vsak projekt Blazor — Blazor Web App, Server ali WebAssembly.

Korak 1 — Pridobite kodo

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-blazor-headless
dotnet build
dotnet test      # bUnit — 1,400+ cases across the catalog

Komponente so v src/LilyBlazorHeadless/Components/ — Button.razor, TextInput.razor — po ena datoteka Razor. Sklicujte se na projekt (ali kopirajte datoteke) iz svoje aplikacije Blazor in dodajte @using LilyBlazorHeadless.Components v _Imports.razor.

Korak 2 — Vaša prva komponenta

<Button OnClick="Save">Save</Button>

Izriše <button class="button">. Skupne konvencije parametrov: Label ( aria-label za preglasitev), CssClass (doda se osnovnemu kavlju), ChildContentin [Parameter(CaptureUnmatchedValues = true)] razprševanje atributov, tako da gre skozi vsak dodaten atribut HTML.

Korak 3 — Sestavite majhen obrazec

<Form OnSubmit="HandleSubmit">
  <Field Label="Full name" Required="true">
    <TextInput Id="name" Label="Full name" @bind-Value="name" Required="true" />
  </Field>
  <Button Type="submit">Save</Button>
</Form>

@code {
  private string name = "";
}

Field sprejme vidno Label kot lasten parameter namesto gnezdene komponente oznake — posredujte jo enkrat, pri Fieldin TextInputiz Label zagotovi dostopno ime.

Preverjeno 2026-08-29: prejšnji osnutek je gnezdil ločeno komponento Label znotraj Field, kar je izrisalo dve oznaki (eno prazno), ker Field že izriše svojo iz vhoda Label parameter — odkrito s pregledom izvorne kode komponente; Form sam nima parametra Label , zato je bila uporaba <Form> iz prejšnjega osnutka popravljena z opustitvijo, namesto da bi si izmislili atribut, ki ne obstaja. Sestavljena pot kontaktnega obrazca je isti vzorec, preizkušen z resničnimi testi e2e in axe.

Preverite svoje delo: zaženite aplikacijo in obrazec je videti gol — natanko kot je bilo načrtovano: oblikovanje šele sledi. Pritisnite Tab: fokus gre skozi vsak kontrolnik, oznaka se izgovori in pošiljanje deluje. Vedenje je končano; videz je vaš in je naslednji korak.

Korak 4 — Oblikujte ga

Oblikujte razredne kavlje — .button, .text-input, .label, .field — v app.cssali povežite že pripravljeno temo v App.razor / index.html: 

<link rel="stylesheet" href="themes/wireframe.css" />

Korak 5 — Poglejte, kako vse deluje

Vzorčna aplikacija Blazor Web prikazuje celoten katalog oblikovan in predstavljen, s testi e2e Playwright: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-blazor-web-examples
dotnet run --project src/LilyBlazorWebExamples

Naslednji koraki

  • Teme — preklapljanje med izvajanjem s pomočnikom theme-picker za Blazor (knjižnica razredov Razor na NuGetu).
  • Pomočniki za nastavitve — jezik in velikost besedila.
  • Katalog komponent — lastnosti, ARIA in tipkovnica za vsako komponento.

Vprašanja na poti? Stran s pomočjo je polna odgovorov — in če bi bil kakšen korak lahko jasnejši, sporočite nam in vodnik bomo z veseljem izboljšali.
