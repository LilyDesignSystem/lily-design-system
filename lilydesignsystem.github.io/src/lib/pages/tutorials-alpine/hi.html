Alpine.js ट्यूटोरियल

Alpine के लिए Lily वे HTML स्निपेट हैं जिन्हें आप अपने पेज में चिपकाते हैं, साथ में एक प्लगइन जो इंटरैक्टिव कॉम्पोनेंट को उनका कीबोर्ड और स्थिति देता है।

आप क्या बनाएँगे

एक छोटा सेटिंग फ़ॉर्म: दो लेबल वाले फ़ील्ड, एक स्विच और एक सेव बटन, असली कीबोर्ड और स्क्रीन रीडर व्यवहार के साथ, पहले सादा, फिर स्टाइल किया हुआ, लगभग 10 मिनट में।

शुरू करने से पहले

आपको Node.js और ऐसा पेज चाहिए जो पहले से Alpine.js 3 लोड करता हो। Alpine में कॉम्पोनेंट मॉडल नहीं है, इसलिए यहाँ Lily कॉम्पोनेंट वह मार्कअप है जिसे आप कॉपी करते हैं, इम्पोर्ट नहीं।

चरण 1 — प्लगइन इंस्टॉल और रजिस्टर करें

npm install alpinejs @lilydesignsystem/alpine-headless
<script type="module">
  import Alpine from "alpinejs";
  import lily from "@lilydesignsystem/alpine-headless/plugin";
  Alpine.plugin(lily);
  Alpine.start();
</script>

प्लगइन हर इंटरैक्टिव कॉम्पोनेंट के लिए एक Alpine.data() व्यवहार रजिस्टर करता है, जिसका नाम lily के बाद कॉम्पोनेंट का नाम है: lilySwitchButton, lilyTabs, lilyCombobox। हर कॉम्पोनेंट के स्निपेट पैकेज के components/ फ़ोल्डर में हैं, हर एक के ऊपर एक टिप्पणी जो उसका एलिमेंट, क्लास हुक, कुंजियाँ और ARIA बताती है।

चरण 2 — आपका पहला कॉम्पोनेंट

ज़्यादातर कॉम्पोनेंट सादा मार्कअप हैं और उन्हें प्लगइन की ज़रूरत नहीं:

<button class="button" type="submit">Save</button>

इंटरैक्टिव कॉम्पोनेंट अपना व्यवहार x-data से जोड़ता है और उसे x-bindसे बाँधता है:

<button
  class="switch-button"
  x-data="lilySwitchButton(false)"
  x-bind="button"
  aria-label="Email me about appointments"
>
  Email me about appointments
</button>

व्यवहार उसे role="switch" देता है और aria-checked को अद्यतन रखता है जब Enter, Space या क्लिक उसे बदलते हैं। शब्द आपके हैं: Lily कभी लेबल नहीं देता।

चरण 3 — एक छोटा फ़ॉर्म बनाएँ

<form class="form" aria-label="Settings">
  <div class="field">
    <label class="label" for="name">Full name</label>
    <input class="text-input" type="text" id="name" name="name" autocomplete="name" required />
  </div>
  <div class="field">
    <label class="label" for="email">Email</label>
    <input class="email-input" type="email" id="email" name="email" autocomplete="email" required />
  </div>
  <button
    class="switch-button"
    type="button"
    x-data="lilySwitchButton(true)"
    x-bind="button"
    aria-label="Email me about appointments"
  >
    Email me about appointments
  </button>
  <button class="button" type="submit">Save</button>
</form>

अपना काम जाँचें: पेज खोलें और दबाएँ Tab। फ़ोकस दोनों फ़ील्ड, स्विच और बटन से होकर जाता है। स्विच पर Space उसे बदलता है, और स्क्रीन रीडर "स्विच, चालू" या "बंद" कहता है। यह सादा दिखता है, और यही सही है: रूप अगला है।

चरण 4 — स्टाइल दें

63 तैयार थीम में से एक लिंक करें, जो उन्हीं क्लास हुक को लक्ष्य करती हैं:

<link rel="stylesheet" href="/themes/light.css" />

या हुक और व्यवहार द्वारा सेट स्थिति पर अपना CSS लिखें:

.switch-button[aria-checked="true"] { background: var(--color-primary); }
.switch-button:focus-visible { outline: 2px solid var(--lily-focus-ring); outline-offset: 2px; }

ARIA स्थिति को स्टाइल करें, अपनी कोई क्लास नहीं: तब रूप कभी उससे अलग नहीं होगा जो स्क्रीन रीडर सुनता है।

चरण 5 — सब कुछ काम करते देखें

  • Alpine.js उदाहरण ऐप, lily-design-system-alpine-examples, हर कॉम्पोनेंट को स्टाइल के साथ दिखाता है: pnpm install && pnpm run build।
  • Alpine के लिए छह हेल्पर हैं: डेटा ग्रिड, कानबन बोर्ड, कैलेंडर, गैंट चार्ट और Markdown व Org एडिटर (@lilydesignsystem/alpine-*)।
