Tiwtorial Alpine.js

Pytiau HTML rydych chi'n eu gludo i'ch tudalen yw Lily ar gyfer Alpine, ynghyd ag un ategyn sy'n rhoi eu bysellfwrdd a'u cyflwr i'r rhai rhyngweithiol.

Beth fyddwch chi'n ei adeiladu

Ffurflen gosodiadau fach: dau faes wedi'u labelu, switsh, a botwm cadw, gydag ymddygiad bysellfwrdd a darllenydd sgrin go iawn, yn foel yn gyntaf, yna wedi'i steilio, mewn tua 10 munud.

Cyn i chi ddechrau

Mae angen Node.js arnoch a thudalen sydd eisoes yn llwytho Alpine.js 3. Nid oes model cydrannau gan Alpine, felly yma marcio rydych chi'n ei gopïo yw cydran Lily, nid mewnforyn.

Cam 1 — Gosod a chofrestru'r ategyn

npm install alpinejs @lilydesignsystem/alpine-headless
<script type="module">
  import Alpine from "alpinejs";
  import lily from "@lilydesignsystem/alpine-headless/plugin";
  Alpine.plugin(lily);
  Alpine.start();
</script>

Mae'r ategyn yn cofrestru un ymddygiad Alpine.data() i bob cydran ryngweithiol, o'r enw lily ac enw'r gydran: lilySwitchButton, lilyTabs, lilyCombobox. Mae pytiau pob cydran yn ffolder components/ y pecyn, pob un â sylw pennyn sy'n rhoi ei elfen, ei fachyn dosbarth, ei fysellau a'i ARIA.

Cam 2 — Eich cydran gyntaf

Marcio plaen yw'r rhan fwyaf o gydrannau, heb angen dim gan yr ategyn:

<button class="button" type="submit">Save</button>

Mae un ryngweithiol yn ychwanegu ei hymddygiad gyda x-data ac yn ei rwymo gyda x-bind:

<button
  class="switch-button"
  x-data="lilySwitchButton(false)"
  x-bind="button"
  aria-label="Email me about appointments"
>
  Email me about appointments
</button>

Mae'r ymddygiad yn rhoi role="switch" iddi ac yn cadw aria-checked yn gyfredol wrth i Enter, Bylchwr neu glic ei droi. Eich geiriau chi ydyn nhw: nid yw Lily byth yn rhoi label.

Cam 3 — Cyfansoddi ffurflen fach

<form class="form" aria-label="Settings">
  <div class="field">
    <label class="label" for="name">Full name</label>
    <input class="text-input" type="text" id="name" name="name" autocomplete="name" required />
  </div>
  <div class="field">
    <label class="label" for="email">Email</label>
    <input class="email-input" type="email" id="email" name="email" autocomplete="email" required />
  </div>
  <button
    class="switch-button"
    type="button"
    x-data="lilySwitchButton(true)"
    x-bind="button"
    aria-label="Email me about appointments"
  >
    Email me about appointments
  </button>
  <button class="button" type="submit">Save</button>
</form>

Gwiriwch eich gwaith: agorwch y dudalen a phwyswch Tab. Mae'r ffocws yn symud drwy'r ddau faes, y switsh a'r botwm. Ar y switsh, mae Space yn ei droi, ac mae darllenydd sgrin yn dweud "switsh, ymlaen" neu "i ffwrdd". Mae'n edrych yn blaen, sy'n gywir: mae'r olwg yn dod nesaf.

Cam 4 — Ei steilio

Cysylltwch un o'r 63 thema barod, sy'n targedu'r un bachau dosbarth:

<link rel="stylesheet" href="/themes/light.css" />

Neu ysgrifennwch eich CSS eich hun yn erbyn y bachau a'r cyflwr y mae'r ymddygiad yn ei osod:

.switch-button[aria-checked="true"] { background: var(--color-primary); }
.switch-button:focus-visible { outline: 2px solid var(--lily-focus-ring); outline-offset: 2px; }

Steiliwch y cyflwr ARIA, nid dosbarth eich hun: wedyn ni all yr olwg fyth anghytuno â'r hyn y mae darllenydd sgrin yn ei glywed.

Cam 5 — Gweld y cyfan yn gweithio

  • Mae'r ap enghreifftiol Alpine.js, lily-design-system-alpine-examples, yn dangos pob cydran wedi'i steilio: pnpm install && pnpm run build.
  • Mae chwe chynorthwyydd ar gyfer Alpine: y grid data, y bwrdd kanban, y calendr, y siart Gantt a'r golygyddion Markdown ac Org (@lilydesignsystem/alpine-*).
