Alpine.js টিউটোরিয়াল

Alpine-এর জন্য Lily হলো HTML স্নিপেট যা আপনি পাতায় বসান, সঙ্গে একটি প্লাগইন যা ইন্টারঅ্যাকটিভ কম্পোনেন্টগুলোকে কীবোর্ড আর অবস্থা দেয়।

আপনি কী বানাবেন

একটি ছোট সেটিংস ফর্ম: দুটি লেবেলযুক্ত ঘর, একটি সুইচ আর একটি সংরক্ষণ বোতাম, আসল কীবোর্ড ও স্ক্রিন রিডার আচরণসহ, প্রথমে সাদামাটা, তারপর স্টাইল করা, প্রায় ১০ মিনিটে।

শুরু করার আগে

আপনার Node.js এবং এমন একটি পাতা লাগবে যা আগে থেকেই Alpine.js 3 লোড করে। Alpine-এ কম্পোনেন্ট মডেল নেই, তাই এখানে Lily কম্পোনেন্ট হলো কপি করা মার্কআপ, ইমপোর্ট নয়।

ধাপ ১ — প্লাগইন ইনস্টল ও নিবন্ধন করুন

npm install alpinejs @lilydesignsystem/alpine-headless
<script type="module">
  import Alpine from "alpinejs";
  import lily from "@lilydesignsystem/alpine-headless/plugin";
  Alpine.plugin(lily);
  Alpine.start();
</script>

প্লাগইন প্রতিটি ইন্টারঅ্যাকটিভ কম্পোনেন্টের জন্য একটি Alpine.data() আচরণ নিবন্ধন করে, যার নাম lily এবং তারপর কম্পোনেন্টের নাম: lilySwitchButton, lilyTabs, lilyCombobox। প্রতিটি কম্পোনেন্টের স্নিপেট প্যাকেজের components/ ফোল্ডারে আছে, প্রতিটির শুরুতে একটি মন্তব্য যা তার এলিমেন্ট, ক্লাস হুক, কী ও ARIA জানায়।

ধাপ ২ — আপনার প্রথম কম্পোনেন্ট

বেশিরভাগ কম্পোনেন্ট সাধারণ মার্কআপ, প্লাগইনের কিছু লাগে না:

<button class="button" type="submit">Save</button>

ইন্টারঅ্যাকটিভ কম্পোনেন্ট তার আচরণ যোগ করে x-data দিয়ে এবং বাঁধে x-bindদিয়ে:

<button
  class="switch-button"
  x-data="lilySwitchButton(false)"
  x-bind="button"
  aria-label="Email me about appointments"
>
  Email me about appointments
</button>

আচরণটি তাকে role="switch" দেয় এবং aria-checked হালনাগাদ রাখে যখন Enter, Space বা ক্লিক তা বদলায়। শব্দগুলো আপনার: Lily কখনো লেবেল দেয় না।

ধাপ ৩ — একটি ছোট ফর্ম তৈরি করুন

<form class="form" aria-label="Settings">
  <div class="field">
    <label class="label" for="name">Full name</label>
    <input class="text-input" type="text" id="name" name="name" autocomplete="name" required />
  </div>
  <div class="field">
    <label class="label" for="email">Email</label>
    <input class="email-input" type="email" id="email" name="email" autocomplete="email" required />
  </div>
  <button
    class="switch-button"
    type="button"
    x-data="lilySwitchButton(true)"
    x-bind="button"
    aria-label="Email me about appointments"
  >
    Email me about appointments
  </button>
  <button class="button" type="submit">Save</button>
</form>

আপনার কাজ যাচাই করুন: পাতাটি খুলে চাপুন Tab। ফোকাস দুটি ঘর, সুইচ ও বোতামের মধ্য দিয়ে যায়। সুইচে Space চাপলে তা বদলায়, আর স্ক্রিন রিডার বলে "সুইচ, চালু" বা "বন্ধ"। এটি সাদামাটা দেখায়, এবং সেটাই ঠিক: চেহারা পরের ধাপে।

ধাপ ৪ — স্টাইল দিন

৬৩টি তৈরি থিমের একটি লিঙ্ক করুন, যেগুলো একই ক্লাস হুক লক্ষ্য করে:

<link rel="stylesheet" href="/themes/light.css" />

অথবা হুক আর আচরণের স্থির করা অবস্থার ওপর নিজের CSS লিখুন:

.switch-button[aria-checked="true"] { background: var(--color-primary); }
.switch-button:focus-visible { outline: 2px solid var(--lily-focus-ring); outline-offset: 2px; }

ARIA অবস্থাকে স্টাইল দিন, নিজের কোনো ক্লাস নয়: তাহলে চেহারা কখনো স্ক্রিন রিডারের শোনা কথার সঙ্গে অমিল হবে না।

ধাপ ৫ — সব কিছু চলতে দেখুন

  • Alpine.js উদাহরণ অ্যাপ, lily-design-system-alpine-examples, প্রতিটি কম্পোনেন্ট স্টাইলসহ দেখায়: pnpm install && pnpm run build।
  • Alpine-এর জন্য ছয়টি সহায়ক আছে: ডেটা গ্রিড, কানবান বোর্ড, ক্যালেন্ডার, গ্যান্ট চার্ট এবং Markdown ও Org সম্পাদক (@lilydesignsystem/alpine-*)।
