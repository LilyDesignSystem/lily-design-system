Alpine.js ٹیوٹوریل

Alpine کے لیے Lily وہ HTML ٹکڑے ہیں جو آپ اپنے صفحے میں چسپاں کرتے ہیں، اور ایک پلگ ان جو تعاملی اجزاء کو ان کا کی بورڈ اور حالت دیتا ہے۔

آپ کیا بنائیں گے

ایک چھوٹا ترتیبات فارم: دو لیبل والے خانے، ایک سوئچ اور ایک محفوظ کرنے کا بٹن، حقیقی کی بورڈ اور اسکرین ریڈر رویّے کے ساتھ، پہلے سادہ، پھر اسٹائل شدہ، تقریباً 10 منٹ میں۔

شروع کرنے سے پہلے

آپ کو Node.js اور ایسا صفحہ چاہیے جو پہلے سے Alpine.js 3 لوڈ کرتا ہو۔ Alpine میں اجزاء کا ماڈل نہیں، اس لیے یہاں Lily جزو وہ مارک اپ ہے جو آپ نقل کرتے ہیں، امپورٹ نہیں۔

مرحلہ 1 — پلگ ان انسٹال اور رجسٹر کریں

npm install alpinejs @lilydesignsystem/alpine-headless
<script type="module">
  import Alpine from "alpinejs";
  import lily from "@lilydesignsystem/alpine-headless/plugin";
  Alpine.plugin(lily);
  Alpine.start();
</script>

پلگ ان ہر تعاملی جزو کے لیے ایک Alpine.data() رویّہ رجسٹر کرتا ہے، جس کا نام lily کے بعد جزو کا نام ہے: lilySwitchButton، lilyTabs، lilyCombobox۔ ہر جزو کے ٹکڑے پیکیج کے components/ فولڈر میں ہیں، ہر ایک کے اوپر ایک تبصرہ جو اس کا عنصر، کلاس ہک، کلیدیں اور ARIA بتاتا ہے۔

مرحلہ 2 — آپ کا پہلا جزو

زیادہ تر اجزاء سادہ مارک اپ ہیں اور انہیں پلگ ان سے کچھ نہیں چاہیے:

<button class="button" type="submit">Save</button>

تعاملی جزو اپنا رویّہ x-data سے جوڑتا ہے اور اسے x-bindسے باندھتا ہے:

<button
  class="switch-button"
  x-data="lilySwitchButton(false)"
  x-bind="button"
  aria-label="Email me about appointments"
>
  Email me about appointments
</button>

رویّہ اسے role="switch" دیتا ہے اور aria-checked کو تازہ رکھتا ہے جب Enter، Space یا کلک اسے بدلتے ہیں۔ الفاظ آپ کے ہیں: Lily کبھی لیبل نہیں دیتا۔

مرحلہ 3 — ایک چھوٹا فارم بنائیں

<form class="form" aria-label="Settings">
  <div class="field">
    <label class="label" for="name">Full name</label>
    <input class="text-input" type="text" id="name" name="name" autocomplete="name" required />
  </div>
  <div class="field">
    <label class="label" for="email">Email</label>
    <input class="email-input" type="email" id="email" name="email" autocomplete="email" required />
  </div>
  <button
    class="switch-button"
    type="button"
    x-data="lilySwitchButton(true)"
    x-bind="button"
    aria-label="Email me about appointments"
  >
    Email me about appointments
  </button>
  <button class="button" type="submit">Save</button>
</form>

اپنا کام جانچیں: صفحہ کھولیں اور دبائیں Tab۔ فوکس دونوں خانوں، سوئچ اور بٹن سے گزرتا ہے۔ سوئچ پر Space اسے بدلتا ہے، اور اسکرین ریڈر "سوئچ، آن" یا "آف" کہتا ہے۔ یہ سادہ دکھتا ہے، اور یہی درست ہے: شکل اگلی ہے۔

مرحلہ 4 — اسٹائل دیں

63 تیار تھیمز میں سے ایک کو لنک کریں، جو انہی کلاس ہکس کو نشانہ بناتی ہیں:

<link rel="stylesheet" href="/themes/light.css" />

یا ہکس اور رویّے کی طے کردہ حالت پر اپنا CSS لکھیں:

.switch-button[aria-checked="true"] { background: var(--color-primary); }
.switch-button:focus-visible { outline: 2px solid var(--lily-focus-ring); outline-offset: 2px; }

ARIA حالت کو اسٹائل دیں، اپنی کوئی کلاس نہیں: تب شکل کبھی اس سے مختلف نہیں ہوگی جو اسکرین ریڈر سنتا ہے۔

مرحلہ 5 — سب کچھ کام کرتا دیکھیں

  • Alpine.js کی مثالی ایپ، lily-design-system-alpine-examples، ہر جزو کو اسٹائل کے ساتھ دکھاتی ہے: pnpm install && pnpm run build۔
  • Alpine کے لیے چھ معاون ہیں: ڈیٹا گرڈ، کانبان بورڈ، کیلنڈر، گینٹ چارٹ، اور Markdown و Org ایڈیٹر (@lilydesignsystem/alpine-*‏)۔
