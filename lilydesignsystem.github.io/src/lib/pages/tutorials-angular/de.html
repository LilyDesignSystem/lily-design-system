Angular-Tutorial

Angular-20-Standalone-Komponenten — Signal-Inputs, OnPush-Änderungserkennung, Inline-Templates, null NgModules, null CSS.

Was du baust

Ein kleines Kontaktformular — beschriftetes Eingabefeld, Absenden-Schaltfläche, Zwei-Wege-Bindung, echtes Tastatur- und Screenreader-Verhalten — zuerst nackt, dann gestaltet, in etwa 10 Minuten.

Bevor du anfängst

Du brauchst git, Node 22 oder neuer und pnpm 10 oder neuer. Jedes Angular-20-Projekt funktioniert — Angular CLI oder Analog.

Schritt 1 — Den Code holen

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-angular-headless
pnpm install
pnpm test        # vitest + TestBed, all 571 components
pnpm run build-storybook

Die Komponenten sind flache Dateien in components/ — Button.ts, TextInput.ts — jede ist eine Standalone-Komponente mit Inline-Template, dazu ihre Spec und ihre Story. Das Barrel index.ts exportiert jede Komponente erneut; pnpm build erzeugt über ng-packagr ein Bundle im Angular Package Format.

Schritt 2 — Deine erste Komponente

import { Component } from "@angular/core";
import { Button } from "@lilydesignsystem/angular-headless";

@Component({
  selector: "app-save-bar",
  standalone: true,
  imports: [Button],
  template: `<lily-button (click)="save()">Save</lily-button>`,
})
export class SaveBar {
  save() { console.log("saved"); }
}

Jede Komponente deklariert einen lily-* -Selektor und rendert das semantische Element mit ihrem Klassen-Hook — <button class="button" type="button"> hier. Die Inputs sind signalbasiert: label() für ein aria-label zum Überschreiben, className() zum Anhängen von Klassen.

Schritt 3 — Ein kleines Formular zusammensetzen

import { Component, signal } from "@angular/core";
import { Form, Field, TextInput, Button } from "@lilydesignsystem/angular-headless";

@Component({
  selector: "app-contact-form",
  standalone: true,
  imports: [Form, Field, TextInput, Button],
  template: `
    <lily-form label="Contact form" (submit)="handleSubmit($event)">
      <lily-field label="Full name" [required]="true">
        <lily-text-input id="name" label="Full name" [(value)]="name" />
      </lily-field>
      <lily-button type="submit">Save</lily-button>
    </lily-form>
  `,
})
export class ContactForm {
  name = signal("");
}

lily-field nimmt das sichtbare Label als eigenen label -Input entgegen statt als verschachtelte Label-Komponente — gib es einmal am Feld an, und das passende lily-text-inputvon label liefert den zugänglichen Namen. Eingabeähnliche Komponenten stellen model() -Werte bereit, daher funktioniert die banana-box [(value)] -Zwei-Wege-Bindung sofort — durchgehend zoneless-kompatibel.

Geprüft am 2026-08-29: ein früherer Entwurf verschachtelte eine separate Label -Komponente in lily-field, was zwei Labels (eines leer) rendert, weil lily-field bereits ein eigenes aus dem label -Input rendert — durch Prüfen des Komponenten-Quellcodes entdeckt. Die zusammengesetzte Kontaktformular-Route ist dasselbe Muster, getestet mit echten e2e- und axe-Tests.

Prüfe deine Arbeit: Starte die App, und das Formular sieht schlicht aus — genau wie beabsichtigt: Die Gestaltung kommt noch. Drücke Tab: Der Fokus wandert durch jedes Bedienelement, das Label wird angesagt und das Absenden funktioniert. Das Verhalten ist fertig; das Aussehen gehört dir und kommt als Nächstes.

Schritt 4 — Gestalten

Gestalte die Klassen-Hooks — .button, .text-input, .label, .field — in styles.css, oder füge ein fertiges Theme dem styles -Array in angular.json hinzu / binde es ein in index.html: 

<link rel="stylesheet" href="/themes/adobe-spectrum.css" />
