Angular-handleiding

Angular 20 standalone componenten — signal-inputs, OnPush-wijzigingsdetectie, inline templates, nul NgModules, nul CSS.

Wat je gaat bouwen

Een klein contactformulier — invoerveld met label, verzendknop, tweerichtingsbinding, echt toetsenbord- en schermlezergedrag — eerst kaal, dan vormgegeven, in ongeveer 10 minuten.

Voordat je begint

Je hebt git, Node 22 of nieuwer en pnpm 10 of nieuwer nodig. Elk Angular 20-project werkt — Angular CLI of Analog.

Stap 1 — Haal de code op

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-angular-headless
pnpm install
pnpm test        # vitest + TestBed, all 571 components
pnpm run build-storybook

De componenten zijn platte bestanden in components/ — Button.ts, TextInput.ts — elk is een standalone component met een inline template, plus zijn spec en story. De barrel index.ts exporteert elke component opnieuw; pnpm build maakt via ng-packagr een bundel in Angular Package Format.

Stap 2 — Je eerste component

import { Component } from "@angular/core";
import { Button } from "@lilydesignsystem/angular-headless";

@Component({
  selector: "app-save-bar",
  standalone: true,
  imports: [Button],
  template: `<lily-button (click)="save()">Save</lily-button>`,
})
export class SaveBar {
  save() { console.log("saved"); }
}

Elke component declareert een lily-* -selector en rendert het semantische element met zijn klassehaak — <button class="button" type="button"> hier. De inputs zijn op signals gebaseerd: label() voor een aria-label om te overschrijven, className() om klassen toe te voegen.

Stap 3 — Stel een klein formulier samen

import { Component, signal } from "@angular/core";
import { Form, Field, TextInput, Button } from "@lilydesignsystem/angular-headless";

@Component({
  selector: "app-contact-form",
  standalone: true,
  imports: [Form, Field, TextInput, Button],
  template: `
    <lily-form label="Contact form" (submit)="handleSubmit($event)">
      <lily-field label="Full name" [required]="true">
        <lily-text-input id="name" label="Full name" [(value)]="name" />
      </lily-field>
      <lily-button type="submit">Save</lily-button>
    </lily-form>
  `,
})
export class ContactForm {
  name = signal("");
}

lily-field neemt het zichtbare label als eigen label -input in plaats van een geneste labelcomponent — geef het één keer door, op het veld, en het bijbehorende lily-text-inputvan label levert de toegankelijke naam. Invoerachtige componenten maken model() -waarden beschikbaar, zodat banana-box [(value)] -tweerichtingsbinding meteen werkt — overal zoneless-compatibel.

Geverifieerd op 2026-08-29: een eerder concept nestelde een aparte Label -component in lily-field, wat twee labels (een leeg) rendert omdat lily-field zijn eigen label al rendert vanuit de label -input — ontdekt door de broncode van de component te controleren. De samengestelde contactformulierroute is hetzelfde patroon, beproefd met echte e2e- en axe-tests.

Controleer je werk: start de app en het formulier ziet er kaal uit — precies zoals bedoeld: de vormgeving komt nog. Druk op Tab: de focus beweegt door elk bedieningselement, het label wordt voorgelezen en verzenden werkt. Het gedrag is klaar; het uiterlijk is aan jou en komt hierna.

Stap 4 — Geef het vorm

Geef de klassehaken vorm — .button, .text-input, .label, .field — in styles.css, of voeg een kant-en-klaar thema toe aan de styles -array in angular.json / koppel het in index.html: 

<link rel="stylesheet" href="/themes/adobe-spectrum.css" />

Stap 5 — Zie alles werken

Angular + Analog voorbeeld-app toont de volledige catalogus met bestandsgebaseerde routering en Vite: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-angular-examples
pnpm install && pnpm run dev

Volgende stappen

  • Thema's — wisselen tijdens het draaien met de Angular-helper theme-picker.
  • Voorkeurenhelpers — taal en tekstgrootte.
  • Componentencatalogus — props, ARIA en toetsenbord per component.
