Návod pro Angular

Samostatné komponenty Angularu 20 — signálové vstupy, detekce změn OnPush, vložené šablony, nula NgModules, nula CSS.

Co vytvoříte

Malý kontaktní formulář — pole se štítkem, tlačítko odeslat, obousměrná vazba, skutečné chování klávesnice a čtečky obrazovky — nejprve holý, potom ostylovaný, zhruba za 10 minut.

Než začnete

Potřebujete git, Node 22 nebo novější a pnpm 10 nebo novější. Hodí se jakýkoli projekt Angular 20 — Angular CLI nebo Analog.

Krok 1 — Získejte kód

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-angular-headless
pnpm install
pnpm test        # vitest + TestBed, all 581 components
pnpm run build-storybook

Komponenty jsou ploché soubory v components/ — Button.ts, TextInput.ts — každá je samostatná komponenta s vloženou šablonou, plus její spec a story. Barrel index.ts znovu exportuje každou komponentu; pnpm build vytváří balíček ve formátu Angular Package Format přes ng-packagr.

Krok 2 — Vaše první komponenta

import { Component } from "@angular/core";
import { Button } from "@lilydesignsystem/angular-headless";

@Component({
  selector: "app-save-bar",
  standalone: true,
  imports: [Button],
  template: `<lily-button (click)="save()">Save</lily-button>`,
})
export class SaveBar {
  save() { console.log("saved"); }
}

Každá komponenta deklaruje selektor lily-* a vykresluje sémantický prvek s jeho třídním háčkem — <button class="button" type="button"> zde. Vstupy jsou založené na signálech: label() pro aria-label k přepsání, className() k přidání tříd.

Krok 3 — Sestavte malý formulář

import { Component, signal } from "@angular/core";
import { Form, Field, TextInput, Button } from "@lilydesignsystem/angular-headless";

@Component({
  selector: "app-contact-form",
  standalone: true,
  imports: [Form, Field, TextInput, Button],
  template: `
    <lily-form label="Contact form" (submit)="handleSubmit($event)">
      <lily-field label="Full name" [required]="true">
        <lily-text-input id="name" label="Full name" [(value)]="name" />
      </lily-field>
      <lily-button type="submit">Save</lily-button>
    </lily-form>
  `,
})
export class ContactForm {
  name = signal("");
}

lily-field přijímá viditelný štítek jako vlastní label vstup místo vnořené komponenty štítku — předejte ho jednou, u pole, a odpovídající lily-text-inputz label dodá přístupný název. Komponenty podobné vstupům zveřejňují hodnoty model() takže banana-box [(value)] obousměrná vazba funguje hned — kompatibilní se zoneless v celém rozsahu.

Ověřeno 2026-08-29: dřívější koncept vnořoval samostatnou komponentu Label dovnitř lily-field, což vykreslilo dva štítky (jeden prázdný), protože lily-field už vykresluje svůj vlastní ze vstupu label — zjištěno kontrolou zdrojového kódu komponenty. Složená trasa kontaktního formuláře je stejný vzor, prověřený skutečnými testy e2e a axe.

Zkontrolujte svou práci: spusťte aplikaci a formulář vypadá holě — přesně jak bylo zamýšleno: stylování teprve přijde. Stiskněte Tab: fokus prochází každým ovládacím prvkem, štítek se oznamuje a odeslání funguje. Chování je hotové; vzhled je váš a je další na řadě.

Krok 4 — Ostylujte ho

Ostylujte třídní háčky — .button, .text-input, .label, .field — v styles.css, nebo přidejte hotové téma do pole styles v angular.json / připojte ho v index.html: 

<link rel="stylesheet" href="/themes/adobe-spectrum.css" />

Krok 5 — Podívejte se, jak to celé funguje

Ukázková aplikace Angular + Analog ukazuje celý katalog s routováním založeným na souborech a Vite: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-angular-examples
pnpm install && pnpm run dev

Další kroky

  • Témata — přepínání za běhu pomocníkem theme-picker pro Angular.
  • Pomocníci pro předvolby — jazyk a velikost textu.
  • Katalog komponent — vlastnosti, ARIA a klávesnice pro každou komponentu.
