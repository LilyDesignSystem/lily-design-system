Посібник з Angular

Автономні компоненти Angular 20 — сигнальні входи, виявлення змін OnPush, вбудовані шаблони, жодних NgModules, жодного CSS.

Що ви створите

Невелика контактна форма — поле з міткою, кнопка надсилання, двостороннє зв’язування, справжня поведінка клавіатури та зчитувача екрана — спочатку «гола», потім стилізована, приблизно за 10 хвилин.

Перш ніж почати

Вам потрібні git, Node 22 або новіший і pnpm 10 або новіший. Підійде будь-який проєкт Angular 20 — Angular CLI або Analog.

Крок 1 — Отримайте код

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-angular-headless
pnpm install
pnpm test        # vitest + TestBed, all 571 components
pnpm run build-storybook

Компоненти — це плоскі файли в components/ — Button.ts, TextInput.ts — кожен є автономним компонентом із вбудованим шаблоном, а також своїми spec і story. Barrel index.ts реекспортує кожен компонент; pnpm build створює пакет Angular Package Format через ng-packagr.

Крок 2 — Ваш перший компонент

import { Component } from "@angular/core";
import { Button } from "@lilydesignsystem/angular-headless";

@Component({
  selector: "app-save-bar",
  standalone: true,
  imports: [Button],
  template: `<lily-button (click)="save()">Save</lily-button>`,
})
export class SaveBar {
  save() { console.log("saved"); }
}

Кожен компонент оголошує lily-* селектор і рендерить семантичний елемент зі своїм клас-гачком — <button class="button" type="button"> тут. Входи побудовані на сигналах: label() для aria-label перевизначення, className() щоб додавати класи.

Крок 3 — Складіть невелику форму

import { Component, signal } from "@angular/core";
import { Form, Field, TextInput, Button } from "@lilydesignsystem/angular-headless";

@Component({
  selector: "app-contact-form",
  standalone: true,
  imports: [Form, Field, TextInput, Button],
  template: `
    <lily-form label="Contact form" (submit)="handleSubmit($event)">
      <lily-field label="Full name" [required]="true">
        <lily-text-input id="name" label="Full name" [(value)]="name" />
      </lily-field>
      <lily-button type="submit">Save</lily-button>
    </lily-form>
  `,
})
export class ContactForm {
  name = signal("");
}

lily-field приймає видиму мітку як власний label вхід, а не як вкладений компонент мітки — передайте її один раз, на полі, і відповідний lily-text-inputу label надає доступну назву. Компоненти, схожі на поля введення, відкривають model() значення, тож banana-box [(value)] двостороннє зв’язування просто працює — сумісно з zoneless скрізь.

Перевірено 2026-08-29: ранній чернетковий варіант вкладав окремий компонент Label всередину lily-field, що рендерило дві мітки (одну порожню), оскільки lily-field уже рендерить власну з label входу — виявлено перевіркою вихідного коду компонента. складений маршрут контактної форми — той самий шаблон, перевірений справжніми e2e- та axe-тестами.

Перевірте свою роботу: запустіть застосунок — форма виглядає простою, саме як і задумано: стилізація ще попереду. Натисніть Tab: фокус проходить через кожен елемент керування, мітка озвучується, а надсилання працює. Поведінка готова; вигляд — ваш, і він наступний.

Крок 4 — Стилізуйте

Стилізуйте клас-гачки — .button, .text-input, .label, .field — у styles.css, або додайте готову тему до масиву styles у angular.json / підключіть її в index.html: 

<link rel="stylesheet" href="/themes/adobe-spectrum.css" />

Крок 5 — Побачте все в дії

Приклад застосунку Angular + Analog показує весь каталог із файловою маршрутизацією та Vite: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-angular-examples
pnpm install && pnpm run dev

Наступні кроки

  • Теми — перемикання під час виконання за допомогою допоміжного засобу Angular theme-picker.
  • Допоміжні засоби налаштувань — мова та розмір тексту.
  • Каталог компонентів — властивості, ARIA та клавіатура для кожного компонента.
