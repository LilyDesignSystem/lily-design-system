Angular 튜토리얼

Angular 20 스탠드얼론 컴포넌트 — 시그널 입력, OnPush 변경 감지, 인라인 템플릿, NgModule 없음, CSS 없음.

만들 것

작은 문의 폼 — 레이블이 있는 입력, 제출 버튼, 양방향 바인딩, 실제 키보드 및 스크린 리더 동작 — 먼저 꾸미지 않은 상태로, 그다음 스타일을 입혀서 약 10분 안에 만듭니다.

시작하기 전에

git, Node 22 이상, pnpm 10 이상이 필요합니다. Angular 20 프로젝트라면 무엇이든 괜찮습니다 — Angular CLI든 Analog든 상관없습니다.

1단계 — 코드 가져오기

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-angular-headless
pnpm install
pnpm test        # vitest + TestBed, all 571 components
pnpm run build-storybook

컴포넌트는 다음 위치에 평평한 파일로 있습니다: components/ — Button.ts, TextInput.ts — 각각 인라인 템플릿을 가진 스탠드얼론 컴포넌트이며, spec과 스토리가 함께 있습니다. 배럴 index.ts 은 모든 컴포넌트를 다시 내보냅니다. pnpm build 은 ng-packagr로 Angular Package Format 번들을 만듭니다.

2단계 — 첫 번째 컴포넌트

import { Component } from "@angular/core";
import { Button } from "@lilydesignsystem/angular-headless";

@Component({
  selector: "app-save-bar",
  standalone: true,
  imports: [Button],
  template: `<lily-button (click)="save()">Save</lily-button>`,
})
export class SaveBar {
  save() { console.log("saved"); }
}

모든 컴포넌트는 lily-* 셀렉터를 선언하고 클래스 훅이 붙은 의미 있는 요소를 렌더링합니다 — <button class="button" type="button"> 여기서는요. 입력은 시그널 기반입니다: label() 는 aria-label 재정의용, className() 는 클래스를 덧붙입니다.

3단계 — 작은 폼 구성하기

import { Component, signal } from "@angular/core";
import { Form, Field, TextInput, Button } from "@lilydesignsystem/angular-headless";

@Component({
  selector: "app-contact-form",
  standalone: true,
  imports: [Form, Field, TextInput, Button],
  template: `
    <lily-form label="Contact form" (submit)="handleSubmit($event)">
      <lily-field label="Full name" [required]="true">
        <lily-text-input id="name" label="Full name" [(value)]="name" />
      </lily-field>
      <lily-button type="submit">Save</lily-button>
    </lily-form>
  `,
})
export class ContactForm {
  name = signal("");
}

lily-field 은 중첩된 레이블 컴포넌트가 아니라 보이는 레이블을 별도의 label 입력으로 받습니다 — 필드에 한 번만 전달하면 lily-text-input의 대응하는 label 가 접근 가능한 이름을 제공합니다. 입력과 비슷한 컴포넌트는 model() 값을 노출하므로 banana-box [(value)] 양방향 바인딩이 그대로 동작합니다 — 전체가 zoneless와 호환됩니다.

2026-08-29 확인 완료: 이전 초안에서는 별도의 Label 컴포넌트를 lily-field안에 중첩했는데, 그러면 두 개의 레이블(하나는 비어 있음)이 렌더링되었습니다. lily-field 가 label 입력으로 자체 레이블을 이미 렌더링하기 때문입니다 — 컴포넌트 소스를 확인하다가 발견했습니다. 문의 폼 조합 라우트 도 같은 패턴이며, 실제 e2e 및 axe 테스트로 검증됩니다.

작동 확인: 앱을 실행하면 폼이 밋밋해 보입니다 — 의도한 대로이며 스타일은 앞으로 입힙니다. Tab키를 눌러 보세요. 포커스가 모든 컨트롤을 따라 이동하고, 레이블이 읽히며, 제출도 동작합니다. 동작은 완성되었고, 모양은 당신 몫이며 다음 단계입니다.

4단계 — 스타일 입히기

클래스 훅에 스타일을 입힙니다 — .button, .text-input, .label, .field — 다음 위치에서: styles.css, 또는 준비된 테마를 styles 배열에 추가하거나 angular.json / 다음 위치에서 링크합니다: index.html: 

<link rel="stylesheet" href="/themes/adobe-spectrum.css" />
