Angular-opas

Angular 20 -itsenäiset komponentit — signaalisyötteet, OnPush-muutostunnistus, sisäiset mallit, nolla NgModulea, nolla CSS:ää.

Mitä rakennat

Pieni yhteydenottolomake — nimiöity kenttä, lähetyspainike, kaksisuuntainen sidonta, aito näppäimistö- ja ruudunlukijakäyttäytyminen — ensin paljaana, sitten tyylitellen, noin 10 minuutissa.

Ennen kuin aloitat

Tarvitset gitin, Node 22:n tai uudemman ja pnpm 10:n tai uudemman. Mikä tahansa Angular 20 -projekti kelpaa — Angular CLI tai Analog.

Vaihe 1 — Hae koodi

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-angular-headless
pnpm install
pnpm test        # vitest + TestBed, all 581 components
pnpm run build-storybook

Komponentit ovat litteitä tiedostoja hakemistossa components/ — Button.ts, TextInput.ts — jokainen on itsenäinen komponentti, jossa on sisäinen malli, sekä sen spec ja story. Barrel index.ts vie kaikki komponentit uudelleen; pnpm build tuottaa Angular Package Format -paketin ng-packagrin kautta.

Vaihe 2 — Ensimmäinen komponenttisi

import { Component } from "@angular/core";
import { Button } from "@lilydesignsystem/angular-headless";

@Component({
  selector: "app-save-bar",
  standalone: true,
  imports: [Button],
  template: `<lily-button (click)="save()">Save</lily-button>`,
})
export class SaveBar {
  save() { console.log("saved"); }
}

Jokainen komponentti julistaa lily-* -valitsimen ja renderöi semanttisen elementin luokkakoukkuineen — <button class="button" type="button"> tässä. Syötteet perustuvat signaaleihin: label() elementille aria-label ohittamiseen, className() luokkien lisäämiseen.

Vaihe 3 — Kokoa pieni lomake

import { Component, signal } from "@angular/core";
import { Form, Field, TextInput, Button } from "@lilydesignsystem/angular-headless";

@Component({
  selector: "app-contact-form",
  standalone: true,
  imports: [Form, Field, TextInput, Button],
  template: `
    <lily-form label="Contact form" (submit)="handleSubmit($event)">
      <lily-field label="Full name" [required]="true">
        <lily-text-input id="name" label="Full name" [(value)]="name" />
      </lily-field>
      <lily-button type="submit">Save</lily-button>
    </lily-form>
  `,
})
export class ContactForm {
  name = signal("");
}

lily-field ottaa näkyvän nimiön omana label -syötteenään sisäkkäisen nimiökomponentin sijaan — välitä se kerran kentälle, niin vastaava lily-text-inputelementistä label antaa saavutettavan nimen. Syötteen kaltaiset komponentit paljastavat model() -arvot, joten banana-box [(value)] -kaksisuuntainen sidonta toimii heti — zoneless-yhteensopiva läpi koko.

Varmistettu 2026-08-29: aiempi luonnos sijoitti erillisen Label -komponentin elementin lily-fieldsisään, mikä renderöi kaksi nimiötä (toinen tyhjä), koska lily-field renderöi jo oman nimiönsä label -syötteestä — havaittu tarkistamalla komponentin lähdekoodi. Koottu yhteydenottolomakkeen reitti on sama malli, jota on koeteltu oikeilla e2e- ja axe-testeillä.

Tarkista työsi: käynnistä sovellus, ja lomake näyttää paljaalta — juuri niin kuin on tarkoitus: tyylittely on vielä edessä. Paina Tab: kohdistus liikkuu jokaisen ohjaimen läpi, nimiö ilmoitetaan ja lähettäminen toimii. Toiminta on valmis; ulkoasu on sinun ja seuraava vaihe.

Vaihe 4 — Tyylittele se

Tyylittele luokkakoukut — .button, .text-input, .label, .field — tiedostossa styles.css, tai lisää valmis teema taulukkoon styles tiedostossa angular.json / linkitä se tiedostossa index.html: 

<link rel="stylesheet" href="/themes/adobe-spectrum.css" />

Vaihe 5 — Katso kaiken toimivan

Angular + Analog -esimerkkisovellus näyttää koko luettelon tiedostopohjaisella reitityksellä ja Vitellä: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-angular-examples
pnpm install && pnpm run dev

Seuraavat askeleet

  • Teemat — vaihto ajon aikana Angularin theme-picker-apuvälineellä.
  • Asetusapuvälineet — kieli ja tekstikoko.
  • Komponenttiluettelo — ominaisuudet, ARIA ja näppäimistö komponenteittain.
