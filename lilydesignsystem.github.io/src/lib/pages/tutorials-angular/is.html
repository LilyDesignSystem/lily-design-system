Angular-kennsluefni

Sjálfstæðir Angular 20 íhlutir — merkjainntök, OnPush breytingagreining, innfelld sniðmát, engar NgModules, ekkert CSS.

Það sem þú munt byggja

Lítið tengiliðaeyðublað — innsláttarreitur með merkimiða, sendihnappur, tvíátta binding, raunveruleg lyklaborðs- og skjálesarahegðun — fyrst ber, svo stílað, á um 10 mínútum.

Áður en þú byrjar

Þú þarft git, Node 22 eða nýrra og pnpm 10 eða nýrra. Hvaða Angular 20 verkefni sem er virkar — Angular CLI eða Analog.

Skref 1 — Náðu í kóðann

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-angular-headless
pnpm install
pnpm test        # vitest + TestBed, all 571 components
pnpm run build-storybook

Íhlutirnir eru flatar skrár í components/ — Button.ts, TextInput.ts — hver sjálfstæður íhlutur með innfelldu sniðmáti, auk spec- og story-skráa. Tunnuskráin index.ts endurútflytur alla íhluti; pnpm build býr til Angular Package Format búnt með ng-packagr.

Skref 2 — Fyrsti íhluturinn þinn

import { Component } from "@angular/core";
import { Button } from "@lilydesignsystem/angular-headless";

@Component({
  selector: "app-save-bar",
  standalone: true,
  imports: [Button],
  template: `<lily-button (click)="save()">Save</lily-button>`,
})
export class SaveBar {
  save() { console.log("saved"); }
}

Hver íhlutur lýsir yfir lily-* veljara og birtir merkingarþáttinn með klasakróknum sínum — <button class="button" type="button"> hér. Inntök byggja á merkjum: label() fyrir aria-label yfirskrift, className() til að bæta við klösum.

Skref 3 — Settu saman lítið eyðublað

import { Component, signal } from "@angular/core";
import { Form, Field, TextInput, Button } from "@lilydesignsystem/angular-headless";

@Component({
  selector: "app-contact-form",
  standalone: true,
  imports: [Form, Field, TextInput, Button],
  template: `
    <lily-form label="Contact form" (submit)="handleSubmit($event)">
      <lily-field label="Full name" [required]="true">
        <lily-text-input id="name" label="Full name" [(value)]="name" />
      </lily-field>
      <lily-button type="submit">Save</lily-button>
    </lily-form>
  `,
})
export class ContactForm {
  name = signal("");
}

lily-field tekur sýnilega merkimiðann sem sitt eigið label inntak frekar en innfelldan merkimiðaíhlut — gefðu hann einu sinni, á reitnum, og samsvarandi lily-text-inputá label sér um aðgengilega heitið. Inntakslíkir íhlutir birta model() gildi, svo banana-box [(value)] tvíátta binding virkar strax — samhæft við zoneless alla leið.

Staðfest 2026-08-29: fyrri drög innfeldu sérstakan Label íhlut inni í lily-field, sem birtir tvo merkimiða (annan tóman) því lily-field birtir þegar sinn eigin út frá label inntakinu — uppgötvað með því að athuga frumkóða íhlutarins. samsetta tengiliðaeyðublaðsleiðin er sama mynstur, prófað með raunverulegum e2e- og axe-prófum.

Athugaðu verkið: keyrðu forritið og eyðublaðið lítur einfalt út — nákvæmlega eins og ætlað er: stíllinn er enn framundan. Ýttu á Tab: fókusinn færist í gegnum hverja stýringu, merkimiðinn er lesinn upp og sending virkar. Hegðunin er tilbúin; útlitið er þitt og er næst.

Skref 4 — Stílaðu það

Stílaðu klasakrókana — .button, .text-input, .label, .field — í styles.css, eða bættu tilbúnu þema við fylkið styles í angular.json / tengdu það í index.html: 

<link rel="stylesheet" href="/themes/adobe-spectrum.css" />

Skref 5 — Sjáðu allt virka

Angular + Analog dæmaforritið sýnir allt safnið með skráamiðaðri leiðsögn og Vite: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-angular-examples
pnpm install && pnpm run dev

Næstu skref

  • Þemu — skipti á keyrslutíma með Angular theme-picker hjálpartækinu.
  • Stillingahjálpartæki — tungumál og textastærð.
  • Íhlutasafn — eiginleikar, ARIA og lyklaborð fyrir hvern íhlut.

Spurningar á leiðinni? hjálparsíðan er full af svörum — og ef skref gæti verið skýrara, segðu okkur og við bætum kennsluefnið með ánægju.
