מדריך Angular

רכיבים עצמאיים של Angular 20 — קלטי signal, זיהוי שינויים OnPush, תבניות מוטבעות, אפס NgModules, אפס CSS.

מה תבנו

טופס יצירת קשר קטן — קלט עם תווית, כפתור שליחה, קשירה דו-כיוונית, התנהגות אמיתית של מקלדת וקורא מסך — קודם חשוף, אחר כך מעוצב, בכ-10 דקות.

לפני שמתחילים

אתם צריכים git, Node 22 ומעלה ו-pnpm 10 ומעלה. כל פרויקט Angular 20 מתאים — Angular CLI או Analog.

שלב 1 — קבלו את הקוד

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-angular-headless
pnpm install
pnpm test        # vitest + TestBed, all 571 components
pnpm run build-storybook

הרכיבים הם קבצים שטוחים ב- components/ — Button.ts, TextInput.ts — כל אחד רכיב עצמאי עם תבנית מוטבעת, בצירוף ה-spec וה-story שלו. ה-barrel index.ts מייצא מחדש כל רכיב; pnpm build מייצר חבילת Angular Package Format באמצעות ng-packagr.

שלב 2 — הרכיב הראשון שלכם

import { Component } from "@angular/core";
import { Button } from "@lilydesignsystem/angular-headless";

@Component({
  selector: "app-save-bar",
  standalone: true,
  imports: [Button],
  template: `<lily-button (click)="save()">Save</lily-button>`,
})
export class SaveBar {
  save() { console.log("saved"); }
}

כל רכיב מצהיר על lily-* בורר ומציג את האלמנט הסמנטי עם ווי המחלקה שלו — <button class="button" type="button"> כאן. הקלטים מבוססי signal: label() עבור aria-label עקיפה, className() כדי להוסיף מחלקות.

שלב 3 — הרכיבו טופס קטן

import { Component, signal } from "@angular/core";
import { Form, Field, TextInput, Button } from "@lilydesignsystem/angular-headless";

@Component({
  selector: "app-contact-form",
  standalone: true,
  imports: [Form, Field, TextInput, Button],
  template: `
    <lily-form label="Contact form" (submit)="handleSubmit($event)">
      <lily-field label="Full name" [required]="true">
        <lily-text-input id="name" label="Full name" [(value)]="name" />
      </lily-field>
      <lily-button type="submit">Save</lily-button>
    </lily-form>
  `,
})
export class ContactForm {
  name = signal("");
}

lily-field לוקח את התווית הגלויה כ label קלט משלו ולא כרכיב תווית מקונן — העבירו אותה פעם אחת, על השדה, וה- lily-text-inputהתואם ב- label מספק את השם הנגיש. רכיבים דמויי קלט חושפים model() ערכים, ולכן banana-box [(value)] קשירה דו-כיוונית פשוט עובדת — תואם zoneless לכל אורכו.

אומת ב-2026-08-29: טיוטה מוקדמת קיננה רכיב נפרד Label בתוך lily-field, מה שהציג שתי תוויות (אחת ריקה) משום ש- lily-field כבר מציג תווית משלו מתוך label הקלט — התגלה על ידי בדיקת קוד המקור של הרכיב. נתיב טופס יצירת הקשר המורכב הוא אותה תבנית, שנבדקה בבדיקות e2e ו-axe אמיתיות.

בדקו את העבודה שלכם: הריצו את האפליקציה והטופס נראה פשוט — בדיוק כמתוכנן: העיצוב עוד לפנינו. לחצו על Tab: המיקוד עובר בכל פקד, התווית מוכרזת והשליחה עובדת. ההתנהגות מוכנה; המראה שלכם והוא הבא בתור.

שלב 4 — עצבו אותו

עצבו את ווי המחלקה — .button, .text-input, .label, .field — ב- styles.css, או הוסיפו ערכת נושא מוכנה למערך styles ב- angular.json / קשרו אותה ב- index.html: 

<link rel="stylesheet" href="/themes/adobe-spectrum.css" />

שלב 5 — ראו הכול עובד

אפליקציית הדוגמה Angular + Analog מציגה את הקטלוג המלא עם ניתוב מבוסס קבצים ו-Vite: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-angular-examples
pnpm install && pnpm run dev

השלבים הבאים

  • ערכות נושא — החלפה בזמן ריצה עם העוזר theme-picker של Angular.
  • עוזרי העדפות — שפה וגודל טקסט.
  • קטלוג הרכיבים — מאפיינים, ARIA ומקלדת לכל רכיב.

שאלות בדרך? עמוד העזרה מלא בתשובות — ואם שלב יכול להיות ברור יותר, ספרו לנו ונשמח לשפר את המדריך.
