Ръководство за Angular

Самостоятелни компоненти на Angular 20 — сигнални входове, откриване на промени OnPush, вградени шаблони, нула NgModules, нула CSS.

Какво ще изградите

Малка форма за контакт — поле с етикет, бутон за изпращане, двупосочно свързване, истинско поведение на клавиатурата и екранния четец — първо гола, после стилизирана, за около 10 минути.

Преди да започнете

Нужни са ви git, Node 22 или по-нов и pnpm 10 или по-нов. Подходящ е всеки проект на Angular 20 — Angular CLI или Analog.

Стъпка 1 — Вземете кода

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-angular-headless
pnpm install
pnpm test        # vitest + TestBed, all 571 components
pnpm run build-storybook

Компонентите са плоски файлове в components/ — Button.ts, TextInput.ts — всеки е самостоятелен компонент с вграден шаблон, плюс неговия spec и story. Barrel файлът index.ts реекспортира всеки компонент; pnpm build произвежда пакет във формат Angular Package Format чрез ng-packagr.

Стъпка 2 — Първият ви компонент

import { Component } from "@angular/core";
import { Button } from "@lilydesignsystem/angular-headless";

@Component({
  selector: "app-save-bar",
  standalone: true,
  imports: [Button],
  template: `<lily-button (click)="save()">Save</lily-button>`,
})
export class SaveBar {
  save() { console.log("saved"); }
}

Всеки компонент декларира селектор lily-* и рендира семантичния елемент със своята класова кука — <button class="button" type="button"> тук. Входовете са базирани на сигнали: label() за aria-label за презаписване, className() за добавяне на класове.

Стъпка 3 — Съставете малка форма

import { Component, signal } from "@angular/core";
import { Form, Field, TextInput, Button } from "@lilydesignsystem/angular-headless";

@Component({
  selector: "app-contact-form",
  standalone: true,
  imports: [Form, Field, TextInput, Button],
  template: `
    <lily-form label="Contact form" (submit)="handleSubmit($event)">
      <lily-field label="Full name" [required]="true">
        <lily-text-input id="name" label="Full name" [(value)]="name" />
      </lily-field>
      <lily-button type="submit">Save</lily-button>
    </lily-form>
  `,
})
export class ContactForm {
  name = signal("");
}

lily-field приема видимия етикет като свой собствен label вход вместо вложен компонент за етикет — подайте го веднъж, на полето, и съответният lily-text-inputот label осигурява достъпното име. Компонентите, подобни на полета, разкриват model() стойности, така че banana-box [(value)] двупосочното свързване работи веднага — съвместимо със zoneless навсякъде.

Проверено на 2026-08-29: по-ранна чернова влагаше отделен компонент Label вътре в lily-field, което рендираше два етикета (единият празен), защото lily-field вече рендира собствения си от входа label — открито чрез проверка на изходния код на компонента. Съставният маршрут на формата за контакт е същият модел, изпитан с истински e2e и axe тестове.

Проверете работата си: стартирайте приложението и формата изглежда гола — точно както е предвидено: стилизирането предстои. Натиснете Tab: фокусът минава през всеки контрол, етикетът се обявява и изпращането работи. Поведението е готово; външният вид е ваш и е следващата стъпка.

Стъпка 4 — Стилизирайте го

Стилизирайте класовите куки — .button, .text-input, .label, .field — в styles.css, или добавете готова тема към масива styles в angular.json / свържете я в index.html: 

<link rel="stylesheet" href="/themes/adobe-spectrum.css" />

Стъпка 5 — Вижте всичко в действие

Примерното приложение Angular + Analog показва пълния каталог с маршрутизиране по файлове и Vite: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-angular-examples
pnpm install && pnpm run dev
