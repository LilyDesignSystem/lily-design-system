Angulari õpetus

Angular 20 iseseisvad komponendid — signaalsisendid, OnPush muudatuste tuvastus, sisemalid, null NgModule'i, null CSS-i.

Mida sa ehitad

Väike kontaktivorm — sildiga väli, saatmisnupp, kahesuunaline sidumine, tõeline klaviatuuri- ja ekraanilugeja käitumine — esmalt paljas, seejärel kujundatud, umbes 10 minutiga.

Enne alustamist

Vaja on gitti, Node 22 või uuemat ja pnpm 10 või uuemat. Sobib iga Angular 20 projekt — Angular CLI või Analog.

Samm 1 — Hangi kood

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-angular-headless
pnpm install
pnpm test        # vitest + TestBed, all 571 components
pnpm run build-storybook

Komponendid on lamedad failid kaustas components/ — Button.ts, TextInput.ts — iga üks on iseseisev komponent sisemalliga, lisaks selle spec ja story. Barrel index.ts ekspordib iga komponendi uuesti; pnpm build koostab ng-packagri kaudu Angular Package Formati paketi.

Samm 2 — Sinu esimene komponent

import { Component } from "@angular/core";
import { Button } from "@lilydesignsystem/angular-headless";

@Component({
  selector: "app-save-bar",
  standalone: true,
  imports: [Button],
  template: `<lily-button (click)="save()">Save</lily-button>`,
})
export class SaveBar {
  save() { console.log("saved"); }
}

Iga komponent deklareerib lily-* valija ja renderdab semantilise elemendi koos oma klassikonksuga — <button class="button" type="button"> siin. Sisendid põhinevad signaalidel: label() elemendile aria-label ülekirjutamiseks, className() klasside lisamiseks.

Samm 3 — Kombineeri väike vorm

import { Component, signal } from "@angular/core";
import { Form, Field, TextInput, Button } from "@lilydesignsystem/angular-headless";

@Component({
  selector: "app-contact-form",
  standalone: true,
  imports: [Form, Field, TextInput, Button],
  template: `
    <lily-form label="Contact form" (submit)="handleSubmit($event)">
      <lily-field label="Full name" [required]="true">
        <lily-text-input id="name" label="Full name" [(value)]="name" />
      </lily-field>
      <lily-button type="submit">Save</lily-button>
    </lily-form>
  `,
})
export class ContactForm {
  name = signal("");
}

lily-field võtab nähtava sildi oma label sisendina pesastatud sildikomponendi asemel — anna see üks kord edasi, väljale, ja vastav lily-text-inputelemendist label annab ligipääsetava nime. Sisendisarnased komponendid avaldavad model() väärtused, nii et banana-box [(value)] kahesuunaline sidumine töötab kohe — zoneless-ühilduv läbivalt.

Kontrollitud 2026-08-29: varasem mustand pesastas eraldi Label komponendi elementi lily-field, mis renderdab kaks silti (üks tühi), sest lily-field renderdab juba oma sildi label sisendist — avastatud komponendi lähtekoodi kontrollides. Koostatud kontaktivormi marsruut on sama muster, proovitud päris e2e- ja axe-testidega.

Kontrolli oma tööd: käivita rakendus ja vorm paistab paljas — täpselt nagu ette nähtud: kujundamine on alles ees. Vajuta Tab: fookus liigub läbi iga juhtelemendi, silt kuulutatakse ette ja saatmine töötab. Käitumine on valmis; välimus on sinu ja järgmine samm.

Samm 4 — Kujunda see

Kujunda klassikonksud — .button, .text-input, .label, .field — failis styles.cssvõi lisa valmis teema massiivi styles failis angular.json / lingi see failis index.html: 

<link rel="stylesheet" href="/themes/adobe-spectrum.css" />

Samm 5 — Vaata kõike töötamas

Angular + Analog näiterakendus näitab kogu kataloogi failipõhise marsruutimise ja Vite'iga: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-angular-examples
pnpm install && pnpm run dev

Järgmised sammud

  • Teemad — vahetamine töö ajal Angulari theme-picker abiga.
  • Eelistuste abilised — keel ja teksti suurus.
  • Komponentide kataloog — omadused, ARIA ja klaviatuur komponendi kohta.
