Tutorial Web Components

Elemen kustom bawaan tanpa runtime kerangka kerja. Masing-masing menghasilkan <button> atau <input> sungguhan di light DOM, sehingga formulir, CSS, dan querySelector bekerja seperti pada HTML yang ditulis tangan.

Yang akan Anda buat

Formulir kontak kecil dengan isian berlabel dan tombol kirim, dihubungkan dengan beberapa baris skrip, polos dulu lalu bergaya, dalam sekitar 10 menit.

Sebelum memulai

Anda memerlukan Node.js dan bundler atau pengaturan apa pun yang menyelesaikan impor modul tanpa jalur. Katalog mencakup 626 dari 661 komponen; subelemen tabel dan beberapa keluarga butir daftar tidak disertakan, karena elemen kustom otonom tidak dapat menggantikan <tr> atau <li>.

Langkah 1 — Pasang dan daftarkan

npm install @lilydesignsystem/web-components-headless
<script type="module">
  import "@lilydesignsystem/web-components-headless";
</script>

Mengimpor paket mendefinisikan setiap elemen, masing-masing bernama lily- ditambah slug komponennya: <lily-button>, <lily-text-input>, <lily-range-fieldset>.

Langkah 2 — Komponen pertama Anda

<lily-button type="submit">Send</lily-button>

Elemen itu menghasilkan <button class="button"> sungguhan di dalam dirinya, sehingga Enter, Spasi, dan peran tombol bersifat bawaan. Atribut yang Anda tambahkan diteruskan ke elemen di dalamnya.

Langkah 3 — Susun formulir kecil

<lily-form label="Contact us">
  <lily-field label="Full name" required>
    <lily-text-input label="Full name" name="name" autocomplete="name" required></lily-text-input>
  </lily-field>
  <lily-field label="Email" required>
    <lily-email-input label="Email" name="email" required></lily-email-input>
  </lily-field>
  <lily-button type="submit">Send</lily-button>
</lily-form>

<script type="module">
  const form = document.querySelector("lily-form form");
  form.addEventListener("submit", () => {
    const data = new FormData(form);
    console.log(Object.fromEntries(data));
  });
</script>

<lily-form> mencegah navigasi halaman dan membiarkan peristiwa submit menggelembung, sehingga skrip Anda yang memutuskan apa yang terjadi. Isiannya adalah kontrol formulir sungguhan, sehingga FormData membacanya.

Periksa hasil kerja Anda: tekan Tab melalui formulir, lalu kirim: konsol menampilkan name dan email. Biarkan satu isian kosong dan pemeriksaan required bawaan peramban menghentikan pengiriman.

Langkah 4 — Beri gaya

Kelasnya ada pada elemen di dalam, sehingga 63 tema dan CSS Anda menyasarnya seperti pada HTML biasa: 

<link rel="stylesheet" href="/themes/light.css" />

<style>
  .button { padding: 0.75rem 1.5rem; }
  lily-field { display: block; margin-block-end: 1rem; }
</style>

Tidak ada shadow DOM yang perlu ditembus: tidak ada yang tersembunyi dari lembar gaya Anda maupun dari teknologi bantu.

Langkah 5 — Lihat semuanya bekerja

  • Setiap elemen punya story: pnpm run storybook di lily-design-system-web-components-headless.
  • Pembantu juga tersedia sebagai elemen kustom: <lily-theme-picker>, kisi data, kalender, dan lainnya (@lilydesignsystem/web-components-*).

Langkah berikutnya

  • Pelatihan — delapan modul, masing-masing dengan latihan dan uji mandiri.
  • Formulir aksesibel — galat, ringkasan galat, dan fokus.
  • Tema — mengganti tema saat berjalan.
  • Katalog komponen — referensi lengkap.
