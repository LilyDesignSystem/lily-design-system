អ្វីដែលមិនមាន

គ្មានបណ្ណាល័យសមាសភាគ Lily ផ្លូវការក្នុង Figma ហើយគ្មាន plugin Figma ដែលថែទាំទេ។ ការសាងសង់ និងថែទាំបណ្ណាល័យឧបករណ៍រចនាឱ្យបានល្អ ជាការប្តេជ្ញាចិត្តពិតប្រាកដ និងបន្ត — រចនាសម្ព័ន្ធសមាសភាគ Figma ការដាក់ឈ្មោះបំរែបំរួល auto-layout បំពង់ផ្សាយផ្ទាល់ខ្លួន — ដាច់ដោយឡែកពីការថែទាំកូដ ហើយគម្រោងនេះមិនបានទទួលវាទេ។

អ្វីដែលមានថ្ងៃនេះ

ស្បែកយោងទាំង ៥៧ នីមួយៗមានធាតុដើមតូខឹនរចនារបស់ខ្លួន — ពណ៌ កាំ ទំហំ ស៊ុម — បោះពុម្ពក្នុង ទ្រង់ទ្រាយ DTCG 2025.10 នៅ themes/tokens/*.json។ ទ្រង់ទ្រាយនោះគឺជាអ្វីដែលឧបករណ៍តូខឹនទំនើបអាន។ អ្នកអាចទាញក្បាលពណ៌ស្បែក Lily ចូល Figma ដោយខ្លួនឯង ឥឡូវនេះ ដោយគ្មាន plugin ពីគម្រោងនេះ៖

  1. ដំឡើង Tokens Studio for Figma plugin សហគមន៍ (ឬការនាំចូល Variables របស់ Figma ផ្ទាល់ កន្លែងដែលផែនការរបស់អ្នកគាំទ្រការនាំចូល DTCG)។
  2. នាំចូល themes/tokens/{theme-slug}.json សម្រាប់ស្បែកណាដែលអ្នកចង់បាន — ឧទាហរណ៍ united-kingdom-national-health-service-england-for-patients.json.
  3. Tokens Studio បង្កើតអថេរ Figma ពីតម្លៃ DTCG ដែលអ្នកអាចអនុវត្តលើសមាសភាគផ្ទាល់ខ្លួនរបស់អ្នក។

នេះផ្តល់ឱ្យអ្នកនូវតូខឹនពណ៌ និងរូបរាងរបស់ Lily ក្នុង Figma។ វាមិនផ្តល់ឱ្យអ្នកនូវសមាសភាគពិតប្រាកដរបស់ Lily ជាសមាសភាគ Figma ទេ — គ្មាននរណាបានសាងសង់វា ហើយទំព័រនេះនឹងមិនធ្វើពុតជាផ្សេងទេ។

តើមានផែនការសម្រាប់បណ្ណាល័យ Figma ពិតប្រាកដទេ?
