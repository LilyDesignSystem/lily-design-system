メンテナンスされている Figma ライブラリはありません — 代わりにあるもの

このページには以前「近日公開」と書かれていました。作っている人がいなかったので、もう書いていません。ここでは正直な現状と、今日から使える現実的な方法をご紹介します。

存在しないもの

Figma に公式の Lily コンポーネントライブラリはなく、メンテナンスされている Figma プラグインもありません。デザインツールのライブラリをきちんと作り維持するのは、本当に継続的な負担です — Figma のコンポーネント構造、バリアントの命名、オートレイアウト、独自の公開パイプラインが必要で、コードの保守とは別の仕事であり、このプロジェクトでは引き受けていません。

今あるもの

57 の参照テーマにはそれぞれ、デザイントークンの基本要素 — 色、角丸、サイズ、境界線 — があり、次の形式で公開されています: DTCG 2025.10 形式 場所: themes/tokens/*.json。この形式は、現代のトークンツールがそのまま読み込めるものです。このプロジェクトのプラグインを使わなくても、今すぐ自分で Lily のテーマのパレットを Figma に取り込めます:

  1. コミュニティの Tokens Studio for Figma プラグインをインストールします(プランが DTCG のインポートに対応している場合は、Figma 自身の Variables インポートでも構いません)。
  2. インポートするもの: themes/tokens/{theme-slug}.json (使いたいテーマのもの)— たとえば united-kingdom-national-health-service-england-for-patients.json.
  3. Tokens Studio は DTCG の値から Figma の変数を作成するので、それを自分のコンポーネントに適用できます。

これで Lily の色と形のトークンを Figma に取り込めます。Lily の実際のコンポーネントを Figma のコンポーネントとして得られるわけではありません — それを作った人はおらず、このページもそうは言いません。

本格的な Figma ライブラリの計画はありますか?

今のところありません。約束するのは簡単ではないからです。次を参照してください: RFC 6 未解決の問題と、プロジェクトの考えを変えるものについて書かれています — とくに役立つのは、このレイヤーに何が必要かをデザイナーが具体的に伝えてくれることです。もしあなたがそうなら、 ぜひ声を聞かせてください か、issue を開いてください。
