没有维护中的 Figma 组件库——现有的替代方案如下

这个页面以前写的是“即将推出”。现在不再这样写了，因为并没有人在做。下面如实说明现状，以及一条今天就能走通的路径。

目前没有的东西

Figma 中没有官方的 Lily 组件库，也没有维护中的 Figma 插件。把一个设计工具组件库做好并长期维护，是一项真实而持续的投入——Figma 组件结构、变体命名、自动布局，以及它自己的发布流程——这与维护代码是两回事，而本项目并没有承担这项工作。

现在有什么

57 套参考主题中的每一套，都把它的设计令牌基础项——颜色、圆角、尺寸、边框——以 DTCG 2025.10 格式 发布在 themes/tokens/*.json。这种格式正是现代令牌工具所读取的格式。你现在就可以自己把某个 Lily 主题的调色板导入 Figma，无需本项目提供任何插件：

  1. 安装社区插件 Tokens Studio for Figma （或者在你的套餐支持 DTCG 导入时，使用 Figma 自带的变量导入）。
  2. 为你想要的主题导入 themes/tokens/{theme-slug}.json——例如 united-kingdom-national-health-service-england-for-patients.json。
  3. Tokens Studio 会根据 DTCG 的取值创建 Figma 变量，之后你就可以把它们应用到自己的组件上。

这样你得到的是 Figma 中的 Lily 颜色和形状令牌，而不是作为 Figma 组件的 Lily 真实组件——还没有人做过这件事，本页面也不会假装做过。

有没有计划做真正的 Figma 组件库？

目前没有，而且这个承诺不能随口许下：悬而未决的问题，以及什么情况会改变项目的想法，请见 RFC 6 ——其中最有帮助的，是设计师明确说出他们需要这一层提供什么。如果你就是这样的设计师， 请告诉我们 或提交一个 issue。
