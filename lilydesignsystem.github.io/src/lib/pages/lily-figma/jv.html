Ora ana pustaka Figma sing dijaga — iki sing ana minangka gantiné

Kaca iki biyèn nyebut "enggal teka." Saiki ora, amarga ora ana sing ngerjakaké. Iki kahanan sing jujur, lan dalan nyata sing mlaku saiki.

Sing ora ana

Ora ana pustaka komponen Lily resmi ing Figma, lan ora ana plugin Figma sing dijaga. Mbangun lan njaga pustaka piranti desain kanthi apik iku komitmen nyata lan terus-terusan — struktur komponen Figma, jeneng varian, auto-layout, pipa panerbitan dhéwé — kapisah saka njaga kode, lan proyek iki durung njupuk.

Sing ana saiki

Saben saka 57 tema rujukan nduwé primitif token desain-é — warna, radius, ukuran, wates — diterbitaké ing format DTCG 2025.10 ing themes/tokens/*.json. Format kuwi persis sing diwaca piranti token modern. Sampeyan bisa narik palet tema Lily menyang Figma dhéwé, saiki, tanpa plugin saka proyek iki:

  1. Instal plugin komunitas Tokens Studio for Figma (utawa impor Variables Figma dhéwé, yèn paket sampeyan ndhukung impor DTCG).
  2. Impor themes/tokens/{theme-slug}.json kanggo tema sing dikarepaké — contoné united-kingdom-national-health-service-england-for-patients.json.
  3. Tokens Studio nggawé variabel Figma saka nilai DTCG, sing banjur bisa sampeyan trapaké ing komponen sampeyan dhéwé.

Iki menehi token warna lan wujud Lily ing Figma. Ora menehi komponen Lily sing sejatiné minangka komponen Figma — durung ana sing mbangun, lan kaca iki ora bakal ndalih liya.

Apa pustaka Figma nyata dirancang?

Saiki ora, lan njanjèkaké iku ora gratis: deleng RFC 6 kanggo pitakon sing isih mbukak lan apa sing bakal ngowahi pikirané proyek — sing paling migunani yaiku desainer sing ngandhani khusus apa sing dibutuhaké saka lapisan iki. Yèn iku sampeyan, kandhanana kita utawa bukak issue.
