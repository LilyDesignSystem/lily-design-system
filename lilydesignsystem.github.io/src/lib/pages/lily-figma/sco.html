Nae maintained Figma library — here's whit exists insteid

This page uised tae say “comin soon.” It disnae onie mair, because naebody wis biggin it. Here is the honest state, an a real path that wirks the day.

Whit disnae exist

There is nae official Lily component library in Figma, an nae maintained Figma plugin. Biggin an maintainin a design-tool library weel is a real, ongaun commitment — Figma component structure, variant namin, auto-layout, a publish pipeline o its ain — separate frae maintainin code, an this project hasnae taen it on.

Whit exists the day

Ilka ane o the 57 reference themes haes its ain design-token primitives — colour, radius, size, border — publishit in DTCG 2025.10 format at themes/tokens/*.json. That format is exactly whit modern token tooling reads. Ye can pull a Lily theme's palette intae Figma yersel, richt noo, wi nae plugin frae this project:

  1. Install the community Tokens Studio for Figma plugin (or Figma's ain Variables import, whaur yer plan supports DTCG import).
  2. Import themes/tokens/{theme-slug}.json for whichever theme ye want — for example united-kingdom-national-health-service-england-for-patients.json.
  3. Tokens Studio creates Figma variables frae the DTCG values, which ye can then apply tae yer ain components.

This gies ye Lily's colour an shape tokens in Figma. It disnae gie ye Lily's actual components as Figma components — naebody haes biggit that, an this page willnae pretend itherwise.

Is a real Figma library plannit?

No currently, an it isnae free tae promise: see RFC 6 for the open question an whit wid chynge the project's mind — maist uiseful, a designer sayin specifically whit they need frae this layer. If that's ye, say sae or open an issue.
