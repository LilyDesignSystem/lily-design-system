Καμία συντηρούμενη βιβλιοθήκη Figma — δείτε τι υπάρχει αντί γι' αυτήν

Αυτή η σελίδα έγραφε κάποτε «σύντομα». Δεν το γράφει πια, επειδή κανείς δεν την έφτιαχνε. Να η ειλικρινής κατάσταση και μια πραγματική διαδρομή που δουλεύει σήμερα.

Τι δεν υπάρχει

Δεν υπάρχει επίσημη βιβλιοθήκη στοιχείων Lily στο Figma, ούτε συντηρούμενο πρόσθετο Figma. Το να χτίσεις και να συντηρήσεις καλά μια βιβλιοθήκη εργαλείου σχεδίασης είναι πραγματική, διαρκής δέσμευση — δομή στοιχείων Figma, ονοματοδοσία παραλλαγών, auto-layout, δικός της αγωγός δημοσίευσης — ξεχωριστή από τη συντήρηση κώδικα, και αυτό το έργο δεν την έχει αναλάβει.

Τι υπάρχει σήμερα

Καθένα από τα 57 θέματα αναφοράς έχει τα βασικά design tokens του — χρώμα, ακτίνα, μέγεθος, περίγραμμα — δημοσιευμένα σε μορφή DTCG 2025.10 στο themes/tokens/*.json. Αυτή η μορφή είναι ακριβώς αυτό που διαβάζουν τα σύγχρονα εργαλεία tokens. Μπορείτε να φέρετε μόνοι σας την παλέτα ενός θέματος Lily στο Figma, αυτή τη στιγμή, χωρίς πρόσθετο από αυτό το έργο:

  1. Εγκαταστήστε το πρόσθετο της κοινότητας Tokens Studio for Figma (ή τη δική του εισαγωγή Variables του Figma, όπου το πλάνο σας υποστηρίζει εισαγωγή DTCG).
  2. Εισαγάγετε το themes/tokens/{theme-slug}.json για όποιο θέμα θέλετε — για παράδειγμα united-kingdom-national-health-service-england-for-patients.json.
  3. Το Tokens Studio δημιουργεί μεταβλητές Figma από τις τιμές DTCG, τις οποίες μπορείτε μετά να εφαρμόσετε στα δικά σας στοιχεία.

Αυτό σας δίνει τα tokens χρώματος και σχήματος της Lily στο Figma. Δεν σας δίνει τα πραγματικά στοιχεία της Lily ως στοιχεία Figma — κανείς δεν το έχει φτιάξει, και αυτή η σελίδα δεν θα προσποιηθεί το αντίθετο.
