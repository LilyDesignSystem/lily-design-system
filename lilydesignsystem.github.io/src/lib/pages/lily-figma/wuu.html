呒没维护中个 Figma 组件库——现有个替代方案如下

搿个页面以前写个是“即将推出”。现在勿再这样写了，因为并呒没人在做。下面如实说明现状，以及一条今天就能走通个路径。

目前呒没个东西

Figma 中呒没官方个 Lily 组件库，也呒没维护中个 Figma 插件。把一个设计工具组件库做好并长期维护，是一项真实而持续个投入——Figma 组件结构、变体命名、自动布局，以及伊自己个发布流程——这与维护代码是两回事，而本项目并呒没承担这项工作。

现在有啥

57 套参考主题中个每一套，侪把伊个设计令牌基础项——颜色、圆角、尺寸、边框——以 DTCG 2025.10 格式 发布在 themes/tokens/*.json。这种格式正是现代令牌工具所读取个格式。侬现在就可以自己把某个 Lily 主题个调色板导入 Figma，无需本项目提供任何插件：

  1. 安装社区插件 Tokens Studio for Figma （或者在侬个套餐支持 DTCG 导入时，使用 Figma 自带个变量导入）。
  2. 为侬想要个主题导入 themes/tokens/{theme-slug}.json——例如 united-kingdom-national-health-service-england-for-patients.json。
  3. Tokens Studio 会根据 DTCG 个取值创建 Figma 变量，之后侬就可以把伊拉应用到自己个组件上。

这样侬得到个是 Figma 中个 Lily 颜色搭形状令牌，而不是作为 Figma 组件个 Lily 真实组件——还呒没人做过这件事，本页面也不会假装做过。
