No maintained Figma library — here na wetin dey instead

Dis page use to talk say “coming soon.” E no talk am again, because nobody dey build am. Dis na di honest state, and real path wey dey work today.

Wetin no exist

No official Lily component library dey for Figma, and no maintained Figma plugin. To build and maintain design-tool library well na real, ongoing commitment — Figma component structure, variant naming, auto-layout, im own publish pipeline — separate from to maintain code, and dis project no carry am.

Wetin dey exist today

Each of di 57 reference themes get im own design-token primitives — colour, radius, size, border — wey dem publish for DTCG 2025.10 format for themes/tokens/*.json. Dat format na exactly wetin modern token tooling dey read. You fit pull Lily theme palette enter Figma yourself, right now, without any plugin from dis project:

  1. Install di community Tokens Studio for Figma plugin (or Figma own Variables import, where your plan support DTCG import).
  2. Import themes/tokens/{theme-slug}.json for whichever theme you want — for example united-kingdom-national-health-service-england-for-patients.json.
  3. Tokens Studio dey create Figma variables from di DTCG values, wey you fit then apply to your own components.

Dis one go give you Lily colours and shape tokens inside Figma. E no give you Lily actual components as Figma components — nobody build am, and dis page no go pretend say e be otherwise.

Dem plan real Figma library?

Not currently, and e no free to promise: see RFC 6 for di open question and wetin go change di project mind — most useful, designer wey talk specifically wetin e need from dis layer. If na you, talk am or open issue.
