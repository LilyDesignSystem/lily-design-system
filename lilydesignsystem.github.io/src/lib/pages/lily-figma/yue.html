冇嘅嘢

Figma 入面冇官方嘅 Lily 元件庫,亦冇維護中嘅 Figma 外掛。好好咁建立同維護設計工具函式庫,係真正持續嘅承擔 — Figma 元件結構、變體命名、auto-layout、自己嘅發佈流程 — 同維護程式碼係兩回事,而呢個項目冇承擔呢件事。

而家有嘅嘢

57 個參考主題每一個都有自己嘅設計令牌原語 — 顏色、圓角、大細、邊框 — 以 DTCG 2025.10 格式 發佈於 themes/tokens/*.json。呢個格式正正係現代令牌工具讀取嘅格式。你可以自己將 Lily 主題嘅配色拉入 Figma,即刻就得,唔需要呢個項目提供任何外掛:

  1. 安裝社群嘅 Tokens Studio for Figma 外掛(或者 Figma 自己嘅 Variables 匯入,只要你嘅方案支援 DTCG 匯入)。
  2. 匯入 themes/tokens/{theme-slug}.json 你想要嘅任何主題 — 例如 united-kingdom-national-health-service-england-for-patients.json.
  3. Tokens Studio 會由 DTCG 值建立 Figma 變數,之後你可以套用到自己嘅元件。

咁樣你就喺 Figma 入面有 Lily 嘅顏色同形狀令牌。但唔會畀你 Lily 嘅真實元件作為 Figma 元件 — 冇人建過,而呢頁亦唔會扮成咁樣。
