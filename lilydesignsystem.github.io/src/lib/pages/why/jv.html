Alesan kanggo Lily

Lily nggawa bagéan-bagéan sing angèl — semantik, aksesibilitas, prilaku keyboard, internasionalisasi — lan ninggal tampilan kabèh, kanthi bungah, marang sampéyan.

Miwiti saka desain sampéyan dhéwé

Tim sampéyan wis ngerti kepriyé produk sampéyan kudu katon. Lily miwiti persis saka kana: nyedhiyakaké bagéan sing pancèn angèl dilakoni kanthi bener lan larang yèn kudu diulang — elemèn semantik sing bener, kahanan ARIA, kontrak keyboard, manajemen fokus — lan ninggal saben kaputusan visual kabèh, kanthi bungah, marang sampéyan. CSS sampéyan iku tampilan sistem desain wiwit dina kapisan.

Amarga saben komponèn nggawa pancingan kelas sing stabil lan struktur murni, gaya sampéyan tetep resik dadi duwèk sampéyan ing saben nganyaraké — lan aksesibilitas ing ngisor kuwi terus makarya, versi sawisé versi.

Sing dijanjèkaké Lily

  • Bisa diaksès kanthi baku. WCAG 2.2 AAA iku target kanggo saben komponèn. Pola-pola nututi WAI-ARIA Authoring Practices; saben komponèn interaktif bisa dioperasikaké nganggo keyboard kanthi kontrak sing didokumentasi; aplikasi conto njaga dasar axe-core sing resik.
  • Bisa diinternasionalisasi saka dhasaré. Saben string sing katon pangguna — saben labèl, kesalahan, lan woro-woro — iku properti kanthi jeneng stabil ing kabèh framework, dadi terjemahan mili kanthi alami. RTL lan tèks rong arah nurunaké saka dir sampéyan. Komponèn sing ngerti lokal nampa lokal minangka properti, tansah kanthi jelas.
  • Siji katalog, wolung framework. 581 komponèn sing padha (546 minangka Web Components asli) kanthi pancingan kelas lan konvènsi properti sing padha ing HTML, Svelte, React, Vue, Angular, Blazor, Nunjucks, lan Web Components. CSS sampéyan lan kawruh tim bisa dipindhah antar tumpukan.
  • Ora gumantung strategi CSS. Siji kelas kebab-case sing stabil saben oyod komponèn. CSS semantik, utilitas Tailwind, CSS-in-JS, utawa salah siji saka 57 tema sing wis siap — Lily nampa kabèh lan minggir kanthi alus.
  • Gratis, salawasé, miturut sarat sampéyan. Sumber terbuka miturut pilihan sampéyan antara BSD, MIT, Apache-2.0, GPL-2.0, utawa GPL-3.0. Ora ana tingkat pro, ora ana lisènsi kursi, ora ana telemetri.

Ambane ing panggonan sing penting

Ngluwihi tombol lan dialog biasa, katalog tekan luwih adoh tinimbang umumé:

  • Pola sektor umum sing ditliti saka sistem desain NHS UK, GOV.UK, USWDS, lan ONS — ringkesan kesalahan, kothak pènget, dhaptar ringkesan, spanduk fase, tautan nglangkahi.
  • 140 komponèn pangenal pribadi nasional sing nyakup pangenal kesehatan, KTP nasional, pajak, lan paspor ing luwih saka 50 negara, saben siji ndokumentasiaké format lan algoritma validasiné.
  • Unsur dhasar editorial lan scrollytelling disesuaikan saka Reuters Graphics — tata letak artikel, scroller, lini wektu, peta ubin.
  • Pembantu pamilih — paket cilik sing nduwèni siji interaksi saka wiwitan nganti pungkasan: ganti tema (kanthi muat stylesheet nalika mlaku), basa, ukuran tèks, gerakan dikurangi, panelusuran, tautan kaca, nuduhaké, lan input tanggal lan wektu. Saben siji iku tombol ikon tanpa sirah sing mbukak popup — dudu <select> asli — kanthi persistensi lan keamanan SSR sing wis ana.

Tema kanggo sektor umum, langsung siap

Lily nyedhiyakaké 57 tema rujukan mandiri sing langsung nargetaké pancingan kelasé: NHS England, NHS Scotland, lan NHS Wales (saben siji ing varian kanggo pasien lan praktisi), GOV.UK, USWDS, palet sing kainspirasi Adobe Spectrum lan Mozilla Protocol, lan sakumpulan tema umum padhang lan peteng. Sambungna siji stylesheet lan tampilan tingkat pamaréntah urip; pembantu theme-picker ngganti kuwi nalika mlaku.

Kepriyé Lily dibandhingaké

Kita njaga pandhengan jujur karo sistem desain liyané , komponèn demi komponèn — sing digayani lan tanpa sirah, komersial lan sektor umum. Ing ngendi pustaka liya luwih cocog kanggo sampéyan, pandhengan bakal nuduhaké; Lily sinau saka kabèh lan nyebutaké sumber inspirasiné kanthi terbuka.

Sapa ing wingkingé

Lily iku proyèk sumber terbuka sing enom lan mandiri sing nampa sinau, tuntunan, lan umpan balik — delengen Babagan kanggo critané lan sumber inspirasi. Kabèh — spesifikasi, tés, peta dalan, malah piranti audit — terbuka ing github.com/LilyDesignSystem.

Bantu Lily thukul

Yèn Lily migunani kanggo sampéyan, perkara paling larang sing bisa sampéyan lakoni:

  • Wènèhana lintang lan nuduhaké. Wènèhana lintang marang repo utama lan tuduhna marang kanca kerja katalog — kawruh iku sumber daya paling langka sing diduwèni proyèk enom.
  • Gawéa apa waé lan kandhanana kita. Laporan panggunaan nyata — apa sing kasil, apa sing bisa luwih lancar — mbentuk peta dalan luwih akèh tinimbang apa waé.
  • Audit aksesibilitas. Pandhuan nganggo pembaca layar (VoiceOver, NVDA, JAWS) ing aplikasi conto iku emas; laporna apa sing sampéyan temokaké.
  • Sumbang tema utawa terjemahan. Loro-loroné iku sumbangan kapisan sing mandiri lan wangun jelas.
  • Nuduhaké apa sing sampéyan temokaké, kanthi réproduksi minimal, ing repositori GitHub, utawa kirim email menyang joel@joelparkerhenderson.com.
