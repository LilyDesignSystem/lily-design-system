Lily கடினமான பகுதிகளை உங்களுக்குத் தருகிறது — பொருள்சார்மை, அணுகல், விசைப்பலகை நடத்தை, சர்வதேசமயமாக்கல் — தோற்றத்தை முழுவதும், மகிழ்ச்சியுடன், உங்களுக்கே விட்டுவிடுகிறது.

உங்கள் சொந்த வடிவமைப்பிலிருந்து தொடங்குங்கள்

Lily சரியாக அங்கிருந்தே தொடங்குகிறது: சரியாகச் செய்ய உண்மையில் கடினமான, மீண்டும் செய்ய விலையுயர்ந்த பகுதிகளை வழங்குகிறது — சரியான பொருள்சார் உறுப்பு, ARIA நிலைகள், விசைப்பலகை ஒப்பந்தம், குவிப்பு மேலாண்மை — ஒவ்வொரு காட்சி முடிவையும் முழுவதும், மகிழ்ச்சியுடன், உங்களுக்கே விட்டுவிடுகிறது. உங்கள் CSS முதல் நாளிலிருந்தே வடிவமைப்பு அமைப்பின் தோற்றம்.

ஒவ்வொரு கூறும் நிலையான வகுப்பு கொக்கியையும் தூய அமைப்பையும் கொண்டிருப்பதால், ஒவ்வொரு மேம்படுத்தலிலும் உங்கள் பாணி சுத்தமாக உங்களுடையதாகவே இருக்கும் — கீழுள்ள அணுகல் பதிப்புக்குப் பதிப்பு தொடர்ந்து வேலை செய்யும்.

  • கட்டமைப்பிலேயே சர்வதேசமயமாக்கத்தக்கது. பயனருக்குத் தெரியும் ஒவ்வொரு சரமும் — ஒவ்வொரு லேபிள், பிழை, அறிவிப்பு — கட்டமைப்புகள் முழுவதும் நிலையான பெயர்களுடன் ஒரு ப்ராப், அதனால் மொழிபெயர்ப்பு இயல்பாகப் பாய்கிறது. RTL மற்றும் இருதிசை உரை உங்கள் dir இலிருந்து மரபுரிமை பெறுகின்றன. மொழிச்சூழல் அறிந்த கூறுகள் மொழிச்சூழலை ப்ராப்பாக எடுக்கின்றன, எப்போதும் வெளிப்படையாக.
  • ஒரு பட்டியல், எட்டு கட்டமைப்புகள். அதே 581 கூறுகள் (546 இயல்பான Web Components ஆக) HTML, Svelte, React, Vue, Angular, Blazor, Nunjucks மற்றும் Web Components இல் அதே வகுப்பு கொக்கிகளுடனும் ப்ராப் மரபுகளுடனும். உங்கள் CSS மற்றும் குழுவின் அறிவு அடுக்குகள் முழுவதும் மாற்றப்படும்.
  • CSS உத்தியைச் சாராதது. ஒவ்வொரு கூறு மூலத்துக்கும் ஒரு நிலையான கபாப்-கேஸ் வகுப்பு. பொருள்சார் CSS, Tailwind பயன்பாடுகள், CSS-in-JS, அல்லது 57 தயார் தீம்களில் ஒன்று — Lily அனைத்தையும் வரவேற்று அழகாக வழிவிடுகிறது.

முக்கியமான இடத்தில் ஆழம்

வழக்கமான பொத்தான்கள், உரையாடல்களுக்கு அப்பால், பட்டியல் பெரும்பாலானவற்றை விட அதிக தூரம் செல்கிறது:

  • பொதுத்துறை வடிவங்கள் NHS UK, GOV.UK, USWDS மற்றும் ONS வடிவமைப்பு அமைப்புகளிலிருந்து ஆராயப்பட்டவை — பிழைச் சுருக்கங்கள், எச்சரிக்கைப் பெட்டிகள், சுருக்கப் பட்டியல்கள், கட்டப் பதாகைகள், தவிர்க்கும் இணைப்புகள்.
  • 140 தேசிய தனிநபர் அடையாளங்காட்டிக் கூறுகள் 50க்கும் மேற்பட்ட நாடுகளில் சுகாதாரம், தேசிய அடையாள அட்டை, வரி மற்றும் கடவுச்சீட்டு அடையாளங்காட்டிகளை உள்ளடக்கியவை, ஒவ்வொன்றும் அதன் வடிவத்தையும் சரிபார்ப்பு படிமுறையையும் ஆவணப்படுத்துகிறது.
  • தலையங்க மற்றும் scrollytelling அடிப்படை கூறுகள் Reuters Graphics இலிருந்து தழுவியவை — கட்டுரை அமைப்புகள், உருட்டிகள், காலவரிசைகள், ஓடு வரைபடங்கள்.
  • தேர்வி உதவியாளர்கள் — ஒரு ஊடாடலை தொடக்கம் முதல் முடிவு வரை சொந்தமாகக் கொண்ட சிறிய தொகுப்புகள்: தீம் மாற்றம் (இயக்க நேர ஸ்டைல்ஷீட் ஏற்றுதலுடன்), மொழி, உரை அளவு, குறைந்த இயக்கம், தேடல், பக்க இணைப்புகள், பகிர்வு, மற்றும் தேதி-நேர உள்ளீடு. ஒவ்வொன்றும் பாப்அப் திறக்கும் தலையற்ற ஐகான் பொத்தான் — இயல்பான <select> அல்ல — உள்ளமைந்த நிலைப்பு மற்றும் SSR பாதுகாப்புடன்.
