Lily માટેની દલીલ

Lily તમને અઘરા ભાગો આપે છે — સેમેન્ટિક્સ, સુલભતા, કીબોર્ડ વર્તન, આંતરરાષ્ટ્રીયકરણ — અને દેખાવ સંપૂર્ણપણે, ખુશીથી, તમારા પર છોડે છે.

તમારી પોતાની ડિઝાઇનથી શરૂ કરો

તમારી ટીમ પહેલેથી જાણે છે કે તમારું ઉત્પાદન કેવું દેખાવું જોઈએ. Lily બરાબર ત્યાંથી શરૂ થાય છે: તે એવા ભાગો પૂરા પાડે છે જે ખરેખર બરાબર કરવા અઘરા અને ફરીથી કરવા મોંઘા છે — સાચું સેમેન્ટિક એલિમેન્ટ, ARIA સ્થિતિઓ, કીબોર્ડ કરાર, ફોકસ વ્યવસ્થાપન — અને દરેક દૃશ્ય નિર્ણય સંપૂર્ણપણે, આનંદથી, તમારા પર છોડે છે. તમારું CSS પહેલા દિવસથી ડિઝાઇન સિસ્ટમનો દેખાવ છે.

કારણ કે દરેક ઘટક સ્થિર ક્લાસ હૂક અને શુદ્ધ માળખું ધરાવે છે, દરેક અપગ્રેડમાં તમારી શૈલી સ્વચ્છ રીતે તમારી જ રહે છે — અને નીચેની સુલભતા આવૃત્તિ પછી આવૃત્તિ કામ કરતી રહે છે.

Lily શેના માટે પ્રતિબદ્ધ છે

  • મૂળભૂત રીતે સુલભ. દરેક ઘટક માટે WCAG 2.2 AAA લક્ષ્ય છે. પેટર્ન WAI-ARIA Authoring Practices ને અનુસરે છે; દરેક ઇન્ટરેક્ટિવ ઘટક દસ્તાવેજીકૃત કરાર સાથે કીબોર્ડથી ચલાવી શકાય છે; ઉદાહરણ એપ્સ સ્વચ્છ axe-core બેઝલાઇન જાળવે છે.
  • બંધારણથી જ આંતરરાષ્ટ્રીયકરણક્ષમ. વપરાશકર્તાને દેખાતી દરેક સ્ટ્રિંગ — દરેક લેબલ, ભૂલ અને જાહેરાત — ફ્રેમવર્કમાં સ્થિર નામો સાથેનો પ્રોપ છે, તેથી અનુવાદ કુદરતી રીતે વહે છે. RTL અને દ્વિદિશ ટેક્સ્ટ તમારા dir પાસેથી વારસો મેળવે છે. લોકેલ-જાગૃત ઘટકો લોકેલને પ્રોપ તરીકે લે છે, હંમેશા સ્પષ્ટ રીતે.
  • એક કેટલોગ, આઠ ફ્રેમવર્ક. એ જ 571 ઘટકો (536 મૂળ Web Components તરીકે) HTML, Svelte, React, Vue, Angular, Blazor, Nunjucks અને Web Components માં સમાન ક્લાસ હૂક અને પ્રોપ સંમેલનો સાથે. તમારું CSS અને ટીમનું જ્ઞાન સ્ટેકમાં સ્થાનાંતરિત થાય છે.
  • CSS વ્યૂહરચનાથી સ્વતંત્ર. દરેક ઘટક મૂળ દીઠ એક સ્થિર કબાબ-કેસ ક્લાસ. સેમેન્ટિક CSS, Tailwind યુટિલિટી, CSS-in-JS, અથવા 57 તૈયાર થીમમાંથી એક — Lily બધાનું સ્વાગત કરે છે અને સુંદર રીતે રસ્તામાંથી ખસી જાય છે.
  • મફત, કાયમ માટે, તમારી શરતો પર. BSD, MIT, Apache-2.0, GPL-2.0, અથવા GPL-3.0 માંથી તમારી પસંદગી હેઠળ ઓપન સોર્સ. કોઈ પ્રો સ્તર નથી, કોઈ સીટ લાઇસન્સ નથી, કોઈ ટેલિમેટ્રી નથી.

જ્યાં મહત્ત્વનું છે ત્યાં ઊંડાણ

સામાન્ય બટન અને સંવાદોથી આગળ, કેટલોગ મોટાભાગના કરતાં વધુ દૂર પહોંચે છે:

  • જાહેર ક્ષેત્રની પેટર્ન NHS UK, GOV.UK, USWDS અને ONS ડિઝાઇન સિસ્ટમોમાંથી સંશોધિત — ભૂલ સારાંશ, ચેતવણી બોક્સ, સારાંશ યાદીઓ, તબક્કા બેનર, છોડવાની લિંક.
  • 140 રાષ્ટ્રીય વ્યક્તિગત ઓળખકર્તા ઘટકો 50 થી વધુ દેશોમાં આરોગ્ય સંભાળ, રાષ્ટ્રીય-ID, કર અને પાસપોર્ટ ઓળખકર્તાઓને આવરી લેતા, દરેક તેનું ફોર્મેટ અને ચકાસણી અલ્ગોરિધમ દસ્તાવેજીકૃત કરે છે.
  • સંપાદકીય અને scrollytelling પાયાના તત્ત્વો Reuters Graphics માંથી અપનાવેલા — લેખ લેઆઉટ, સ્ક્રોલર, ટાઇમલાઇન, ટાઇલ નકશા.
  • પસંદગીકાર સહાયકો — નાના પેકેજ જે એક ક્રિયાપ્રતિક્રિયા શરૂઆતથી અંત સુધી સંભાળે છે: થીમ બદલવી (રનટાઇમ સ્ટાઇલશીટ લોડિંગ સાથે), ભાષા, ટેક્સ્ટ કદ, ઘટાડેલી ગતિ, શોધ, પૃષ્ઠ લિંક, શેરિંગ, અને તારીખ-સમય દાખલ. દરેક એક હેડલેસ આઇકન બટન છે જે પોપઅપ ખોલે છે — મૂળ <select> નહીં — બિલ્ટ-ઇન ટકાઉપણું અને SSR સુરક્ષા સાથે.

જાહેર ક્ષેત્ર માટે થીમ, બોક્સમાંથી જ તૈયાર

Lily 57 સ્વતંત્ર સંદર્ભ થીમ આપે છે જે સીધા તેના ક્લાસ હૂકને લક્ષ્ય બનાવે છે: NHS England, NHS Scotland અને NHS Wales (દરેક દર્દી-લક્ષી અને વ્યવસાયી-લક્ષી પ્રકારોમાં), GOV.UK, USWDS, Adobe Spectrum અને Mozilla Protocol થી પ્રેરિત પેલેટ, અને સામાન્ય-હેતુ હળવી અને ઘેરી થીમનો સમૂહ. એક સ્ટાઇલશીટ જોડો અને સરકારી સ્તરનો દેખાવ ચાલુ થાય છે; સહાયક theme-picker તેમને રનટાઇમ પર બદલે છે.

Lily ની સરખામણી કેવી રીતે થાય છે

અમે પ્રામાણિક, ઘટક-દર-ઘટક અન્ય ડિઝાઇન સિસ્ટમો સાથે સરખામણી રાખીએ છીએ — શૈલીબદ્ધ અને હેડલેસ, વ્યાપારી અને જાહેર ક્ષેત્રની. જ્યાં બીજી લાઇબ્રેરી તમને વધુ બંધ બેસે છે, ત્યાં સરખામણી તે બતાવશે; Lily બધામાંથી શીખે છે અને પોતાના પ્રેરણા સ્ત્રોતો ખુલ્લેઆમ જણાવે છે.

તેની પાછળ કોણ છે

Lily એક યુવાન, સ્વતંત્ર ઓપન-સોર્સ પ્રોજેક્ટ છે જે સહયોગ, માર્ગદર્શન અને પ્રતિસાદનું સ્વાગત કરે છે — જુઓ વિશે વાર્તા અને પ્રેરણા સ્ત્રોતો માટે. બધું — સ્પષ્ટીકરણ, પરીક્ષણો, રોડમેપ, ઓડિટ સાધનો પણ — અહીં ખુલ્લું છે: github.com/LilyDesignSystem.

Lily ને વધવામાં મદદ કરો

જો Lily તમને ઉપયોગી હોય, તો તમે કરી શકો તેવી સૌથી મૂલ્યવાન બાબતો:

  • તારો આપો અને શેર કરો. ને તારો આપો મુખ્ય રેપો અને કોઈ સહકર્મીને કેટલોગ બતાવો — જાગૃતિ એ યુવાન પ્રોજેક્ટ પાસે સૌથી દુર્લભ સંસાધન છે.
  • કંઈક બનાવો અને અમને જણાવો. વાસ્તવિક-દુનિયાના ઉપયોગના અહેવાલો — શું કામ કર્યું, શું વધુ સરળ હોઈ શકે — રોડમેપને બીજી કોઈપણ બાબત કરતાં વધુ આકાર આપે છે.
  • સુલભતાનું ઓડિટ કરો. સ્ક્રીન-રીડર પાસ (VoiceOver, NVDA, JAWS) ઉદાહરણ એપ્સ પર સોના સમાન છે; તમને જે મળે તે નોંધો.
  • થીમ અથવા અનુવાદનું યોગદાન આપો. બંને સ્વયંપૂર્ણ, સારી રીતે મર્યાદિત પ્રથમ યોગદાનો છે.
  • તમને જે મળે તે ઓછામાં ઓછા પુનરુત્પાદન સાથે શેર કરો, GitHub રિપોઝિટરી પર, અથવા ઇમેઇલ કરો joel@joelparkerhenderson.com.
