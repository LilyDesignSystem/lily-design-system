Lilyren aldeko argudioa

Lilyk zati zailak ematen dizkizu — semantika, irisgarritasuna, teklatuaren portaera, nazioartekotzea — eta itxura osoa, pozik, zuri uzten dizu.

Hasi zure diseinutik

Zure taldeak badaki jada zer itxura izan behar duen zure produktuak. Lily toki horretatik abiatzen da: ondo egiteko benetan zailak eta berregiteko garestiak diren zatiak ematen ditu — elementu semantiko zuzena, ARIA egoerak, teklatu-kontratua, fokuaren kudeaketa — eta erabaki bisual guztiak osorik, pozik, zureak uzten ditu. Zure CSSa da diseinu-sistemaren itxura, lehen egunetik.

Osagai bakoitzak klase-gako egonkorra eta egitura garbia duenez, zure estiloa garbi zurea izaten jarraitzen du eguneraketa guztietan — eta azpiko irisgarritasunak funtzionatzen jarraitzen du, bertsioz bertsio.

Lilyk zer konpromiso hartzen duen

  • Irisgarria lehenespenez. WCAG 2.2 AAA da osagai bakoitzaren helburua. Patroiek WAI-ARIA Authoring Practices jarraitzen dituzte; osagai interaktibo guztiak teklatuarekin erabil daitezke kontratu dokumentatu batekin; adibide-aplikazioek axe-core oinarri-lerro garbia mantentzen dute.
  • Nazioartekotu daiteke eraikuntzaz. Erabiltzaileak ikusten duen kate guztia — etiketa, errore eta jakinarazpen bakoitza — framework-etan izen egonkorrak dituen propa da, eta itzulpena modu naturalean doa. RTL eta bi noranzkoko testua zure dir-tik heredatzen dira. Locale-a ezagutzen duten osagaiek locale-a propa gisa hartzen dute, beti esplizituki.
  • Katalogo bat, zortzi framework. 571 osagai berak (536 Web Components natibo gisa) klase-gako eta propa-hitzarmen berdinekin HTML, Svelte, React, Vue, Angular, Blazor, Nunjucks eta Web Components-en. Zure CSSa eta zure taldearen ezagutza stack batetik bestera pasatzen dira.
  • CSS estrategiarekiko neutrala. Kebab-case klase egonkor bat osagai-erro bakoitzeko. CSS semantikoa, Tailwind utilitateak, CSS-in-JS edo prest dauden 57 gaietako bat — Lilyk guztiak ongi hartzen ditu eta dotore kentzen da bidetik.
  • Doakoa, betiko, zure baldintzetan. Kode irekia zure aukerako lizentziapean: BSD, MIT, Apache-2.0, GPL-2.0 edo GPL-3.0. Pro mailarik ez, eserleku-lizentziarik ez, telemetriarik ez.

Sakontasuna axola duen tokian

Botoi eta elkarrizketa-koadro ohikoetatik harago, katalogoak gehienek baino urrutiago iristen da:

  • Sektore publikoko patroiak NHS UK, GOV.UK, USWDS eta ONS diseinu-sistemetan ikertuak — errore-laburpenak, ohar-koadroak, laburpen-zerrendak, fase-bannerrak, saltoko estekak.
  • 140 nortasun-identifikatzaile nazionaleko osagai 50 herrialde baino gehiagotako osasun, nortasun-agiri, zerga eta pasaporte identifikatzaileak biltzen dituztenak, bakoitzak bere formatua eta baliozkotze-algoritmoa dokumentatuta.
  • Edizio- eta scrollytelling-primitiboak Reuters Graphics-etik egokituak — artikulu-diseinuak, scroll-gailuak, denbora-lerroak, lauza-mapak.
  • Hautatzaile-laguntzaileak — elkarrekintza bat hasieratik amaierara bere gain hartzen duten pakete txikiak: gai-aldaketa (exekuzio-garaiko estilo-orrien karga barne), hizkuntza, testu-tamaina, mugimendu murriztua, bilaketa, orri-estekak, partekatzea eta data-ordu sarrera. Bakoitza popup bat irekitzen duen ikono-botoi buru gabea da — ez natiboa <select> — iraunkortasun eta SSR segurtasun integratuarekin.

Sektore publikorako gaiak, kutxatik atera berri

Lilyk 57 erreferentzia-gai independente ditu, bere klase-gakoak zuzenean helburu dituztenak: NHS England, NHS Scotland eta NHS Wales (bakoitza pazienteentzako eta profesionalentzako aldaeretan), GOV.UK, USWDS, Adobe Spectrum eta Mozilla Protocol-ek inspiratutako paletak, eta gai argi eta ilun orokorren multzo bat. Lotu estilo-orri bat eta gobernu-mailako itxura martxan dago; theme-picker laguntzaileak exekuzio-garaian aldatzen ditu.

Nola konparatzen den Lily

Konparazio zintzoa mantentzen dugu, osagaiz osagai, beste diseinu-sistema batzuekin — estilatuak eta buru gabeak, komertzialak eta sektore publikokoak. Beste liburutegi bat egokiagoa bada zuretzat, konparazioak erakutsiko du; Lilyk guztietatik ikasten du eta bere inspirazioak argi aipatzen ditu.

Nor dago atzean

Lily proiektu gazte eta independente bat da, kode irekikoa, lankidetza, orientazioa eta iritziak ongi hartzen dituena — ikusi Honi buruz istorioa eta inspirazioak ezagutzeko. Dena — espezifikazioa, probak, bide-orria, auditoretza-tresnak ere — irekia dago hemen: github.com/LilyDesignSystem.

Lagundu Lilyri hazten

Lily baliagarria baduzu, egin dezakezun gauzarik baliotsuenak:

  • Eman izarra eta partekatu. Eman izarra biltegi nagusiari eta erakutsi lankide bati katalogoa — ezagutza da proiektu gazte batek duen baliabide eskasena.
  • Eraiki zerbait eta kontatu. Benetako erabileraren txostenek — zerk funtzionatu duen, zerk hobetu daitekeen — bide-orria beste ezerk baino gehiago osatzen dute.
  • Auditatu irisgarritasuna. Pantaila-irakurgailuekin (VoiceOver, NVDA, JAWS) egindako probak adibide-aplikazioetan urre hutsa dira; eman berri aurkitzen duzuna.
  • Eman gai bat edo itzulpen bat. Biak dira lehen ekarpen autonomo eta ongi mugatuak.
  • Partekatu aurkitzen duzuna, erreprodukzio minimo batekin, GitHub biltegian, edo idatzi hona: joel@joelparkerhenderson.com.
