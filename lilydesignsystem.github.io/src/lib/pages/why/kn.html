Lily ಪರವಾದ ವಾದ

Lily ನಿಮಗೆ ಕಠಿಣ ಭಾಗಗಳನ್ನು — ಶಬ್ದಾರ್ಥ, ಪ್ರವೇಶಿಸುವಿಕೆ, ಕೀಬೋರ್ಡ್ ವರ್ತನೆ, ಅಂತರರಾಷ್ಟ್ರೀಕರಣ — ಕೈಗೆ ನೀಡುತ್ತದೆ, ಮತ್ತು ನೋಟವನ್ನು ಸಂಪೂರ್ಣವಾಗಿ, ಸಂತೋಷದಿಂದ ನಿಮಗೇ ಬಿಡುತ್ತದೆ.

ನಿಮ್ಮ ವಿನ್ಯಾಸದಿಂದ ಆರಂಭಿಸಿ

ನಿಮ್ಮ ಉತ್ಪನ್ನ ಹೇಗೆ ಕಾಣಬೇಕೆಂದು ನಿಮ್ಮ ತಂಡಕ್ಕೆ ಈಗಾಗಲೇ ತಿಳಿದಿದೆ. Lily ನಿಖರವಾಗಿ ಅಲ್ಲಿಂದಲೇ ಆರಂಭಿಸುತ್ತದೆ: ಸರಿಯಾಗಿ ಮಾಡಲು ನಿಜವಾಗಿ ಕಷ್ಟಕರವಾದ ಮತ್ತು ಮರುಮಾಡಲು ದುಬಾರಿಯಾದ ಭಾಗಗಳನ್ನು — ಸರಿಯಾದ ಶಬ್ದಾರ್ಥ ಎಲಿಮೆಂಟ್, ARIA ಸ್ಥಿತಿಗಳು, ಕೀಬೋರ್ಡ್ ಒಪ್ಪಂದ, ಫೋಕಸ್ ನಿರ್ವಹಣೆ — ಅದು ಒದಗಿಸುತ್ತದೆ, ಮತ್ತು ಪ್ರತಿ ದೃಶ್ಯ ನಿರ್ಧಾರವನ್ನೂ ಸಂಪೂರ್ಣವಾಗಿ, ಆನಂದದಿಂದ ನಿಮ್ಮದಾಗಿಸುತ್ತದೆ. ನಿಮ್ಮ CSS ಮೊದಲ ದಿನದಿಂದಲೇ ವಿನ್ಯಾಸ ವ್ಯವಸ್ಥೆಯ ನೋಟ.

ಪ್ರತಿ ಘಟಕವೂ ಸ್ಥಿರ ಕ್ಲಾಸ್ ಹುಕ್ ಮತ್ತು ಶುದ್ಧ ರಚನೆಯನ್ನು ಹೊಂದಿರುವುದರಿಂದ, ಪ್ರತಿ ಅಪ್‌ಗ್ರೇಡ್‌ನಲ್ಲೂ ನಿಮ್ಮ ಶೈಲಿ ಸ್ವಚ್ಛವಾಗಿ ನಿಮ್ಮದೇ ಆಗಿರುತ್ತದೆ — ಮತ್ತು ಅದರ ಕೆಳಗಿನ ಪ್ರವೇಶಿಸುವಿಕೆ ಆವೃತ್ತಿಯ ನಂತರ ಆವೃತ್ತಿ ಕೆಲಸ ಮಾಡುತ್ತಲೇ ಇರುತ್ತದೆ.

Lily ಏನನ್ನು ಬದ್ಧತೆಯಾಗಿ ನೀಡುತ್ತದೆ

  • ಡೀಫಾಲ್ಟ್ ಆಗಿ ಪ್ರವೇಶಿಸಬಹುದಾದ. ಪ್ರತಿ ಘಟಕಕ್ಕೂ WCAG 2.2 AAA ಗುರಿ. ಮಾದರಿಗಳು WAI-ARIA Authoring Practices ಅನ್ನು ಅನುಸರಿಸುತ್ತವೆ; ಪ್ರತಿ ಸಂವಾದಾತ್ಮಕ ಘಟಕವನ್ನೂ ದಾಖಲಿತ ಒಪ್ಪಂದದೊಂದಿಗೆ ಕೀಬೋರ್ಡ್‌ನಿಂದ ನಿರ್ವಹಿಸಬಹುದು; ಉದಾಹರಣೆ ಅಪ್ಲಿಕೇಶನ್‌ಗಳು ಶುದ್ಧ axe-core ಮೂಲರೇಖೆಯನ್ನು ಕಾಯ್ದುಕೊಳ್ಳುತ್ತವೆ.
  • ನಿರ್ಮಾಣದಿಂದಲೇ ಅಂತರರಾಷ್ಟ್ರೀಯಗೊಳಿಸಬಹುದಾದ. ಬಳಕೆದಾರರು ನೋಡುವ ಪ್ರತಿ ಸ್ಟ್ರಿಂಗ್ — ಪ್ರತಿ ಲೇಬಲ್, ದೋಷ ಮತ್ತು ಪ್ರಕಟಣೆ — ಫ್ರೇಮ್‌ವರ್ಕ್‌ಗಳಾದ್ಯಂತ ಸ್ಥಿರ ಹೆಸರುಗಳಿರುವ ಪ್ರಾಪ್, ಆದ್ದರಿಂದ ಅನುವಾದ ಸಹಜವಾಗಿ ಹರಿಯುತ್ತದೆ. RTL ಮತ್ತು ದ್ವಿದಿಕ್ಕಿನ ಪಠ್ಯ ನಿಮ್ಮ dirನಿಂದ ಪಡೆಯಲ್ಪಡುತ್ತದೆ. ಲೊಕೇಲ್ ಅರಿವಿರುವ ಘಟಕಗಳು ಲೊಕೇಲ್ ಅನ್ನು ಪ್ರಾಪ್ ಆಗಿ ತೆಗೆದುಕೊಳ್ಳುತ್ತವೆ, ಯಾವಾಗಲೂ ಸ್ಪಷ್ಟವಾಗಿ.
  • ಒಂದು ಕ್ಯಾಟಲಾಗ್, ಎಂಟು ಫ್ರೇಮ್‌ವರ್ಕ್‌ಗಳು. HTML, Svelte, React, Vue, Angular, Blazor, Nunjucks ಮತ್ತು Web Components ನಲ್ಲಿ ಅದೇ ಕ್ಲಾಸ್ ಹುಕ್‌ಗಳು ಮತ್ತು ಪ್ರಾಪ್ ಸಂಪ್ರದಾಯಗಳೊಂದಿಗೆ ಅದೇ 571 ಘಟಕಗಳು (536 ಸ್ಥಳೀಯ Web Components ಆಗಿ). ನಿಮ್ಮ CSS ಮತ್ತು ನಿಮ್ಮ ತಂಡದ ಜ್ಞಾನ ಸ್ಟ್ಯಾಕ್‌ಗಳಾದ್ಯಂತ ವರ್ಗಾವಣೆಯಾಗುತ್ತದೆ.
  • CSS ತಂತ್ರಕ್ಕೆ ತಟಸ್ಥ. ಪ್ರತಿ ಘಟಕದ ರೂಟ್‌ಗೆ ಒಂದು ಸ್ಥಿರ kebab-case ಕ್ಲಾಸ್. ಶಬ್ದಾರ್ಥ CSS, Tailwind ಯುಟಿಲಿಟಿಗಳು, CSS-in-JS, ಅಥವಾ 57 ಸಿದ್ಧ ಥೀಮ್‌ಗಳಲ್ಲಿ ಒಂದು — Lily ಅವೆಲ್ಲವನ್ನೂ ಸ್ವಾಗತಿಸುತ್ತದೆ ಮತ್ತು ಸೊಗಸಾಗಿ ದಾರಿಯಿಂದ ಸರಿಯುತ್ತದೆ.
  • ಉಚಿತ, ಶಾಶ್ವತವಾಗಿ, ನಿಮ್ಮ ನಿಯಮಗಳ ಮೇಲೆ. BSD, MIT, Apache-2.0, GPL-2.0, ಅಥವಾ GPL-3.0 ನಿಮ್ಮ ಆಯ್ಕೆಯ ಅಡಿಯಲ್ಲಿ ಮುಕ್ತ ಮೂಲ. ಪ್ರೊ ಹಂತವಿಲ್ಲ, ಸೀಟ್ ಪರವಾನಗಿಗಳಿಲ್ಲ, ಟೆಲಿಮೆಟ್ರಿ ಇಲ್ಲ.

ಮುಖ್ಯವಾದಲ್ಲಿ ಆಳ

ಸಾಮಾನ್ಯ ಬಟನ್‌ಗಳು ಮತ್ತು ಡೈಲಾಗ್‌ಗಳ ಆಚೆಗೆ, ಕ್ಯಾಟಲಾಗ್ ಹೆಚ್ಚಿನವುಗಳಿಗಿಂತ ದೂರ ತಲುಪುತ್ತದೆ:

  • ಸಾರ್ವಜನಿಕ ವಲಯದ ಮಾದರಿಗಳು NHS UK, GOV.UK, USWDS, ಮತ್ತು ONS ವಿನ್ಯಾಸ ವ್ಯವಸ್ಥೆಗಳಿಂದ ಸಂಶೋಧಿಸಲ್ಪಟ್ಟವು — ದೋಷ ಸಾರಾಂಶಗಳು, ಎಚ್ಚರಿಕೆ ಕಾಲ್‌ಔಟ್‌ಗಳು, ಸಾರಾಂಶ ಪಟ್ಟಿಗಳು, ಹಂತ ಬ್ಯಾನರ್‌ಗಳು, ಸ್ಕಿಪ್ ಲಿಂಕ್‌ಗಳು.
  • 140 ರಾಷ್ಟ್ರೀಯ ವೈಯಕ್ತಿಕ ಗುರುತಿಸುವಿಕೆ ಘಟಕಗಳು 50+ ದೇಶಗಳಾದ್ಯಂತ ಆರೋಗ್ಯ, ರಾಷ್ಟ್ರೀಯ ಗುರುತಿನ ಚೀಟಿ, ತೆರಿಗೆ ಮತ್ತು ಪಾಸ್‌ಪೋರ್ಟ್ ಗುರುತಿಸುವಿಕೆಗಳನ್ನು ಒಳಗೊಂಡಿರುವ, ಪ್ರತಿಯೊಂದೂ ತನ್ನ ಸ್ವರೂಪ ಮತ್ತು ಮೌಲ್ಯೀಕರಣ ಅಲ್ಗಾರಿದಮ್ ಅನ್ನು ದಾಖಲಿಸುತ್ತದೆ.
  • ಸಂಪಾದಕೀಯ ಮತ್ತು ಸ್ಕ್ರೋಲಿಟೆಲ್ಲಿಂಗ್ ಮೂಲಭೂತ ಅಂಶಗಳು Reuters Graphics ನಿಂದ ಅಳವಡಿಸಿಕೊಂಡ — ಲೇಖನ ವಿನ್ಯಾಸಗಳು, ಸ್ಕ್ರೋಲರ್‌ಗಳು, ಟೈಮ್‌ಲೈನ್‌ಗಳು, ಟೈಲ್ ನಕ್ಷೆಗಳು.
  • ಪಿಕ್ಕರ್ ಸಹಾಯಕಗಳು — ಒಂದು ಸಂವಾದವನ್ನು ಆರಂಭದಿಂದ ಅಂತ್ಯದವರೆಗೆ ಹೊಂದಿರುವ ಸಣ್ಣ ಪ್ಯಾಕೇಜ್‌ಗಳು: ಥೀಮ್ ಬದಲಾವಣೆ (ರನ್‌ಟೈಮ್ ಸ್ಟೈಲ್‌ಶೀಟ್ ಲೋಡಿಂಗ್‌ನೊಂದಿಗೆ), ಭಾಷೆ, ಪಠ್ಯದ ಗಾತ್ರ, ಕಡಿಮೆ ಚಲನೆ, ಹುಡುಕಾಟ, ಪುಟ ಲಿಂಕ್‌ಗಳು, ಹಂಚಿಕೆ, ಮತ್ತು ದಿನಾಂಕ-ಸಮಯ ನಮೂದು. ಪ್ರತಿಯೊಂದೂ ಪಾಪ್‌ಅಪ್ ತೆರೆಯುವ ಹೆಡ್‌ಲೆಸ್ ಐಕಾನ್ ಬಟನ್ — ಸ್ಥಳೀಯ <select> ಅಲ್ಲ — ಪರ್ಸಿಸ್ಟೆನ್ಸ್ ಮತ್ತು SSR ಸುರಕ್ಷತೆ ಅಂತರ್ನಿರ್ಮಿತವಾಗಿ.

ಸಾರ್ವಜನಿಕ ವಲಯಕ್ಕಾಗಿ ಥೀಮ್‌ಗಳು, ಪೆಟ್ಟಿಗೆಯಿಂದಲೇ

Lily 57 ಸ್ವತಂತ್ರ ಉಲ್ಲೇಖ ಥೀಮ್‌ಗಳೊಂದಿಗೆ ಬರುತ್ತದೆ, ಅವು ಅದರ ಕ್ಲಾಸ್ ಹುಕ್‌ಗಳನ್ನು ನೇರವಾಗಿ ಗುರಿಯಾಗಿಸುತ್ತವೆ: NHS England, NHS Scotland, ಮತ್ತು NHS Wales (ಪ್ರತಿಯೊಂದೂ ರೋಗಿ-ಮುಖಿ ಮತ್ತು ವೈದ್ಯ-ಮುಖಿ ರೂಪಾಂತರಗಳಲ್ಲಿ), GOV.UK, USWDS, Adobe Spectrum ಮತ್ತು Mozilla Protocol ಪ್ರೇರಿತ ಪ್ಯಾಲೆಟ್‌ಗಳು, ಮತ್ತು ಸಾಮಾನ್ಯ ಉದ್ದೇಶದ ತಿಳಿ ಮತ್ತು ಗಾಢ ಥೀಮ್‌ಗಳ ಒಂದು ಗುಂಪು. ಒಂದು ಸ್ಟೈಲ್‌ಶೀಟ್ ಲಿಂಕ್ ಮಾಡಿ ಮತ್ತು ಸರ್ಕಾರಿ ಮಟ್ಟದ ನೋಟ ಆನ್ ಆಗುತ್ತದೆ; theme-picker ಸಹಾಯಕ ಅವುಗಳನ್ನು ರನ್‌ಟೈಮ್‌ನಲ್ಲಿ ಬದಲಾಯಿಸುತ್ತದೆ.

Lily ಹೇಗೆ ಹೋಲಿಕೆಯಾಗುತ್ತದೆ

ನಾವು ಪ್ರಾಮಾಣಿಕ, ಘಟಕ-ಘಟಕವಾಗಿ ಇತರ ವಿನ್ಯಾಸ ವ್ಯವಸ್ಥೆಗಳೊಂದಿಗೆ ಹೋಲಿಕೆ ಅನ್ನು ಇಟ್ಟುಕೊಳ್ಳುತ್ತೇವೆ — ಶೈಲೀಕೃತ ಮತ್ತು ಹೆಡ್‌ಲೆಸ್, ವಾಣಿಜ್ಯ ಮತ್ತು ಸಾರ್ವಜನಿಕ ವಲಯ. ಇನ್ನೊಂದು ಲೈಬ್ರರಿ ನಿಮಗೆ ಹೆಚ್ಚು ಸೂಕ್ತವಾದರೆ, ಹೋಲಿಕೆ ಅದನ್ನು ತೋರಿಸುತ್ತದೆ; Lily ಅವೆಲ್ಲದರಿಂದ ಕಲಿಯುತ್ತದೆ ಮತ್ತು ತನ್ನ ಸ್ಫೂರ್ತಿಗಳನ್ನು ಬಹಿರಂಗವಾಗಿ ಉಲ್ಲೇಖಿಸುತ್ತದೆ.

ಇದರ ಹಿಂದೆ ಯಾರಿದ್ದಾರೆ

Lily ಒಂದು ಯುವ, ಸ್ವತಂತ್ರ ಮುಕ್ತ ಮೂಲ ಯೋಜನೆ, ಸಹಯೋಗ, ಮಾರ್ಗದರ್ಶನ ಮತ್ತು ಪ್ರತಿಕ್ರಿಯೆಯನ್ನು ಸ್ವಾಗತಿಸುತ್ತದೆ — ನೋಡಿ ಕುರಿತು ಕಥೆ ಮತ್ತು ಸ್ಫೂರ್ತಿಗಳಿಗಾಗಿ. ಎಲ್ಲವೂ — ವಿಶೇಷಣ, ಪರೀಕ್ಷೆಗಳು, ರೋಡ್‌ಮ್ಯಾಪ್, ಲೆಕ್ಕಪರಿಶೋಧನೆ ಸಾಧನಗಳೂ ಸಹ — ಇಲ್ಲಿ ಮುಕ್ತವಾಗಿವೆ: github.com/LilyDesignSystem.

Lily ಬೆಳೆಯಲು ಸಹಾಯ ಮಾಡಿ

Lily ನಿಮಗೆ ಉಪಯುಕ್ತವಾದರೆ, ನೀವು ಮಾಡಬಹುದಾದ ಅತ್ಯಂತ ಮೌಲ್ಯಯುತ ಕೆಲಸಗಳು:

  • ನಕ್ಷತ್ರ ನೀಡಿ ಮತ್ತು ಹಂಚಿಕೊಳ್ಳಿ. ನಕ್ಷತ್ರ ನೀಡಿ ಮುಖ್ಯ ರೆಪೊಸಿಟರಿಗೆ ಮತ್ತು ಸಹೋದ್ಯೋಗಿಗೆ ತೋರಿಸಿ ಕ್ಯಾಟಲಾಗ್ — ಅರಿವು ಯುವ ಯೋಜನೆಗೆ ಅತ್ಯಂತ ವಿರಳ ಸಂಪನ್ಮೂಲ.
  • ಏನನ್ನಾದರೂ ನಿರ್ಮಿಸಿ ಮತ್ತು ನಮಗೆ ತಿಳಿಸಿ. ನಿಜ ಜಗತ್ತಿನ ಬಳಕೆಯ ವರದಿಗಳು — ಏನು ಕೆಲಸ ಮಾಡಿತು, ಏನು ಸುಗಮವಾಗಬಹುದಿತ್ತು — ಬೇರೆ ಯಾವುದಕ್ಕಿಂತಲೂ ರೋಡ್‌ಮ್ಯಾಪ್ ಅನ್ನು ರೂಪಿಸುತ್ತವೆ.
  • ಪ್ರವೇಶಿಸುವಿಕೆಯನ್ನು ಪರಿಶೋಧಿಸಿ. ಸ್ಕ್ರೀನ್-ರೀಡರ್ ಪರೀಕ್ಷೆಗಳು (VoiceOver, NVDA, JAWS) ಉದಾಹರಣೆ ಅಪ್ಲಿಕೇಶನ್‌ಗಳ ಮೇಲೆ ಚಿನ್ನಕ್ಕೆ ಸಮಾನ; ನೀವು ಕಂಡುಕೊಂಡದ್ದನ್ನು ಸಲ್ಲಿಸಿ.
  • ಥೀಮ್ ಅಥವಾ ಅನುವಾದವನ್ನು ಕೊಡುಗೆ ನೀಡಿ. ಎರಡೂ ಸ್ವಯಂ-ಪೂರ್ಣ, ಚೆನ್ನಾಗಿ ವ್ಯಾಪ್ತಿ ನಿರ್ಧರಿಸಿದ ಮೊದಲ ಕೊಡುಗೆಗಳು.
  • ನೀವು ಕಂಡುಕೊಂಡದ್ದನ್ನು, ಕನಿಷ್ಠ ಪುನರುತ್ಪಾದನೆಯೊಂದಿಗೆ ಹಂಚಿಕೊಳ್ಳಿ, GitHub ರೆಪೊಸಿಟರಿಯಲ್ಲಿ, ಅಥವಾ ಇಮೇಲ್ ಮಾಡಿ joel@joelparkerhenderson.com.
