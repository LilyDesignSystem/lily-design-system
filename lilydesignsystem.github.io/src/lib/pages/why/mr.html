Lily साठी युक्तिवाद

Lily तुम्हाला कठीण भाग देते — सेमँटिक्स, सुलभता, कीबोर्ड वर्तन, आंतरराष्ट्रीयीकरण — आणि रूप पूर्णपणे, आनंदाने, तुमच्यावर सोडते.

तुमच्या डिझाइनपासून सुरुवात करा

तुमच्या टीमला आधीच माहीत आहे की तुमचे उत्पादन कसे दिसले पाहिजे. Lily नेमके तिथून सुरू होते: ते असे भाग पुरवते जे खरोखर बरोबर करणे कठीण आणि पुन्हा करणे महागडे आहे — योग्य सेमँटिक घटक, ARIA स्थिती, कीबोर्ड करार, फोकस व्यवस्थापन — आणि प्रत्येक दृश्य निर्णय पूर्णपणे, आनंदाने, तुमच्यावर सोडते. तुमचे CSS हेच पहिल्या दिवसापासून डिझाइन प्रणालीचे रूप आहे.

प्रत्येक घटकाकडे स्थिर क्लास हुक आणि शुद्ध रचना असल्यामुळे, प्रत्येक अपग्रेडमधून तुमची शैली स्वच्छपणे तुमचीच राहते — आणि खालील सुलभता आवृत्ती नंतर आवृत्ती काम करत राहते.

Lily कशाशी बांधील आहे

  • मूलतः सुलभ. प्रत्येक घटकासाठी WCAG 2.2 AAA हे लक्ष्य आहे. नमुने WAI-ARIA Authoring Practices चे अनुसरण करतात; प्रत्येक परस्परसंवादी घटक दस्तऐवजीकृत कराराने कीबोर्डवरून चालवता येतो; उदाहरण अॅप्स स्वच्छ axe-core बेसलाइन राखतात.
  • रचनेपासूनच आंतरराष्ट्रीयीकरणक्षम. वापरकर्त्याला दिसणारी प्रत्येक स्ट्रिंग — प्रत्येक लेबल, त्रुटी आणि घोषणा — फ्रेमवर्कमध्ये स्थिर नावांचे प्रॉप आहे, त्यामुळे भाषांतर नैसर्गिकपणे वाहते. RTL आणि द्विदिश मजकूर तुमच्या dir कडून वारसा घेतात. लोकेल-जागरूक घटक लोकेल प्रॉप म्हणून घेतात, नेहमी स्पष्टपणे.
  • एक कॅटलॉग, आठ फ्रेमवर्क. तेच 571 घटक (536 मूळ Web Components म्हणून) HTML, Svelte, React, Vue, Angular, Blazor, Nunjucks आणि Web Components मध्ये समान क्लास हुक आणि प्रॉप संकेतांसह. तुमचे CSS आणि टीमचे ज्ञान स्टॅकमध्ये हस्तांतरित होते.
  • CSS धोरणापासून स्वतंत्र. प्रत्येक घटक मुळासाठी एक स्थिर केबाब-केस क्लास. सेमँटिक CSS, Tailwind युटिलिटी, CSS-in-JS किंवा 57 तयार थीमपैकी एक — Lily सर्वांचे स्वागत करते आणि सुंदरपणे बाजूला होते.
  • मोफत, कायमचे, तुमच्या अटींवर. BSD, MIT, Apache-2.0, GPL-2.0, किंवा GPL-3.0 यापैकी तुमच्या निवडीनुसार ओपन सोर्स. प्रो स्तर नाही, सीट परवाने नाहीत, टेलिमेट्री नाही.

जिथे महत्त्वाचे तिथे खोली

नेहमीच्या बटणे आणि डायलॉगच्या पलीकडे, कॅटलॉग बहुतेकांपेक्षा पुढे पोहोचतो:

  • सार्वजनिक क्षेत्रातील नमुने NHS UK, GOV.UK, USWDS आणि ONS डिझाइन प्रणालींकडून अभ्यासलेले — त्रुटी सारांश, इशारा बॉक्स, सारांश यादी, टप्पा बॅनर, वगळण्याचे दुवे.
  • 140 राष्ट्रीय वैयक्तिक ओळखकर्ता घटक 50 पेक्षा जास्त देशांमधील आरोग्यसेवा, राष्ट्रीय-ओळखपत्र, कर आणि पासपोर्ट ओळखकर्ते समाविष्ट करणारे, प्रत्येक त्याचे स्वरूप आणि पडताळणी अल्गोरिदम दस्तऐवजीकृत करतो.
  • संपादकीय आणि scrollytelling मूलभूत घटक Reuters Graphics कडून रुपांतरित — लेख मांडणी, स्क्रोलर, टाइमलाइन, टाइल नकाशे.
  • निवडक सहाय्यक — लहान पॅकेजेस जे एक परस्परसंवाद सुरुवातीपासून शेवटपर्यंत सांभाळतात: थीम बदल (रनटाइम स्टाइलशीट लोडिंगसह), भाषा, मजकूर आकार, कमी गती, शोध, पृष्ठ दुवे, शेअरिंग आणि तारीख-वेळ नोंद. प्रत्येक एक हेडलेस आयकॉन बटण आहे जे पॉपअप उघडते — मूळ <select> नाही — अंगभूत टिकाऊपणा आणि SSR सुरक्षिततेसह.

सार्वजनिक क्षेत्रासाठी थीम, लगेच तयार

Lily 57 स्वतंत्र संदर्भ थीम पुरवते जे थेट त्याच्या क्लास हुकला लक्ष्य करतात: NHS England, NHS Scotland आणि NHS Wales (प्रत्येक रुग्णाभिमुख आणि व्यावसायिकाभिमुख प्रकारांत), GOV.UK, USWDS, Adobe Spectrum आणि Mozilla Protocol कडून प्रेरित पॅलेट आणि सामान्य-उद्देश हलक्या व गडद थीमचा संच. एक स्टाइलशीट जोडा आणि सरकारी दर्जाचे रूप चालू होते; सहाय्यक theme-picker त्यांना रनटाइमला बदलतो.

Lily ची तुलना कशी होते

आम्ही एक प्रामाणिक, घटक-दर-घटक इतर डिझाइन प्रणालींशी तुलना ठेवतो — शैलीबद्ध आणि हेडलेस, व्यावसायिक आणि सार्वजनिक क्षेत्रातील. जिथे दुसरी लायब्ररी तुम्हाला अधिक योग्य आहे, तिथे तुलना ते दाखवेल; Lily सर्वांकडून शिकते आणि आपले प्रेरणास्रोत उघडपणे नमूद करते.

यामागे कोण आहे

Lily हा एक तरुण, स्वतंत्र ओपन-सोर्स प्रकल्प आहे जो सहकार्य, मार्गदर्शन आणि अभिप्रायाचे स्वागत करतो — पहा माहिती कथा आणि प्रेरणास्रोतांसाठी. सर्व काही — तपशील, चाचण्या, रोडमॅप, अगदी ऑडिट साधनेही — येथे खुले आहे: github.com/LilyDesignSystem.

Lily ला वाढण्यास मदत करा

Lily तुम्हाला उपयुक्त असल्यास, तुम्ही करू शकता अशा सर्वात मौल्यवान गोष्टी:

  • तारा द्या आणि शेअर करा. याला तारा द्या मुख्य रेपो आणि एखाद्या सहकाऱ्याला कॅटलॉग दाखवा — जागरूकता हे तरुण प्रकल्पाकडे असलेले सर्वात दुर्मिळ संसाधन आहे.
