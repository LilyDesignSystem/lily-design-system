Book an appointment in .NET MAUI

A booking screen for iOS and Android from one C# project, with .NET MAUI and Lily: labelled choices, a line of guidance, and the bars a phone app has.

What you'll build

One screen of a booking app, on iOS and Android, with .NET MAUI: a top bar of labelled buttons, a large heading, a line of guidance, four choices (where, what type, with whom, and what time of day), and a tab bar. It is generic: a service anyone might book, with example places and people. About 30 minutes.

Before you start

You need the .NET 11 SDK with the MAUI workload (dotnet workload install maui), and Xcode for iOS or the Android SDK for Android. LilyDesignSystem.Maui is not on NuGet yet, so the app references it from a clone of the repository, beside the app: 

git clone https://github.com/LilyDesignSystem/lily-design-system
dotnet new maui -n BookAppointment
cd BookAppointment
rm App.xaml App.xaml.cs AppShell.xaml AppShell.xaml.cs MainPage.xaml MainPage.xaml.cs
rm -r Resources/Styles Resources/Images/dotnet_bot.png

The app is written in C#, so the template's XAML pages and styles go. Each code block below is one whole file in BookAppointment; replace the file the template made where the names match.

Step 3: Describe the booking

Booking.cs

namespace BookAppointment;

/// <summary>One choice in a list: the id the service knows it by, and the words the person sees.</summary>
public record Choice(string Id, string Label);

/// <summary>What the person has chosen, and the choices offered. The choices come from the service; these are examples.</summary>
public class Booking
{
    public string Location { get; set; } = "main";
    public string Type { get; set; } = "";
    public string Person { get; set; } = "any";
    public string TimeOfDay { get; set; } = "";

    /// <summary>Times can be looked for once a type is chosen: the type decides how long the appointment is.</summary>
    public bool CanFindTimes => Type.Length > 0;

    public static readonly Choice[] Locations = [new("main", "Main office"), new("north", "North branch"), new("online", "Online")];
    public static readonly Choice[] Types =
        [new("", "Select type"), new("first", "First visit"), new("follow-up", "Follow-up"), new("advice", "Advice by phone")];
    public static readonly Choice[] People = [new("any", "No preference"), new("sam", "Sam Okoro"), new("alex", "Alex Kim")];
    public static readonly Choice[] TimesOfDay =
        [new("", "Select an option"), new("morning", "Morning"), new("afternoon", "Afternoon"), new("evening", "Evening")];
}

Step 4: Choose the colours and styles

Lily ships no brand, and its MAUI controls set no colour or size: an app styles them by style class, as the web themes style class names.

Brand.cs

namespace BookAppointment;

/// <summary>
/// The service's own colours. A brand colour colours a band or a line, never text on the page; the text on the band is white,
/// well above 4.5:1 on this navy (AGENTS/visual-identity.md). Lily ships no brand: these are yours.
/// </summary>
public static class Brand
{
    public static readonly Color Band = Color.FromArgb("#1F2A44");
    public static readonly Color OnBand = Colors.White;
    public static readonly Color Line = Color.FromArgb("#C89B3C");
}

AppStyles.cs

namespace BookAppointment;

/// <summary>
/// The app's styles for Lily's class hooks. Lily's controls set no colour, size or font; an app styles them by StyleClass, as
/// the web themes style the kebab-case classes.
/// </summary>
public static class AppStyles
{
    public static ResourceDictionary Create()
    {
        var styles = new ResourceDictionary();
        void Class<T>(string name, BindableProperty property, object value)
            where T : BindableObject
        {
            var style = new Style(typeof(T)) { Class = name, ApplyToDerivedTypes = true };
            style.Setters.Add(new Setter { Property = property, Value = value });
            styles.Add(style);
        }

        Class<Label>("field-label", Label.FontSizeProperty, 17d);
        Class<Label>("inset-text-text", Label.FontSizeProperty, 17d);
        return styles;
    }
}

Step 5: Ask for a choice

Lily's Field draws the label and gives the control its spoken name. The box and chevron are the app's; the platform's own field border is taken off in MauiProgram.cs.

ChoiceField.cs

using LilyDesignSystem.Maui;

namespace BookAppointment;

/// <summary>A labelled choice drawn as a box with a chevron, like a web select. Lily's Field gives the label and the spoken name.</summary>
public static class ChoiceField
{
    public static Field Create(string label, Choice[] choices, string selected, Action<string> onSelect)
    {
        var picker = new Picker
        {
            ItemsSource = choices.Select(c => c.Label).ToList(),
            SelectedIndex = Math.Max(0, Array.FindIndex(choices, c => c.Id == selected)),
            FontSize = 17,
            TextColor = Colors.Black,
        };
        picker.SelectedIndexChanged += (_, _) => onSelect(choices[picker.SelectedIndex].Id);
        var chevron = new Image { Source = "chevron.png", WidthRequest = 22, HeightRequest = 22, VerticalOptions = LayoutOptions.Center };
        AutomationProperties.SetIsInAccessibleTree(chevron, false);
        var box = new Border
        {
            Stroke = Colors.Black,
            StrokeThickness = 2,
            BackgroundColor = Colors.White,
            Padding = new Thickness(16, 4),
            MaximumWidthRequest = 300,
            HorizontalOptions = LayoutOptions.Start,
            WidthRequest = 300,
            HeightRequest = 52,
            Content = new Grid
            {
                ColumnDefinitions = [new ColumnDefinition(GridLength.Star), new ColumnDefinition(GridLength.Auto)],
                Children = { picker, chevron },
            },
        };
        Grid.SetColumn(chevron, 1);
        return new Field { Label = label, Control = box };
    }
}

Step 7: Draw the page

Both bars are drawn here to match the service's design, and each paints its own edge of the screen. MAUI has no selected trait for a button, so the selected tab says "selected" in its spoken name, from Words.

BookAppointmentPage.cs

using LilyDesignSystem.Maui;

namespace BookAppointment;

/// <summary>
/// The app's one page: a top bar of labelled buttons, the form, and a tab bar. Both bars are drawn here so they match the
/// service's design.
/// </summary>
public class BookAppointmentPage : ContentPage
{
    private readonly Booking booking = new();

    public BookAppointmentPage()
    {
        // Each bar paints its own edge of the screen: the top bar under the status bar, the tab bar under the home indicator.
        SafeAreaEdges = SafeAreaEdges.None;
        BackgroundColor = Colors.White;
        var find = new Button { Text = Words.FindTimes, IsEnabled = false, HorizontalOptions = LayoutOptions.Start };
        void Changed() => find.IsEnabled = booking.CanFindTimes;

        var title = new Label { Text = Words.Title, FontSize = 40, FontAttributes = FontAttributes.Bold, TextColor = Colors.Black };
        SemanticProperties.SetHeadingLevel(title, SemanticHeadingLevel.Level1);
        // Lily's InsetText is the words; the rail at its leading edge is the app's drawing.
        var inset = new Grid { ColumnDefinitions = [new ColumnDefinition(4), new ColumnDefinition(GridLength.Star)], ColumnSpacing = 12 };
        inset.Add(new BoxView { Color = Colors.Black }, 0);
        inset.Add(new InsetText { Text = Words.Intro }, 1);

        var form = new VerticalStackLayout
        {
            Spacing = 20,
            Padding = new Thickness(20, 16),
            Children =
            {
                title,
                inset,
                ChoiceField.Create(Words.Location, Booking.Locations, booking.Location, v => { booking.Location = v; Changed(); }),
                ChoiceField.Create(Words.Type, Booking.Types, booking.Type, v => { booking.Type = v; Changed(); }),
                ChoiceField.Create(Words.Person, Booking.People, booking.Person, v => { booking.Person = v; Changed(); }),
                ChoiceField.Create(Words.TimeOfDay, Booking.TimesOfDay, booking.TimeOfDay, v => { booking.TimeOfDay = v; Changed(); }),
                find,
            },
        };

        var content = new Grid
        {
            SafeAreaEdges = SafeAreaEdges.None,
            RowDefinitions = [new RowDefinition(GridLength.Auto), new RowDefinition(GridLength.Star), new RowDefinition(GridLength.Auto)],
        };
        content.Add(TopBar(), 0, 0);
        content.Add(new ScrollView { Content = form, BackgroundColor = Color.FromArgb("#F8F8F8") }, 0, 1);
        content.Add(TabBar(), 0, 2);
        Content = content;
    }

    private static Button BarButton(string icon, string label, Color color) => new()
    {
        ImageSource = icon,
        Text = label,
        FontSize = 11,
        TextColor = color,
        BackgroundColor = Colors.Transparent,
        Padding = new Thickness(4),
        MinimumHeightRequest = 48,
        MinimumWidthRequest = 52,
        ContentLayout = new Button.ButtonContentLayout(Button.ButtonContentLayout.ImagePosition.Top, 2),
    };

    private static View TopBar()
    {
        var logo = new HorizontalStackLayout
        {
            Spacing = 6,
            HorizontalOptions = LayoutOptions.Center,
            VerticalOptions = LayoutOptions.Center,
            Children =
            {
                new Image { Source = "logo.png", HeightRequest = 28, WidthRequest = 28 },
                new Label { Text = Words.AppName, TextColor = Brand.OnBand, FontSize = 12, FontAttributes = FontAttributes.Bold, VerticalOptions = LayoutOptions.Center },
            },
        };
        SemanticProperties.SetDescription(logo, Words.AppName);
        SemanticProperties.SetHeadingLevel(logo, SemanticHeadingLevel.Level2);
        var bar = new Grid
        {
            SafeAreaEdges = new SafeAreaEdges(SafeAreaRegions.None, SafeAreaRegions.All, SafeAreaRegions.None, SafeAreaRegions.None),
            BackgroundColor = Brand.Band,
            Padding = new Thickness(4, 0, 4, 8),
            ColumnDefinitions =
            [
                new ColumnDefinition(GridLength.Auto), new ColumnDefinition(GridLength.Auto), new ColumnDefinition(GridLength.Star),
                new ColumnDefinition(GridLength.Auto), new ColumnDefinition(GridLength.Auto),
            ],
        };
        bar.Add(BarButton("home.png", Words.Home, Brand.OnBand), 0);
        bar.Add(BarButton("language.png", Words.Language, Brand.OnBand), 1);
        bar.Add(logo, 2);
        bar.Add(BarButton("help.png", Words.Help, Brand.OnBand), 3);
        bar.Add(BarButton("messages.png", Words.Messages, Brand.OnBand), 4);
        // The band reaches the top of the screen, under the status bar; the buttons stay below it.
        return new ContentView { BackgroundColor = Brand.Band, SafeAreaEdges = SafeAreaEdges.None, Content = bar };
    }

    private static View TabBar()
    {
        (string Label, string Icon)[] tabs =
            [(Words.Appointments, "calendar.png"), (Words.Orders, "bag.png"), (Words.Account, "account.png"), (Words.More, "more.png")];
        var bar = new Grid { BackgroundColor = Colors.White, Padding = new Thickness(0, 6, 0, 0) };
        for (var i = 0; i < tabs.Length; i++)
        {
            bar.ColumnDefinitions.Add(new ColumnDefinition(GridLength.Star));
            var button = BarButton(tabs[i].Icon, tabs[i].Label, i == 0 ? Brand.Band : Colors.Black);
            if (i == 0)
            {
                button.FontAttributes = FontAttributes.Bold;
                SemanticProperties.SetDescription(button, Words.Selected(tabs[i].Label));
            }
            bar.Add(button, i);
        }
        return new VerticalStackLayout
        {
            SafeAreaEdges = new SafeAreaEdges(SafeAreaRegions.None, SafeAreaRegions.None, SafeAreaRegions.None, SafeAreaRegions.All),
            Children = { new BoxView { Color = Brand.Line, HeightRequest = 2 }, bar },
            BackgroundColor = Colors.White,
        };
    }
}

Step 8: Start the app

MauiProgram.cs

using LilyDesignSystem.Maui.Themes;

namespace BookAppointment;

public static class MauiProgram
{
    public static MauiApp CreateMauiApp()
    {
        var builder = MauiApp.CreateBuilder();
        builder.UseMauiApp<App>();
        // The box round each choice is the app's (ChoiceField), so the platform's own field border is taken off.
        Microsoft.Maui.Handlers.PickerHandler.Mapper.AppendToMapping("NoBorder", (handler, _) =>
        {
#if IOS
            handler.PlatformView.BorderStyle = UIKit.UITextBorderStyle.None;
#elif ANDROID
            handler.PlatformView.Background = null;
#endif
        });
        return builder.Build();
    }
}

public class App : Application
{
    public App()
    {
        // The light theme's tokens, for {DynamicResource lily-color-…}, and the app's styles for Lily's class hooks.
        LilyTheme.Apply(Resources, LilyTokens.Light);
        Resources.MergedDictionaries.Add(AppStyles.Create());
    }

    protected override Window CreateWindow(IActivationState? activationState) =>
        new(new BookAppointmentPage()) { Title = Words.AppName };
}

Run it with dotnet build -t:Run -f net11.0-ios, or -f net11.0-android with an emulator running.

Check your work: turn on VoiceOver or TalkBack and move through the screen: each choice says its label, then its value, and the Appointments tab says it is selected. "Find times" is dimmed until you choose a type.

What this does not do yet

  • The buttons in the bars and "Find times" do nothing: the screen is the lesson, not the booking.
  • The choices are fixed examples. A real app asks its service for them, in the person's language.
  • It has one language. The words are in one place, so adding another touches no view.
