Dyskewgh Lily, gradh ha gradh

Dynnargh! Pub dyskans a dhalleth dhiworth nagonan ha drehevel an keth tra vyghan — furv hedhesys ha stylys — yn a-dro dhe 10 mynysenn, may hyllowgh kehevelepi framwyth yn gwiw. Ena ewgh downa gans tebelyow ha dewisyow devnydhyer.

Kyns dalleth

Ty a'n jeves othom a nebes dres-marth:

  • Rag an dyskans HTML — unnik gwiaskodhor ha golyoryer tekst. Henn yw an toulys oll.
  • Rag Svelte, React, Vue, Angular, po Nunjucks — git, Node 26, ha pnpm 10 po nowodhyes.
  • Rag Blazor — git ha'n .NET SDK 8 po nowodhyes.

Nowydh dhe dharnow heb pen? Y'th eus y'n le ewn — pub dyskans a displetya an pyth a hwarvos ha'n kamm a dhiskwedh an koodh ewn dhe gopia.

Peswar kamm dhiworth nagonan dhe dhelivrans

  1. Dha dharn kynsa (~5 mynysenn) — dewisewgh dha framwyth a-woeles, kevewgh an koodh, ha dyskwedhewgh Button.
  2. Kesstrewewgh ha stylyewgh (~5 mynysenn) — drehevewgh furv gans lavellow ha stylyewgh orth krogow klass kebab-case (rann a bub dyskans framwyth).
  3. Rewgh tebel dhodho (~15 mynysenn) — chanjewgh dha CSS skrifys dre leuv gans onan a'n 57 tebel parys, ena gadewgh an devnydhyoryon dhe chanjya y'n termyn-dyrghas: dyskans tebelyow.
  4. Gwithewgh dewisyow (~15 mynysenn) — keworrewgh dewis yeth ha myns an skrif gans an gweresoryon dewisyow: dyskans gweresoryon.

Ewgh downa

Tebelyow

Gweresoryon dewisyow

~15 mynysenn

Wosa an dyskansow
