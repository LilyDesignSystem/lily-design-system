Learn Lily small small, step by step

Welcome! Every tutorial start from scratch and build di same small thing — accessible, styled form — for about 10 minutes, so you fit compare frameworks fair and square. Then go deeper with theming and user preferences.

Before you start

You need very small tins:

  • For di HTML tutorial — just browser and text editor. Na all di toolkit be dat.
  • For Svelte, React, Vue, Angular, abi Nunjucks — git, Node 26, and pnpm 10 or newer one.
  • For Blazor — git and di .NET SDK 8 or later.

You new to headless components? You don reach di right place — each tutorial dey explain wetin dey happen as you dey go, and every step show di exact code to copy.

Four steps wey go take you from zero reach shipping

  1. Your first component (~5 minutes) — pick your framework below, get di code, and render Button.
  2. Compose and style (~5 minutes) — build labelled form and style am against di kebab-case class hooks (part of each framework tutorial).
  3. Theme am (~15 minutes) — swap your hand-written CSS for one of di 57 ready-made themes, then let users switch for runtime: theming tutorial.
  4. Respect preferences (~15 minutes) — add language and text-size selection with di preference helpers: helpers tutorial.
