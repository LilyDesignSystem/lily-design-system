មុនពេលអ្នកចាប់ផ្តើម

អ្នកត្រូវការតិចតួចគួរឱ្យភ្ញាក់ផ្អើល៖

ថ្មីចំពោះសមាសភាគគ្មានក្បាល? អ្នកនៅកន្លែងត្រឹមត្រូវ — មេរៀននីមួយៗពន្យល់ពីអ្វីដែលកំពុងកើតឡើងនៅពេលអ្នកដំណើរទៅមុខ ហើយជំហាននីមួយៗបង្ហាញកូដពិតប្រាកដដើម្បីចម្លង។

បួនជំហានពីសូន្យទៅការដឹកជញ្ជូន

  1. សមាសភាគដំបូងរបស់អ្នក (~៥ នាទី) — ជ្រើសរើសក្របខណ្ឌរបស់អ្នកខាងក្រោម យកកូដ ហើយបង្ហាញ Button មួយ។
  2. ផ្សំ និងដាក់រចនាប័ទ្ម (~៥ នាទី) — សាងសង់ទម្រង់ដែលមានស្លាក ហើយដាក់រចនាប័ទ្មប្រឆាំងនឹង class hook kebab-case (ផ្នែកនៃមេរៀនក្របខណ្ឌនីមួយៗ)។
  3. ដាក់ស្បែក (~១៥ នាទី) — ជំនួស CSS ដែលសរសេរដោយដៃរបស់អ្នកដោយស្បែករួចជាស្រេច ៥៧ មួយ បន្ទាប់មកអនុញ្ញាតឱ្យអ្នកប្រើប្តូរនៅពេលដំណើរការ៖ មេរៀនស្បែក.
  4. គោរពចំណូលចិត្ត (~១៥ នាទី) — បន្ថែមការជ្រើសរើសភាសា និងទំហំអក្សរជាមួយជំនួយការចំណូលចិត្ត៖ មេរៀនជំនួយការ.
