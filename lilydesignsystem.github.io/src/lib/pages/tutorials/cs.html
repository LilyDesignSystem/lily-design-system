Naučte se Lily krok za krokem

Vítejte! Každý návod začíná od nuly a staví tutéž malou věc — přístupný, nastylovaný formulář — asi za 10 minut, abyste mohli frameworky porovnat za stejných podmínek. Pak jděte hlouběji k motivům a uživatelským předvolbám.

Než začnete

Potřebujete překvapivě málo:

  • Pro návod k HTML — jen prohlížeč a textový editor. To je celá sada nástrojů.
  • Pro Svelte, React, Vue, Angular nebo Nunjucks — git, Node 26 a pnpm 10 nebo novější.
  • Pro Blazor — git a .NET SDK 8 nebo novější.

Jste v bezhlavých komponentách noví? Jste na správném místě — každý návod vysvětluje, co se děje, a každý krok ukazuje přesný kód ke zkopírování.

Čtyři kroky od nuly k nasazení

  1. Vaše první komponenta (~5 minut) — vyberte níže svůj framework, získejte kód a vykreslete Button.
  2. Skládání a stylování (~5 minut) — postavte formulář se štítky a nastylujte ho pomocí háčků tříd v kebab-case (součást každého návodu k frameworku).
  3. Dejte mu motiv (~15 minut) — vyměňte ručně psané CSS za jeden z 57 hotových motivů a pak nechte uživatele přepínat za běhu: návod k motivům.
  4. Respektujte předvolby (~15 minut) — přidejte výběr jazyka a velikosti textu pomocí pomocníků pro předvolby: návod k pomocníkům.

Zkopírujte sémantické HTML s háčky tříd a jděte na to — stačí prohlížeč a editor.

Nemůžete se rozhodnout? Začněte s HTML — učí smlouvu o háčcích tříd, kterou sdílí všechny ostatní frameworky, a běží přímo ze souboru.

Jděte hlouběji

Motivy

Odkažte jeden z 57 hotových motivů — NHS, GOV.UK, USWDS, světlý, tmavý a další — přepište jej vlastním CSS a přidejte přepínání motivů za běhu pomocníkem theme-picker.

~15 minut

Pomocníci pro předvolby

Dejte uživatelům kontrolu nad motivem, jazykem, velikostí textu, pohybem, hledáním, odkazy na stránky, sdílením a zadáváním data/času pomocí theme-picker, locale-picker, text-size-picker, motion-picker, search-picker, link-picker, share-picker a date-time-picker: bezhlavé ovládací prvky s perzistencí, bezpečností SSR a automatickou detekcí RTL.

~15 minut

Po návodech

  • Projděte si katalog komponent — každá komponenta dokumentuje své vlastnosti, smlouvu ARIA a chování klávesnice.
  • Naklonujte ukázkovou aplikaci , abyste viděli všech 571 komponent nastylovaných a spolupracujících — CSS cílí na stejné háčky tříd, které jste právě použili, takže zkopírujte libovolnou část do svého projektu a upravte ji podle libosti.
  • Otázky? Stránka nápovědy má odpovědi, často kladené otázky a způsoby, jak se spojit s přátelským člověkem. A pokud by některý návod mohl být jasnější, řekněte nám — rádi ho vylepšíme.
