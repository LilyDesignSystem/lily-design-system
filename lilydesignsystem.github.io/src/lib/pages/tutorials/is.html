Lærðu Lily, skref fyrir skref

Velkomin! Hvert kennsluefni byrjar frá grunni og byggir sama litla hlutinn — aðgengilegt, stílað eyðublað — á um 10 mínútum, svo þú getir borið saman ramma á jafnréttisgrundvelli. Farðu svo dýpra með þemu og notendastillingar.

Áður en þú byrjar

Þú þarft undrafátt:

  • Fyrir HTML-kennsluefnið — bara vafra og textaritil. Það eru öll verkfærin.
  • Fyrir Svelte, React, Vue, Angular eða Nunjucks — git, Node 26 og pnpm 10 eða nýrra.
  • Fyrir Blazor — git og .NET SDK 8 eða nýrra.

Nýbyrjuð(að) með höfuðlausa íhluti? Þú ert á réttum stað — hvert kennsluefni útskýrir hvað er að gerast jafnóðum og hvert skref sýnir nákvæmlega kóðann sem á að afrita.

Fjögur skref frá núlli að útgáfu

  1. Fyrsti íhluturinn þinn (~5 mínútur) — veldu ramma hér að neðan, náðu í kóðann og birtu Button.
  2. Settu saman og stílaðu (~5 mínútur) — byggðu eyðublað með merkimiðum og stílaðu það gegn kebab-case klasakrókunum (hluti af hverju rammakennsluefni).
  3. Settu þema á það (~15 mínútur) — skiptu handskrifuðu CSS út fyrir eitt af 57 tilbúnu þemunum og leyfðu svo notendum að skipta á keyrslutíma: þemakennsluefni.
  4. Virtu stillingar (~15 mínútur) — bættu við vali á tungumáli og textastærð með stillingahjálpartækjunum: hjálpartækjakennsluefni.

Farðu dýpra

Þemu

Tengdu eitt af 57 tilbúnum þemum — NHS, GOV.UK, USWDS, ljóst, dökkt og fleiri — hnekktu því með þínu eigin CSS og bættu við þemaskiptum á keyrslutíma með theme-picker hjálpartækinu.

~15 mínútur

Stillingahjálpartæki

Gefðu notendum stjórn á þema, tungumáli, textastærð, hreyfingu, leit, síðutenglum, deilingu og dagsetninga-/tímainnslætti með theme-picker, locale-picker, text-size-picker, motion-picker, search-picker, link-picker, share-picker og date-time-picker: höfuðlausar stýringar með þrautseigju, SSR-öryggi og sjálfvirkri RTL-greiningu.

~15 mínútur

Eftir kennsluefnin

  • Skoðaðu íhlutasafnið — hver íhlutur skjalfestir eiginleika sína, ARIA-samning og lyklaborðshegðun.
  • Afritaðu dæmaforrit til að sjá alla 581 íhlutina stílaða og vinna saman — CSS-ið miðar á sömu klasakróka og þú varst að nota, svo afritaðu hvaða hluta sem er í verkefnið þitt og aðlagaðu að vild.
  • Spurningar? hjálparsíðan hefur svör, algengar spurningar og leiðir til að ná í vingjarnlega manneskju. Og ef kennsluefni gæti verið skýrara, segðu okkur — við bætum það með ánægju.
