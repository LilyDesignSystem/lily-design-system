Merħba! Kull tutorja tibda mill-bidu u tibni l-istess ħaġa żgħira — formola aċċessibbli u stilizzata — f’madwar 10 minuti, biex tkun tista’ tqabbel il-frameworks fuq bażi ndaqs. Imbagħad mur aktar fil-fond bit-temi u l-preferenzi tal-utent.

Qabel tibda

Għandek bżonn sorprendentement ftit:

  • Għat-tutorja tal-HTML — biss browser u editur tat-test. Dik hija l-għodda kollha.
  • Għal Svelte, React, Vue, Angular jew Nunjucks — git, Node 26 u pnpm 10 jew aktar ġdid.
  • Għal Blazor — git u l- .NET SDK 8 jew aktar ġdid.

Ġdid għall-komponenti headless? Int fil-post it-tajjeb — kull tutorja tispjega x’qed jiġri hekk kif timxi, u kull pass juri l-kodiċi eżatt biex tikkopja.

Erba’ passi miż-żero sal-ħruġ

  1. L-ewwel komponent tiegħek (~5 minuti) — agħżel il-framework tiegħek hawn taħt, ikseb il-kodiċi u renderja Button.
  2. Ikkomponi u stilizza (~5 minuti) — ibni formola bi tikketti u stilizzaha skont il-ganċijiet tal-klassi f’kebab-case (parti minn kull tutorja tal-framework).
  3. Agħtih tema (~15-il minuta) — ibdel is-CSS miktub b’idejk b’waħda mit-57 tema lesta, imbagħad ħalli l-utenti jibdlu waqt it-tħaddim: tutorja tat-temi.
  4. Irrispetta l-preferenzi (~15-il minuta) — żid l-għażla tal-lingwa u tad-daqs tat-test bl-għajnuniet tal-preferenzi: tutorja tal-għajnuniet.

Agħżel il-framework tiegħek

HTML

Ikkopja HTML semantiku bil-ganċijiet tal-klassi u mur — browser u editur huma dak kollu li jeħtieġ.

~10 minuti · l-aktar bidu faċli

Svelte

Runes ta’ Svelte 5, snippets u rbit bidirezzjonali ma’ bind:value .

~10 minuti

React

Komponenti ta’ funzjoni bi value + onChange u firxa tal-proprjetajiet li jifdal.

~10 minuti

Vue

Komponenti ta’ fajl wieħed ta’ Vue 3 b’appoġġ għal v-model .

~10 minuti

Angular

Komponenti standalone ta’ Angular b’inputs signal u [(value)].

~10 minuti

Blazor

Komponenti Razor bi parametri, ChildContentu testijiet bUnit.

~10 minuti

Nunjucks

Makrows renderjati fuq is-server għal Eleventy u kwalunkwe pipeline tat-templates ta’ Node.

~10 minuti

Imdejjaq bejniethom? Ibda b’ HTML — jgħallem il-kuntratt tal-ganċijiet tal-klassi li jaqsmu l-frameworks l-oħra kollha, u jaħdem direttament minn fajl.

Mur aktar fil-fond

Temi

Qabbad waħda mit-57 tema lesta — NHS, GOV.UK, USWDS, ċara, skura u aktar — issostitwiha bis-CSS tiegħek stess, u żid it-tibdil tat-tema waqt it-tħaddim bl-għajnuna theme-picker.

~15-il minuta

Għajnuniet tal-preferenzi

Agħti lill-utenti kontroll tat-tema, il-lingwa, id-daqs tat-test, il-moviment, it-tfittxija, il-links tal-paġni, il-qsim u d-daħla tad-data/ħin b’theme-picker, locale-picker, text-size-picker, motion-picker, search-picker, link-picker, share-picker u date-time-picker: kontrolli headless b’persistenza, sigurtà SSR u skoperta awtomatika tal-RTL.

~15-il minuta

Wara t-tutorjals

  • Esplora l- katalgu tal-komponenti — kull komponent jiddokumenta l-proprjetajiet tiegħu, il-kuntratt ARIA u l-imġieba tat-tastiera.
