Book an appointment tutorials

The same booking screen for phones, three ways: pick your platform.

Each tutorial builds one screen of a booking app: a top bar of labelled buttons, a large heading, a line of guidance, four labelled choices and a tab bar. Each is the whole app, file by file, with a screenshot of the result.

  • Swift: iOS, with SwiftUI.
  • Kotlin: Android, with Jetpack Compose.
  • .NET MAUI: iOS and Android from one C# project.
