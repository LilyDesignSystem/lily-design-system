Vodnik za React

Tipizirane funkcijske komponente, po ena datoteka, nadzorovane s standardnim vzorcem value + onChange — vse deluje tako, kot React že deluje.

Kaj boste ustvarili

Majhen kontaktni obrazec — polje z oznako, gumb za pošiljanje, nadzorovano stanje, resnično vedenje tipkovnice in bralnika zaslona — najprej gol, nato oblikovan, v približno 10 minutah.

Preden začnete

Potrebujete git, Node 22 ali novejši in pnpm 10 ali novejši. Primeren je vsak projekt React 18+ — Next.js, Vite ali navaden React.

Korak 1 — Pridobite kodo

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 571 components

Komponente so ravne datoteke v components/ — Button.tsx, TextInput.tsx — vsaka z lastnim testom, storyjem in dokumentacijo ob sebi. Kopirajte potrebne datoteke v svojo aplikacijo ali povlecite repozitorij in uvozite iz njega.

Korak 2 — Vaša prva komponenta

import Button from "lily-design-system-react-headless/components/Button";

export function SaveBar() {
  return <Button onClick={save}>Save</Button>;
}

Izriše <button class="button" type="button">. Propi: type, disabled, pressed (izriše aria-pressed), label ( aria-label za preglasitev), className, vsak dodaten atribut pa se razprši na koren.

Korak 3 — Sestavite majhen obrazec

import { useState } from "react";
import Form from ".../components/Form";
import Field from ".../components/Field";
import TextInput from ".../components/TextInput";
import Button from ".../components/Button";

export function ContactForm() {
  const [name, setName] = useState("");
  return (
    <Form label="Contact form" onSubmit={handleSubmit}>
      <Field label="Full name" required>
        <TextInput id="name" label="Full name" value={name} onChange={setName} required />
      </Field>
      <Button type="submit">Save</Button>
    </Form>
  );
}

Field sprejme vidno label kot lasten prop namesto gnezdene komponente oznake — posredujte jo enkrat, pri Fieldin TextInputiz label zagotovi dostopno ime.

Preverjeno 2026-08-29: prejšnji osnutek je gnezdil ločeno komponento Label znotraj Field, kar je izrisalo dve oznaki (eno prazno), ker Field že izriše svojo iz vhoda label prop — odkrito s prevajanjem natančnega izrezka. Pot Sestavljena pot kontaktnega obrazca je isti vzorec, preizkušen z resničnimi testi e2e in axe.

Korak 4 — Oblikujte ga

Vse zgoraj se izriše kot čista struktura, pripravljena na vaše sloge. Oblikujte kavlje — .button, .text-input, .label, .field — v svoji slogovni datoteki, plastite pripomočke Tailwind prek classNameali povežite že pripravljeno temo: 

<link rel="stylesheet" href="/themes/united-states-web-design-system.css" />

Korak 5 — Poglejte, kako vse deluje

Vzorčna aplikacija Next.js je celoten katalog oblikovan in predstavljen, s Playwright e2e in izhodiščem axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-next-examples
pnpm install && pnpm run dev

Naslednji koraki

  • Teme — preklapljanje med izvajanjem s pomočnikom theme-picker za React.
  • Pomočniki za nastavitve — jezik in velikost besedila.
  • Katalog komponent — lastnosti, ARIA in tipkovnica za vsako komponento.

Vprašanja na poti? Stran s pomočjo je polna odgovorov — in če bi bil kakšen korak lahko jasnejši, sporočite nam in vodnik bomo z veseljem izboljšali.
