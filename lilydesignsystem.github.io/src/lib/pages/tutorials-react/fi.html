React-opas

Tyypitetyt funktiokomponentit, yksi tiedosto kutakin, ohjattuna vakiomallilla value + onChange — kaikki toimii niin kuin React jo toimii.

Mitä rakennat

Pieni yhteydenottolomake — nimiöity kenttä, lähetyspainike, hallittu tila, aito näppäimistö- ja ruudunlukijakäyttäytyminen — ensin paljaana, sitten tyylitellen, noin 10 minuutissa.

Ennen kuin aloitat

Tarvitset gitin, Node 22:n tai uudemman ja pnpm 10:n tai uudemman. Mikä tahansa React 18+ -projekti kelpaa — Next.js, Vite tai pelkkä React.

Vaihe 1 — Hae koodi

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 581 components

Komponentit ovat litteitä tiedostoja hakemistossa components/ — Button.tsx, TextInput.tsx — kullakin on testinsä, storynsa ja dokumentaationsa vieressään. Kopioi tarvitsemasi tiedostot sovellukseesi tai tuo repo mukaan ja tuo siitä.

Vaihe 2 — Ensimmäinen komponenttisi

import Button from "lily-design-system-react-headless/components/Button";

export function SaveBar() {
  return <Button onClick={save}>Save</Button>;
}

Renderöi <button class="button" type="button">. Propit: type, disabled, pressed (renderöi aria-pressed), label ( aria-label ohittamiseen), className, ja mikä tahansa ylimääräinen attribuutti levitetään juurielementille.

Vaihe 3 — Kokoa pieni lomake

import { useState } from "react";
import Form from ".../components/Form";
import Field from ".../components/Field";
import TextInput from ".../components/TextInput";
import Button from ".../components/Button";

export function ContactForm() {
  const [name, setName] = useState("");
  return (
    <Form label="Contact form" onSubmit={handleSubmit}>
      <Field label="Full name" required>
        <TextInput id="name" label="Full name" value={name} onChange={setName} required />
      </Field>
      <Button type="submit">Save</Button>
    </Form>
  );
}

Field ottaa näkyvän label omana proppinaan sisäkkäisen nimiökomponentin sijaan — välitä se kerran elementille Fieldja TextInputelementistä label antaa saavutettavan nimen.

Varmistettu 2026-08-29: aiempi luonnos sijoitti erillisen Label sisällä Fieldsisään, mikä renderöi kaksi nimiötä (toinen tyhjä), koska Field renderöi jo oman nimiönsä label -prop — havaittu kääntämällä täsmällinen koodinpätkä. Reitti Koottu yhteydenottolomakkeen reitti on sama malli, jota on koeteltu oikeilla e2e- ja axe-testeillä.

Vaihe 4 — Tyylittele se

Kaikki yllä renderöityy puhtaana rakenteena, valmiina tyyleillesi. Tyylittele koukut — .button, .text-input, .label, .field — tyylitiedostossasi, kerrosta Tailwind-apuluokkia kautta className, tai linkitä valmis teema: 

<link rel="stylesheet" href="/themes/united-states-web-design-system.css" />

Vaihe 5 — Katso kaiken toimivan

Next.js-esimerkkisovellus on koko luettelo tyyliteltynä ja esiteltynä, Playwright e2e:llä ja axe-core-lähtötasolla: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-next-examples
pnpm install && pnpm run dev

Seuraavat askeleet

  • Teemat — vaihto ajon aikana Reactin theme-picker-apuvälineellä.
  • Asetusapuvälineet — kieli ja tekstikoko.
  • Komponenttiluettelo — ominaisuudet, ARIA ja näppäimistö komponenteittain.
