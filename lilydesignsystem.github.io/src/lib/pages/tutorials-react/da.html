React-vejledning

Typede funktionskomponenter, én fil hver, styret med standardmønsteret value + onChange — alt virker, som React allerede gør.

Det her bygger du

En lille kontaktformular — felt med etiket, send-knap, kontrolleret tilstand, ægte tastatur- og skærmlæseradfærd — først nøgen, derefter formgivet, på omkring 10 minutter.

Før du går i gang

Du skal bruge git, Node 22 eller nyere og pnpm 10 eller nyere. Ethvert React 18+-projekt virker — Next.js, Vite eller almindelig React.

Trin 1 — Hent koden

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 581 components

Komponenterne er flade filer i components/ — Button.tsx, TextInput.tsx — hver med sin test, story og dokumentation ved siden af. Kopiér de filer, du har brug for, ind i din app, eller hent repoet og importér derfra.

Trin 2 — Din første komponent

import Button from "lily-design-system-react-headless/components/Button";

export function SaveBar() {
  return <Button onClick={save}>Save</Button>;
}

Gengiver <button class="button" type="button">. Props: type, disabled, pressed (gengiver aria-pressed), label (et aria-label til at tilsidesætte), className, og enhver ekstra attribut spredes på rodelementet.

Trin 3 — Sæt en lille formular sammen

import Form from ".../components/Form";
import Field from ".../components/Field";
import TextInput from ".../components/TextInput";
import Button from ".../components/Button";

Field tager den synlige label som sin egen prop i stedet for en indlejret etiketkomponent — send den én gang, på Fieldog TextInputfra label giver det tilgængelige navn.

Verificeret 2026-08-29: et tidligere udkast indlejrede en separat Label inde i Field, hvilket gengiver to etiketter (en tom), fordi Field allerede gengiver sin egen fra label -prop — opdaget ved at kompilere det præcise kodeeksempel. Ruten Den sammensatte kontaktformularrute er det samme mønster, afprøvet med ægte e2e- og axe-tests.

Trin 4 — Giv den stil

Alt ovenfor gengives som ren struktur, klar til dine stilarter. Formgiv krogene — .button, .text-input, .label, .field — i dit typografiark, læg Tailwind-hjælpeklasser ovenpå via className, eller link et færdigt tema: 

<link rel="stylesheet" href="/themes/united-states-web-design-system.css" />

Trin 5 — Se det hele virke

Next.js eksempelapp er hele kataloget formgivet og demonstreret, med Playwright e2e og en axe-core-baseline: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-next-examples
pnpm install && pnpm run dev

Næste skridt

  • Temaer — skift under kørsel med React-hjælperen theme-picker.
  • Indstillingshjælpere — sprog og tekststørrelse.
  • Komponentkatalog — egenskaber, ARIA og tastatur pr. komponent.
