React apmācība

Tipizētas funkciju komponentes, katra vienā datnē, kontrolētas ar standarta modeli value + onChange — viss darbojas tā, kā React jau darbojas.

Ko jūs izveidosiet

Neliela kontaktu veidlapa — lauks ar iezīmi, iesniegšanas poga, kontrolēts stāvoklis, īsta tastatūras un ekrāna lasītāja darbība — vispirms kaila, tad noformēta, apmēram 10 minūtēs.

Pirms sākat

Nepieciešams git, Node 22 vai jaunāks un pnpm 10 vai jaunāks. Der jebkurš React 18+ projekts — Next.js, Vite vai tīrs React.

1. solis — Iegūstiet kodu

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 571 components

Komponentes ir plakanas datnes direktorijā components/ — Button.tsx, TextInput.tsx — katra ar savu testu, story un dokumentāciju blakus. Nokopējiet vajadzīgās datnes savā lietotnē vai ievelciet repozitoriju un importējiet no tā.

2. solis — Jūsu pirmā komponente

import Button from "lily-design-system-react-headless/components/Button";

export function SaveBar() {
  return <Button onClick={save}>Save</Button>;
}

Attēlo <button class="button" type="button">. Props: type, disabled, pressed (attēlo aria-pressed), label ( aria-label lai pārrakstītu), className, un jebkurš papildu atribūts tiek izklāts uz saknes elementa.

3. solis — Salieciet nelielu veidlapu

import { useState } from "react";
import Form from ".../components/Form";
import Field from ".../components/Field";
import TextInput from ".../components/TextInput";
import Button from ".../components/Button";

export function ContactForm() {
  const [name, setName] = useState("");
  return (
    <Form label="Contact form" onSubmit={handleSubmit}>
      <Field label="Full name" required>
        <TextInput id="name" label="Full name" value={name} onChange={setName} required />
      </Field>
      <Button type="submit">Save</Button>
    </Form>
  );
}

Field pieņem redzamo label kā savu propu, nevis iekļautu iezīmes komponenti — nododiet to vienreiz, pie Fieldun TextInputno label nodrošina pieejamo nosaukumu.

Pārbaudīts 2026-08-29: agrāks melnraksts iekļāva atsevišķu Label iekšā Field, kas attēloja divas iezīmes (vienu tukšu), jo Field jau pati attēlo savu no label prop — atklāts, kompilējot precīzo fragmentu. Maršruts Salikto kontaktu veidlapas maršrutu ir tas pats modelis, pārbaudīts ar īstiem e2e un axe testiem.

4. solis — Noformējiet to

Viss iepriekš tiek attēlots kā tīra struktūra, gatava jūsu stiliem. Noformējiet āķus — .button, .text-input, .label, .field — savā stilu lapā, uzklājiet Tailwind utilītas ar classNamevai saistiet gatavu motīvu: 

<link rel="stylesheet" href="/themes/united-states-web-design-system.css" />

5. solis — Redziet, kā viss darbojas

Next.js paraugu lietotne ir viss katalogs noformēts un demonstrēts, ar Playwright e2e un axe-core bāzlīniju: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-next-examples
pnpm install && pnpm run dev

Nākamie soļi

  • Motīvi — pārslēgšana izpildes laikā ar React palīgu theme-picker.
  • Preferenču palīgi — valoda un teksta izmērs.
  • Komponenšu katalogs — īpašības, ARIA un tastatūra katrai komponentei.

Jautājumi pa ceļam? Palīdzības lapa ir pilna atbilžu — un, ja kāds solis varētu būt skaidrāks, pastāstiet mums un mēs labprāt uzlabosim apmācību.
