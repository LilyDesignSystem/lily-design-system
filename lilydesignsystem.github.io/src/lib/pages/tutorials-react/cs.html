Návod pro React

Typované funkční komponenty, každá v jednom souboru, řízené standardním vzorem value + onChange — všechno funguje tak, jak React už funguje.

Co vytvoříte

Malý kontaktní formulář — pole se štítkem, tlačítko odeslat, řízený stav, skutečné chování klávesnice a čtečky obrazovky — nejprve holý, potom ostylovaný, zhruba za 10 minut.

Než začnete

Potřebujete git, Node 22 nebo novější a pnpm 10 nebo novější. Hodí se jakýkoli projekt React 18+ — Next.js, Vite nebo čistý React.

Krok 1 — Získejte kód

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 581 components

Komponenty jsou ploché soubory v components/ — Button.tsx, TextInput.tsx — každá s vlastním testem, story a dokumentací po boku. Zkopírujte potřebné soubory do své aplikace, nebo si repozitář vezměte a importujte z něj.

Krok 2 — Vaše první komponenta

import Button from "lily-design-system-react-headless/components/Button";

export function SaveBar() {
  return <Button onClick={save}>Save</Button>;
}

Vykresluje <button class="button" type="button">. Props: type, disabled, pressed (vykresluje aria-pressed), label ( aria-label k přepsání), classNamea jakýkoli další atribut se rozprostře na kořenový prvek.

Krok 3 — Sestavte malý formulář

import { useState } from "react";
import Form from ".../components/Form";
import Field from ".../components/Field";
import TextInput from ".../components/TextInput";
import Button from ".../components/Button";

export function ContactForm() {
  const [name, setName] = useState("");
  return (
    <Form label="Contact form" onSubmit={handleSubmit}>
      <Field label="Full name" required>
        <TextInput id="name" label="Full name" value={name} onChange={setName} required />
      </Field>
      <Button type="submit">Save</Button>
    </Form>
  );
}

Field přijímá viditelný label jako vlastní prop místo vnořené komponenty štítku — předejte ho jednou, u Fielda TextInputz label dodá přístupný název.

Ověřeno 2026-08-29: dřívější koncept vnořoval samostatnou komponentu Label uvnitř Field, což vykreslilo dva štítky (jeden prázdný), protože Field už vykresluje svůj vlastní ze vstupu label prop — zjištěno kompilací přesné ukázky. Trasa Složená trasa kontaktního formuláře je stejný vzor, prověřený skutečnými testy e2e a axe.

Krok 4 — Ostylujte ho

Vše výše se vykresluje jako čistá struktura, připravená na vaše styly. Ostylujte háčky — .button, .text-input, .label, .field — ve svém stylopisu, přidejte nástroje Tailwind přes className, nebo připojte hotové téma: 

<link rel="stylesheet" href="/themes/united-states-web-design-system.css" />

Krok 5 — Podívejte se, jak to celé funguje

Ukázková aplikace Next.js je celý katalog ostylovaný a předvedený, s Playwright e2e a základní linií axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-next-examples
pnpm install && pnpm run dev
