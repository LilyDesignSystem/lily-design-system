React チュートリアル

型付きの関数コンポーネントで、1 ファイルに 1 つ、標準の value + onChange パターンで制御します — すべて React ですでに慣れた動きをします。

作るもの

小さなお問い合わせフォーム — ラベル付き入力、送信ボタン、制御された状態、本物のキーボードとスクリーンリーダーの動作 — まずは装飾なしで、次にスタイルを付けて、約 10 分で作ります。

始める前に

git、Node 22 以降、pnpm 10 以降が必要です。React 18 以降のプロジェクトならどれでも使えます — Next.js、Vite、素の React のいずれでも構いません。

ステップ 1 — コードを入手する

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 571 components

コンポーネントは次の場所にフラットなファイルとして置かれています: components/ — Button.tsx, TextInput.tsx — それぞれテスト、ストーリー、ドキュメントが隣に置かれています。必要なファイルをアプリにコピーするか、リポジトリを取り込んでそこからインポートします。

ステップ 2 — 最初のコンポーネント

import Button from "lily-design-system-react-headless/components/Button";

export function SaveBar() {
  return <Button onClick={save}>Save</Button>;
}

描画する要素: <button class="button" type="button">。プロパティ: type, disabled, pressed (描画する要素: aria-pressed), label ( aria-label の上書き用)、 className)、追加の属性はルート要素に展開されます。

ステップ 3 — 小さなフォームを組み立てる

import { useState } from "react";
import Form from ".../components/Form";
import Field from ".../components/Field";
import TextInput from ".../components/TextInput";
import Button from ".../components/Button";

export function ContactForm() {
  const [name, setName] = useState("");
  return (
    <Form label="Contact form" onSubmit={handleSubmit}>
      <Field label="Full name" required>
        <TextInput id="name" label="Full name" value={name} onChange={setName} required />
      </Field>
      <Button type="submit">Save</Button>
    </Form>
  );
}

Field は、表示用の label を、ネストしたラベルコンポーネントではなく専用のプロパティとして受け取ります — 一度だけ渡せば、 Field、そして TextInputの対応する label がアクセシブルな名前を与えます。

2026-08-29 に確認済み: 以前の下書きでは、別の Label の中の Fieldの中にネストしていたため、 2 つの ラベル(1 つは空)が描画されていました。 Field は label プロパティ — 実際のスニペットをコンパイルして見つけました。 お問い合わせフォームの組み合わせルート も同じパターンで、本物の e2e テストと axe テストで検証されています。

ステップ 4 — スタイルを付ける

上のコードはすべて純粋な構造として描画され、スタイルを待っています。フックにスタイルを付けます — .button, .text-input, .label, .field — スタイルシートで、 className経由で Tailwind のユーティリティを重ねるか、既成のテーマをリンクします: 

<link rel="stylesheet" href="/themes/united-states-web-design-system.css" />

ステップ 5 — 動いているところを見る

Next.js サンプルアプリ は、スタイル付きでデモ付きの完全なカタログで、Playwright e2e と axe-core のベースラインを備えています: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-next-examples
pnpm install && pnpm run dev
