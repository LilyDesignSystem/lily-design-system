React-handledning

Typade funktionskomponenter, en fil vardera, styrda med standardmönstret value + onChange — allt fungerar som React redan gör.

Det här bygger du

Ett litet kontaktformulär — fält med etikett, skicka-knapp, kontrollerat tillstånd, verkligt tangentbords- och skärmläsarbeteende — först naket, sedan formgivet, på ungefär 10 minuter.

Innan du börjar

Du behöver git, Node 22 eller senare och pnpm 10 eller senare. Alla React 18+-projekt fungerar — Next.js, Vite eller vanlig React.

Steg 1 — Hämta koden

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 571 components

Komponenterna är platta filer i components/ — Button.tsx, TextInput.tsx — var och en med sitt test, sin story och sin dokumentation bredvid. Kopiera de filer du behöver till din app, eller hämta förvaret och importera därifrån.

Steg 2 — Din första komponent

import Button from "lily-design-system-react-headless/components/Button";

export function SaveBar() {
  return <Button onClick={save}>Save</Button>;
}

Renderar <button class="button" type="button">. Props: type, disabled, pressed (renderar aria-pressed), label (ett aria-label för att åsidosätta), className, och varje extra attribut sprids på rotelementet.

Steg 3 — Sätt ihop ett litet formulär

import { useState } from "react";
import Form from ".../components/Form";
import Field from ".../components/Field";
import TextInput from ".../components/TextInput";
import Button from ".../components/Button";

export function ContactForm() {
  const [name, setName] = useState("");
  return (
    <Form label="Contact form" onSubmit={handleSubmit}>
      <Field label="Full name" required>
        <TextInput id="name" label="Full name" value={name} onChange={setName} required />
      </Field>
      <Button type="submit">Save</Button>
    </Form>
  );
}

Field tar den synliga label som sin egen prop i stället för en nästlad etikettkomponent — skicka den en gång, på Fieldoch TextInputfrån label ger det tillgängliga namnet.

Verifierat 2026-08-29: ett tidigare utkast nästlade en separat Label inuti Field, vilket renderar två etiketter (en tom) eftersom Field redan renderar sin egen från label -prop — upptäckt genom att kompilera det exakta kodavsnittet. Rutten Den sammansatta kontaktformulärsrutten är samma mönster, prövat med riktiga e2e- och axe-tester.

Steg 4 — Formge det

Allt ovan renderas som ren struktur, redo för dina stilar. Formge krokarna — .button, .text-input, .label, .field — i din stilmall, lägg Tailwind-verktyg ovanpå via className, eller länka ett färdigt tema: 

<link rel="stylesheet" href="/themes/united-states-web-design-system.css" />

Steg 5 — Se allt fungera

Exempelappen Next.js är hela katalogen formgiven och demonstrerad, med Playwright e2e och en axe-core-baslinje: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-next-examples
pnpm install && pnpm run dev

Nästa steg

  • Teman — byte under körning med React-hjälparen theme-picker.
  • Inställningshjälpare — språk och textstorlek.
  • Komponentkatalog — egenskaper, ARIA och tangentbord per komponent.

Frågor på vägen? Hjälpsidan är full av svar — och om ett steg kan bli tydligare, berätta för oss så förbättrar vi gärna handledningen.
