Návod pre React

Typované funkčné komponenty, každý v jednom súbore, riadené štandardným vzorom value + onChange — všetko funguje tak, ako React už funguje.

Čo vytvoríte

Malý kontaktný formulár — pole s popisom, tlačidlo odoslať, riadený stav, skutočné správanie klávesnice a čítačky obrazovky — najprv holý, potom ostylovaný, približne za 10 minút.

Skôr než začnete

Potrebujete git, Node 22 alebo novší a pnpm 10 alebo novší. Hodí sa akýkoľvek projekt React 18+ — Next.js, Vite alebo čistý React.

Krok 1 — Získajte kód

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 581 components

Komponenty sú ploché súbory v components/ — Button.tsx, TextInput.tsx — každý s vlastným testom, story a dokumentáciou po boku. Skopírujte potrebné súbory do svojej aplikácie, alebo si repozitár vezmite a importujte z neho.

Krok 2 — Váš prvý komponent

import Button from "lily-design-system-react-headless/components/Button";

export function SaveBar() {
  return <Button onClick={save}>Save</Button>;
}

Vykresľuje <button class="button" type="button">. Props: type, disabled, pressed (vykresľuje aria-pressed), label ( aria-label na prepísanie), classNamea akýkoľvek ďalší atribút sa rozprestrie na koreňový prvok.

Krok 3 — Zložte malý formulár

import { useState } from "react";
import Form from ".../components/Form";
import Field from ".../components/Field";
import TextInput from ".../components/TextInput";
import Button from ".../components/Button";

export function ContactForm() {
  const [name, setName] = useState("");
  return (
    <Form label="Contact form" onSubmit={handleSubmit}>
      <Field label="Full name" required>
        <TextInput id="name" label="Full name" value={name} onChange={setName} required />
      </Field>
      <Button type="submit">Save</Button>
    </Form>
  );
}

Field prijíma viditeľný label ako vlastný prop namiesto vnoreného komponentu popisu — odovzdajte ho raz, pri Fielda TextInputz label poskytne prístupný názov.

Overené 2026-08-29: skorší koncept vnáral samostatný komponent Label vnútri Field, čo vykreslilo dva popisy (jeden prázdny), pretože Field už vykresľuje svoj vlastný zo vstupu label prop — zistené kompiláciou presnej ukážky. Trasa Zložená trasa kontaktného formulára je rovnaký vzor, preverený skutočnými testami e2e a axe.

Krok 4 — Ostylujte ho

Všetko vyššie sa vykresľuje ako čistá štruktúra, pripravená na vaše štýly. Ostylujte háčiky — .button, .text-input, .label, .field — vo svojej štýlovej šablóne, pridajte nástroje Tailwind cez className, alebo pripojte hotovú tému: 

<link rel="stylesheet" href="/themes/united-states-web-design-system.css" />

Krok 5 — Pozrite sa, ako to celé funguje

Ukážková aplikácia Next.js je celý katalóg ostylovaný a predvedený, s Playwright e2e a základnou líniou axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-next-examples
pnpm install && pnpm run dev

Ďalšie kroky

  • Témy — prepínanie za behu pomocníkom theme-picker pre React.
  • Pomocníci pre predvoľby — jazyk a veľkosť textu.
  • Katalóg komponentov — vlastnosti, ARIA a klávesnica pre každý komponent.

Otázky po ceste? Stránka pomocníka je plná odpovedí — a ak by niektorý krok mohol byť jasnejší, dajte nám vedieť a návod radi vylepšíme.
