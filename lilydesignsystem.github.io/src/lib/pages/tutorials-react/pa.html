React ਟਿਊਟੋਰਿਅਲ

ਟਾਈਪ ਕੀਤੇ ਫੰਕਸ਼ਨ ਕੰਪੋਨੈਂਟ, ਹਰ ਇੱਕ ਇੱਕ ਫ਼ਾਈਲ, ਮਿਆਰੀ ਪੈਟਰਨ ਨਾਲ ਕਾਬੂ ਕੀਤੇ value + onChange — ਸਭ ਕੁਝ ਉਂਝ ਹੀ ਕੰਮ ਕਰਦਾ ਹੈ ਜਿਵੇਂ React ਪਹਿਲਾਂ ਹੀ ਕਰਦਾ ਹੈ।

ਤੁਸੀਂ ਕੀ ਬਣਾਓਗੇ

ਇੱਕ ਛੋਟਾ ਸੰਪਰਕ ਫ਼ਾਰਮ — ਲੇਬਲ ਵਾਲਾ ਖੇਤਰ, ਜਮ੍ਹਾਂ ਕਰਨ ਦਾ ਬਟਨ, ਕਾਬੂ ਕੀਤੀ ਅਵਸਥਾ, ਅਸਲੀ ਕੀਬੋਰਡ ਅਤੇ ਸਕ੍ਰੀਨ-ਰੀਡਰ ਵਿਹਾਰ — ਪਹਿਲਾਂ ਨੰਗਾ, ਫਿਰ ਸਟਾਈਲ ਕੀਤਾ, ਲਗਭਗ 10 ਮਿੰਟਾਂ ਵਿੱਚ।

ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ

ਤੁਹਾਨੂੰ git, Node 22 ਜਾਂ ਨਵਾਂ, ਅਤੇ pnpm 10 ਜਾਂ ਨਵਾਂ ਚਾਹੀਦਾ ਹੈ। ਕੋਈ ਵੀ React 18+ ਪ੍ਰੋਜੈਕਟ ਚੱਲੇਗਾ — Next.js, Vite ਜਾਂ ਸਾਦਾ React।

ਪੜਾਅ 1 — ਕੋਡ ਪ੍ਰਾਪਤ ਕਰੋ

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 581 components

ਕੰਪੋਨੈਂਟ ਇਸ ਵਿੱਚ ਸਮਤਲ ਫ਼ਾਈਲਾਂ ਹਨ: components/ — Button.tsx, TextInput.tsx — ਹਰ ਇੱਕ ਦੇ ਨਾਲ ਉਸਦਾ ਟੈਸਟ, story ਅਤੇ ਦਸਤਾਵੇਜ਼। ਜੋ ਫ਼ਾਈਲਾਂ ਚਾਹੀਦੀਆਂ ਹਨ ਉਨ੍ਹਾਂ ਨੂੰ ਆਪਣੀ ਐਪ ਵਿੱਚ ਕਾਪੀ ਕਰੋ, ਜਾਂ ਰਿਪੋ ਲੈ ਆਓ ਅਤੇ ਉਸ ਤੋਂ ਆਯਾਤ ਕਰੋ।

ਪੜਾਅ 2 — ਤੁਹਾਡਾ ਪਹਿਲਾ ਕੰਪੋਨੈਂਟ

import Button from "lily-design-system-react-headless/components/Button";

export function SaveBar() {
  return <Button onClick={save}>Save</Button>;
}

ਇਹ ਦਿਖਾਉਂਦਾ ਹੈ <button class="button" type="button">। Props: type, disabled, pressed (ਦਿਖਾਉਂਦਾ ਹੈ aria-pressed), label (ਇੱਕ aria-label ਓਵਰਰਾਈਡ ਕਰਨ ਲਈ), className, ਅਤੇ ਕੋਈ ਵੀ ਵਾਧੂ ਗੁਣ ਮੂਲ ਤੱਤ ਉੱਤੇ ਫੈਲ ਜਾਂਦਾ ਹੈ।

ਪੜਾਅ 3 — ਇੱਕ ਛੋਟਾ ਫ਼ਾਰਮ ਬਣਾਓ

import { useState } from "react";
import Form from ".../components/Form";
import Field from ".../components/Field";
import TextInput from ".../components/TextInput";
import Button from ".../components/Button";

export function ContactForm() {
  const [name, setName] = useState("");
  return (
    <Form label="Contact form" onSubmit={handleSubmit}>
      <Field label="Full name" required>
        <TextInput id="name" label="Full name" value={name} onChange={setName} required />
      </Field>
      <Button type="submit">Save</Button>
    </Form>

Field ਦਿੱਸਦੇ label ਨੂੰ ਆਪਣੇ prop ਵਜੋਂ ਲੈਂਦਾ ਹੈ, ਨਾ ਕਿ ਅੰਦਰ ਰੱਖੇ ਲੇਬਲ ਕੰਪੋਨੈਂਟ ਵਜੋਂ — ਇਸਨੂੰ ਇੱਕ ਵਾਰ ਦਿਓ, ਉੱਤੇ Field, ਅਤੇ TextInputਦਾ label ਪਹੁੰਚਯੋਗ ਨਾਮ ਦਿੰਦਾ ਹੈ।

2026-08-29 ਨੂੰ ਪੁਸ਼ਟੀ ਕੀਤੀ: ਇੱਕ ਪਹਿਲੇ ਖਰੜੇ ਨੇ ਵੱਖਰਾ Label ਦੇ ਅੰਦਰ Fieldਦੇ ਅੰਦਰ ਰੱਖਿਆ, ਜਿਸ ਨੇ ਦੋ ਲੇਬਲ (ਇੱਕ ਖਾਲੀ) ਦਿਖਾਏ ਕਿਉਂਕਿ Field ਪਹਿਲਾਂ ਹੀ ਆਪਣਾ ਲੇਬਲ label prop — ਠੀਕ ਟੁਕੜੇ ਨੂੰ ਕੰਪਾਇਲ ਕਰਕੇ ਪਤਾ ਲੱਗਾ। ਰੂਟ ਸੰਯੁਕਤ ਸੰਪਰਕ-ਫ਼ਾਰਮ ਰੂਟ ਉਹੀ ਪੈਟਰਨ ਹੈ, ਅਸਲੀ e2e ਅਤੇ axe ਟੈਸਟਾਂ ਨਾਲ ਪਰਖਿਆ।

ਪੜਾਅ 4 — ਇਸਨੂੰ ਸਟਾਈਲ ਕਰੋ

ਉੱਪਰ ਸਭ ਕੁਝ ਸ਼ੁੱਧ ਬਣਤਰ ਵਜੋਂ ਦਿਖਾਇਆ ਜਾਂਦਾ ਹੈ, ਤੁਹਾਡੇ ਸਟਾਈਲਾਂ ਲਈ ਤਿਆਰ। ਹੁੱਕਾਂ ਨੂੰ ਸਟਾਈਲ ਕਰੋ — .button, .text-input, .label, .field — ਆਪਣੀ ਸਟਾਈਲਸ਼ੀਟ ਵਿੱਚ, ਇਸ ਰਾਹੀਂ Tailwind ਉਪਯੋਗਤਾਵਾਂ ਦੀ ਪਰਤ ਲਗਾਓ className, ਜਾਂ ਇੱਕ ਤਿਆਰ ਥੀਮ ਲਿੰਕ ਕਰੋ: 

<link rel="stylesheet" href="/themes/united-states-web-design-system.css" />

ਪੜਾਅ 5 — ਸਭ ਕੁਝ ਕੰਮ ਕਰਦਾ ਵੇਖੋ

Next.js ਉਦਾਹਰਨ ਐਪ ਪੂਰਾ ਕੈਟਾਲਾਗ ਸਟਾਈਲ ਕੀਤਾ ਅਤੇ ਡੈਮੋ ਸਮੇਤ ਹੈ, Playwright e2e ਅਤੇ axe-core ਆਧਾਰ-ਰੇਖਾ ਨਾਲ: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-next-examples
pnpm install && pnpm run dev

ਅਗਲੇ ਕਦਮ

  • ਥੀਮ — React theme-picker ਸਹਾਇਕ ਨਾਲ ਚੱਲਦੇ ਸਮੇਂ ਬਦਲਣਾ।
  • ਤਰਜੀਹ ਸਹਾਇਕ — ਭਾਸ਼ਾ ਅਤੇ ਲਿਖਤ ਦਾ ਆਕਾਰ।
  • ਕੰਪੋਨੈਂਟ ਕੈਟਾਲਾਗ — ਹਰ ਕੰਪੋਨੈਂਟ ਲਈ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ, ARIA ਅਤੇ ਕੀਬੋਰਡ।

ਰਾਹ ਵਿੱਚ ਸਵਾਲ ਹਨ? ਮਦਦ ਪੰਨਾ ਜਵਾਬਾਂ ਨਾਲ ਭਰਿਆ ਹੈ — ਅਤੇ ਜੇ ਕੋਈ ਕਦਮ ਹੋਰ ਸਾਫ਼ ਹੋ ਸਕਦਾ ਹੈ, ਸਾਨੂੰ ਦੱਸੋ ਅਤੇ ਅਸੀਂ ਖ਼ੁਸ਼ੀ ਨਾਲ ਟਿਊਟੋਰਿਅਲ ਸੁਧਾਰਾਂਗੇ।
