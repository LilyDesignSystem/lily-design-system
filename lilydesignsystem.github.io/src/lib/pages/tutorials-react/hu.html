React oktatóanyag

Típusos függvénykomponensek, mindegyik egy fájl, a szabványos mintával vezérelve value + onChange — minden úgy működik, ahogy a React már eleve működik.

Mit fogsz építeni

Egy kis kapcsolatfelvételi űrlap — címkézett mező, küldés gomb, vezérelt állapot, valódi billentyűzet- és képernyőolvasó-viselkedés — először csupaszon, aztán stílusosan, nagyjából 10 perc alatt.

Mielőtt elkezdenéd

Szükséged van gitre, Node 22-re vagy újabbra és pnpm 10-re vagy újabbra. Bármelyik React 18+ projekt megfelel — Next.js, Vite vagy sima React.

1. lépés — Szerezd meg a kódot

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 581 components

A komponensek lapos fájlok itt: components/ — Button.tsx, TextInput.tsx — mindegyik saját teszttel, story-val és dokumentációval a háta mögött. Másold a szükséges fájlokat az alkalmazásodba, vagy hozd be a tárolót és importálj belőle.

2. lépés — Az első komponensed

import Button from "lily-design-system-react-headless/components/Button";

export function SaveBar() {
  return <Button onClick={save}>Save</Button>;
}

Ezt rendereli: <button class="button" type="button">. Propok: type, disabled, pressed (ezt rendereli: aria-pressed), label (egy aria-label felülíráshoz), className, és minden további attribútum a gyökérelemre szóródik.

3. lépés — Állíts össze egy kis űrlapot

import { useState } from "react";
import Form from ".../components/Form";
import Field from ".../components/Field";
import TextInput from ".../components/TextInput";
import Button from ".../components/Button";

export function ContactForm() {
  const [name, setName] = useState("");
  return (
    <Form label="Contact form" onSubmit={handleSubmit}>
      <Field label="Full name" required>
        <TextInput id="name" label="Full name" value={name} onChange={setName} required />
      </Field>
      <Button type="submit">Save</Button>
    </Form>
  );
}

Field a látható label a saját propjaként beágyazott címkekomponens helyett — add át egyszer, a Fieldés TextInputa label biztosítja a hozzáférhető nevet.

Ellenőrizve 2026-08-29: egy korábbi vázlat külön Label belül a Fieldelembe, ami két címkét renderelt (az egyik üres), mert a Field már magától rendereli a sajátját a label prop — a pontos kódrészlet lefordításával derült ki. A Az összeállított kapcsolatfelvételi űrlap útvonala ugyanez a minta, valódi e2e- és axe-tesztekkel kipróbálva.

4. lépés — Stílus hozzá

Minden fent tiszta szerkezetként renderelődik, készen a stílusaidra. Stílusozd a kampókat — .button, .text-input, .label, .field — a stíluslapodban, rétegezz Tailwind-segédosztályokat a classNamesegítségével, vagy hivatkozz egy kész témára: 

<link rel="stylesheet" href="/themes/united-states-web-design-system.css" />

5. lépés — Nézd meg, ahogy az egész működik

A Next.js példaalkalmazás a teljes katalógus stílusosan és bemutatva, Playwright e2e-vel és axe-core alapvonallal: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-next-examples
pnpm install && pnpm run dev

További lépések

  • Témák — váltás futásidőben a React theme-picker segédjével.
  • Beállítási segédek — nyelv és szövegméret.
  • Komponenskatalógus — tulajdonságok, ARIA és billentyűzet komponensenként.
