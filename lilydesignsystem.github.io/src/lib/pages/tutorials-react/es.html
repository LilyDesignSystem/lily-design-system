Tutorial de React

Componentes de función tipados, un archivo cada uno, controlados con el patrón estándar value + onChange ; todo funciona como React ya funciona.

Qué vas a construir

Un pequeño formulario de contacto: campo con etiqueta, botón de envío, estado controlado, comportamiento real de teclado y lector de pantalla; primero desnudo, luego con estilo, en unos 10 minutos.

Antes de empezar

Necesitas git, Node 22 o posterior y pnpm 10 o posterior. Sirve cualquier proyecto de React 18+: Next.js, Vite o React simple.

Paso 1: Obtén el código

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 571 components

Los componentes son archivos planos en components/ — Button.tsx, TextInput.tsx ; cada uno con su prueba, su story y su documentación al lado. Copia los archivos que necesites en tu aplicación, o trae el repositorio e importa desde él.

Paso 2: Tu primer componente

import Button from "lily-design-system-react-headless/components/Button";

export function SaveBar() {
  return <Button onClick={save}>Save</Button>;
}

Renderiza <button class="button" type="button">. Props: type, disabled, pressed (renderiza aria-pressed), label (un aria-label para anular), className, y cualquier atributo adicional se esparce sobre el elemento raíz.

Paso 3: Compón un formulario pequeño

import { useState } from "react";
import Form from ".../components/Form";
import Field from ".../components/Field";
import TextInput from ".../components/TextInput";
import Button from ".../components/Button";

export function ContactForm() {
  const [name, setName] = useState("");
  return (
    <Form label="Contact form" onSubmit={handleSubmit}>
      <Field label="Full name" required>
        <TextInput id="name" label="Full name" value={name} onChange={setName} required />
      </Field>
      <Button type="submit">Save</Button>
    </Form>
  );
}

Field toma el label como su propia prop en lugar de un componente de etiqueta anidado: pásala una vez, en Fieldy TextInputcorrespondiente de label aporta el nombre accesible.

Verificado el 2026-08-29: un borrador anterior anidaba un componente Label dentro de Field, lo que renderizaba dos etiquetas (una vacía) porque Field ya renderiza la suya propia a partir de la entrada label prop; se detectó compilando el fragmento exacto. Paso 4: Dale estilo

Todo lo anterior se renderiza como estructura pura, lista para tus estilos. Da estilo a los ganchos: .button, .text-input, .label, .field , en tu hoja de estilos, aplica utilidades de Tailwind mediante className, o enlaza un tema ya hecho: 

<link rel="stylesheet" href="/themes/united-states-web-design-system.css" />

Paso 5: Míralo todo funcionando

La aplicación de ejemplo Next.js es el catálogo completo con estilo y demostrado, con Playwright e2e y una línea base de axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-next-examples
pnpm install && pnpm run dev
