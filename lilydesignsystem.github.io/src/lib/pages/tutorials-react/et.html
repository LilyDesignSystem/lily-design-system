Reacti õpetus

Tüübitud funktsioonikomponendid, igaüks üks fail, juhitud standardmustriga value + onChange — kõik töötab nii, nagu React juba töötab.

Mida sa ehitad

Väike kontaktivorm — sildiga väli, saatmisnupp, kontrollitud olek, tõeline klaviatuuri- ja ekraanilugeja käitumine — esmalt paljas, seejärel kujundatud, umbes 10 minutiga.

Enne alustamist

Vaja on gitti, Node 22 või uuemat ja pnpm 10 või uuemat. Sobib iga React 18+ projekt — Next.js, Vite või lihtne React.

Samm 1 — Hangi kood

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 581 components

Komponendid on lamedad failid kaustas components/ — Button.tsx, TextInput.tsx — igaühel oma test, story ja dokumentatsioon kõrval. Kopeeri vajalikud failid oma rakendusse või too repo kaasa ja impordi sealt.

Samm 2 — Sinu esimene komponent

import Button from "lily-design-system-react-headless/components/Button";

export function SaveBar() {
  return <Button onClick={save}>Save</Button>;
}

Renderdab <button class="button" type="button">. Propid: type, disabled, pressed (renderdab aria-pressed), label ( aria-label ülekirjutamiseks), classNameja iga lisaatribuut jagatakse juurelemendile laiali.

Samm 3 — Kombineeri väike vorm

import { useState } from "react";
import Form from ".../components/Form";
import Field from ".../components/Field";
import TextInput from ".../components/TextInput";
import Button from ".../components/Button";

export function ContactForm() {
  const [name, setName] = useState("");
  return (
    <Form label="Contact form" onSubmit={handleSubmit}>
      <Field label="Full name" required>
        <TextInput id="name" label="Full name" value={name} onChange={setName} required />
      </Field>
      <Button type="submit">Save</Button>
    </Form>
  );
}

Field võtab nähtava label oma propina pesastatud sildikomponendi asemel — anna see üks kord edasi, elemendile Fieldja TextInputelemendist label annab ligipääsetava nime.

Kontrollitud 2026-08-29: varasem mustand pesastas eraldi Label sees Field, mis renderdab kaks silti (üks tühi), sest Field renderdab juba oma sildi label prop — avastatud täpse koodilõigu kompileerimisel. Marsruut Koostatud kontaktivormi marsruut on sama muster, proovitud päris e2e- ja axe-testidega.

Samm 4 — Kujunda see

Kõik ülaltoodu renderdatakse puhta struktuurina, valmis sinu stiilidele. Kujunda konksud — .button, .text-input, .label, .field — oma laadilehes, kihi Tailwindi utiliidid kaudu classNamevõi lingi valmis teema: 

<link rel="stylesheet" href="/themes/united-states-web-design-system.css" />

Samm 5 — Vaata kõike töötamas

Next.js näiterakendus on kogu kataloog kujundatuna ja demonstreeritult, Playwright e2e ja axe-core baasjoonega: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-next-examples
pnpm install && pnpm run dev

Järgmised sammud

  • Eelistuste abilised — keel ja teksti suurus.
  • Komponentide kataloog — omadused, ARIA ja klaviatuur komponendi kohta.
