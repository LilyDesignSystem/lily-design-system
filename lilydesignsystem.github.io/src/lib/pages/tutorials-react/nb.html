React-veiledning

Typede funksjonskomponenter, én fil hver, kontrollert med standard value + onChange mønster — alt fungerer slik React allerede gjør.

Hva du skal bygge

Et lite kontaktskjema — inndatafelt med etikett, send-knapp, kontrollert tilstand, ekte tastatur- og skjermleseroppførsel — først bart, så stilet, på omtrent 10 minutter.

Før du begynner

Du trenger git, Node 22 eller nyere og pnpm 10 eller nyere. Ethvert React 18+-prosjekt fungerer — Next.js, Vite eller ren React.

Steg 1 — Hent koden

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 581 components

Komponentene er flate filer i components/ — Button.tsx, TextInput.tsx — hver med sin test, story og dokumentasjon ved siden av. Kopier filene du trenger inn i appen din, eller vendor repoet og importer fra det.

Steg 2 — Din første komponent

import Button from "lily-design-system-react-headless/components/Button";

export function SaveBar() {
  return <Button onClick={save}>Save</Button>;
}

Gjengir <button class="button" type="button">. Egenskaper: type, disabled, pressed (gjengir aria-pressed), label (en aria-label overstyring), className, og ethvert ekstra attributt spres på rotelementet.

Steg 3 — Sett sammen et lite skjema

import { useState } from "react";
import Form from ".../components/Form";
import Field from ".../components/Field";
import TextInput from ".../components/TextInput";
import Button from ".../components/Button";

export function ContactForm() {
  const [name, setName] = useState("");
  return (
    <Form label="Contact form" onSubmit={handleSubmit}>
      <Field label="Full name" required>
        <TextInput id="name" label="Full name" value={name} onChange={setName} required />
      </Field>
      <Button type="submit">Save</Button>
    </Form>
  );
}

Field tar den synlige label som sin egen egenskap i stedet for en nøstet etikettkomponent — send den inn én gang, på Fieldog TextInputpå label gir det tilgjengelige navnet.

Verifisert 2026-08-29: et tidligere utkast nøstet en separat Label inni Field, som gjengir to etiketter (én tom) fordi Field allerede gjengir sin egen fra label egenskap — oppdaget ved å kompilere den nøyaktige snutten. Den sammensatte kontaktskjema-ruten er det samme mønsteret, prøvd med ekte e2e- og axe-tester.

Steg 4 — Stil det

Alt ovenfor gjengis som ren struktur, klar for stilene dine. Stil krokene — .button, .text-input, .label, .field — i stilarket ditt, legg Tailwind-verktøyklasser oppå via className, eller lenk et ferdig tema: 

<link rel="stylesheet" href="/themes/united-states-web-design-system.css" />

Steg 5 — Se alt fungere

Next.js-eksempelappen er hele katalogen stilet og demonstrert, med Playwright e2e og en axe-core-baseline: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-next-examples
pnpm install && pnpm run dev

Neste steg

  • Tema — bytte ved kjøretid med React theme-picker-hjelperen.
  • Preferansehjelpere — språk og tekststørrelse.
  • Komponentkatalog — egenskaper, ARIA og tastatur per komponent.

Spørsmål underveis? hjelpesiden er full av svar — og hvis et steg kan bli tydeligere, fortell oss så forbedrer vi gjerne veiledningen.
