Dyskans React

Darnow-oberow tyskys, unn restren pub onan, kontrollys gans an patrom value + onChange standard — pubtra a ober fatell wra React seulajys.

Pyth a wrewgh drehevel

Furv kestava byghan — mewnos gans lavell, botton danvon, stad kontrollys, hwedhel klavyer ha skrin-redyer gwir — kynsa noeth, ena stylys, yn a-dro dhe 10 mynysenn.

Kyns dalleth

Ty a'n jeves othom a git, Node 22 po nowodhyes, ha pnpm 10 po nowodhyes. Raglen React 18+ vyth a ober — Next.js, Vite, po React plen.

Kamm 1 — Kevewgh an koodh

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 571 components

An darnow yw restrennow plat yn components/ — Button.tsx, TextInput.tsx — pub onan gans y brov, story, ha dhogynnans ryb. Kopiewgh an restrennow a'n jeves othom dhe'th app, po vendorewgh an gwithva hag enporthewgh dhiworto.

Kamm 2 — Dha dharn kynsa

import Button from "lily-design-system-react-headless/components/Button";

export function SaveBar() {
  return <Button onClick={save}>Save</Button>;
}

Dyskwedh <button class="button" type="button">. Perthynasow: type, disabled, pressed (a dhyskwedh aria-pressed), label ( aria-label gorholans), className, ha peub perthynas ekstra a lesans war an elven wreydh.

Field a gemmer an label avel perthynas y honan yn le darn lavell nessys — passewgh hi unnweyth, war Fieldha TextInputkehevelys war label a re an hanow hedhesys.

Gwiriys 2026-08-29: kynsa towl a nesas darn dyvers Label a-berth Field, hag a dhyskwedhas dew lavell (unn gwag) drefen Field seulajys a dhyskwedh y honan dhiworth an label perthynas — kefys dre gesolya an snippet ewn. An fordh furv-kestava kesstrewys yw an keth patrom, previys gans e2e ha axe gwir.

Kamm 4 — Stylyewgh

Pubtra a-ugh a vydh dyskwedhys avel strewyans pur, parys rag dha stilyow. Stylyewgh an krogow — .button, .text-input, .label, .field — yn dha folen-stil, gorrewgh toulys Tailwind dre className, po kevrewgh tebel parys: 

<link rel="stylesheet" href="/themes/united-states-web-design-system.css" />

Kamm 5 — Gwelewgh pubtra ow ’oberi

An App ensampel Next.js yw an rolyans kowl stylys ha displetys, gans Playwright e2e ha linenn-selys axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-next-examples
pnpm install && pnpm run dev

Kammow nessa

  • Tebelyow — chanj y'n termyn-dyrghas gans an gweresor React theme-picker.
  • Gweresoryon dewisyow — yeth ha myns an skrif.
  • Rolyans darnow — perthynasow, ARIA, ha klavyer dre bub darn.
