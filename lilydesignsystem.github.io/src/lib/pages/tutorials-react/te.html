React ట్యుటోరియల్

టైప్ చేసిన ఫంక్షన్ కాంపోనెంట్లు, ఒక్కొక్కటి ఒక ఫైల్, ప్రామాణిక నమూనాతో నియంత్రించబడతాయి value + onChange — అన్నీ React ఇప్పటికే పనిచేసే విధంగానే పనిచేస్తాయి.

మీరు ఏమి నిర్మిస్తారు

ఒక చిన్న సంప్రదింపు ఫారమ్ — లేబుల్ ఉన్న ఫీల్డ్, సమర్పించే బటన్, నియంత్రిత స్థితి, నిజమైన కీబోర్డ్ మరియు స్క్రీన్-రీడర్ ప్రవర్తన — మొదట ఖాళీగా, తర్వాత శైలీకరించి, సుమారు 10 నిమిషాల్లో.

ప్రారంభించే ముందు

మీకు git, Node 22 లేదా కొత్తది, మరియు pnpm 10 లేదా కొత్తది కావాలి. ఏ React 18+ ప్రాజెక్ట్ అయినా పనిచేస్తుంది — Next.js, Vite లేదా సాదా React.

దశ 1 — కోడ్ పొందండి

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 571 components

కాంపోనెంట్లు ఇక్కడ చదునైన ఫైళ్లుగా ఉన్నాయి: components/ — Button.tsx, TextInput.tsx — ప్రతి ఒక్కటి దాని పరీక్ష, story మరియు డాక్యుమెంటేషన్‌తో పక్కనే. మీకు కావలసిన ఫైళ్లను మీ యాప్‌లోకి కాపీ చేయండి, లేదా రిపోను తెచ్చి దాని నుండి దిగుమతి చేసుకోండి.

దశ 2 — మీ మొదటి కాంపోనెంట్

import Button from "lily-design-system-react-headless/components/Button";

export function SaveBar() {
  return <Button onClick={save}>Save</Button>;
}

ఇది చూపిస్తుంది <button class="button" type="button">. Props: type, disabled, pressed (చూపిస్తుంది aria-pressed), label (ఒక aria-label ఓవర్‌రైడ్ చేయడానికి), className, మరియు ఏ అదనపు గుణమైనా మూల మూలకంపై వ్యాపిస్తుంది.

దశ 3 — ఒక చిన్న ఫారమ్‌ను కూర్చండి

import { useState } from "react";
import Form from ".../components/Form";
import Field from ".../components/Field";
import TextInput from ".../components/TextInput";
import Button from ".../components/Button";

export function ContactForm() {
  const [name, setName] = useState("");
  return (
    <Form label="Contact form" onSubmit={handleSubmit}>
      <Field label="Full name" required>
        <TextInput id="name" label="Full name" value={name} onChange={setName} required />
      </Field>
      <Button type="submit">Save</Button>
    </Form>
  );
}

Field కనిపించే label దాని స్వంత prop గా, లోపల ఉంచిన లేబుల్ కాంపోనెంట్‌గా కాదు — దాన్ని ఒకసారి ఇవ్వండి, పై Fieldమరియు TextInputయొక్క label అందుబాటులో ఉండే పేరును అందిస్తుంది.

2026-08-29న ధృవీకరించబడింది: ముందటి చిత్తుప్రతి ఒక ప్రత్యేక Label లోపల Fieldలోపల ఉంచింది, దాని వల్ల రెండు లేబుళ్లు (ఒకటి ఖాళీ) కనిపించాయి ఎందుకంటే Field ఇప్పటికే తన స్వంతదాన్ని label prop — సరిగ్గా ఆ స్నిప్పెట్‌ను కంపైల్ చేయడం ద్వారా గుర్తించబడింది. మార్గం సంయుక్త సంప్రదింపు-ఫారమ్ మార్గం అదే నమూనా, నిజమైన e2e మరియు axe పరీక్షలతో పరీక్షించబడింది.

దశ 4 — శైలీకరించండి

పైన ఉన్నదంతా స్వచ్ఛమైన నిర్మాణంగా రెండర్ అవుతుంది, మీ శైలులకు సిద్ధంగా. హుక్‌లను శైలీకరించండి — .button, .text-input, .label, .field — మీ స్టైల్‌షీట్‌లో, దీని ద్వారా Tailwind యుటిలిటీలను పొరగా వేయండి className, లేదా సిద్ధమైన థీమ్‌ను లింక్ చేయండి: 

<link rel="stylesheet" href="/themes/united-states-web-design-system.css" />

దశ 5 — అంతా పనిచేయడం చూడండి

Next.js ఉదాహరణ యాప్ పూర్తి కేటలాగ్ శైలీకరించి, ప్రదర్శనతో ఉంది, Playwright e2e మరియు axe-core ఆధారరేఖతో: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-next-examples
pnpm install && pnpm run dev

తదుపరి దశలు

  • థీమ్‌లు — React theme-picker సహాయకంతో రన్‌టైమ్‌లో మార్చడం.
  • ప్రాధాన్యత సహాయకాలు — భాష మరియు టెక్స్ట్ పరిమాణం.
  • కాంపోనెంట్ కేటలాగ్ — ప్రతి కాంపోనెంట్‌కు లక్షణాలు, ARIA మరియు కీబోర్డ్.

దారిలో ప్రశ్నలా? సహాయ పేజీ సమాధానాలతో నిండి ఉంది — మరియు ఏదైనా దశను మరింత స్పష్టంగా చేయవచ్చంటే, మాకు చెప్పండి మరియు మేము సంతోషంగా ట్యుటోరియల్‌ను మెరుగుపరుస్తాము.
