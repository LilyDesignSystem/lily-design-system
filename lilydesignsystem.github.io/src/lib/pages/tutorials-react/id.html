Tutorial React

Komponen fungsi bertipe, satu berkas masing-masing, dikendalikan dengan pola standar value + onChange — semuanya bekerja seperti yang sudah dilakukan React.

Apa yang akan Anda bangun

Formulir kontak kecil — kolom berlabel, tombol kirim, status terkendali, perilaku papan ketik dan pembaca layar yang nyata — pertama polos, lalu bergaya, dalam sekitar 10 menit.

Sebelum memulai

Anda memerlukan git, Node 22 atau lebih baru, dan pnpm 10 atau lebih baru. Proyek React 18+ mana pun bisa — Next.js, Vite, atau React biasa.

Langkah 1 — Dapatkan kodenya

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 571 components

Komponen berupa berkas datar di components/ — Button.tsx, TextInput.tsx — masing-masing dengan pengujian, story, dan dokumentasinya di sampingnya. Salin berkas yang Anda perlukan ke aplikasi Anda, atau tarik repositori dan impor darinya.

Langkah 2 — Komponen pertama Anda

import Button from "lily-design-system-react-headless/components/Button";

export function SaveBar() {
  return <Button onClick={save}>Save</Button>;
}

Merender <button class="button" type="button">. Props: type, disabled, pressed (merender aria-pressed), label (sebuah aria-label untuk menimpa), className, dan atribut tambahan apa pun disebarkan ke elemen akar.

Langkah 3 — Susun formulir kecil

import { useState } from "react";
import Form from ".../components/Form";
import Field from ".../components/Field";
import TextInput from ".../components/TextInput";
import Button from ".../components/Button";

export function ContactForm() {
  const [name, setName] = useState("");
  return (
    <Form label="Contact form" onSubmit={handleSubmit}>
      <Field label="Full name" required>
        <TextInput id="name" label="Full name" value={name} onChange={setName} required />
      </Field>
      <Button type="submit">Save</Button>
    </Form>
  );
}

Field menerima label sebagai prop-nya sendiri, bukan komponen label bersarang — teruskan sekali, pada Fielddan TextInputyang cocok dari label memberikan nama yang dapat diakses.

Diverifikasi 2026-08-29: draf sebelumnya menyarangkan komponen Label di dalam Field, yang merender dua label (satu kosong) karena Field sudah merender labelnya sendiri dari input label prop — ditemukan dengan mengompilasi cuplikan yang persis. Rute Rute formulir kontak gabungan adalah pola yang sama, diuji dengan pengujian e2e dan axe yang nyata.

Langkah 4 — Beri gaya

Semua di atas dirender sebagai struktur murni, siap untuk gaya Anda. Beri gaya pada kait — .button, .text-input, .label, .field — di lembar gaya Anda, lapiskan utilitas Tailwind melalui className, atau tautkan tema siap pakai: 

<link rel="stylesheet" href="/themes/united-states-web-design-system.css" />

Langkah 5 — Lihat semuanya bekerja

Aplikasi contoh Next.js adalah katalog lengkap yang bergaya dan didemonstrasikan, dengan Playwright e2e dan garis dasar axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-next-examples
pnpm install && pnpm run dev

Langkah berikutnya

  • Tema — pengalihan saat berjalan dengan pembantu theme-picker React.
  • Pembantu preferensi — bahasa dan ukuran teks.
  • Katalog komponen — properti, ARIA, dan papan ketik per komponen.

Ada pertanyaan di tengah jalan? Halaman bantuan penuh jawaban — dan jika suatu langkah bisa lebih jelas, beri tahu kami dan kami dengan senang hati akan memperbaiki tutorial ini.
