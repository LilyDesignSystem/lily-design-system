מדריך React

רכיבי פונקציה מוקלדים, קובץ אחד לכל רכיב, נשלטים בתבנית הסטנדרטית value + onChange — הכול עובד כפי ש-React כבר עובד.

מה תבנו

טופס יצירת קשר קטן — קלט עם תווית, כפתור שליחה, מצב נשלט, התנהגות אמיתית של מקלדת וקורא מסך — קודם חשוף, אחר כך מעוצב, בכ-10 דקות.

לפני שמתחילים

אתם צריכים git, Node 22 ומעלה ו-pnpm 10 ומעלה. כל פרויקט React 18+ מתאים — Next.js, Vite או React פשוט.

שלב 1 — קבלו את הקוד

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 581 components

הרכיבים הם קבצים שטוחים ב- components/ — Button.tsx, TextInput.tsx — כל אחד עם הבדיקה, ה-story והתיעוד שלו לצדו. העתיקו את הקבצים שאתם צריכים לאפליקציה שלכם, או עשו vendoring למאגר וייבאו ממנו.

שלב 2 — הרכיב הראשון שלכם

import Button from "lily-design-system-react-headless/components/Button";

export function SaveBar() {
  return <Button onClick={save}>Save</Button>;
}

מציג <button class="button" type="button">. מאפיינים: type, disabled, pressed (מציג aria-pressed), label ( aria-label עקיפה), className, וכל מאפיין נוסף מתפזר על אלמנט השורש.

שלב 3 — הרכיבו טופס קטן

import { useState } from "react";
import Form from ".../components/Form";
import Field from ".../components/Field";
import TextInput from ".../components/TextInput";
import Button from ".../components/Button";

export function ContactForm() {
  const [name, setName] = useState("");
  return (
    <Form label="Contact form" onSubmit={handleSubmit}>
      <Field label="Full name" required>
        <TextInput id="name" label="Full name" value={name} onChange={setName} required />
      </Field>
      <Button type="submit">Save</Button>
    </Form>
  );
}

Field לוקח את ה label כמאפיין משלו ולא כרכיב תווית מקונן — העבירו אותה פעם אחת, על Field, ו TextInputהתואם ב- label מספק את השם הנגיש.

אומת ב-2026-08-29: טיוטה מוקדמת קיננה רכיב נפרד Label בתוך Field, מה שהציג שתי תוויות (אחת ריקה) משום ש- Field כבר מציג תווית משלו מתוך label מאפיין — התגלה על ידי הידור הקטע המדויק. נתיב טופס יצירת הקשר המורכב הוא אותה תבנית, שנבדקה בבדיקות e2e ו-axe אמיתיות.

שלב 4 — עצבו אותו

כל מה שלמעלה מוצג כמבנה טהור, מוכן לעיצוב שלכם. עצבו את הווים — .button, .text-input, .label, .field — בגיליון הסגנון שלכם, שכבו כלי עזר של Tailwind דרך className, או קשרו ערכת נושא מוכנה: 

<link rel="stylesheet" href="/themes/united-states-web-design-system.css" />

שלב 5 — ראו הכול עובד

אפליקציית הדוגמה Next.js היא הקטלוג המלא מעוצב ומודגם, עם Playwright e2e וקו בסיס axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-next-examples
pnpm install && pnpm run dev

השלבים הבאים

  • ערכות נושא — החלפה בזמן ריצה עם העוזר theme-picker של React.
  • עוזרי העדפות — שפה וגודל טקסט.
  • קטלוג הרכיבים — מאפיינים, ARIA ומקלדת לכל רכיב.

שאלות בדרך? עמוד העזרה מלא בתשובות — ואם שלב יכול להיות ברור יותר, ספרו לנו ונשמח לשפר את המדריך.
