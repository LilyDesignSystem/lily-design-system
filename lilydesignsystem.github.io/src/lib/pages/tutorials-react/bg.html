Ръководство за React

Типизирани функционални компоненти, по един файл, контролирани със стандартния модел value + onChange — всичко работи така, както React вече работи.

Какво ще изградите

Малка форма за контакт — поле с етикет, бутон за изпращане, контролирано състояние, истинско поведение на клавиатурата и екранния четец — първо гола, после стилизирана, за около 10 минути.

Преди да започнете

Нужни са ви git, Node 22 или по-нов и pnpm 10 или по-нов. Подходящ е всеки проект на React 18+ — Next.js, Vite или чист React.

Стъпка 1 — Вземете кода

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 581 components

Компонентите са плоски файлове в components/ — Button.tsx, TextInput.tsx — всеки със свой тест, story и документация до него. Копирайте нужните файлове в приложението си или вземете хранилището и импортирайте от него.

Стъпка 2 — Първият ви компонент

import Button from "lily-design-system-react-headless/components/Button";

export function SaveBar() {
  return <Button onClick={save}>Save</Button>;
}

Рендира <button class="button" type="button">. Props: type, disabled, pressed (рендира aria-pressed), label ( aria-label за презаписване), className, а всеки допълнителен атрибут се разпръсква върху коренния елемент.

Стъпка 3 — Съставете малка форма

import { useState } from "react";
import Form from ".../components/Form";
import Field from ".../components/Field";
import TextInput from ".../components/TextInput";
import Button from ".../components/Button";

export function ContactForm() {
  const [name, setName] = useState("");
  return (
    <Form label="Contact form" onSubmit={handleSubmit}>
      <Field label="Full name" required>
        <TextInput id="name" label="Full name" value={name} onChange={setName} required />
      </Field>
      <Button type="submit">Save</Button>
    </Form>
  );
}

Field приема видимия label като свой собствен prop вместо вложен компонент за етикет — подайте го веднъж, на Fieldи TextInputот label осигурява достъпното име.

Проверено на 2026-08-29: по-ранна чернова влагаше отделен компонент Label вътре в Field, което рендираше два етикета (единият празен), защото Field вече рендира собствения си от входа label prop — открито чрез компилиране на точния фрагмент. Маршрутът Съставният маршрут на формата за контакт е същият модел, изпитан с истински e2e и axe тестове.

Стъпка 4 — Стилизирайте го

Всичко по-горе се рендира като чиста структура, готова за вашите стилове. Стилизирайте куките — .button, .text-input, .label, .field — във вашата таблица със стилове, наслоете Tailwind помощни класове чрез classNameили свържете готова тема: 

<link rel="stylesheet" href="/themes/united-states-web-design-system.css" />

Стъпка 5 — Вижте всичко в действие

Примерното приложение Next.js е целият каталог стилизиран и демонстриран, с Playwright e2e и базова линия axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-next-examples
pnpm install && pnpm run dev
