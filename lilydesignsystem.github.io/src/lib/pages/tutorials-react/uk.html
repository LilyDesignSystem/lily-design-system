Посібник з React

Типізовані функціональні компоненти, по одному файлу на кожен, керовані стандартним value + onChange шаблоном — усе працює так, як React уже робить.

Що ви створите

Невелика контактна форма — поле з міткою, кнопка надсилання, керований стан, справжня поведінка клавіатури та зчитувача екрана — спочатку «гола», потім стилізована, приблизно за 10 хвилин.

Перш ніж почати

Вам потрібні git, Node 22 або новіший і pnpm 10 або новіший. Підійде будь-який проєкт React 18+ — Next.js, Vite або чистий React.

Крок 1 — Отримайте код

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 571 components

Компоненти — це плоскі файли в components/ — Button.tsx, TextInput.tsx — кожен із тестом, story та документацією поруч. Скопіюйте потрібні файли у свій застосунок або вендорте репозиторій та імпортуйте з нього.

Крок 2 — Ваш перший компонент

import Button from "lily-design-system-react-headless/components/Button";

export function SaveBar() {
  return <Button onClick={save}>Save</Button>;
}

Рендерить <button class="button" type="button">. Властивості: type, disabled, pressed (рендерить aria-pressed), label ( aria-label перевизначення), className, а будь-який додатковий атрибут розповсюджується на кореневий елемент.

Крок 3 — Складіть невелику форму

import { useState } from "react";
import Form from ".../components/Form";
import Field from ".../components/Field";
import TextInput from ".../components/TextInput";
import Button from ".../components/Button";

export function ContactForm() {
  const [name, setName] = useState("");
  return (
    <Form label="Contact form" onSubmit={handleSubmit}>
      <Field label="Full name" required>
        <TextInput id="name" label="Full name" value={name} onChange={setName} required />
      </Field>
      <Button type="submit">Save</Button>
    </Form>
  );
}

Field приймає видиму label як власну властивість, а не вкладений компонент мітки — передайте її один раз, на Field, і TextInputу label надає доступну назву.

Перевірено 2026-08-29: ранній чернетковий варіант вкладав окремий компонент Label всередині Field, що рендерило дві мітки (одну порожню), оскільки Field уже рендерить власну з label властивість — виявлено компіляцією точного фрагмента. складений маршрут контактної форми — той самий шаблон, перевірений справжніми e2e- та axe-тестами.

Крок 4 — Стилізуйте

Усе вище рендериться як чиста структура, готова до ваших стилів. Стилізуйте гачки — .button, .text-input, .label, .field — у своїй таблиці стилів, накладайте утиліти Tailwind через classNameабо підключіть готову тему: 

<link rel="stylesheet" href="/themes/united-states-web-design-system.css" />

Крок 5 — Побачте все в дії

Приклад застосунку Next.js — це весь каталог зі стилями й демонстраціями, з Playwright e2e та базовою лінією axe-core: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-next-examples
pnpm install && pnpm run dev
