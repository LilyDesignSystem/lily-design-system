React-Tutorial

Typiséiert Funktiounskomponenten, eng Datei jidd, kontrolléiert mam Standardmuster value + onChange — alles funktionéiert esou, wéi React et scho mécht.

Wat Dir bauen wäert

E klengt Kontaktformulaire — Feld mat Etikett, Schécken-Knäppchen, kontrolléierten Zoustand, richtegt Tastatur- an Écranliesser-Verhalen — fir d'éischt nackeg, duerno gestalt, an ongeféier 10 Minutten.

Ier Dir ufänkt

Dir braucht git, Node 22 oder méi nei a pnpm 10 oder méi nei. All React 18+ Projet funktionéiert — Next.js, Vite oder einfachen React.

Schrëtt 1 — D'Code kréien

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 571 components

D'Komponenten sinn flaach Dateien am components/ — Button.tsx, TextInput.tsx — jidd mat sengem Test, senger Story a senger Dokumentatioun niewendrun. Kopéiert d'Dateien, déi Dir braucht, an Är App, oder hellt de Repo eran an importéiert dovunner.
