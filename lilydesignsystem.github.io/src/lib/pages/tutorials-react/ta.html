React பயிற்சி

வகைப்படுத்தப்பட்ட செயல்பாட்டுக் கூறுகள், ஒவ்வொன்றும் ஒரு கோப்பு, நிலையான முறையால் கட்டுப்படுத்தப்படுகின்றன value + onChange — எல்லாம் React ஏற்கனவே வேலை செய்யும் விதத்திலேயே வேலை செய்கிறது.

நீங்கள் என்ன உருவாக்குவீர்கள்

ஒரு சிறிய தொடர்புப் படிவம் — லேபிளுடன் கூடிய புலம், சமர்ப்பிக்கும் பொத்தான், கட்டுப்படுத்தப்பட்ட நிலை, உண்மையான விசைப்பலகை மற்றும் திரை வாசிப்பான் நடத்தை — முதலில் வெறுமையாக, பிறகு பாணியுடன், சுமார் 10 நிமிடங்களில்.

தொடங்குவதற்கு முன்

உங்களுக்கு git, Node 22 அல்லது புதியது, மற்றும் pnpm 10 அல்லது புதியது தேவை. எந்த React 18+ திட்டமும் வேலை செய்யும் — Next.js, Vite அல்லது எளிய React.

படி 1 — குறியீட்டைப் பெறுங்கள்

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 571 components

கூறுகள் இங்கே தட்டையான கோப்புகளாக உள்ளன: components/ — Button.tsx, TextInput.tsx — ஒவ்வொன்றும் அதன் சோதனை, story மற்றும் ஆவணங்களுடன் அருகிலேயே. தேவையான கோப்புகளை உங்கள் பயன்பாட்டில் நகலெடுங்கள், அல்லது களஞ்சியத்தைக் கொண்டுவந்து அதிலிருந்து இறக்குமதி செய்யுங்கள்.

படி 2 — உங்கள் முதல் கூறு

import Button from "lily-design-system-react-headless/components/Button";

export function SaveBar() {
  return <Button onClick={save}>Save</Button>;
}

இது வழங்குகிறது <button class="button" type="button">. Props: type, disabled, pressed (வழங்குகிறது aria-pressed), label (ஒரு aria-label மேலெழுத), className, மற்றும் கூடுதல் பண்பு எதுவும் மூல உறுப்பில் பரவுகிறது.

படி 3 — ஒரு சிறிய படிவத்தை உருவாக்குங்கள்

import { useState } from "react";
import Form from ".../components/Form";
import Field from ".../components/Field";
import TextInput from ".../components/TextInput";
import Button from ".../components/Button";

export function ContactForm() {
  const [name, setName] = useState("");
  return (
    <Form label="Contact form" onSubmit={handleSubmit}>
      <Field label="Full name" required>
        <TextInput id="name" label="Full name" value={name} onChange={setName} required />
      </Field>
      <Button type="submit">Save</Button>
    </Form>
  );
}

Field தெரியும் label அதன் சொந்த prop ஆக, உள்ளமைந்த லேபிள் கூறாக அல்ல — அதை ஒருமுறை கொடுங்கள், மீது Fieldமற்றும் TextInputஇன் label அணுகத்தக்க பெயரை வழங்குகிறது.

2026-08-29 அன்று சரிபார்க்கப்பட்டது: முந்தைய வரைவு தனி Label உள்ளே Fieldஉள்ளே வைத்தது, அதனால் இரண்டு லேபிள்கள் (ஒன்று காலி) வழங்கப்பட்டன, ஏனெனில் Field ஏற்கனவே தன் சொந்தத்தை label prop — சரியான துணுக்கைத் தொகுத்ததன் மூலம் கண்டறியப்பட்டது. வழி இணைந்த தொடர்புப் படிவ வழி அதே முறைதான், உண்மையான e2e மற்றும் axe சோதனைகளால் சோதிக்கப்பட்டது.

படி 4 — பாணியிடுங்கள்

மேலுள்ள அனைத்தும் தூய கட்டமைப்பாக ரெண்டர் ஆகின்றன, உங்கள் பாணிகளுக்குத் தயாராக. கொக்கிகளுக்குப் பாணியிடுங்கள் — .button, .text-input, .label, .field — உங்கள் நடைத்தாளில், இதன் வழியாக Tailwind பயன்பாடுகளை அடுக்குங்கள் className, அல்லது தயார் தீமை இணைக்கவும்: 

<link rel="stylesheet" href="/themes/united-states-web-design-system.css" />

படி 5 — எல்லாம் வேலை செய்வதைப் பாருங்கள்

Next.js எடுத்துக்காட்டுப் பயன்பாடு முழு பட்டியலும் பாணியுடனும் செயல்விளக்கத்துடனும் உள்ளது, Playwright e2e மற்றும் axe-core அடிப்படையுடன்: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-next-examples
pnpm install && pnpm run dev

அடுத்த படிகள்

  • தீம்கள் — React theme-picker உதவியாளருடன் இயங்கும் போதே மாற்றுதல்.
  • விருப்ப உதவியாளர்கள் — மொழி மற்றும் உரை அளவு.
  • கூறுப் பட்டியல் — ஒவ்வொரு கூறுக்கும் பண்புகள், ARIA மற்றும் விசைப்பலகை.

வழியில் கேள்விகளா? உதவிப் பக்கம் பதில்களால் நிறைந்தது — ஒரு படி இன்னும் தெளிவாக இருக்க முடிந்தால், எங்களிடம் சொல்லுங்கள் நாங்கள் மகிழ்ச்சியுடன் பயிற்சியை மேம்படுத்துவோம்.
