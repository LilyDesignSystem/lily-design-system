React-kennsluefni

Tegundum bundnir fallaíhlutir, ein skrá hver, stýrðir með hefðbundnu value + onChange mynstri — allt virkar eins og React gerir nú þegar.

Það sem þú munt byggja

Lítið tengiliðaeyðublað — innsláttarreitur með merkimiða, sendihnappur, stýrt ástand, raunveruleg lyklaborðs- og skjálesarahegðun — fyrst ber, svo stílað, á um 10 mínútum.

Áður en þú byrjar

Þú þarft git, Node 22 eða nýrra og pnpm 10 eða nýrra. Hvaða React 18+ verkefni sem er virkar — Next.js, Vite eða hreint React.

Skref 1 — Náðu í kóðann

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 571 components

Íhlutirnir eru flatar skrár í components/ — Button.tsx, TextInput.tsx — hver með prófi, story og skjölum við hliðina. Afritaðu skrárnar sem þú þarft í forritið þitt, eða taktu geymsluna inn og fluttu inn úr henni.

Skref 2 — Fyrsti íhluturinn þinn

import Button from "lily-design-system-react-headless/components/Button";

export function SaveBar() {
  return <Button onClick={save}>Save</Button>;
}

Birtir <button class="button" type="button">. Props: type, disabled, pressed (birtir aria-pressed), label ( aria-label yfirskrift), className, og hvaða aukaeigind sem er dreifist á rótarþáttinn.

Skref 3 — Settu saman lítið eyðublað

import { useState } from "react";
import Form from ".../components/Form";
import Field from ".../components/Field";
import TextInput from ".../components/TextInput";
import Button from ".../components/Button";

export function ContactForm() {
  const [name, setName] = useState("");
  return (
    <Form label="Contact form" onSubmit={handleSubmit}>
      <Field label="Full name" required>
        <TextInput id="name" label="Full name" value={name} onChange={setName} required />
      </Field>
      <Button type="submit">Save</Button>
    </Form>
  );
}

Field tekur sýnilega label sem sinn eigin prop frekar en innfelldan merkimiðaíhlut — gefðu hann einu sinni, á Fieldog TextInputá label sér um aðgengilega heitið.

Staðfest 2026-08-29: fyrri drög innfeldu sérstakan Label inni í Field, sem birtir tvo merkimiða (annan tóman) því Field birtir þegar sinn eigin út frá label prop — uppgötvað með því að þýða nákvæmlega snifsið. Sá samsetta tengiliðaeyðublaðsleiðin er sama mynstur, prófað með raunverulegum e2e- og axe-prófum.

Skref 4 — Stílaðu það

Allt hér að ofan birtist sem hrein uppbygging, tilbúin fyrir stílana þína. Stílaðu krókana — .button, .text-input, .label, .field — í stílblaðinu þínu, leggðu Tailwind-tól yfir með className, eða tengdu tilbúið þema: 

<link rel="stylesheet" href="/themes/united-states-web-design-system.css" />

Skref 5 — Sjáðu allt virka

Next.js dæmaforritið er allt safnið stílað og sýnt, með Playwright e2e og axe-core grunnlínu: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-next-examples
pnpm install && pnpm run dev

Næstu skref

  • Þemu — skipti á keyrslutíma með React theme-picker hjálpartækinu.
  • Stillingahjálpartæki — tungumál og textastærð.
  • Íhlutasafn — eiginleikar, ARIA og lyklaborð fyrir hvern íhlut.

Spurningar á leiðinni? hjálparsíðan er full af svörum — og ef skref gæti verið skýrara, segðu okkur og við bætum kennsluefnið með ánægju.
