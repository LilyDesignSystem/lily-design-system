React-Tutorial

Typisierte Funktionskomponenten, je eine Datei, gesteuert mit dem Standardmuster value + onChange — alles funktioniert so, wie React es schon tut.

Was du baust

Ein kleines Kontaktformular — beschriftetes Eingabefeld, Absenden-Schaltfläche, kontrollierter Zustand, echtes Tastatur- und Screenreader-Verhalten — zuerst nackt, dann gestaltet, in etwa 10 Minuten.

Bevor du anfängst

Du brauchst git, Node 22 oder neuer und pnpm 10 oder neuer. Jedes React-18+-Projekt funktioniert — Next.js, Vite oder reines React.

Schritt 1 — Den Code holen

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install
pnpm test        # vitest + @testing-library/react
pnpm run storybook   # browse all 571 components

Die Komponenten sind flache Dateien in components/ — Button.tsx, TextInput.tsx — jede mit ihrem Test, ihrer Story und ihrer Dokumentation daneben. Kopiere die benötigten Dateien in deine App, oder hole das Repo und importiere daraus.

Schritt 2 — Deine erste Komponente

import Button from "lily-design-system-react-headless/components/Button";

export function SaveBar() {
  return <Button onClick={save}>Save</Button>;
}

Rendert <button class="button" type="button">. Props: type, disabled, pressed (rendert aria-pressed), label (ein aria-label zum Überschreiben), className, und jedes zusätzliche Attribut wird auf das Wurzelelement verteilt.

Field nimmt das sichtbare label als eigene Prop statt als verschachtelte Label-Komponente — gib es einmal an, bei Fieldund TextInputvon label liefert den zugänglichen Namen.

Schritt 4 — Gestalten

Alles oben wird als reine Struktur gerendert, bereit für deine Styles. Gestalte die Hooks — .button, .text-input, .label, .field — in deinem Stylesheet, schichte Tailwind-Utilities über className, oder binde ein fertiges Theme ein: 

<link rel="stylesheet" href="/themes/united-states-web-design-system.css" />
