Every example app get di same shape

To make framework-hopping feel familiar, every example app provide:

  • Welcome route for / wey introduce di project.
  • Components index for /components wey list every component.
  • Demo page for each component for /components/<component>.
  • Real CSS — no be abstract design tokens — so you fit copy styles directly.
  • Working keyboard navigation and focus management out of di box.

You need to see how one component dey styled?

Open di relevant example app, go /components/<name>, and copy di markup and CSS enter your own project. Di example apps use plain CSS (or near-plain) on purpose so you fit adapt dem to any system wey you like.

You want headless instead?

Pair any example app with im matching headless package — dem publish di same components without any CSS, ready for your own design tokens.
