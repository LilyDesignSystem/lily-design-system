Kull applikazzjoni ta’ eżempju għandha l-istess forma

Biex it-tbandil bejn frameworks iħossu familjari, kull applikazzjoni ta’ eżempju tipprovdi:

  • Rotta ta’ merħba fuq / li tintroduċi l-proġett.
  • Indiċi tal-komponenti fuq /components li jelenka kull komponent.
  • Paġna demo għal kull komponent fuq /components/<component>.
  • CSS reali — mhux tokens tad-disinn astratti — biex tissellef l-istili direttament.
  • Navigazzjoni bit-tastiera u ġestjoni tal-fokus li jaħdmu mill-kaxxa.

Trid tara kif komponent wieħed huwa stilizzat?

Iftaħ l-applikazzjoni ta’ eżempju rilevanti, mur fuq /components/<name>u ikkopja l-markup u s-CSS fil-proġett tiegħek. L-applikazzjonijiet ta’ eżempju apposta jużaw CSS sempliċi (jew kważi sempliċi) biex tadattahom għal kwalunkwe sistema li tippreferi.

Trid headless minflok?

Akkoppja kwalunkwe applikazzjoni ta’ eżempju mal-pakkett headless korrispondenti — dawk jippubblikaw l-istess komponenti mingħajr CSS, lesti għat-tokens tad-disinn tiegħek stess.
