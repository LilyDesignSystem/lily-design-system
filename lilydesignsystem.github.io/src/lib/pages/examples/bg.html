Всяко примерно приложение има една и съща форма

За да е познато превключването между фреймуърци, всяко примерно приложение предоставя:

  • Приветствен маршрут на / който представя проекта.
  • Индекс на компонентите на /components който изброява всеки компонент.
  • Демо страница за всеки компонент на /components/<component>.
  • Истински CSS — не абстрактни дизайн токени — за да вземате стилове директно.
  • Работеща навигация с клавиатура и управление на фокуса от самото начало.

Трябва ви да видите как е стилизиран един компонент?

Отворете съответното примерно приложение, отидете на /components/<name>и копирайте маркировката и CSS в собствения си проект. Примерните приложения умишлено използват обикновен (или почти обикновен) CSS, за да ги адаптирате към всяка система, която предпочитате.

Искате безглав вместо това?

Съчетайте което и да е примерно приложение със съответния безглав пакет — те публикуват същите компоненти без никакъв CSS, готови за вашите собствени дизайн токени.
