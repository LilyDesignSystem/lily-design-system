All Beispillapplikatioun huet déiselwecht Form

Fir dass d’Sprangen tëscht Frameworken vertraut ausgesäit, bitt all Beispillapplikatioun:

  • Eng Wëllkomroute op / déi de Projet virstellt.
  • E Komponenteindex op /components deen all Komponent opzielt.
  • Eng Demosäit pro Komponent op /components/<component>.
  • Richtege CSS — net abstrakt Design-Tokens — fir dass Dir Stiler direkt iwwerhuele kënnt.
  • Funktionéierend Tastaturnavigatioun a Fokusverwaltung direkt aus der Këscht.

Wëllt Dir gesinn, wéi eng eenzel Komponent gestylt ass?

Mécht déi entspriechend Beispillapplikatioun op, gitt op /components/<name>a kopéiert d’Markup an de CSS an Äre Projet. D’Beispillapplikatioune benotzen bewosst einfachen (oder bal einfachen) CSS, fir dass Dir se u all System upasse kënnt, dat Dir léiwer hutt.

Léiwer headless?

Kombinéiert all Beispillapplikatioun mam entspriechende Headless- Pakéit — dës verëffentleche déiselwecht Komponenten ouni CSS, prett fir Är eegen Design-Tokens.
