Každá ukážková aplikácia má rovnaký tvar

Aby sa prechádzanie medzi frameworkmi zdalo povedomé, každá ukážková aplikácia poskytuje:

  • Uvítaciu trasu na / ktorá predstavuje projekt.
  • Index komponentov na /components ktorý vypisuje každý komponent.
  • Ukážkovú stránku pre každý komponent na /components/<component>.
  • Skutočné CSS — nie abstraktné dizajnové tokeny — aby ste mohli štýly priamo preberať.
  • Funkčnú navigáciu klávesnicou a správu fokusu hneď po vybalení.

Potrebujete vidieť, ako je naštýlovaný jeden komponent?

Otvorte príslušnú ukážkovú aplikáciu, prejdite na /components/<name>a skopírujte značky a CSS do vlastného projektu. Ukážkové aplikácie zámerne používajú jednoduché (alebo takmer jednoduché) CSS, aby ste ich mohli prispôsobiť akémukoľvek systému, ktorý uprednostňujete.

Chcete radšej bezhlavé?

Spárujte ľubovoľnú ukážkovú aplikáciu s príslušným bezhlavým balíčkom — tie publikujú rovnaké komponenty bez akéhokoľvek CSS, pripravené pre vaše vlastné dizajnové tokeny.
