每个示例应用个结构侪相同

为了让在框架之间切换感觉熟悉，每个示例应用侪提供：

  • 位于 / 个欢迎路由，用来介绍本项目。
  • 位于 /components 个组件索引，列出每一个组件。
  • 位于 /components/<component> 个每个组件一页个演示页面。
  • 真实个 CSS——而不是抽象个设计令牌——方便侬直接借鉴样式。
  • 开箱即用个键盘导航搭焦点管理。

想看某一个组件是哪能设置样式个？

打开相应个示例应用，进入 /components/<name>，把标记搭 CSS 复制到侬自己个项目里。示例应用刻意使用朴素（或接近朴素）个 CSS，方便侬适配到任何侬偏好个体系。

想要 headless 版本？

把任一示例应用与其对应个 headless 包搭配——伊拉发布同样个组件，但完全勿带 CSS，随时可接上侬自己个设计令牌。
