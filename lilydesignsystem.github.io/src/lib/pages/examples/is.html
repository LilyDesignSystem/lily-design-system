Öll dæmaforrit hafa sömu lögun

Til að gera flakk milli ramma kunnuglegt býður hvert dæmaforrit:

  • Velkomuleið á / sem kynnir verkefnið.
  • Íhlutayfirlit á /components sem telur upp hvern íhlut.
  • Sýnisíðu fyrir hvern íhlut á /components/<component>.
  • Raunverulegt CSS — ekki óhlutbundin hönnunargildi — svo þú getir afritað stíla beint.
  • Lyklaborðsleiðsögn og fókusstýring sem virka strax.

Þarftu að sjá hvernig einn íhlutur er stílaður?

Opnaðu viðeigandi dæmaforrit, farðu á /components/<name>og afritaðu markup og CSS í þitt eigið verkefni. Dæmaforritin nota viljandi venjulegt CSS (eða því sem næst) svo þú getir aðlagað þau að hvaða kerfi sem þú vilt.

Viltu frekar höfuðlaust?

Paraðu hvaða dæmaforrit sem er við samsvarandi höfuðlausa pakka — þeir gefa út sömu íhluti án nokkurs CSS, tilbúna fyrir þín eigin hönnunargildi.
