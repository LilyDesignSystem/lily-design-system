Katrai paraugu lietotnei ir viena un tā pati forma

Lai pārlēkšana starp ietvariem šķistu pazīstama, katra paraugu lietotne nodrošina:

  • Sveiciena maršrutu uz / kas iepazīstina ar projektu.
  • Komponenšu indeksu uz /components kas uzskaita katru komponenti.
  • Demonstrācijas lapu katrai komponentei uz /components/<component>.
  • Īstu CSS — nevis abstraktus dizaina marķierus — lai varētu tieši aizņemties stilus.
  • Darbojošos navigāciju ar tastatūru un fokusa pārvaldību uzreiz.

Jāredz, kā ir stilizēta atsevišķa komponente?

Atveriet attiecīgo paraugu lietotni, dodieties uz /components/<name>un nokopējiet marķējumu un CSS savā projektā. Paraugu lietotnes apzināti izmanto vienkāršu (vai gandrīz vienkāršu) CSS, lai varētu tās pielāgot jebkurai jūsu vēlamai sistēmai.

Vēlaties drīzāk bezgalvas?

Savienojiet jebkuru paraugu lietotni ar atbilstošo bezgalvas pakotni — tās publicē tās pašas komponentes bez jebkāda CSS, gatavas jūsu pašu dizaina marķieriem.
