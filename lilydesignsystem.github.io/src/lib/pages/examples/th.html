ทุกแอปตัวอย่างมีรูปแบบเดียวกัน

เพื่อให้การเปลี่ยนเฟรมเวิร์กรู้สึกคุ้นเคย ทุกแอปตัวอย่างมี:

  • เส้นทางต้อนรับที่ / ซึ่งแนะนำโครงการ
  • ดัชนีคอมโพเนนต์ที่ /components ซึ่งแสดงรายการทุกคอมโพเนนต์
  • หน้าเดโมสำหรับแต่ละคอมโพเนนต์ที่ /components/<component>.
  • CSS จริง — ไม่ใช่โทเค็นการออกแบบเชิงนามธรรม — เพื่อให้คุณหยิบสไตล์ไปใช้ได้โดยตรง
  • การนำทางด้วยแป้นพิมพ์และการจัดการโฟกัสที่ใช้งานได้ตั้งแต่แรก

อยากดูว่าคอมโพเนนต์ตัวเดียวถูกจัดสไตล์อย่างไร?

เปิดแอปตัวอย่างที่เกี่ยวข้อง ไปที่ /components/<name> แล้วคัดลอกมาร์กอัปและ CSS ไปใส่ในโปรเจกต์ของคุณเอง แอปตัวอย่างใช้ CSS ธรรมดา (หรือเกือบธรรมดา) โดยตั้งใจ เพื่อให้คุณปรับให้เข้ากับระบบใดก็ได้ที่คุณชอบ

ต้องการแบบ headless มากกว่าไหม?

จับคู่แอปตัวอย่างใดก็ได้กับแพ็กเกจ headless ที่ตรงกัน — แพ็กเกจเหล่านั้นเผยแพร่คอมโพเนนต์ชุดเดียวกันโดยไม่มี CSS พร้อมสำหรับโทเค็นการออกแบบของคุณเอง
