Každá ukázková aplikace má stejný tvar

Aby se přecházení mezi frameworky zdálo povědomé, každá ukázková aplikace poskytuje:

  • Uvítací trasu na / která představuje projekt.
  • Index komponent na /components který vypisuje každou komponentu.
  • Ukázkovou stránku pro každou komponentu na /components/<component>.
  • Skutečné CSS — ne abstraktní návrhové tokeny — abyste mohli styly přímo přebírat.
  • Funkční navigaci klávesnicí a správu fokusu hned po vybalení.

Potřebujete vidět, jak je nastylovaná jedna komponenta?

Otevřete příslušnou ukázkovou aplikaci, přejděte na /components/<name>a zkopírujte značky a CSS do svého projektu. Ukázkové aplikace záměrně používají prosté (nebo téměř prosté) CSS, abyste je mohli přizpůsobit jakémukoli systému, který preferujete.

Chcete raději bezhlavé?

Spárujte libovolnou ukázkovou aplikaci s odpovídajícím bezhlavým balíčkem — ty publikují stejné komponenty bez jakéhokoli CSS, připravené pro vaše vlastní návrhové tokeny.
