Fiecare aplicație-exemplu are aceeași formă

Pentru ca trecerea între framework-uri să pară familiară, fiecare aplicație-exemplu oferă:

  • O rută de bun venit la / care prezintă proiectul.
  • Un index de componente la /components care listează fiecare componentă.
  • O pagină demo pentru fiecare componentă la /components/<component>.
  • CSS real — nu tokenuri de design abstracte — ca să poți prelua direct stilurile.
  • Navigare cu tastatura și gestionare a focalizării funcționale din start.

Vrei să vezi cum este stilizată o singură componentă?

Deschide aplicația-exemplu relevantă, navighează la /components/<name>și copiază markup-ul și CSS-ul în propriul proiect. Aplicațiile-exemplu folosesc intenționat CSS simplu (sau aproape simplu), ca să le poți adapta la orice sistem preferi.

Preferi headless?

Asociază orice aplicație-exemplu cu pachetul headless corespunzător — acestea publică aceleași componente fără niciun CSS, gata pentru propriile tale tokenuri de design.
