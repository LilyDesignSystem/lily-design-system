Każda aplikacja przykładowa ma ten sam kształt

Aby przechodzenie między frameworkami było znajome, każda aplikacja przykładowa zapewnia:

  • Trasę powitalną pod adresem / która przedstawia projekt.
  • Indeks komponentów pod adresem /components który wymienia każdy komponent.
  • Stronę demonstracyjną dla każdego komponentu pod adresem /components/<component>.
  • Prawdziwy CSS — nie abstrakcyjne tokeny projektowe — żebyś mógł od razu zapożyczać style.
  • Działającą nawigację klawiaturą i zarządzanie fokusem od razu po instalacji.

Chcesz zobaczyć, jak ostylowany jest pojedynczy komponent?

Otwórz odpowiednią aplikację przykładową, przejdź do /components/<name>i skopiuj znaczniki oraz CSS do własnego projektu. Aplikacje przykładowe celowo używają zwykłego (lub prawie zwykłego) CSS, żebyś mógł dostosować je do dowolnego systemu, który wolisz.

Wolisz bezgłowo?

Połącz dowolną aplikację przykładową z odpowiadającym jej bezgłowym pakietem — publikują one te same komponenty bez żadnego CSS, gotowe na twoje własne tokeny projektowe.
