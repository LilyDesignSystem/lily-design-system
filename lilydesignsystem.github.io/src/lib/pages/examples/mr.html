प्रत्येक उदाहरण अॅपची रचना सारखीच आहे

फ्रेमवर्क बदलणे परिचित वाटावे म्हणून, प्रत्येक उदाहरण अॅप पुरवते:

  • येथे स्वागत मार्ग / जो प्रकल्पाची ओळख करून देतो.
  • येथे घटक अनुक्रमणिका /components जी प्रत्येक घटकाची यादी करते.
  • येथे प्रत्येक घटकासाठी एक डेमो पृष्ठ /components/<component>.
  • वास्तविक CSS — अमूर्त डिझाइन टोकन नव्हे — म्हणजे तुम्ही शैली थेट उसन्या घेऊ शकता.
  • बॉक्सबाहेर काम करणारे कीबोर्ड नेव्हिगेशन आणि फोकस व्यवस्थापन.

एका घटकाला शैली कशी दिली आहे ते पाहायचे आहे का?

संबंधित उदाहरण अॅप उघडा, येथे जा /components/<name>आणि मार्कअप व CSS तुमच्या स्वतःच्या प्रकल्पात कॉपी करा. उदाहरण अॅप्स जाणीवपूर्वक साधे (किंवा जवळजवळ साधे) CSS वापरतात म्हणजे तुम्ही त्यांना तुमच्या आवडत्या कोणत्याही प्रणालीशी जुळवू शकता.

त्याऐवजी हेडलेस हवे आहे?

कोणतेही उदाहरण अॅप त्याच्या संबंधित हेडलेस पॅकेजसह जोडा — ते तेच घटक कोणत्याही CSS शिवाय प्रकाशित करतात, तुमच्या स्वतःच्या डिझाइन टोकनसाठी तयार.
