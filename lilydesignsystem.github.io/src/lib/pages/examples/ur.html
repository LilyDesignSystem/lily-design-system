ہر مثالی ایپ کی ایک ہی ساخت ہے

فریم ورکس کے درمیان آنا جانا مانوس لگے، اس کے لیے ہر مثالی ایپ یہ فراہم کرتی ہے:

  • / پر ایک خوش آمدید روٹ جو منصوبے کا تعارف کراتا ہے۔
  • /components پر کمپوننٹس کا انڈیکس جو ہر کمپوننٹ کی فہرست دیتا ہے۔
  • /components/<component> پر ہر کمپوننٹ کے لیے ایک ڈیمو صفحہ۔
  • حقیقی CSS — تجریدی ڈیزائن ٹوکن نہیں — تاکہ آپ سٹائلز براہِ راست نقل کر سکیں۔
  • پہلے ہی لمحے سے کام کرنے والی کی بورڈ نیویگیشن اور فوکس کا انتظام۔

دیکھنا چاہتے ہیں کہ ایک کمپوننٹ کیسے سٹائل ہوا ہے؟

متعلقہ مثالی ایپ کھولیں، /components/<name> پر جائیں، اور مارک اپ اور CSS اپنے منصوبے میں نقل کر لیں۔ مثالی ایپس دانستہ سادہ (یا تقریباً سادہ) CSS استعمال کرتی ہیں تاکہ آپ انہیں اپنی پسند کے کسی بھی نظام میں ڈھال سکیں۔

اس کے بجائے headless چاہیے؟

کسی بھی مثالی ایپ کو اس کے متعلقہ headless پیکیج کے ساتھ ملائیں — وہ انہی کمپوننٹس کو بغیر کسی CSS کے شائع کرتے ہیں، آپ کے اپنے ڈیزائن ٹوکنز کے لیے تیار۔
