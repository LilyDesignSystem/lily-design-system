Kiekviena pavyzdinė programa turi tą pačią formą

Kad šuoliai tarp karkasų atrodytų pažįstami, kiekviena pavyzdinė programa suteikia:

  • Sveikinimo maršrutą adresu / kuris pristato projektą.
  • Komponentų indeksą adresu /components kuris išvardija kiekvieną komponentą.
  • Demonstracinį puslapį kiekvienam komponentui adresu /components/<component>.
  • Tikrą CSS — ne abstrakčius dizaino žetonus — kad galėtumėte tiesiogiai pasiskolinti stilius.
  • Veikiantį naršymą klaviatūra ir fokuso valdymą iškart.

Reikia pamatyti, kaip stilizuotas atskiras komponentas?

Atidarykite atitinkamą pavyzdinę programą, eikite į /components/<name>ir nukopijuokite žymėjimą bei CSS į savo projektą. Pavyzdinės programos sąmoningai naudoja paprastą (arba beveik paprastą) CSS, kad galėtumėte jas pritaikyti bet kuriai jūsų pageidaujamai sistemai.

Norite bevaigio?

Suporuokite bet kurią pavyzdinę programą su atitinkamu bevaigiu paketu — jie skelbia tuos pačius komponentus be jokio CSS, paruoštus jūsų pačių dizaino žetonams.
