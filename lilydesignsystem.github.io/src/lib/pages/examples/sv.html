Varje exempelapp har samma form

För att det ska kännas bekant att hoppa mellan ramverk har varje exempelapp:

  • En välkomstrutt på / som presenterar projektet.
  • Ett komponentindex på /components som listar varje komponent.
  • En demosida per komponent på /components/<component>.
  • Riktig CSS – inte abstrakta designtokens – så att du kan hämta stilar direkt.
  • Fungerande tangentbordsnavigering och fokushantering direkt.

Behöver du se hur en enskild komponent formges?

Öppna den aktuella exempelappen, gå till /components/<name>och kopiera markup och CSS till ditt eget projekt. Exempelapparna använder medvetet ren (eller nästan ren) CSS så att du kan anpassa dem till vilket system du föredrar.

Vill du hellre ha huvudlöst?

Para ihop vilken exempelapp som helst med motsvarande huvudlösa paket – de publicerar samma komponenter utan någon CSS, redo för dina egna designtokens.
