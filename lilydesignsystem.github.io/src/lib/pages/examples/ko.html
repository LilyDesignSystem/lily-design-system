모든 예제 앱은 같은 구성입니다

프레임워크를 옮겨 다녀도 낯설지 않도록, 모든 예제 앱은 다음을 제공합니다.

  • 프로젝트를 소개하는 /의 환영 라우트.
  • 모든 컴포넌트를 나열하는 /components의 컴포넌트 색인.
  • 컴포넌트별 데모 페이지 /components/<component>.
  • 추상적인 디자인 토큰이 아닌 실제 CSS. 스타일을 그대로 가져다 쓸 수 있습니다.
  • 처음부터 동작하는 키보드 탐색과 포커스 관리.

컴포넌트 하나의 스타일이 궁금하다면?

해당 예제 앱을 열고 /components/<name>로 이동해서 마크업과 CSS를 프로젝트에 복사하세요. 예제 앱은 일부러 순수 CSS(또는 그에 가까운 것)를 사용하므로 원하는 어떤 시스템에도 맞출 수 있습니다.

헤드리스를 원하시나요?

어떤 예제 앱이든 대응하는 헤드리스 패키지와 함께 쓸 수 있습니다. 그쪽은 같은 컴포넌트를 CSS 없이 배포하므로, 여러분의 디자인 토큰을 바로 적용할 수 있습니다.
