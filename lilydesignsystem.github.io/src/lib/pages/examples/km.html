កម្មវិធីគំរូនីមួយៗមានរាងដូចគ្នា

ដើម្បីឱ្យការលោតរវាងក្របខណ្ឌមានអារម្មណ៍ស្គាល់ កម្មវិធីគំរូនីមួយៗផ្តល់៖

  • ផ្លូវស្វាគមន៍នៅ / ដែលណែនាំគម្រោង។
  • សន្ទស្សន៍សមាសភាគនៅ /components ដែលរាយសមាសភាគនីមួយៗ។
  • ទំព័របង្ហាញសម្រាប់សមាសភាគនីមួយៗនៅ /components/<component>.
  • CSS ពិតប្រាកដ — មិនមែនតូខឹនរចនាអរូបីទេ — ដូច្នេះអ្នកអាចយករចនាប័ទ្មដោយផ្ទាល់។
  • ការរុករកដោយក្តារចុច និងការគ្រប់គ្រងការផ្តោតដែលដំណើរការចេញពីប្រអប់។

ត្រូវការមើលថាតើសមាសភាគមួយត្រូវបានដាក់រចនាប័ទ្មយ៉ាងដូចម្តេច?

បើកកម្មវិធីគំរូដែលពាក់ព័ន្ធ រុករកទៅ /components/<name>ហើយចម្លងម៉ាកអាប់ និង CSS ចូលគម្រោងផ្ទាល់ខ្លួនរបស់អ្នក។ កម្មវិធីគំរូប្រើ CSS ធម្មតា (ឬជិតធម្មតា) ដោយចេតនា ដូច្នេះអ្នកអាចសម្របវាទៅនឹងប្រព័ន្ធណាមួយដែលអ្នកចូលចិត្ត។

ចង់បានគ្មានក្បាលវិញ?

ផ្គូផ្គងកម្មវិធីគំរូណាមួយជាមួយកញ្ចប់ គ្មានក្បាល ដែលត្រូវគ្នា — ពួកវាបោះពុម្ពសមាសភាគដូចគ្នាដោយគ្មាន CSS ណាមួយ រួចជាស្រេចសម្រាប់តូខឹនរចនាផ្ទាល់ខ្លួនរបស់អ្នក។
