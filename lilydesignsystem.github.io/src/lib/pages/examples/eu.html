Adibide-aplikazio guztiek forma bera dute

Framework batetik bestera jauzi egitea ezaguna senti dadin, adibide-aplikazio bakoitzak hauek eskaintzen ditu:

  • Ongi etorri-ibilbide bat hemen: / proiektua aurkezten duena.
  • Osagai-indize bat hemen: /components osagai guztiak zerrendatzen dituena.
  • Osagai bakoitzaren demo-orri bat hemen: /components/<component>.
  • CSS erreala — diseinu-token abstraktuak ez — estiloak zuzenean kopiatu ahal izateko.
  • Teklatu-nabigazioa eta fokuaren kudeaketa kutxatik ateratzen den bezala.

Osagai bakar bat nola estilatzen den ikusi behar duzu?

Ireki dagokion adibide-aplikazioa, joan hona: /components/<name>, eta kopiatu markaketa eta CSSa zure proiektura. Adibide-aplikazioek nahita CSS soila (edo ia soila) erabiltzen dute, nahi duzun edozein sistemarako egokitu ahal izateko.

Buru gabeko bertsioa nahiago?

Parekatu edozein adibide-aplikazio dagokion buru gabeko paketearekin — osagai berberak argitaratzen dituzte CSSrik gabe, zure diseinu-tokenetarako prest.
