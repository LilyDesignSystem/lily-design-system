Jede Beispiel-App hat dieselbe Form

Damit der Wechsel zwischen Frameworks vertraut wirkt, bietet jede Beispiel-App:

  • Eine Willkommensroute unter / die das Projekt vorstellt.
  • Einen Komponentenindex unter /components der jede Komponente auflistet.
  • Eine Demoseite pro Komponente unter /components/<component>.
  • Echtes CSS – keine abstrakten Design-Tokens –, sodass Sie Stile direkt übernehmen können.
  • Funktionierende Tastaturnavigation und Fokusverwaltung von Anfang an.

Möchten Sie sehen, wie eine einzelne Komponente gestaltet ist?

Öffnen Sie die passende Beispiel-App, navigieren Sie zu /components/<name>und kopieren Sie das Markup und das CSS in Ihr eigenes Projekt. Die Beispiel-Apps verwenden bewusst schlichtes (oder fast schlichtes) CSS, damit Sie sie an jedes System anpassen können, das Sie bevorzugen.

Lieber headless?

Kombinieren Sie jede der Beispiel-Apps mit dem zugehörigen Headless- Paket – diese veröffentlichen dieselben Komponenten ganz ohne CSS, bereit für Ihre eigenen Design-Tokens.
