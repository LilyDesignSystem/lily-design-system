У всех примеров приложений одна и та же структура

Чтобы переход между фреймворками казался привычным, каждое приложение-пример предоставляет:

  • Приветственный маршрут /, представляющий проект.
  • Индекс компонентов по адресу /components со списком всех компонентов.
  • Демонстрационную страницу для каждого компонента по адресу /components/<component>.
  • Настоящий CSS, а не абстрактные дизайн-токены, чтобы вы могли напрямую подглядеть стили.
  • Работающую из коробки навигацию с клавиатуры и управление фокусом.

Нужно увидеть, как оформлен один компонент?

Откройте нужное приложение-пример, перейдите на /components/<name> и скопируйте разметку и CSS в свой проект. Приложения-примеры намеренно используют простой (или почти простой) CSS, чтобы вы могли адаптировать их к любой системе.

Нужен именно headless?

Сочетайте любое приложение-пример с соответствующим headless-пакетом — он публикует те же компоненты вообще без CSS, готовые к вашим собственным дизайн-токенам.
