لكل تطبيق مثال الشكل نفسه

لكي يبدو التنقل بين أطر العمل مألوفًا، يوفّر كل تطبيق مثال ما يلي:

  • مسار ترحيب في / يقدّم المشروع.
  • فهرس للمكوّنات في /components يسرد كل مكوّن.
  • صفحة عرض لكل مكوّن في /components/<component>.
  • CSS حقيقي — لا رموز تصميم مجردة — لتنقل الأنماط مباشرة.
  • تنقل بلوحة المفاتيح وإدارة للتركيز يعملان من أول لحظة.

تحتاج إلى معرفة كيف يُنسَّق مكوّن واحد؟

افتح تطبيق المثال المعني، وانتقل إلى /components/<name>، وانسخ الترميز وCSS إلى مشروعك. تستخدم تطبيقات الأمثلة عمدًا CSS عاديًا (أو شبه عادي) لتتمكن من تكييفها مع أي نظام تفضّله.
