هر برنامهٔ نمونه شکل یکسانی دارد

برای آنکه جابه‌جایی میان چارچوب‌ها آشنا به نظر برسد، هر برنامهٔ نمونه این‌ها را ارائه می‌دهد:

  • یک مسیر خوش‌آمد در / که پروژه را معرفی می‌کند.
  • یک نمایهٔ مؤلفه‌ها در /components که هر مؤلفه را فهرست می‌کند.
  • یک صفحهٔ نمایشی برای هر مؤلفه در /components/<component>.
  • CSS واقعی — نه توکن‌های طراحی انتزاعی — تا بتوانید سبک‌ها را مستقیماً قرض بگیرید.
  • پیمایش صفحه‌کلید و مدیریت تمرکز که از همان ابتدا کار می‌کند.

می‌خواهید ببینید یک مؤلفهٔ منفرد چگونه سبک‌دهی شده؟

برنامهٔ نمونهٔ مربوط را باز کنید، به /components/<name>بروید و نشانه‌گذاری و CSS را در پروژهٔ خودتان رونوشت کنید. برنامه‌های نمونه عمداً از CSS ساده (یا تقریباً ساده) استفاده می‌کنند تا بتوانید آن‌ها را با هر سامانه‌ای که ترجیح می‌دهید تطبیق دهید.

به‌جای آن بدون‌سر می‌خواهید؟

هر برنامهٔ نمونه را با بستهٔ بدون‌سر متناظرش جفت کنید — آن‌ها همان مؤلفه‌ها را بدون هیچ CSS منتشر می‌کنند، آمادهٔ توکن‌های طراحی خودتان.
