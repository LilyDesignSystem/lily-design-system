Pareho ang hugis ng bawat halimbawang app

Para maging pamilyar ang paglipat-lipat ng framework, bawat halimbawang app ay nagbibigay ng:

  • Isang welcome route sa / na nagpapakilala sa proyekto.
  • Isang index ng component sa /components na naglilista ng bawat component.
  • Isang demo page para sa bawat component sa /components/<component>.
  • Tunay na CSS — hindi abstract na design token — para direkta mong makopya ang mga istilo.
  • Gumaganang pag-navigate gamit ang keyboard at pamamahala ng focus agad-agad.

Kailangan mong makita kung paano binigyan ng istilo ang isang component?

Buksan ang kaukulang halimbawang app, pumunta sa /components/<name>, at kopyahin ang markup at CSS sa sarili mong proyekto. Sadyang gumagamit ng simpleng CSS (o halos simple) ang mga halimbawang app para maiangkop mo ang mga ito sa anumang sistemang gusto mo.

Gusto mo ng headless sa halip?

Ipares ang anumang halimbawang app sa katumbas nitong headless na package — inilalathala nila ang parehong mga component na walang anumang CSS, handa para sa sarili mong mga design token.
