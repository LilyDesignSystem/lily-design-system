每個範例應用程式都有相同嘅形狀

為咗令框架之間嘅跳轉感覺熟悉,每個範例應用程式都提供:

  • 一個歡迎路由,位於 / 介紹項目。
  • 一個元件索引,位於 /components 列出每個元件。
  • 每個元件一個示範頁面,位於 /components/<component>.
  • 真實 CSS — 唔係抽象嘅設計令牌 — 等你可以直接抄樣式。
  • 開箱即用嘅鍵盤導覽同焦點管理。

需要睇一個元件點樣加樣式?

打開相關嘅範例應用程式,前往 /components/<name>,然後將標記同 CSS 複製入你自己嘅項目。範例應用程式特意使用普通 CSS(或者近乎普通),等你可以調整去配合任何你鍾意嘅系統。

想要無頭多啲?

將任何範例應用程式同對應嘅 無頭 套件配對 — 佢哋發佈同樣嘅元件,完全冇 CSS,準備好畀你自己嘅設計令牌。
