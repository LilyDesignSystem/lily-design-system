Pub app ensampel a'n jeves an keth furv

Rag gul lemmel y'tarn framwyth hevel aswonnys, pub app ensampel a re:

  • Fordh dynnargh orth / a dhalgh an raglen.
  • Menegva darnow orth /components a rol pub darn.
  • Folen dyskwedhyans dre bub darn orth /components/<component>.
  • CSS gwir — nyns yw tokenys dyllans dhyvles — may hyllowgh kopya stylys yn tevri.
  • Lewyans klavyer hag oberi fokus ow kerdhes yn-mes a'n bos.

Ilvyn gweles fatell yw unn darn stylys?

Igorewgh an app ensampel dhe-les, ewgh dhe /components/<name>, ha kopiewgh an markup ha CSS dhe'th raglen dha honan. An appys ensampel a wra devnydh a CSS plen (po ogas plen) yn arbennik may hyllowgh aga assaya dhe system vyth a garewgh.

Mynnewgh heb pen yn le henna?

Junyewgh peub app ensampel gans y bakkya heb pen kehevelys — y a dhelergh an keth darnow heb CSS vyth, parys rag dha dokenys dyllans dha honan.
