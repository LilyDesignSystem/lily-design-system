Setiap aplikasi contoh memiliki bentuk yang sama

Agar berpindah antarframework terasa akrab, setiap aplikasi contoh menyediakan:

  • Rute sambutan di / yang memperkenalkan proyek.
  • Indeks komponen di /components yang mencantumkan setiap komponen.
  • Satu halaman demo per komponen di /components/<component>.
  • CSS nyata — bukan token desain abstrak — sehingga Anda dapat langsung menyontek gayanya.
  • Navigasi papan ketik dan pengelolaan fokus yang langsung berfungsi.

Perlu melihat cara satu komponen ditata?

Buka aplikasi contoh yang relevan, buka /components/<name>, lalu salin markup dan CSS ke proyek Anda sendiri. Aplikasi contoh sengaja memakai CSS biasa (atau hampir biasa) agar Anda dapat menyesuaikannya dengan sistem apa pun yang Anda sukai.

Ingin headless saja?

Padukan aplikasi contoh mana pun dengan paket headless yang sesuai — paket itu menerbitkan komponen yang sama tanpa CSS sama sekali, siap untuk token desain Anda sendiri.
