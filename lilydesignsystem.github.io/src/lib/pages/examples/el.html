Δες το Lily σε πραγματικές εφαρμογές

Επτά πλήρη έργα-παραδείγματα δείχνουν πώς να πάρεις τα κεφαλοχωρίς στοιχεία, να προσθέσεις μορφοποίηση και να δημοσιεύσεις έναν πραγματικό ιστότοπο. Διάλεξε το πλαίσιο που χρησιμοποιείς.

Εφαρμογές επίδειξης με πλήρες CSS και δρομολόγηση

HTML JavaScript

Απλές σελίδες HTML, καθαρή JavaScript, χωρίς εργαλεία δόμησης. Χωράει σε οποιονδήποτε στατικό διακομιστή — ιδανικό για μικρούς ιστότοπους και προοδευτική βελτίωση.

Κάθε εφαρμογή-παράδειγμα έχει το ίδιο σχήμα

Για να μοιάζει οικείο το πέρασμα από πλαίσιο σε πλαίσιο, κάθε εφαρμογή-παράδειγμα παρέχει:

  • Μια διαδρομή καλωσορίσματος στο / που παρουσιάζει το έργο.
  • Ένα ευρετήριο στοιχείων στο /components που απαριθμεί κάθε στοιχείο.
  • Μια σελίδα επίδειξης για κάθε στοιχείο στο /components/<component>.
  • Πραγματικό CSS — όχι αφηρημένα design tokens — ώστε να δανείζεσαι στυλ απευθείας.
  • Λειτουργική πλοήγηση με πληκτρολόγιο και διαχείριση εστίασης αμέσως.

Χρειάζεσαι να δεις πώς μορφοποιείται ένα μεμονωμένο στοιχείο;

Άνοιξε την αντίστοιχη εφαρμογή-παράδειγμα, πήγαινε στο /components/<name>και αντίγραψε το markup και το CSS στο δικό σου έργο. Οι εφαρμογές-παραδείγματα χρησιμοποιούν σκόπιμα απλό (ή σχεδόν απλό) CSS ώστε να τις προσαρμόσεις σε όποιο σύστημα προτιμάς.

Προτιμάς κεφαλοχωρίς;

Συνδύασε οποιαδήποτε εφαρμογή-παράδειγμα με το αντίστοιχο κεφαλοχωρίς πακέτο — αυτά δημοσιεύουν τα ίδια στοιχεία χωρίς κανένα CSS, έτοιμα για τα δικά σου design tokens.
