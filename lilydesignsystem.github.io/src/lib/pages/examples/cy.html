Mae gan bob ap enghreifftiol yr un siâp

I wneud i neidio rhwng fframweithiau deimlo'n gyfarwydd, mae pob ap enghreifftiol yn darparu:

  • Llwybr croeso yn / sy'n cyflwyno'r prosiect.
  • Mynegai cydrannau yn /components sy'n rhestru pob cydran.
  • Tudalen arddangos fesul cydran yn /components/<component>.
  • CSS go iawn — nid tocynnau dylunio haniaethol — fel y gallwch gopïo arddulliau'n uniongyrchol.
  • Llywio bysellfwrdd a rheoli ffocws sy'n gweithio o'r bocs.

Angen gweld sut mae un gydran wedi'i harddullio?

Agorwch yr ap enghreifftiol perthnasol, ewch i /components/<name>, a chopïwch y marcio a'r CSS i'ch prosiect eich hun. Mae'r apiau enghreifftiol yn defnyddio CSS plaen (neu bron yn blaen) yn fwriadol fel y gallwch eu haddasu i unrhyw system a ffafriwch.

Eisiau headless yn lle hynny?

Pârwch unrhyw un o'r apiau enghreifftiol â'u pecyn headless cyfatebol — mae'r rheini'n cyhoeddi'r un cydrannau heb unrhyw CSS, yn barod ar gyfer eich tocynnau dylunio eich hun.
