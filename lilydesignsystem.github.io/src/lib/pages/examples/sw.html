Kila programu ya mifano ina umbo lilelile

Ili kuruka kati ya mifumo ya kazi kuhisi kuwa kawaida, kila programu ya mifano hutoa:

  • Njia ya karibu kwenye / inayoutambulisha mradi.
  • Faharasa ya vipengele kwenye /components inayoorodhesha kila kipengele.
  • Ukurasa wa maonyesho kwa kila kipengele kwenye /components/<component>.
  • CSS halisi — si tokeni za usanifu za kidhahania — ili uweze kunakili mitindo moja kwa moja.
  • Usogezaji wa kibodi unaofanya kazi na usimamizi wa umakini tangu mwanzo.

Unahitaji kuona jinsi kipengele kimoja kinavyopambwa?

Fungua programu husika ya mifano, nenda kwa /components/<name>, na unakili HTML na CSS kwenye mradi wako mwenyewe. Programu za mifano kwa makusudi hutumia CSS ya kawaida (au karibu ya kawaida) ili uweze kuzirekebisha kwa mfumo wowote unaoupendelea.

Unataka bila mwonekano badala yake?

Unganisha programu yoyote ya mifano na kifurushi chake cha bila mwonekano — hivyo huchapisha vipengele vilevile bila CSS yoyote, tayari kwa tokeni zako za usanifu.
