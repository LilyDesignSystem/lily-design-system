ਹਰ ਉਦਾਹਰਨ ਐਪ ਦਾ ਇੱਕੋ ਜਿਹਾ ਰੂਪ ਹੈ

ਫ੍ਰੇਮਵਰਕਾਂ ਵਿਚਕਾਰ ਛਾਲ ਮਾਰਨ ਨੂੰ ਜਾਣਿਆ-ਪਛਾਣਿਆ ਬਣਾਉਣ ਲਈ, ਹਰ ਉਦਾਹਰਨ ਐਪ ਇਹ ਦਿੰਦੀ ਹੈ:

  • ਇੱਥੇ ਇੱਕ ਸਵਾਗਤ ਰੂਟ / ਜੋ ਪ੍ਰੋਜੈਕਟ ਦੀ ਜਾਣ-ਪਛਾਣ ਕਰਵਾਉਂਦਾ ਹੈ।
  • ਇੱਥੇ ਇੱਕ ਕੰਪੋਨੈਂਟ ਸੂਚਕਾਂਕ /components ਜੋ ਹਰ ਕੰਪੋਨੈਂਟ ਦੀ ਸੂਚੀ ਦਿੰਦਾ ਹੈ।
  • ਇੱਥੇ ਹਰ ਕੰਪੋਨੈਂਟ ਲਈ ਇੱਕ ਡੈਮੋ ਪੰਨਾ /components/<component>.
  • ਅਸਲ CSS — ਅਮੂਰਤ ਡਿਜ਼ਾਈਨ ਟੋਕਨ ਨਹੀਂ — ਤਾਂ ਜੋ ਤੁਸੀਂ ਸਟਾਈਲ ਸਿੱਧੇ ਉਧਾਰ ਲੈ ਸਕੋ।
  • ਡੱਬੇ ਵਿੱਚੋਂ ਹੀ ਕੰਮ ਕਰਦੀ ਕੀਬੋਰਡ ਨੈਵੀਗੇਸ਼ਨ ਅਤੇ ਫੋਕਸ ਪ੍ਰਬੰਧਨ।

ਇੱਕ ਇਕੱਲੇ ਕੰਪੋਨੈਂਟ ਦੀ ਸਟਾਈਲਿੰਗ ਵੇਖਣੀ ਹੈ?

ਸੰਬੰਧਿਤ ਉਦਾਹਰਨ ਐਪ ਖੋਲ੍ਹੋ, ਇੱਥੇ ਜਾਓ /components/<name>ਅਤੇ ਮਾਰਕਅੱਪ ਤੇ CSS ਆਪਣੇ ਪ੍ਰੋਜੈਕਟ ਵਿੱਚ ਕਾਪੀ ਕਰੋ। ਉਦਾਹਰਨ ਐਪਾਂ ਜਾਣ-ਬੁੱਝ ਕੇ ਸਾਦੀ (ਜਾਂ ਲਗਭਗ ਸਾਦੀ) CSS ਵਰਤਦੀਆਂ ਹਨ ਤਾਂ ਜੋ ਤੁਸੀਂ ਇਨ੍ਹਾਂ ਨੂੰ ਆਪਣੇ ਪਸੰਦੀਦਾ ਕਿਸੇ ਵੀ ਸਿਸਟਮ ਵਿੱਚ ਢਾਲ ਸਕੋ।

ਇਸ ਦੀ ਬਜਾਏ ਹੈੱਡਲੈੱਸ ਚਾਹੀਦਾ ਹੈ?

ਕਿਸੇ ਵੀ ਉਦਾਹਰਨ ਐਪ ਨੂੰ ਇਸ ਦੇ ਸੰਬੰਧਿਤ ਹੈੱਡਲੈੱਸ ਪੈਕੇਜ ਨਾਲ ਜੋੜੋ — ਉਹ ਉਹੀ ਕੰਪੋਨੈਂਟ ਬਿਨਾਂ ਕਿਸੇ CSS ਦੇ ਪ੍ਰਕਾਸ਼ਿਤ ਕਰਦੇ ਹਨ, ਤੁਹਾਡੇ ਆਪਣੇ ਡਿਜ਼ਾਈਨ ਟੋਕਨਾਂ ਲਈ ਤਿਆਰ।
