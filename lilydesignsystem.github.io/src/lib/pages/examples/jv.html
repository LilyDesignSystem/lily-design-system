Saben aplikasi conto duwé wangun sing padha

Supaya mlumpat antar framework kroso akrab, saben aplikasi conto nyedhiyakaké:

  • Rute sambutan ing / sing ngenalaké proyèk.
  • Indèks komponèn ing /components sing ndaftar saben komponèn.
  • Kaca demo saben komponèn ing /components/<component>.
  • CSS nyata — dudu token desain abstrak — supaya sampéyan bisa langsung nyilih gaya.
  • Navigasi keyboard lan manajemen fokus sing langsung makarya.

Péngin ndeleng carané siji komponèn digayani?

Bukak aplikasi conto sing cocog, menyanga /components/<name>lan salinen markup lan CSS menyang proyèk sampéyan dhéwé. Aplikasi conto sengaja nganggo CSS biasa (utawa meh biasa) supaya sampéyan bisa nyesuaikaké karo sistem apa waé sing sampéyan senengi.

Péngin tanpa sirah?

Pasangna aplikasi conto apa waé karo paket tanpa sirah sing cocog — kuwi ngrilis komponèn sing padha tanpa CSS apa waé, siap kanggo token desain sampéyan dhéwé.
