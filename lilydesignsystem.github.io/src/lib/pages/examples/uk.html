Кожен приклад застосунку має однакову форму

Щоб перехід між фреймворками здавався знайомим, кожен приклад застосунку містить:

  • Вітальний маршрут за адресою / що знайомить із проєктом.
  • Індекс компонентів за адресою /components що перелічує кожен компонент.
  • Демосторінку для кожного компонента за адресою /components/<component>.
  • Справжній CSS — не абстрактні дизайн-токени — щоб ви могли переймати стилі безпосередньо.
  • Робочу навігацію клавіатурою та керування фокусом «з коробки».

Потрібно побачити, як стилізовано один компонент?

Відкрийте відповідний приклад застосунку, перейдіть до /components/<name>і скопіюйте розмітку та CSS у свій проєкт. Приклади застосунків навмисно використовують звичайний CSS (або майже звичайний), щоб ви могли адаптувати їх до будь-якої системи на ваш смак.

Хочете «безголове» натомість?

Поєднайте будь-який приклад застосунку з відповідним «безголовим» пакетом — вони публікують ті самі компоненти без жодного CSS, готові до ваших власних дизайн-токенів.
