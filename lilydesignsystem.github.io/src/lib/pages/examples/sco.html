Ilka example app haes the same shape

Tae mak framework-hoppin feel familiar, ilka example app provides:

  • A walcome route at / that introduces the project.
  • A components index at /components that lists ilka component.
  • A demo page per component at /components/<component>.
  • Real CSS — no abstract design tokens — sae ye can crib styles directly.
  • Wirkin keyboard navigation an focus management oot o the box.

Need tae see hoo a single component is styled?

Open the relevant example app, navigate tae /components/<name>, an copy the markup an CSS intae yer ain project. The example apps deliberately uise plain CSS (or near-plain) sae ye can adapt them tae onie system ye prefer.

Want headless insteid?

Pair onie example app wi its corresponding headless package — they publish the same components wioot onie CSS, ready for yer ain design tokens.
