Setiap aplikasi contoh mempunyai bentuk yang sama

Supaya melompat antara rangka kerja terasa biasa, setiap aplikasi contoh menyediakan:

  • Laluan sambutan di / yang memperkenalkan projek.
  • Indeks komponen di /components yang menyenaraikan setiap komponen.
  • Halaman demo bagi setiap komponen di /components/<component>.
  • CSS sebenar — bukan token reka bentuk abstrak — supaya anda boleh meniru gaya terus.
  • Navigasi papan kekunci dan pengurusan fokus yang berfungsi terus.

Perlu melihat bagaimana satu komponen digayakan?

Buka aplikasi contoh yang berkaitan, pergi ke /components/<name>, dan salin markup serta CSS ke projek anda sendiri. Aplikasi contoh sengaja menggunakan CSS biasa (atau hampir biasa) supaya anda boleh menyesuaikannya dengan sistem apa pun yang anda suka.

Mahu tanpa kepala sahaja?

Pasangkan mana-mana aplikasi contoh dengan pakej tanpa kepala yang sepadan — ia menerbitkan komponen yang sama tanpa sebarang CSS, sedia untuk token reka bentuk anda sendiri.
