לכל אפליקציית דוגמה אותה צורה

כדי שהמעבר בין מסגרות ירגיש מוכר, כל אפליקציית דוגמה מספקת:

  • נתיב קבלת פנים ב- / שמציג את הפרויקט.
  • אינדקס רכיבים ב- /components שמפרט כל רכיב.
  • עמוד הדגמה לכל רכיב ב- /components/<component>.
  • CSS אמיתי — לא אסימוני עיצוב מופשטים — כדי שתוכלו להעתיק סגנונות ישירות.
  • ניווט מקלדת וניהול מיקוד שעובדים מהקופסה.

צריכים לראות איך רכיב אחד מעוצב?

פתחו את אפליקציית הדוגמה הרלוונטית, נווטו אל /components/<name>, והעתיקו את הסימון וה-CSS לפרויקט שלכם. אפליקציות הדוגמה משתמשות בכוונה ב-CSS רגיל (או כמעט רגיל) כדי שתוכלו להתאים אותן לכל מערכת שתעדיפו.

רוצים דווקא ללא ראש?

צרפו כל אפליקציית דוגמה לחבילה ללא הראש המתאימה — הן מפרסמות את אותם רכיבים ללא CSS כלל, מוכנות לאסימוני העיצוב שלכם.
