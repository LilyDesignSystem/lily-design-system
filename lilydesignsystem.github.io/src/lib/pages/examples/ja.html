どのサンプルアプリも同じ構成です

フレームワークを渡り歩いても違和感がないよう、どのサンプルアプリにも次のものがあります。

  • プロジェクトを紹介する、/ のウェルカムルート。
  • すべてのコンポーネントを一覧にする、/components のコンポーネント索引。
  • コンポーネントごとのデモページ、/components/<component>。
  • 抽象的なデザイントークンではない実際の CSS。そのままスタイルを拝借できます。
  • 最初から動作するキーボード操作とフォーカス管理。

1 つのコンポーネントのスタイルを知りたいときは？

該当するサンプルアプリを開き、/components/<name> に移動して、マークアップと CSS を自分のプロジェクトにコピーしてください。 サンプルアプリは意図的に素の CSS（またはそれに近いもの）を使っているので、お好みのどんなシステムにも合わせられます。

ヘッドレスのほうが良いですか？

どのサンプルアプリも、対応するヘッドレスパッケージと組み合わせられます。そちらは同じコンポーネントを CSS なしで公開しており、 あなた自身のデザイントークンをそのまま使えます。
