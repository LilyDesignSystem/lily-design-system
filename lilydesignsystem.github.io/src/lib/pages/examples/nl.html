Elke voorbeeldapp heeft dezelfde vorm

Om van framework wisselen vertrouwd te laten voelen, biedt elke voorbeeldapp:

  • Een welkomstroute op / die het project introduceert.
  • Een componentenindex op /components die elke component toont.
  • Een demopagina per component op /components/<component>.
  • Echte CSS – geen abstracte designtokens – zodat je stijlen direct kunt overnemen.
  • Werkende toetsenbordnavigatie en focusbeheer direct uit de doos.

Wil je zien hoe één component is opgemaakt?

Open de betreffende voorbeeldapp, ga naar /components/<name>en kopieer de markup en CSS naar je eigen project. De voorbeeldapps gebruiken bewust gewone (of bijna gewone) CSS, zodat je ze kunt aanpassen aan elk systeem dat je prefereert.

Liever headless?

Combineer elke voorbeeldapp met het bijbehorende headless pakket – die publiceren dezelfde componenten zonder enige CSS, klaar voor je eigen designtokens.
