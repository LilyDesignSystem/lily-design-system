Tha an aon chruth aig gach tagradh eisimpleir

Gus gum bi leum eadar frèamaichean a’ faireachdainn eòlach, bheir gach tagradh eisimpleir:

  • Slighe fàilte aig / a tha a’ toirt a-steach am pròiseact.
  • Clàr-amais cho-phàirtean aig /components a tha a’ liostadh gach co-phàirt.
  • Duilleag thaisbeanaidh airson gach co-phàirt aig /components/<component>.
  • CSS fìor — chan e tòcain dealbhaidh eas-chruthach — gus an urrainn dhut stoidhlean a ghoid gu dìreach.
  • Seòladh a’ chlàr-iuchrach is stiùireadh fòcais ag obair a-mach às a’ bhogsa.

A bheil thu airson faicinn mar a tha aon cho-phàirt air a stoidhleadh?

Fosgail an tagradh eisimpleir iomchaidh, rach gu /components/<name>, agus dèan lethbhreac den mharcachadh is den CSS dhan phròiseact agad fhèin. Bidh na tagraidhean eisimpleir a’ cleachdadh CSS sìmplidh (no cha mhòr sìmplidh) a dh’aona ghnothach gus an urrainn dhut an atharrachadh airson siostam sam bith as fheàrr leat.

A bheil thu airson gun cheann an àite sin?

Càraich tagradh eisimpleir sam bith leis a’ phasgan gun cheann aige — bidh iad sin a’ foillseachadh nan aon cho-phàirtean gun CSS sam bith, deiseil airson na tòcain dealbhaidh agad fhèin.
