Tá an cruth céanna ar gach aip shamplach

Chun go mbeidh sé cosúil go bhfuil tú sa bhaile agus tú ag léim idir chreataí, soláthraíonn gach aip shamplach:

  • Bealach fáilte ag / a chuireann an tionscadal in aithne.
  • Innéacs comhpháirteanna ag /components a liostaíonn gach comhpháirt.
  • Leathanach taispeána in aghaidh gach comhpháirte ag /components/<component>.
  • CSS fíor — ní comharthaí dearaidh teibí — ionas gur féidir leat stíleanna a fháil ar iasacht go díreach.
  • Nascleanúint méarchláir agus bainistiú fócais atá ag obair as an mbosca.

An gá duit a fheiceáil conas atá comhpháirt amháin stílithe?

Oscail an aip shamplach ábhartha, nascleanúint go /components/<name>agus cóipeáil an marcáil agus an CSS isteach i do thionscadal féin. Úsáideann na haipeanna samplacha CSS simplí (nó beagnach simplí) d’aon ghnó ionas gur féidir leat iad a oiriúnú d’aon chóras is fearr leat.

An mian leat gan cheann ina ionad?

Péireáil aon aip shamplach lena pacáiste gan cheann comhfhreagrach — foilsíonn siad na comhpháirteanna céanna gan aon CSS, réidh do do chomharthaí dearaidh féin.
