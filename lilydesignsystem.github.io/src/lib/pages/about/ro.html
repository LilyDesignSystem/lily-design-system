Ce este Lily?

Un sistem de design gratuit, open source, care pune accesibilitatea pe primul loc: te întâlnește acolo unde scrii cod și se dă la o parte când nu ai nevoie de el.

Pe scurt

Lily este un catalog de componente web, fiecare implementată în opt variante headless (HTML, Svelte, React, Vue, Angular, Blazor, Nunjucks și Web Components), plus un set de aplicații-exemplu complete care arată cum se stilizează.

Versiunile headless vin cu zero CSS. Îți oferă HTML semantic, roluri și stări ARIA, suport pentru tastatură și proprietăți prietenoase cu internaționalizarea. Designul vizual îl aduci tu.

Principii de design

Accesibil

Fiecare componentă pornește de la HTML semantic. ARIA se adaugă doar acolo unde HTML-ul singur nu poate exprima modelul. Componentele țintesc WCAG 2.2 AAA — culorile, spațierea, focalizarea și navigarea cu tastatura sunt toate luate în considerare.

Compozabil

Lily preferă componente mici, cu un singur scop, care se potrivesc între ele. Modelele compuse apar iar și iar:

  • Nav → List → ListItem — pentru breadcrumbs, liste de conținut, meniuri acordeon, meniuri arborescente și paginare
  • Form → Field → Input — pentru orice aranjament de formular cu etichete, indicii și erori
  • Table → Head/Body/Foot → Row → Data — pentru tabele, calendare, diagrame Gantt și panouri kanban
  • Bar → BarButton — pentru bare de instrumente, bare de file, bare de sarcini, bare de acțiuni și bare de meniu
  • Picker → PickerButton — pentru selectoare de culoare, selectoare de evaluare, selectoare de temă

Internaționalizabil

Niciun șir vizibil utilizatorului nu este scris direct în cod. Etichetele, substituenții, mesajele de eroare, textul butoanelor — toate sunt parametri. Conectează-ți propriul sistem de traducere și Lily vorbește orice limbă vorbești tu.

Headless

Componentele headless au zero CSS, niciun bloc <style> , niciun token de design pe care să nu-l fi ales tu. Expun un singur nume de clasă în kebab-case pe fiecare element rădăcină, ca să le poți ținti cum dorești — CSS semantic, Tailwind, CSS-in-JS, alegerea ta.

Exemple complete

Aplicațiile-exemplu arată cum se stilizează componentele pentru utilizare reală — ce tokenuri de design să setezi, ce variante să adaugi, cum să compui pagini. Sunt aplicații complete SvelteKit, Next.js, Nuxt, Blazor și Eleventy, nu doar medii de testare.

  • Adobe Spectrum
  • Ant Design

  • Reuters graphics components
