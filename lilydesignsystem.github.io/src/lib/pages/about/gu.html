Lily શું છે?

સુલભતાને પ્રથમ રાખતી મફત, ઓપન-સોર્સ ડિઝાઇન સિસ્ટમ, જે તમે જ્યાં કોડ લખો છો ત્યાં તમને મળે છે — અને જરૂર ન હોય ત્યારે રસ્તામાંથી ખસી જાય છે.

ટૂંકમાં

Lily એ વેબ ઘટકોનો કેટલોગ છે, જેમાંનો દરેક આઠ હેડલેસ સ્વરૂપોમાં (HTML, Svelte, React, Vue, Angular, Blazor, Nunjucks અને Web Components) અમલમાં મુકાયેલો છે, ઉપરાંત તેમને શૈલી કેવી રીતે આપવી તે બતાવતી સંપૂર્ણ ઉદાહરણ એપ્સનો સમૂહ.

હેડલેસ આવૃત્તિઓ આવે છે શૂન્ય CSS સાથે. તે તમને સેમેન્ટિક HTML, ARIA ભૂમિકાઓ અને સ્થિતિઓ, કીબોર્ડ સપોર્ટ અને આંતરરાષ્ટ્રીયકરણ-અનુકૂળ પ્રોપ્સ આપે છે. દૃશ્ય ડિઝાઇન તમે લાવો છો.

ડિઝાઇન સિદ્ધાંતો

સુલભ

દરેક ઘટક સેમેન્ટિક HTML થી શરૂ થાય છે. ફક્ત જ્યાં HTML એકલું પેટર્ન વ્યક્ત કરી શકતું નથી ત્યાં જ ARIA ઉમેરાય છે. ઘટકો લક્ષ્ય રાખે છે: WCAG 2.2 AAA — રંગો, અંતર, ફોકસ અને કીબોર્ડ નેવિગેશન બધાનો વિચાર કરવામાં આવે છે.

જોડી શકાય તેવું

Lily નાના, એક-હેતુવાળા ઘટકો પસંદ કરે છે જે એકબીજામાં બેસે છે. સંયુક્ત પેટર્ન વારંવાર દેખાય છે:

  • Nav → List → ListItem — બ્રેડક્રમ્બ, સૂચિ યાદીઓ, અકોર્ડિયન મેનુ, ટ્રી મેનુ અને પૃષ્ઠાંકન માટે
  • Form → Field → Input — લેબલ, સંકેતો અને ભૂલો સાથેના કોઈપણ ફોર્મ લેઆઉટ માટે
  • Table → Head/Body/Foot → Row → Data — કોષ્ટકો, કેલેન્ડર, ગેન્ટ ચાર્ટ અને કાનબન બોર્ડ માટે
  • Bar → BarButton — ટૂલ બાર, ટેબ બાર, ટાસ્ક બાર, એક્શન બાર અને મેનુ બાર માટે
  • Picker → PickerButton — રંગ પસંદગીકારો, રેટિંગ પસંદગીકારો, થીમ પસંદગીકારો માટે

આંતરરાષ્ટ્રીયકરણક્ષમ

વપરાશકર્તાને દેખાતી એક પણ સ્ટ્રિંગ કોડમાં પાકી લખેલી નથી. લેબલ, પ્લેસહોલ્ડર, ભૂલ સંદેશા, બટન ટેક્સ્ટ — બધા પેરામીટર છે. તમારી પોતાની અનુવાદ સિસ્ટમ જોડો અને તમે જે ભાષા બોલો છો તે Lily બોલે છે.

હેડલેસ

હેડલેસ ઘટકોમાં CSS નથી, કોઈ <style> બ્લોક નથી, તમે પસંદ ન કરેલા કોઈ ડિઝાઇન ટોકન નથી. તે દરેક રૂટ એલિમેન્ટ પર એક કબાબ-કેસ ક્લાસ નામ ખુલ્લું કરે છે જેથી તમે તેમને ગમે તે રીતે લક્ષ્ય બનાવી શકો — સેમેન્ટિક CSS, Tailwind, CSS-in-JS, તમારી પસંદગી.

સંપૂર્ણ ઉદાહરણો

ઉદાહરણ એપ્સ બતાવે છે કે વાસ્તવિક ઉપયોગ માટે ઘટકોને શૈલી કેવી રીતે આપવી — કયા ડિઝાઇન ટોકન સેટ કરવા, કયા પ્રકારો ઉમેરવા, પૃષ્ઠો કેવી રીતે રચવા. તે સંપૂર્ણ SvelteKit, Next.js, Nuxt, Blazor અને Eleventy એપ્સ છે, માત્ર સેન્ડબોક્સ નથી.
