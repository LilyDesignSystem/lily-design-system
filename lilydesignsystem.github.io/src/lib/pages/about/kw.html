Pyth yw Lily?

System dyllans rydh, ygor-fenten, ow settya hedhesadewder kynsa, hag a vyth ow tos orth dha dhorn le may skrifydh koodh — hag a wra ri fordh dhis pan na vo othom anodho.

An versyon verr

Lily yw rolyans a dharnow gwiasva, pub onan gwrys yn eth form heb pen (HTML, Svelte, React, Vue, Angular, Blazor, Nunjucks, ha Web Components) ha set a appys ensampel kowl a dhysk fatell yllir aga stylya.

An versyons heb pen a dheu gans CSS hwath. Y a re dhis HTML a dhiswelyans, rollow ha stadys ARIA, skoodhyans klavyer, ha perthynasow dha gerensow i18n. Ty a dhre an dyllans hewelus.

Arghasow dyllans

Hedhesys

Pub darn a dhalleth gans HTML a dhiswelyans. ARIA a vydh keworrys yn unnik le na yll HTML hepken diskwedhes an patrom. An darnow a wra hweles WCAG 2.2 AAA — liwyow, spasow, fokus, ha lewyans klavyer yw aga hwithrys oll.

Kesstrewyadow

Lily a gar darnow byghan gans unn amkan a yll junya an eyl gans y gila. Patromow kesstrewys a dheu arta ha arta:

  • Nav → List → ListItem — rag bara-krommow, rolyow gorholyon, menusow akordyon, menusow gwydhenn, ha folennans
  • Form → Field → Input — rag peub gorfarth furvyow gans lavellow, kuntellow, ha gwallow
  • Table → Head/Body/Foot → Row → Data — rag tablow, deiziadurow, tablow gantt, ha tavlennow kanban
  • Bar → BarButton — rag barrow-toulys, barrow-tab, barrow-oberow, barrow-gwrians, ha barrow-menu
  • Picker → PickerButton — rag dhewisyoryon liw, dhewisyoryon dhevnydh, dhewisyoryon tebel

Yn-ranngeneledhek

Nyns eus unn linenn a wel an devnydhyer skrifys yn kowl yn koodh. Lavellow, gwithyoryon-le, messajys gwall, tekst bottonow — pubtra yw parametrow. Gorra dha system dhrehedhans dha honan ha Lily a gewsa an yeth a gewsydh.

Heb pen

Nyns eus gans darnow heb pen CSS, nyns eus <style> blokkys, na tokenys dyllans na wrussys dewis. Y a dhiskwedh unn hanow klass kebab-case war pub elven hwedh may hyllir aga hweles herwydh dha vodh — CSS a dhiswelyans, Tailwind, CSS-in-JS, dha dhewis.

Ensamplow kowl

An appys ensampel a dhisk fatell yllir stylya an darnow rag devnydh gwir — pyth tokenys dyllans a dal settya, pyth gemmyskans a dal keworra, fatell yllir kesstrewi folennow. Y yw appys SvelteKit, Next.js, Nuxt, Blazor, hag Eleventy kowl, nyns yw hepken lowarthow-tewl.
