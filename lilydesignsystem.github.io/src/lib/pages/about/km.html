ខ្លឹមសារសង្ខេប

Lily ជាកាតាឡុកនៃ សមាសភាគវេបដែលនីមួយៗត្រូវបានអនុវត្តជាប្រាំបីរូបភាពគ្មានក្បាល (HTML, Svelte, React, Vue, Angular, Blazor, Nunjucks និង Web Components) បូកជាមួយកម្មវិធីគំរូពេញលេញមួយសំណុំដែលបង្ហាញពីរបៀបដាក់រចនាប័ទ្មឱ្យពួកវា។

អាចផ្សំបាន

Lily ចូលចិត្តសមាសភាគតូចៗដែលមានគោលបំណងតែមួយ ដែលភ្ជាប់គ្នាបានយ៉ាងងាយ។ លំនាំផ្សំលេចឡើងម្តងហើយម្តងទៀត៖

  • Nav → List → ListItem — សម្រាប់ breadcrumbs បញ្ជីមាតិកា ម៉ឺនុយអាកាឌីយ៉ុង ម៉ឺនុយដើមឈើ និងការបែងចែកទំព័រ
  • Form → Field → Input — សម្រាប់ប្លង់ទម្រង់ណាមួយដែលមានស្លាក ព័ត៌មានណែនាំ និងកំហុស
  • Table → Head/Body/Foot → Row → Data — សម្រាប់តារាង ប្រតិទិន តារាង Gantt និងក្តារ kanban
  • Bar → BarButton — សម្រាប់របារឧបករណ៍ របារផ្ទាំង របារកិច្ចការ របារសកម្មភាព និងរបារម៉ឺនុយ
  • Picker → PickerButton — សម្រាប់ឧបករណ៍ជ្រើសពណ៌ ឧបករណ៍ជ្រើសការវាយតម្លៃ ឧបករណ៍ជ្រើសស្បែក
