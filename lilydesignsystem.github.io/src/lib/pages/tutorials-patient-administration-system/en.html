Patient administration system tutorial

Appointments, a waiting list, and reminders that never leave a silent patient behind. You finish with a small working app, and the way to the full project.

What you'll build

A small patient administration system: a clinic calendar, a waiting list, reminders that end with a person picking up the phone, and a link by which a patient confirms or cancels. It is administrative: it holds no diagnosis and no result. About 90 minutes.

It leads to the open-source Patient Administration System, whose site is patient-administration-system.github.io. That project is built for the NHS in Wales, is tested, and is not yet in use with real patients.

For learning only. Use invented people, never a real person's details.

Step 3: Decide the next step

src/lib/reminders.ts

import type { Appointment, Contact } from "./types.js";

export type Step =
  | { kind: "send"; daysBefore: number }
  | { kind: "phone" }
  | { kind: "nothing"; why: "cancelled" | "replied" | "opted-out" | "past" | "quiet" | "not-yet" };

const DAY = 86_400_000;
const LADDER = [7, 4, 3, 1];

/** The hour in the clinic's own time zone, not the server's. */
const hourIn = (timeZone: string, now: Date) =>
  Number(new Intl.DateTimeFormat("en-GB", { timeZone, hour: "2-digit", hourCycle: "h23" }).format(now));

/** What to do next about one appointment. Pure: the clock is an argument, so every case is a test. */
export function nextStep(
  appointment: Appointment,
  contact: Contact,
  now: Date,
  timeZone: string,
): Step {
  if (appointment.status === "cancelled") return { kind: "nothing", why: "cancelled" };
  const daysLeft = (Date.parse(appointment.start) - now.getTime()) / DAY;
  if (daysLeft <= 0) return { kind: "nothing", why: "past" };
  // The patient was told that someone will phone, so someone is asked to.
  if (appointment.status === "held") return { kind: "phone" };
  if (contact.replied) return { kind: "nothing", why: "replied" };

  const due = LADDER.filter((days) => daysLeft <= days);
  const step = due.at(-1);
  if (step === undefined) return { kind: "nothing", why: "not-yet" };

  // An opt-out stops messages. It never stops a person from being looked after.
  if (contact.optedOut) return step === 1 ? { kind: "phone" } : { kind: "nothing", why: "opted-out" };

  if (!contact.sent.includes(step)) {
    const hour = hourIn(timeZone, now);
    if (hour < 8 || hour >= 20) return { kind: "nothing", why: "quiet" };
    return { kind: "send", daysBefore: step };
  }
  // Every message has gone unanswered, so a person phones. Silence is never a reason to discharge.
  return step === 1 ? { kind: "phone" } : { kind: "nothing", why: "not-yet" };
}

Read it as policy, because it is:

  • Silence goes to a person. When every message is unanswered, someone phones. A missed message never removes anyone from a list.
  • An opt-out stops messages, not care.
  • Quiet hours are the clinic's, in its time zone, and not the server's.
  • A held cancellation asks for a call, even though the patient replied, because the patient was told that someone would phone.

Step 4: Test the policy

The clock is an argument, so every case is one line.

src/lib/reminders.test.ts

import { describe, expect, it } from "vitest";
import { nextStep } from "./reminders.js";
import type { Appointment, Contact } from "./types.js";

const appointment: Appointment = {
  id: "a1",
  personId: "p1",
  service: "Physiotherapy",
  start: "2026-12-10T10:00:00Z",
  status: "booked",
  urgent: false,
};
const contact: Contact = { optedOut: false, sent: [], replied: false };
const on = (now: string, c: Partial<Contact> = {}, a: Partial<Appointment> = {}) =>
  nextStep({ ...appointment, ...a }, { ...contact, ...c }, new Date(now), "Europe/London");

describe("nextStep", () => {
  it("waits, then sends the first reminder at seven days", () => {
    expect(on("2026-12-01T10:00:00Z")).toEqual({ kind: "nothing", why: "not-yet" });
    expect(on("2026-12-03T12:00:00Z")).toEqual({ kind: "send", daysBefore: 7 });
  });

  it("does not send one twice, and sends only the newest after a gap", () => {
    expect(on("2026-12-03T12:00:00Z", { sent: [7] })).toEqual({ kind: "nothing", why: "not-yet" });
    expect(on("2026-12-07T12:00:00Z", { sent: [7] })).toEqual({ kind: "send", daysBefore: 3 });
  });

  it("asks a person to phone when every message goes unanswered", () => {
    expect(on("2026-12-09T12:00:00Z", { sent: [7, 4, 3, 1] })).toEqual({ kind: "phone" });
  });

  it("stops when the patient replies, cancels or has been seen", () => {
    expect(on("2026-12-09T12:00:00Z", { replied: true })).toMatchObject({ why: "replied" });
    expect(on("2026-12-09T12:00:00Z", {}, { status: "cancelled" })).toMatchObject({ why: "cancelled" });
    expect(on("2026-12-10T10:00:00Z")).toMatchObject({ why: "past" });
  });

  it("asks a person to phone when a cancellation is held, though the patient replied", () => {
    expect(on("2026-12-03T22:00:00Z", { replied: true }, { status: "held" })).toEqual({ kind: "phone" });
  });

  it("never messages someone who opted out, and still has a person phone", () => {
    expect(on("2026-12-03T12:00:00Z", { optedOut: true })).toMatchObject({ why: "opted-out" });
    expect(on("2026-12-09T12:00:00Z", { optedOut: true })).toEqual({ kind: "phone" });
  });

  it("keeps quiet hours in the clinic's time zone", () => {
    expect(on("2026-12-03T22:00:00Z")).toMatchObject({ why: "quiet" });
    const tokyo = nextStep(appointment, contact, new Date("2026-12-03T12:00:00Z"), "Asia/Tokyo");
    expect(tokyo).toMatchObject({ why: "quiet" });
  });
});

Step 5: Make safe reply links

src/lib/server/links.ts

import { createHash, randomBytes } from "node:crypto";

interface Link {
  appointmentId: string;
  expires: number;
  used: boolean;
}

const hash = (token: string) => createHash("sha256").update(token).digest("hex");

/** Reply links. Only the hash is kept, so a copy of the table opens nobody's appointment. */
export class Links {
  #links = new Map<string, Link>();

  issue(appointmentId: string, expires: Date): string {
    const token = randomBytes(32).toString("base64url");
    this.#links.set(hash(token), { appointmentId, expires: expires.getTime(), used: false });
    return token;
  }

  /** Look, without using it up: a mail scanner that opens the link changes nothing. */
  peek(token: string, now: Date): string | undefined {
    const link = this.#links.get(hash(token));
    return link && !link.used && now.getTime() < link.expires ? link.appointmentId : undefined;
  }

  /** Use it, once. */
  use(token: string, now: Date): string | undefined {
    const appointmentId = this.peek(token, now);
    if (appointmentId) this.#links.get(hash(token))!.used = true;
    return appointmentId;
  }
}

Only a hash is stored, so a copy of the table opens nobody's appointment. A link works once, and it expires.

Step 6: Keep the appointments

src/lib/server/pas.ts

import type { Appointment, Contact, Wait } from "../types.js";
import { Links } from "./links.js";

const DAY = 86_400_000;
const NOON = Math.floor(Date.now() / DAY) * DAY + DAY / 2;
const inDays = (days: number) => new Date(NOON + days * DAY).toISOString();

export type Outcome = "confirmed" | "cancelled" | "held";

/** In memory, for learning: everything is lost when the server stops. */
export class Pas {
  links = new Links();
  #appointments = new Map<string, Appointment>();
  #contacts = new Map<string, Contact>();
  waits: Wait[] = [];
  audit: { at: string; what: string; id: string }[] = [];

  book(appointment: Appointment, contact: Partial<Contact> = {}) {
    this.#appointments.set(appointment.id, appointment);
    this.#contacts.set(appointment.id, { optedOut: false, sent: [], replied: false, ...contact });
  }

  appointments(): Appointment[] {
    return [...this.#appointments.values()];
  }

  appointment(id: string): Appointment | undefined {
    return this.#appointments.get(id);
  }

  contact(id: string): Contact | undefined {
    return this.#contacts.get(id);
  }

  /** A patient's reply, through a link that works once. */
  reply(token: string, answer: "confirm" | "cancel", now: Date): Outcome | undefined {
    const id = this.links.use(token, now);
    const appointment = id ? this.#appointments.get(id) : undefined;
    if (!appointment) return undefined;
    const outcome: Outcome =
      answer === "confirm" ? "confirmed" : appointment.urgent ? "held" : "cancelled";
    this.#appointments.set(appointment.id, { ...appointment, status: outcome });
    this.#contacts.set(appointment.id, { ...this.#contacts.get(appointment.id)!, replied: true });
    this.audit.push({ at: now.toISOString(), what: `reply: ${outcome}`, id: appointment.id });
    return outcome;
  }
}

export const pas = new Pas();

const now = new Date("2026-12-03T12:00:00Z");

  urgent: false,

let token: string;

  pas = new Pas();
  pas.book(appointment);
  token = pas.links.issue("a1", later);

describe("reply links", () => {
  it("look without acting", () => {
    expect(pas.links.peek(token, now)).toBe("a1");
    expect(pas.links.peek(token, now)).toBe("a1");
    expect(pas.appointment("a1")?.status).toBe("booked");

Step 7: Write the words, and turn data into views

src/lib/words.ts

import type { Step } from "./reminders.js";
import type { Appointment, Wait } from "./types.js";

export const locale = "en-GB";
/** The clinic's time zone: every time on every page is the clinic's, never the reader's. */
export const timeZone = "Europe/London";

export const appointmentStatus: Record<Appointment["status"], string> = {
  booked: "Booked",
  confirmed: "Confirmed",
  cancelled: "Cancelled",
  held: "Cancellation asked for: waiting for a person",
};

export const waitColumns: { id: Wait["status"]; title: string }[] = [
  { id: "waiting", title: "Waiting" },
  { id: "booked", title: "Booked" },
  { id: "treated", title: "Treated" },
  { id: "removed", title: "Removed" },
];

export const priority: Record<Wait["priority"], string> = { urgent: "Urgent", routine: "Routine" };

const why: Record<Extract<Step, { kind: "nothing" }>["why"], string> = {
  cancelled: "Nothing: cancelled",
  replied: "Nothing: the patient replied",
  "opted-out": "Nothing yet: opted out of messages",
  past: "Nothing: the time has passed",
  quiet: "Wait: quiet hours",
  "not-yet": "Nothing yet",
};

export function stepWords(step: Step): string {
  if (step.kind === "phone") return "Phone the patient";
  if (step.kind === "nothing") return why[step.why];
  return `Send the reminder for day ${step.daysBefore}`;
}

export const when = (iso: string) =>
  new Intl.DateTimeFormat(locale, { dateStyle: "full", timeStyle: "short", timeZone }).format(new Date(iso));

src/lib/views.ts

import type { CalendarEvent } from "@lilydesignsystem/svelte-calendar";
import type { KanbanCard } from "@lilydesignsystem/svelte-kanban-board";
import type { Appointment, Wait } from "./types.js";
import { appointmentStatus, locale, priority, timeZone } from "./words.js";

/** The clinic's calendar day of an instant, as YYYY-MM-DD. */
export function clinicDay(iso: string): string {
  const parts = new Intl.DateTimeFormat("en-GB", {
    timeZone,
    year: "numeric",
    month: "2-digit",
    day: "2-digit",
  }).formatToParts(new Date(iso));
  const part = (type: string) => parts.find((p) => p.type === type)!.value;
  return `${part("year")}-${part("month")}-${part("day")}`;
}

const clinicTime = (iso: string) =>
  new Intl.DateTimeFormat(locale, { timeZone, timeStyle: "short" }).format(new Date(iso));

export const appointmentEvents = (rows: Appointment[]): CalendarEvent[] =>
  rows.map((a) => ({
    id: a.id,
    date: clinicDay(a.start),
    title: `${clinicTime(a.start)} ${a.service}`,
    values: { status: appointmentStatus[a.status] },
  }));

/** Urgent first. The priority is a word on the card, so it never depends on colour. */
export const waitCards = (rows: Wait[]): KanbanCard[] =>
  [...rows]
    .sort((a, b) => Number(b.priority === "urgent") - Number(a.priority === "urgent"))
    .map((w) => ({
      id: w.id,
      columnId: w.status,
      title: w.service,
      subtitle: `Patient ${w.personId}`,
      badges: [priority[w.priority]],
    }));

src/lib/server/sessions.ts

import { randomBytes } from "node:crypto";
import type { Role } from "../types.js";

// A stand-in for OpenID Connect. The browser holds a random id and the server holds the role, so
// nobody can make themselves staff by editing a cookie.
const sessions = new Map<string, Role>();

export function signIn(role: Role): string {
  const id = randomBytes(32).toString("base64url");
  sessions.set(id, role);
  return id;
}

export const roleOf = (id: string | undefined): Role | null => sessions.get(id ?? "") ?? null;

src/lib/server/guard.ts

import { error, redirect } from "@sveltejs/kit";

/** Every staff page calls this in its own load. Hiding a link protects nothing. */
export function requireStaff(locals: App.Locals) {
  if (!locals.role) redirect(303, "/signin");
  if (locals.role !== "staff") error(403, "Staff only");
}

src/hooks.server.ts

import type { Handle } from "@sveltejs/kit/hooks";
import { roleOf } from "#lib/server/sessions.js";

export const handle: Handle = async ({ event, resolve }) => {
  event.locals.role = roleOf(event.cookies.get("session"));
  const response = await resolve(event);
  response.headers.set("cache-control", "no-store");
  // A reply link is a secret: never send its address to another site.
  response.headers.set("referrer-policy", "no-referrer");
  return response;
};

};

Step 13: Let the patient reply

src/routes/r/[token]/+page.server.ts

import { error } from "@sveltejs/kit";
import { pas } from "#lib/server/pas.js";
import type { Actions, PageServerLoad } from "./$types";

// Reads only. Opening the link, or a mail scanner opening it, changes nothing.
export const load: PageServerLoad = ({ params }) => {
  const id = pas.links.peek(params.token, new Date());
  const appointment = id ? pas.appointment(id) : undefined;
  // The date and time, and no more: whoever holds the phone may not be the patient.
  return { start: appointment?.start ?? null };
};

export const actions: Actions = {
  default: async ({ request, params }) => {
    const answer = (await request.formData()).get("answer");
    if (answer !== "confirm" && answer !== "cancel") error(400, "Unknown answer");
    return { outcome: pas.reply(params.token, answer, new Date()) ?? null };
  },
};

Opening the link reads, and only the button acts. Mail scanners open every link they see: if opening one cancelled, they would cancel your clinic.

Check your work: run pnpm dev. Open the appointments: you are sent to sign in. Sign in as a patient: you are refused. Sign in as staff: two appointments are on the calendar. On the reminders page make a link for the breast clinic, open it, and choose "I cannot come": nothing is cancelled, you are told that someone will phone, and the reminders page now says "Phone the patient". Open the link again: it has been used.

What this does not do yet

  • It keeps everything in memory, and signing in has no password.
  • It sends nothing. A real service texts the link and never shows it to staff.
  • The built version marks its cookie as secure, so it needs https.
