Getting started in five minutes

Three steps in any framework: install the package, render a labelled email field and a button, and link a theme.

What you will have

A small sign-up form: a visible label tied to an email input, and a submit button. The components bring the semantic HTML, the ARIA and the keyboard behaviour; the theme brings the look. Lily ships no CSS of its own, so without a theme you get the browser's defaults, which is the point: every visual decision is yours.

Every user-facing string, the label and the button text, is yours too, so the same code works in any language.

Pick your framework

  • React, Vue, Svelte, Solid, Angular
  • Web Components, HTML, Nunjucks, Alpine.js
  • Blazor

React

React 18 or 19, in Vite, Next.js or any React app.

npm install @lilydesignsystem/react-headless @lilydesignsystem/themes
import { useState } from "react";
import { Field, EmailInput, Button } from "@lilydesignsystem/react-headless";
import "@lilydesignsystem/themes/light.css";

export default function Signup() {
  const [email, setEmail] = useState("");
  return (
    <form onSubmit={(event) => event.preventDefault()}>
      <Field label="Email address" inputId="email">
        <EmailInput id="email" label="Email address" value={email} onChange={setEmail} required />
      </Field>
      <Button type="submit">Subscribe</Button>
    </form>
  );
}

onChange receives the new string, not an event.

Vue

Vue 3.4 or later, in Vite or Nuxt.

npm install @lilydesignsystem/vue-headless @lilydesignsystem/themes
<script setup>
import { ref } from "vue";
import { Field, EmailInput, Button } from "@lilydesignsystem/vue-headless";
import "@lilydesignsystem/themes/light.css";

const email = ref("");
</script>

<template>
  <form @submit.prevent>
    <Field label="Email address" input-id="email">
      <EmailInput id="email" label="Email address" v-model="email" required />
    </Field>
    <Button type="submit">Subscribe</Button>
  </form>
</template>

Svelte

Svelte 5, in SvelteKit or Vite. The package ships .svelte files for your bundler to compile. 

npm install @lilydesignsystem/svelte-headless @lilydesignsystem/themes
<script>
  import { Field, EmailInput, Button } from "@lilydesignsystem/svelte-headless";
  import "@lilydesignsystem/themes/light.css";

  let email = $state("");
</script>

<form onsubmit={(event) => event.preventDefault()}>
  <Field label="Email address" inputId="email">
    <EmailInput id="email" label="Email address" bind:value={email} required />
  </Field>
  <Button type="submit">Subscribe</Button>
</form>

Solid

Solid 2.0, in Vite.

npm install @lilydesignsystem/solid-headless @lilydesignsystem/themes
import { createSignal } from "solid-js";
import { Field, EmailInput, Button } from "@lilydesignsystem/solid-headless";
import "@lilydesignsystem/themes/light.css";

export default function Signup() {
  const [email, setEmail] = createSignal("");
  return (
    <form onSubmit={(event) => event.preventDefault()}>
      <Field label="Email address" inputId="email">
        <EmailInput id="email" label="Email address" value={email()} onChange={setEmail} required />
      </Field>
      <Button type="submit">Subscribe</Button>
    </form>
  );
}

Angular

Angular 20 to 22, standalone components. Add the theme to styles in angular.json. 

npm install @lilydesignsystem/angular-headless @lilydesignsystem/themes
// angular.json: "styles": ["node_modules/@lilydesignsystem/themes/dist/light.css"]
import { Component } from "@angular/core";
import { EmailInput, Button } from "@lilydesignsystem/angular-headless";

@Component({
  selector: "app-signup",
  imports: [EmailInput, Button],
  template: `
    <form (submit)="$event.preventDefault()">
      <label>
        Email address
        <lily-email-input label="Email address" [required]="true" />
      </label>
      <lily-button type="submit">Subscribe</lily-button>
    </form>
  `,
})
export class Signup {}

The visible label wraps the component, which labels the <input> inside it, in every version. From @lilydesignsystem/angular-headless 0.13.0 you can use <lily-field inputId="email"> around <lily-email-input id="email"> instead.

Web Components

Any page or framework. Importing the package registers every lily-* element.

npm install @lilydesignsystem/web-components-headless @lilydesignsystem/themes
<link rel="stylesheet" href="node_modules/@lilydesignsystem/themes/dist/light.css" />
<script type="module">
  import "@lilydesignsystem/web-components-headless";
</script>

<form>
  <label>
    Email address
    <lily-email-input label="Email address" required></lily-email-input>
  </label>
  <lily-button type="submit">Subscribe</lily-button>
</form>

The bare import needs a bundler or an import map. The wrapping label reaches the inner <input> in every version; from 0.13.0, <lily-field label="Email address"> around the input does too.

HTML

No install and no build: Lily's HTML is plain markup with class hooks. Link a theme from a CDN and write the markup. 

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@lilydesignsystem/themes@0.6.2/dist/light.css" />

<form>
  <div class="field">
    <label for="email">Email address</label>
    <input class="email-input" id="email" type="email" required />
  </div>
  <button class="button" type="submit">Subscribe</button>
</form>

Every component's markup is in @lilydesignsystem/html-headless (components/{slug}.html) and on its page in the catalog.

Nunjucks

Nunjucks 3, in Eleventy or Express. Add the package's templates to your loader.

npm install @lilydesignsystem/nunjucks-headless nunjucks @lilydesignsystem/themes
// setup
const nunjucks = require("nunjucks");
const { templatesDir } = require("@lilydesignsystem/nunjucks-headless");
const env = new nunjucks.Environment(new nunjucks.FileSystemLoader([templatesDir, "views"]));

{# views/signup.njk #}
{% from "field/macro.njk" import field %}
{% from "label/macro.njk" import label %}
{% from "email-input/macro.njk" import emailInput %}
{% from "button/macro.njk" import button %}

<form method="post">
  {% call field() %}
    {{ label({ for: "email", text: "Email address" }) }}
    {{ emailInput({ id: "email", autocomplete: "email", required: true }) }}
  {% endcall %}
  {{ button({ type: "submit", text: "Subscribe" }) }}
</form>

Alpine.js

Alpine 3.14 or later. The markup is the same as HTML's; the plugin adds state and keyboard behaviour to the interactive components (menus, tabs, listboxes), so register it once. 

npm install @lilydesignsystem/alpine-headless alpinejs @lilydesignsystem/themes
import Alpine from "alpinejs";
import lily from "@lilydesignsystem/alpine-headless/plugin";
import "@lilydesignsystem/themes/light.css";

Alpine.plugin(lily);
Alpine.start();

Then use the HTML form above. Each component's annotated snippet is in @lilydesignsystem/alpine-headless (components/{slug}.html). The plugin needs 0.3.1 or later.

Blazor

.NET 11, a Blazor Web App. Link the theme from wwwroot or a CDN in App.razor. 

dotnet add package LilyDesignSystem.Blazor.Headless
@page "/signup"
@using LilyBlazorHeadless.Components

<form @onsubmit="Subscribe">
    <Field Label="Email address" InputId="email">
        <EmailInput id="email" Label="Email address" @bind-Value="email" required />
    </Field>
    <Button type="submit">Subscribe</Button>
</form>

@code {
    private string email = "";

    private void Subscribe() { }
}
