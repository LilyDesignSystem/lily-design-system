Installazzjoni

Lily tgħix f’monorepo wieħed ta’ Git, b’direttorju għal-librerija headless, il-pakketti tal-għajnuna u l-applikazzjoni ta’ eżempju ta’ kull framework. L-aktar mod mgħaġġel biex tipprovaha huwa li tikklona l-monorepo u tiftaħ il-librerija headless għall-istack tiegħek: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install

L-istess xejra taħdem għall-frameworks l-oħra:

  • @lilydesignsystem/html-headless — l-ebda installazzjoni meħtieġa; ikkopja l-fajls .html
  • @lilydesignsystem/svelte-headless — pnpm install
  • @lilydesignsystem/react-headless — pnpm install
  • @lilydesignsystem/vue-headless — pnpm install
  • @lilydesignsystem/angular-headless — pnpm install
  • @lilydesignsystem/nunjucks-headless — pnpm install
  • lily-design-system-blazor-headless — dotnet build

Il-libreriji headless huma ddisinjati biex jiġu kklonati jew inkorporati — ittratta l-kodiċi sors bħala s-sors tal-verità u ikkopja dak li għandek bżonn. għajnuniet tal-preferenzi jiġu wkoll bħala pakketti installabbli b’pipeline tal-bini u tal-pubblikazzjoni (npm għall-frameworks JS, NuGet għal Blazor).

Uża komponent headless

Il-komponenti headless jipprovdu HTML semantiku, ARIA u proprjetajiet — imma l-ebda CSS. Hawn Button f’kull framework:

HTML

<button class="button" type="button" aria-label="Save">
  Save
</button>

Svelte

<script>
  import Button from "lily-design-system-svelte-headless/components/Button/Button.svelte";
</script>

<Button onclick={save}>Save</Button>

React

import Button from "lily-design-system-react-headless/components/Button";

<Button onClick={save}>Save</Button>

Vue

<script setup>
  import Button from "lily-design-system-vue-headless/components/Button.vue";
</script>

<Button @click="save">Save</Button>

Angular

import { Button } from "@lilydesignsystem/angular-headless";

@Component({
  imports: [Button],
  template: `<lily-button (click)="save()">Save</lily-button>`,
})

Blazor

<Button OnClick="Save">Save</Button>

Nunjucks

{% from "components/button/macro.njk" import button %}

{{ button({ text: "Save", type: "button" }) }}

Uża eżempju stilizzat

L-applikazzjonijiet ta’ eżempju jinkludu CSS, rotot u paġni demo sħaħ. L-aktar mod mgħaġġel biex tesperimenta huwa li tibda l-applikazzjoni ta’ eżempju SvelteKit, Next, Nuxt, Analog jew Eleventy u tara d-demo fuq /components. 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-sveltekit-examples
pnpm install
pnpm run dev

Imbagħad iftaħ http://localhost:5173 u esplora /components.

Stilizzazzjoni u tokens tad-disinn

Kull komponent jiġi renderjat b’klassi waħda f’kebab-case fuq l-element għerq tiegħu. Pereżempju, <Button> jiġi renderjat bħala <button class="button">. Stilizzah kif trid: 

.button {
  background: var(--my-primary);
  color: #fff;
  padding: 0.75rem 1.5rem;
  border-radius: 0.5rem;
}
.button:hover { background: var(--my-primary-hover); }

Il-paletta tal-kuluri awtomatika ta’ Lily (użata fl-applikazzjonijiet ta’ eżempju) hija:

  • Primarju: #2563eb
  • Periklu: #dc2626
  • Twissija: #f59e0b
  • Suċċess: #16a34a
  • Isfond tal-paġna: #f9fafb
  • Isfond tal-kard: #ffffff

Dawn huma suġġerimenti, mhux rekwiżiti. Ibdilhom bil-paletta tal-marka tiegħek stess u Lily tikkonforma bil-ferħ.

Temi lesti

Ma tridx tikteb CSS mill-bidu? Lily tibgħat 57 tema ta’ referenza awtonoma fid-direttorju themes/ . Kull waħda hija stylesheet wieħed li jimmira lejn il-ganċijiet tal-klassi ta’ Lily — qabbdu u int stilizzat: 

<link rel="stylesheet" href="/assets/themes/united-kingdom-government-digital-service.css" />

Is-sett ikopri:

  • Settur pubbliku — NHS England, NHS Scotland u NHS Wales (kull waħda f’varjanti għall-pazjenti u għall-prattikanti), GOV.UK GDS u l-U.S. Web Design System.
  • Ispirati mill-bejjiegħa — Adobe Spectrum, Mozilla Protocol.
  • Użu ġenerali — light, dark, nord, dracula, wireframe u tletin oħra jew hekk.

Is-selectors tat-temi jużaw :where(...), għalhekk is-CSS tiegħek stess dejjem jirbaħ fl-ispeċifiċità. Akkoppjahom mal-għajnuna theme-picker hawn taħt għat-tibdil waqt it-tħaddim, jew segwi tutorja tat-temi.

Għajnuniet tal-preferenzi

Kull framework għandu tmien għażliet żgħar, kull wieħed pakkett lily-design-system-{framework}-{package} tiegħu stess (u picker-bar li jiġbor flimkien). Kull wieħed huwa buttuna headless b’ikona li tiftaħ popup — listbox, lista ta’ links, formola tat-tfittxija jew (għal date-time-picker) dijalogu tal-għażla tad-data — mhux <select>nattiv; huwa sigur għal SSR; u ma jibgħatx CSS:

  • theme-picker — jgħabbi stylesheets tat-temi waqt it-tħaddim billi jibdel <link>ġestit, jistabbilixxi data-theme fuq id-dokument u b’mod fakultattiv jiffranka f’ localStorage.
  • locale-picker — jistabbilixxi lang u dir (b’skoperta awtomatika tal-RTL) biex il-librerija i18n tiegħek tkun tista’ ssegwi; ma jittraduċi xejn waħdu.
  • text-size-picker — jistabbilixxi data-text-size fuq id-dokument; is-CSS tiegħek jimmappja kull valur għad-daqs tal-font.
  • motion-picker — jistabbilixxi data-motion fuq id-dokument, jibda mill-issettjar tal-moviment imnaqqas tal-viżitatur; is-CSS u l-iscripts tiegħek jiddeċiedu x’għandu jiġi mrażżan.
  • search-picker — buttuna b’ikona li tiftaħ qasam tat-tfittxija; is-sottomissjoni tmur fuq paġna tat-tfittxija. Hija sid ta’ azzjoni, mhux preferenza.
  • link-picker — ikona tad-dar li tiftaħ menu tal-links tal-paġni li l-applikazzjoni tiegħek tiddefinixxi (Home, Dwarna, Ikkuntattjana, Politika tal-Privatezza, …). Hija sid ta’ azzjoni, mhux preferenza.
  • share-picker — tiftaħ il-folja nattiva tal-qsim jew lista ta’ destinazzjonijiet ipprovduta mill-konsumatur, flimkien mal-kopja tal-URL. Hija sid ta’ azzjoni, mhux preferenza: ma tapplika xejn, ma tiffranka xejn.
  • date-time-picker — qasam tat-test flimkien ma’ dijalogu APG tal-għażla tad-data għal data, ħin, jew it-tnejn. Hija sid ta’ valur ta’ formola, mhux preferenza: is-sekwenza ISO tinbidel bidirezzjonalment għal <input type="date">.

Aċċessibbiltà

Il-komponenti jimmiraw lejn WCAG 2.2 AAA. Isegwu dawn ix-xejriet:

  • Elementi HTML semantiċi minflok <div>s.
  • <label for="id"> ġeneriċi li jorbtu t-tikketti mal-inputs.
  • aria-labelledby / aria-describedby għal referenzi inkroċjati.
  • aria-invalid + aria-errormessage għal stati ta’ żball.
  • role="alert" u aria-live għal kontenut dinamiku.
  • aria-pressed, aria-expanded, aria-current għall-istat.
  • Roving tabindex għall-grids.

L-indikaturi tal-fokus huma apposta pprovduti mill-konsumatur — Lily qatt ma tpinġi ċirku tal-fokus awtomatiku li jmur kontra d-disinn tiegħek. L-applikazzjonijiet ta’ eżempju jżommu linja bażi axe-core nadifa fuq ir-rotot kollha tagħhom.

Internazzjonalizzazzjoni

Kull tikketta, placeholder, messaġġ ta’ żball u test ta’ buttuna hija proprjetà. M’hemmx sekwenzi miktuba direttament. Qabbad il-framework tat-traduzzjoni li tippreferi — Paraglide, i18next, vue-i18n, react-intl, fajls .resx, kwalunkwe.

Għal dati, numri u muniti, il-komponenti jaċċettaw sekwenzi ffurmattjati minn qabel: int tifformattja b’ Intl.DateTimeFormat / Intl.NumberFormat / il-librerija preferuta tiegħek u tgħaddi r-riżultat.

L-għajnuna locale-picker tgħarraf il-lokal magħżul lill-librerija i18n tiegħek billi tistabbilixxi lang u dir fuq l-għerq tad-dokument.

Ittestjar

Kull sottoproġett ta’ framework jibgħat it-testijiet tiegħu stess bl-istack idjomatiku tiegħu:

  • HTML: WebDriverIO li jħaddem browsers reali.
  • Svelte: Vitest + @testing-library/svelte.
  • React: Vitest + @testing-library/react.
  • Vue: Vitest + @testing-library/vue.
  • Angular: Vitest + TestBed (permezz tal-plugin Vite ta’ Analog).
  • Nunjucks: Vitest b’għajnuna tar-renderjar.
  • Blazor: bUnit.

It-testijiet jużaw biss il-matchers integrati ta’ Vitest — qatt il-matchers ta’ jest-dom . Dan iżomm is-suites tat-testijiet portabbli. L-applikazzjonijiet ta’ eżempju jżidu suites end-to-end ta’ Playwright, linji bażi tal-aċċessibbiltà axe-core u skannjar tal-viewports responsivi.

Soluzzjoni tal-problemi

Komponent jiġi renderjat imma jidher mhux stilizzat

Dak huwa headless jaħdem kif intenzjonat — l-ebda CSS ma jiġi mal-komponent. Jew ikteb CSS għall-klassi f’kebab-case tal-komponent (murija fuq kull paġna tal-katalgu) jew qabbad waħda mit- 57 tema lesta.

Is-CSS tiegħi ma jidhirx li japplika fuq tema

Għandu — is-selectors tat-temi huma mgeżwra f’ :where(...), li għandu speċifiċità żero. Jekk regola xorta titlef, ivverifika li l-istylesheet tiegħek jitgħabba wara l- <link> tat-tema u li s-selector verament jaqbel mal-ganċ tal-klassi tal-komponent.

pnpm install jonqos b’żball ta’ peer jew ta’ verżjoni

Uża pnpm kurrenti (v10+) u Node 22+. Kull sottoproġett jibbloka l-verżjonijiet tal-framework tiegħu fil- package.jsontiegħu stess; jekk it-toolchain globali tiegħek huwa eqdem, pnpm env use --global lts huwa l-eqreb soluzzjoni.

Il-qarrej tal-iskrin iħabbar isem ħażin għal kontroll

Iċċekkja l-proprjetà meħtieġa label tal-komponent — il-komponenti li m’għandhomx test viżibbli jeħtieġu waħda, u aria-label / aria-labelledby ipprovdut mill-konsumatur u mgħoddi permezz ta’ rest-props apposta jirbaħ fuq it-twaħħil integrat. Kull paġna tal-katalgu tiddokumenta l-kuntratt ARIA tal-komponent.

L-għajnuna theme-picker ma tibdilx l-istylesheets

Ikkonferma li themesUrl jipponta lejn direttorju li l-browser jista’ jġib (servi l-fajls themes/ bħala assi statiċi) u li l-slugs tat-temi fil-proprjetà themes tiegħek jaqblu mal-ismijiet tal-fajls. L-għajnuna tibdel il- href ta’ <link data-lily-theme-picker> ġestit wieħed — spezzjonah fl-għodod tal-iżviluppatur biex tara l-URL mitlub.

FAQ

Għaliex headless minflok stilizzat?

Il-komponenti pre-stilizzati huma komdi — sakemm ma jaqblux mal-marka tiegħek. Il-komponenti headless jeħtieġu ftit aktar xogħol fil-bidu imma jagħtuk kontroll sħiħ tad-disinn viżwali. L-applikazzjonijiet ta’ eżempju u t-57 tema juru modi kif tistilizzahom; tista’ tieħodhom jew tissostitwihom kompletament. L-argument itwal jinsab fuq Għaliex Lily.

Għaliex tant komponenti?

Lily timmira li tkopri x-xejriet li l-biċċa l-kbira tal-applikazzjonijiet jeħtieġu mingħajr ma ġġiegħlek tibnihom mill-bidu — inklużi affarijiet fondi bħal inputs ta’ identifikaturi nazzjonali u scrollytelling editorjali. Il-katalgu jieħu minn tużżana sistemi tad-disinn stabbiliti flimkien ma’ xogħol oriġinali — ara Dwar.

Nista’ nuża Lily ma’ Tailwind?

Iva. Kull komponent jesponi klassi għerq waħda f’kebab-case flimkien ma’ className / classipprovdut mill-konsumatur. Poġġi utilitajiet Tailwind fuq kif trid.

Nista’ nuża Lily ma’ frameworks CSS semantiċi bħal DaisyUI?

Iva. L-ismijiet tal-klassi f’kebab-case fuq l-element għerq jaħdmu bħala ganċijiet CSS semantiċi. Akkoppja Lily ma’ framework semantiku u tikseb komponenti pre-stilizzati li xorta jirrispettaw ARIA u i18n.

Hemm pakkett npm?

L- għajnuniet tal-preferenzi jiġu bħala pakketti b’pipeline tal-pubblikazzjoni npm/NuGet. Il-libreriji tal-komponenti headless huma ddisinjati biex jiġu kklonati jew inkorporati — il-kodiċi sors huwa dak li tibgħat, biex tkun tista’ taqra, tnaqqas u tippossjedi eżattament dak li tibgħat. Il-pubblikazzjoni fir-reġistri tal-libreriji headless għadha fil-pjan.

Għaliex liċenzji multipli?

Proġetti differenti għandhom bżonnijiet differenti ta’ liċenzjar. BSD u MIT huma permissivi, Apache-2.0 għandha għoti ta’ privattiva, u l-għażliet GPL jappoġġjaw il-copyleft. Agħżel dik li taqbel mas-sitwazzjoni tiegħek.
