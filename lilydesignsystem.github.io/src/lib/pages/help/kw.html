Stallya

Lily a trig yn unn monorepo Git, gans kuntelleth rag lyverva heb pen, pakkyow gweresoryon, hag app ensampel pub framwyth. An fordh kyns dhe assaya yw klonya an monorepo hag igeri an lyverva heb pen rag dha stakk: 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-react-headless
pnpm install

An keth patrom a oberow rag an framwyth erell:

  • @lilydesignsystem/html-headless — heb othom stallya; kopiewgh .html restrennow
  • @lilydesignsystem/svelte-headless — pnpm install
  • @lilydesignsystem/react-headless — pnpm install
  • @lilydesignsystem/vue-headless — pnpm install
  • @lilydesignsystem/angular-headless — pnpm install
  • @lilydesignsystem/nunjucks-headless — pnpm install
  • lily-design-system-blazor-headless — dotnet build

An lyvervaow heb pen yw dyllys dhe vos klonys po vendorys — kemerewgh an fenten avel fenten an gwiryonedh ha kopiewgh an pyth a'n jeves othom. gweresoryon dewisyow a dheu ynwedh avel pakkyow stallys gans fordh-drehevel ha fordh-dyllans (npm rag framwyth JS, NuGet rag Blazor).

Devnydhyewgh darn heb pen

Darnow heb pen a re HTML a dhiswelyans, ARIA, ha perthynasow — mes heb CSS. Omma yw Button yn pub framwyth:

HTML

<button class="button" type="button" aria-label="Save">
  Save
</button>

Svelte

<script>
  import Button from "lily-design-system-svelte-headless/components/Button/Button.svelte";
</script>

<Button onclick={save}>Save</Button>

React

import Button from "lily-design-system-react-headless/components/Button";

<Button onClick={save}>Save</Button>

Vue

<script setup>
  import Button from "lily-design-system-vue-headless/components/Button.vue";
</script>

<Button @click="save">Save</Button>

Angular

import { Button } from "@lilydesignsystem/angular-headless";

@Component({
  imports: [Button],
  template: `<lily-button (click)="save()">Save</lily-button>`,
})

Blazor

<Button OnClick="Save">Save</Button>

Nunjucks

{% from "components/button/macro.njk" import button %}

{{ button({ text: "Save", type: "button" }) }}

Devnydhyewgh ensampel stylys

An appys ensampel a'n jeves CSS, fordhow, ha folennow dyskwedhyans kowl. An fordh vyttha dhe assaya yw dalleth an app ensampel SvelteKit, Next, Nuxt, Analog, po Eleventy ha gweles an dyskwedhyans orth /components. 

git clone https://github.com/LilyDesignSystem/lily-design-system
cd lily-design-system/lily-design-system-svelte-sveltekit-examples
pnpm install
pnpm run dev

Ena igorewgh http://localhost:5173 ha whelewgh /components.

Stylyans ha tokenys dyllans

Pub darn a vydh dyskwedhys gans unn klass kebab-case war y elven wreydh. Rag ensampel, <Button> a dhyskwedh <button class="button">. Stylyewgh herwydh dha vodh: 

.button {
  background: var(--my-primary);
  color: #fff;
  padding: 0.75rem 1.5rem;
  border-radius: 0.5rem;
}
.button:hover { background: var(--my-primary-hover); }

Tebelyow parys

Na vynnewgh skrifa CSS dhiworth nagonan? Lily a dheu gans 57 tebel dre-honan kehevelys y'n kuntelleth themes/ . Pub onan yw unn folen-stil a hwel krogow klass Lily — kevrewgh hi ha ty yw stylys: 

<link rel="stylesheet" href="/assets/themes/united-kingdom-government-digital-service.css" />

An set a wra kuntell:

  • Sektour poblek — NHS England, NHS Scotland, ha NHS Wales (versyonow rag klavyoryon ha gwithyoryon pub onan), GOV.UK GDS, ha'n U.S. Web Design System.
  • Enspyrys gans gwerther — Adobe Spectrum, Mozilla Protocol.
  • Amkan kenedhlek — light, dark, nord, dracula, wireframe, ha deg ha trigans moy.

Dewisyoryon tebel a wra devnydh a :where(...), rag henna dha CSS dha honan a wayn pub prys war an arbennigrwydh. Junyewgh anedha gans an gweresor theme-picker a-woeles rag chanj y'n termyn-dyrghas, po sewyewgh an dyskans tebelyow.

Gweresoryon dewisyow

Pub framwyth a'n jeves eth dewisyer byghan, pub onan y'y bakkya dha honan lily-design-system-{framework}-{package} (ha picker-bar a vynn aga junya). Pub onan yw botton-ikon heb pen a idzhek popup — listbox, rol kevrennow, furv whelas, po (rag date-time-picker) kowtys dewis-deiz — nyns yw genesek <select>; yw diogel dhe SSR; ha dheu heb CSS:

  • theme-picker — a gar folennow-stil tebel y'n termyn-dyrghas dre chanjya <link>governys, a sett data-theme war an skrif, ha yn kuntellys a with dhe localStorage.
  • locale-picker — a sett lang ha dir (gans ertheg RTL awtomatek) may hyll dha lyverva i18n sewya; ny wra treylyans yn honan.
  • text-size-picker — a sett data-text-size war an skrif; dha CSS a vapp pub gwerth dhe vyns-lytherenn.
  • motion-picker — a sett data-motion war an skrif, ow talleth dhiworth settyans gwayans-lehes an gwelyer; dha CSS ha skrypow a dhewis pyth a vydh dyslywys.
  • search-picker — botton-ikon a idzhek hwel-whelas; danvon a dhre dhe folen whelas. A'n jeves gwrians, nyns yw dewis.
  • link-picker — ikon-chi a idzhek menu a gevrennow folen a styr dha app (Tre, A-dro dhyn, Kestewgh genen, Polisi Privetter, …). A'n jeves gwrians, nyns yw dewis.
  • share-picker — a idzhek an folen-rannans genesek po rol-pennow-lyes dhiworth devnydhyer, ha kopi an URL. A'n jeves gwrians, nyns yw dewis: ny wra gul neppyth, ny with neppyth.
  • date-time-picker — hwel-tekst ha kowtys dewis-deiz APG rag deiz, termyn, po an dhew. A'n jeves gwerth furv, nyns yw dewis: an linenn ISO a dhreyl dhe <input type="date">.

Hedhesadewder

Darnow a hwel WCAG 2.2 AAA. Y a sew an patromow ma:

  • Elvennow HTML a dhiswelyans dres kenedhlek <div>s.
  • <label for="id"> ow kevrewi lavellow orth hwelyow.
  • aria-labelledby / aria-describedby rag kesresegyansow.
  • aria-invalid + aria-errormessage rag stadys gwall.
  • role="alert" ha aria-live rag dalgh kevrennus.
  • aria-pressed, aria-expanded, aria-current rag stad.
  • Roving tabindex rag grydhow.

Dyskwedhoryon fokus yw arbennik provyes gans an devnydhyer — Lily ny wra bythkweth peynta kylgh-fokus ragosodhys a rydh gans dha dyllans. An appys ensampel a with linenn-selys axe-core glan dres aga fordhow.

Ynter-ranngeneledhegeth

Pub lavell, gwithyer-le, messaj wall, ha tekst botton yw perthynas. Nyns eus linennow kowl yn koodh. Gorrewgh dha framwyth treylyans dewisys — Paraglide, i18next, vue-i18n, react-intl, restrennow .resx, pubtra.

Rag deiziow, niverow, ha mona, an darnow a gemmer linennow furvys a-rag: ty a furv gans Intl.DateTimeFormat / Intl.NumberFormat / dha lyverva dewisys ha passya an sewyans.

An locale-picker gweresor a sinyas an yeth dewisys dhe'th lyverva i18n dre settya lang ha dir war wreydh an skrif.

Kudynnow

Darn a vydh dyskwedhys mes a hevel heb stil

Hemma yw an heb pen ow ’ober herwydh an bryntyans — nyns eus CSS gans an darn. Skrifewgh CSS orth klass kebab-case an darn (dyskwedhys war pub folen rolyans) po kevrewgh onan a'n 57 tebel parys.

Ny hevel dha CSS bos gweythys a-ugh tebel

Y tal — dewisyoryon tebel yw lappys yn :where(...), a'n jeves arbennigrwydh nagonan. Mar kyllyr hwath rol, hwithrewgh may fo dha folen-stil kargys wosa hwedh an tebel <link> ha may hevelep an dewisyer yn tevri orth krok klass an darn.

pnpm install a fyll gans gwall peer po versyon

Devnydhyewgh pnpm ownek (v10+) ha Node 22+. Pub isravel a dhegh y versyonow framwyth y'y package.jsondha honan; mar pe dha doul-chayn kenedhlek hen, pnpm env use --global lts yw an fordh-wella skaffa.

Skrin-redyer a lever hanow kamm rag kontroll

Hwithrewgh perthynas ilvyn an darn label — darnow heb tekst hewelus a'n jeves othom a unn, ha aria-label / aria-labelledby provyes gans an devnydhyer, passyes dre rest-props, a wayn yn arbennik a-ugh an gwiaswigow gwrys ino. Pub folen rolyans a ddisplet kevambos ARIA an darn.

An gweresor theme-picker ny chanj folennow-stil

Gwiriewgh may themesUrl a bonts dhe gunteleth a yll an gwiaskodhor kyrghes (servyewgh an themes/ restrennow avel gwaryowyow stedhek) ha may hevel an slugs tebel y'th themes perthynas orth henwyn restrennow. An gweresor a gevyska an href a unn <link data-lily-theme-picker> governys — hwithrewgh y'n devtools rag gweles an URL a vydh govynnys.

FAQ

Prag heb pen yn le stylys?

Darnow rag-stylys yw hegar — bys pan na gessenvons gans dha vark. Darnow heb pen yw nebes moy a ober orth an kynsa mes a re dhis governans tien war an dyllans hewelus. An appys ensampel ha'n 57 tebel a dhiskwedh fordhow dhe aga stylya; ty a yll aga kemeres po aga chanjya yn tien. An kaws hirrah yw orth Prag Lily.

Prag kemmys darnow?

Lily a wra hweles an patromow a'n jeves othom an moyha a appys heb dha dhrehevel dhiworth nagonan — a-ji doll kefyow downa avel entrys aswonnyoryon kenedhlek ha hwedhlow-skrollya dyllans-skrifer. An rolyans a gemmer dhiworth dhewdhek system dyllans selys ha'n oberenn gynsa — gwelewgh A-dro dhe.

A yllav usya Lily gans Tailwind?

Yllir. Pub darn a dhiskwedh unn klass gwreydh kebab-case ha className / classprovyes gans an devnydhyer. Gorrewgh toulys Tailwind a-ughto herwydh dha vodh.

A yllav usya Lily gans framwyth CSS a dhiswelyans avel DaisyUI?

Yllir. An hynwyn klass kebab-case war an elven wreydh a ober avel krogow CSS a dhiswelyans. Junyewgh Lily gans framwyth a dhiswelyans ha ty a gev darnow rag-stylys a with hwath ARIA ha i18n.

A eus pakkya npm?

An gweresoryon dewisyow a dheu avel pakkyow gans fordh-dyllans npm/NuGet. An lyvervaow darnow heb pen yw dyllys dhe vos klonys po vendorys — an fenten yw an delivrans, may hyllowgh redya, trimya, ha perthi an pyth a delivrowgh. Dyllans y'n gwithva rag an lyvervaow heb pen a berth hwath war an fordh-gwayans.

Prag lies kummyas?

Raglenow dyffrans a'n jeves othomow kummyas dyffrans. BSD ha MIT yw leth, Apache-2.0 a'n jeves rann breynans, ha dewisyow GPL a skoodh copyleft. Dewisewgh an pyth a gormel orth dha stat.
