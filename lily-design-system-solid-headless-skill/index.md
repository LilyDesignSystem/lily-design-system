# Lily Design System™ — Solid Headless Skill

A Claude Skill ([`SKILL.md`](SKILL.md)) that explains how to install, import and use the Solid 2.0 headless
implementation of Lily Design System™: the `@lilydesignsystem/solid-headless` npm package, its two builds, its JSX
consumption idiom (`class`, rest props, controlled props with signals) and where the framework-agnostic naming and
composition rules live.

It is one of three Solid skills, with
[`lily-design-system-solid-helpers-skill`](../lily-design-system-solid-helpers-skill/) (the helper packages) and
[`lily-design-system-solid-skill`](../lily-design-system-solid-skill/) (the map of the Solid layers and the example
app). All three are narrower siblings of [`lily-design-system-skill`](../lily-design-system-skill/).

Spec: [spec/index.md](spec/index.md). Agents: [AGENTS.md](AGENTS.md).
