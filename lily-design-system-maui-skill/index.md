# Lily Design System™ — .NET MAUI Skill

A Claude Skill ([`SKILL.md`](SKILL.md)) for using Lily in a .NET MAUI app: the native controls of
[`lily-design-system-maui`](../lily-design-system-maui/) for the mobile subset, and Blazor Hybrid for the rest of the catalog.
It points into the subproject and [spec/dotnet-maui](../spec/dotnet-maui/index.md) rather than restating them.
