# OneTimePasswordInput

One real numeric input for a verification code, with SMS autofill and a fixed length.

## Canonical documentation

See [components/one-time-password-input/index.md](../../../components/one-time-password-input/index.md) for the full component documentation, including ARIA, keyboard interactions, props, and usage guidance.

```svelte
<script lang="ts">
    import OneTimePasswordInput from "./OneTimePasswordInput.svelte";
</script>

<OneTimePasswordInput />
```
