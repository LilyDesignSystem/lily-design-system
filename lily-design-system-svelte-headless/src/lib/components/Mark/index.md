# Mark

A headless wrapper for an inline highlight marking text as relevant or referenced, such as a search match, using the native mark element.

## Canonical documentation

See [components/mark/index.md](../../../../../components/mark/index.md) for the full component documentation: behaviour, props and guidance.

## Usage

```svelte
<p>Found 3 results for <Mark>accessible</Mark> components.</p>
```

## Contract

The native `<mark class="mark">`; children and rest props only; no ARIA, state or strings.
