# FiveFaceRatingRadioGroup

a fieldset radio group for selecting a 1-5 satisfaction rating using face labels

This is the Angular headless implementation. See `components/five-face-rating-radio-group/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-five-face-rating-radio-group></lily-five-face-rating-radio-group>
```

## Files

- `FiveFaceRatingRadioGroup.ts` — standalone Angular 20 component (signal inputs, OnPush)
- `FiveFaceRatingRadioGroup.spec.ts` — vitest + TestBed render test
