# LuxembourgMatriculeView

a read-only display of Luxembourg's Numéro d'Identification Nationale (Matricule)

This is the Angular headless implementation. See `components/luxembourg-matricule-view/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-luxembourg-matricule-view></lily-luxembourg-matricule-view>
```

## Files

- `LuxembourgMatriculeView.ts` — standalone Angular 20 component (signal inputs, OnPush)
- `LuxembourgMatriculeView.spec.ts` — vitest + TestBed render test
