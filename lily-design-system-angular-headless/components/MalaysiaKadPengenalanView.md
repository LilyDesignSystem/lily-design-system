# MalaysiaKadPengenalanView

a read-only display of Malaysia's MyKad Number (NRIC)

This is the Angular headless implementation. See `components/malaysia-kad-pengenalan-view/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-malaysia-kad-pengenalan-view></lily-malaysia-kad-pengenalan-view>
```

## Files

- `MalaysiaKadPengenalanView.ts` — standalone Angular 20 component (signal inputs, OnPush)
- `MalaysiaKadPengenalanView.spec.ts` — vitest + TestBed render test
