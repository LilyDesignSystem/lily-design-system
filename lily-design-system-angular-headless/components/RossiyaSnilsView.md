# RossiyaSnilsView

a read-only display of Russia's СНИЛС (Individual Insurance Account Number)

This is the Angular headless implementation. See `components/rossiya-snils-view/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-rossiya-snils-view></lily-rossiya-snils-view>
```

## Files

- `RossiyaSnilsView.ts` — standalone Angular 20 component (signal inputs, OnPush)
- `RossiyaSnilsView.spec.ts` — vitest + TestBed render test
