# ColombiaCedulaDeCiudadaniaView

a read-only display of Colombia's Cedula de Ciudadania Number

This is the Angular headless implementation. See `components/colombia-cedula-de-ciudadania-view/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-colombia-cedula-de-ciudadania-view></lily-colombia-cedula-de-ciudadania-view>
```

## Files

- `ColombiaCedulaDeCiudadaniaView.ts` — standalone Angular 20 component (signal inputs, OnPush)
- `ColombiaCedulaDeCiudadaniaView.spec.ts` — vitest + TestBed render test
