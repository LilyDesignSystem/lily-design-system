# TuaisceartEireannHealthAndCareNumberInput

an input for entering Tuaisceart Eireann Health and Care (H&C) Number unique national healthcare identifier

This is the Angular headless implementation. See `components/tuaisceart-eireann-health-and-care-number-input/index.md`
in the canonical repo root for the cross-framework documentation.
