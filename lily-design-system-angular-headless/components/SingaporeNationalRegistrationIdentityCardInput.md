# SingaporeNationalRegistrationIdentityCardInput

an input for entering Singapore's National Registration Identity Card Number / Foreign Identification Number (NRIC/FIN)

This is the Angular headless implementation. See `components/singapore-national-registration-identity-card-input/index.md`
in the canonical repo root for the cross-framework documentation.
