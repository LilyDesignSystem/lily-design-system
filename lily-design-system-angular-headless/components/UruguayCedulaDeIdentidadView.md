# UruguayCedulaDeIdentidadView

a read-only display of Uruguay's Cedula de Identidad Number

This is the Angular headless implementation. See `components/uruguay-cedula-de-identidad-view/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-uruguay-cedula-de-identidad-view></lily-uruguay-cedula-de-identidad-view>
```

- `UruguayCedulaDeIdentidadView.spec.ts` — vitest + TestBed render test
