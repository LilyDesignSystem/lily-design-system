# MultiSelectWithExtras

a multiple-choice select with additional features like search, groups, or selected-value chips

This is the Angular headless implementation. See `components/multi-select-with-extras/index.md`
for the full canonical documentation.

Wrapper div with `[before]` / `[after]` projection slots around a native `<select multiple>`. Deviation: projection attributes instead of Svelte snippets; no rest-props spread.
