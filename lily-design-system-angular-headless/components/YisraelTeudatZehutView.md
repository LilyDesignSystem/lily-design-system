# YisraelTeudatZehutView

a read-only display of Israel's Teudat Zehut (תעודת זהות)

This is the Angular headless implementation. See `components/yisrael-teudat-zehut-view/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-yisrael-teudat-zehut-view></lily-yisrael-teudat-zehut-view>
```

## Files

- `YisraelTeudatZehutView.ts` — standalone Angular 20 component (signal inputs, OnPush)
- `YisraelTeudatZehutView.spec.ts` — vitest + TestBed render test
