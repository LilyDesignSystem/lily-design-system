# ChileRolUnicoNacionalInput

an input for entering Chile's Rol Único Nacional (RUN)

This is the Angular headless implementation. See `components/chile-rol-unico-nacional-input/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-chile-rol-unico-nacional-input></lily-chile-rol-unico-nacional-input>
```

- `ChileRolUnicoNacionalInput.spec.ts` — vitest + TestBed render test
