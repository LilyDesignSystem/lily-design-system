# YisraelTeudatZehutInput

an input for entering Israel's Teudat Zehut (תעודת זהות)

This is the Angular headless implementation. See `components/yisrael-teudat-zehut-input/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-yisrael-teudat-zehut-input></lily-yisrael-teudat-zehut-input>
```

## Files

- `YisraelTeudatZehutInput.ts` — standalone Angular 20 component (signal inputs, OnPush)
- `YisraelTeudatZehutInput.spec.ts` — vitest + TestBed render test
