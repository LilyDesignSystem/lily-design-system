# IbanView

a read-only display of an International Bank Account Number (IBAN)

This is the Angular headless implementation. See `components/iban-view/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-iban-view></lily-iban-view>
```

## Files

- `IbanView.ts` — standalone Angular 20 component (signal inputs, OnPush)
- `IbanView.spec.ts` — vitest + TestBed render test
