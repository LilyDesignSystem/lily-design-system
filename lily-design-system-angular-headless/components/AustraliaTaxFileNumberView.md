# AustraliaTaxFileNumberView

a read-only display of Australia's Tax File Number (TFN)

This is the Angular headless implementation. See `components/australia-tax-file-number-view/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-australia-tax-file-number-view></lily-australia-tax-file-number-view>
```

- `AustraliaTaxFileNumberView.spec.ts` — vitest + TestBed render test
