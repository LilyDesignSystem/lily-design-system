# OsterreichSozialversicherungsnummerInput

an input for entering Austria's Sozialversicherungsnummer (SVNR)

This is the Angular headless implementation. See `components/osterreich-sozialversicherungsnummer-input/index.md`
in the canonical repo root for the cross-framework documentation.

