# BrasilCartaoNacionalDeSaudeView

a read-only display of Brazil's Cartão Nacional de Saúde (CNS)

This is the Angular headless implementation. See `components/brasil-cartao-nacional-de-saude-view/index.md`
in the canonical repo root for the cross-framework documentation.
