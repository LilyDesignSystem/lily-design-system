# UruguayCedulaDeIdentidadInput

an input for entering Uruguay's Cedula de Identidad Number

This is the Angular headless implementation. See `components/uruguay-cedula-de-identidad-input/index.md`
in the canonical repo root for the cross-framework documentation.
