# ColombiaCedulaDeCiudadaniaInput

an input for entering Colombia's Cedula de Ciudadania Number

This is the Angular headless implementation. See `components/colombia-cedula-de-ciudadania-input/index.md`
in the canonical repo root for the cross-framework documentation.

