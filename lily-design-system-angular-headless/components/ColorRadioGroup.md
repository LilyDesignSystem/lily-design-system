# ColorRadioGroup

a fieldset radio group for selecting a color swatch

This is the Angular headless implementation. See `components/color-radio-group/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-color-radio-group></lily-color-radio-group>
```

## Files

- `ColorRadioGroup.ts` — standalone Angular 20 component (signal inputs, OnPush)
- `ColorRadioGroup.spec.ts` — vitest + TestBed render test
