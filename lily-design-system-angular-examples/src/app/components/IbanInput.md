# IbanInput

an input for entering an International Bank Account Number (IBAN)

This is the Angular headless implementation. See `components/iban-input/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-iban-input></lily-iban-input>
```

## Files

- `IbanInput.ts` — standalone Angular 20 component (signal inputs, OnPush)
- `IbanInput.spec.ts` — vitest + TestBed render test
