# AotearoaNationalHealthIndexInput

an input for entering New Zealand's National Health Index (NHI) Number

This is the Angular headless implementation. See `components/aotearoa-national-health-index-input/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-aotearoa-national-health-index-input></lily-aotearoa-national-health-index-input>
```

## Files

- `AotearoaNationalHealthIndexInput.ts` — standalone Angular 20 component (signal inputs, OnPush)
- `AotearoaNationalHealthIndexInput.spec.ts` — vitest + TestBed render test
