# ArgentinaCodigoUnicoDeIdentificacionLaboralInput

an input for entering Argentina's Código Único de Identificación Laboral (CUIL)

This is the Angular headless implementation. See `components/argentina-codigo-unico-de-identificacion-laboral-input/index.md`
in the canonical repo root for the cross-framework documentation.
