# GuatemalaCodigoUnicoDeIdentificacionView

a read-only display of Guatemala's Código Único de Identificación (CUI)

This is the Angular headless implementation. See `components/guatemala-codigo-unico-de-identificacion-view/index.md`
in the canonical repo root for the cross-framework documentation.
