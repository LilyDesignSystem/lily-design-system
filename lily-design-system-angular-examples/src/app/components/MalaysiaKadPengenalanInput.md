# MalaysiaKadPengenalanInput

an input for entering Malaysia's MyKad Number (NRIC)

This is the Angular headless implementation. See `components/malaysia-kad-pengenalan-input/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-malaysia-kad-pengenalan-input></lily-malaysia-kad-pengenalan-input>
```

## Files

- `MalaysiaKadPengenalanInput.ts` — standalone Angular 20 component (signal inputs, OnPush)
- `MalaysiaKadPengenalanInput.spec.ts` — vitest + TestBed render test
