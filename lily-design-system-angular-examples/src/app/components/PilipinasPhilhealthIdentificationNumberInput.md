# PilipinasPhilhealthIdentificationNumberInput

an input for entering the Philippines's PhilHealth Identification Number (PIN)

This is the Angular headless implementation. See `components/pilipinas-philhealth-identification-number-input/index.md`
in the canonical repo root for the cross-framework documentation.

```html
<lily-pilipinas-philhealth-identification-number-input></lily-pilipinas-philhealth-identification-number-input>
```

- `PilipinasPhilhealthIdentificationNumberInput.spec.ts` — vitest + TestBed render test
