# RossiyaSnilsInput

an input for entering Russia's СНИЛС (Individual Insurance Account Number)

This is the Angular headless implementation. See `components/rossiya-snils-input/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-rossiya-snils-input></lily-rossiya-snils-input>
```

## Files

- `RossiyaSnilsInput.ts` — standalone Angular 20 component (signal inputs, OnPush)
- `RossiyaSnilsInput.spec.ts` — vitest + TestBed render test
