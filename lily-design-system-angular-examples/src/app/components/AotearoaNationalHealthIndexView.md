# AotearoaNationalHealthIndexView

a read-only display of New Zealand's National Health Index (NHI) Number

This is the Angular headless implementation. See `components/aotearoa-national-health-index-view/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-aotearoa-national-health-index-view></lily-aotearoa-national-health-index-view>
```

## Files

- `AotearoaNationalHealthIndexView.ts` — standalone Angular 20 component (signal inputs, OnPush)
- `AotearoaNationalHealthIndexView.spec.ts` — vitest + TestBed render test
