# OsterreichSozialversicherungsnummerView

a read-only display of Austria's Sozialversicherungsnummer (SVNR)

This is the Angular headless implementation. See `components/osterreich-sozialversicherungsnummer-view/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-osterreich-sozialversicherungsnummer-view></lily-osterreich-sozialversicherungsnummer-view>
```

## Files

- `OsterreichSozialversicherungsnummerView.ts` — standalone Angular 20 component (signal inputs, OnPush)
- `OsterreichSozialversicherungsnummerView.spec.ts` — vitest + TestBed render test
