# EcuadorCedulaDeIdentidadView

a read-only display of Ecuador's Cedula de Identidad Number

This is the Angular headless implementation. See `components/ecuador-cedula-de-identidad-view/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-ecuador-cedula-de-identidad-view></lily-ecuador-cedula-de-identidad-view>
```

## Files

- `EcuadorCedulaDeIdentidadView.spec.ts` — vitest + TestBed render test
