# MagyarorszagTajSzamInput

an input for entering Hungary's Társadalombiztosítási Azonosító Jel (TAJ)

This is the Angular headless implementation. See `components/magyarorszag-taj-szam-input/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-magyarorszag-taj-szam-input></lily-magyarorszag-taj-szam-input>
```

- `MagyarorszagTajSzamInput.ts` — standalone Angular 20 component (signal inputs, OnPush)
- `MagyarorszagTajSzamInput.spec.ts` — vitest + TestBed render test
