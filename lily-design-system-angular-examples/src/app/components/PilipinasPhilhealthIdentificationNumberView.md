# PilipinasPhilhealthIdentificationNumberView

a read-only display of the Philippines's PhilHealth Identification Number (PIN)

This is the Angular headless implementation. See `components/pilipinas-philhealth-identification-number-view/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-pilipinas-philhealth-identification-number-view></lily-pilipinas-philhealth-identification-number-view>
```

## Files

- `PilipinasPhilhealthIdentificationNumberView.ts` — standalone Angular 20 component (signal inputs, OnPush)
- `PilipinasPhilhealthIdentificationNumberView.spec.ts` — vitest + TestBed render test
