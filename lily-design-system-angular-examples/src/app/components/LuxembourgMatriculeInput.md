# LuxembourgMatriculeInput

an input for entering Luxembourg's Numéro d'Identification Nationale (Matricule)

This is the Angular headless implementation. See `components/luxembourg-matricule-input/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-luxembourg-matricule-input></lily-luxembourg-matricule-input>
```

- `LuxembourgMatriculeInput.spec.ts` — vitest + TestBed render test
