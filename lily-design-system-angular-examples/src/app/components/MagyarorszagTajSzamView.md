# MagyarorszagTajSzamView

a read-only display of Hungary's Társadalombiztosítási Azonosító Jel (TAJ)

This is the Angular headless implementation. See `components/magyarorszag-taj-szam-view/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-magyarorszag-taj-szam-view></lily-magyarorszag-taj-szam-view>
```

- `MagyarorszagTajSzamView.spec.ts` — vitest + TestBed render test
