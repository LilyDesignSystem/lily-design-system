# IranKodEMelliView

a read-only display of Iran's National Code (Kod-e Melli)

This is the Angular headless implementation. See `components/iran-kod-e-melli-view/index.md`
in the canonical repo root for the cross-framework documentation.


- `IranKodEMelliView.spec.ts` — vitest + TestBed render test
