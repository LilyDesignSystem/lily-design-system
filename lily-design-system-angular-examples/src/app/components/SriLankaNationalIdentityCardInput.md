# SriLankaNationalIdentityCardInput

an input for entering Sri Lanka's National Identity Card (NIC) number

This is the Angular headless implementation. See `components/sri-lanka-national-identity-card-input/index.md`
in the canonical repo root for the cross-framework documentation.

```html
<lily-sri-lanka-national-identity-card-input></lily-sri-lanka-national-identity-card-input>
```

- `SriLankaNationalIdentityCardInput.spec.ts` — vitest + TestBed render test
