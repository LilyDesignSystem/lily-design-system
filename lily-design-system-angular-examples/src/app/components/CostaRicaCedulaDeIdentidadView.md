# CostaRicaCedulaDeIdentidadView

a read-only display of Costa Rica's Cédula de Identidad

This is the Angular headless implementation. See `components/costa-rica-cedula-de-identidad-view/index.md`
in the canonical repo root for the cross-framework documentation.
