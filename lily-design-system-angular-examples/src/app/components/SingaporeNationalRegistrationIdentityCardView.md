# SingaporeNationalRegistrationIdentityCardView

a read-only display of Singapore's National Registration Identity Card Number / Foreign Identification Number (NRIC/FIN)

This is the Angular headless implementation. See `components/singapore-national-registration-identity-card-view/index.md`
in the canonical repo root for the cross-framework documentation.

