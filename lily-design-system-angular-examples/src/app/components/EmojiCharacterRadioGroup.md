# EmojiCharacterRadioGroup

a fieldset radio group for selecting an emoji character

This is the Angular headless implementation. See `components/emoji-character-radio-group/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-emoji-character-radio-group></lily-emoji-character-radio-group>
```

## Files

- `EmojiCharacterRadioGroup.ts` — standalone Angular 20 component (signal inputs, OnPush)
- `EmojiCharacterRadioGroup.spec.ts` — vitest + TestBed render test
