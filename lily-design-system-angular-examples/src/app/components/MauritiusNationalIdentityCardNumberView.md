# MauritiusNationalIdentityCardNumberView

a read-only display of Mauritius's National Identity Card number

This is the Angular headless implementation. See `components/mauritius-national-identity-card-number-view/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-mauritius-national-identity-card-number-view></lily-mauritius-national-identity-card-number-view>
```

## Files

- `MauritiusNationalIdentityCardNumberView.ts` — standalone Angular 20 component (signal inputs, OnPush)
- `MauritiusNationalIdentityCardNumberView.spec.ts` — vitest + TestBed render test
