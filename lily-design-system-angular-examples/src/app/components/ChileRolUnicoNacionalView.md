# ChileRolUnicoNacionalView

a read-only display of Chile's Rol Único Nacional (RUN)

This is the Angular headless implementation. See `components/chile-rol-unico-nacional-view/index.md`
in the canonical repo root for the cross-framework documentation.

## Selector

```html
<lily-chile-rol-unico-nacional-view></lily-chile-rol-unico-nacional-view>
```

- `ChileRolUnicoNacionalView.spec.ts` — vitest + TestBed render test
