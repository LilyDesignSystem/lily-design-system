# BangladeshNationalIdentityCardInput

A headless Vue 3 input for Bangladesh's National ID (NID) number.

Format: 7 or 8 digits plus a trailing Modulus-11 check character computed with repeating weights 2-7 (K represents 10).

Companion: `BangladeshNationalIdentityCardView`.

References: https://en.wikipedia.org/wiki/National_identity_card_(Bangladesh)
