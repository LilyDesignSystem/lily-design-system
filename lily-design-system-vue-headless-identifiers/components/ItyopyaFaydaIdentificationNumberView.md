# ItyopyaFaydaIdentificationNumberView

A headless Vue 3 read-only display for Ethiopia's Fayda Identification Number (FIN).

Format: 7 or 8 digits plus a trailing Modulus-11 check character computed with repeating weights 2-7 (K represents 10).

Companion: `ItyopyaFaydaIdentificationNumberInput`.

References: https://en.wikipedia.org/wiki/Fayda_ID
