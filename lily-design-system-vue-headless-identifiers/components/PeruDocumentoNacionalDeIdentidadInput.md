# PeruDocumentoNacionalDeIdentidadInput

A headless Vue 3 input for Peru's Documento Nacional de Identidad (DNI).

Format: 7 or 8 digits plus a trailing Modulus-11 check character computed with repeating weights 2-7 (K represents 10).

Companion: `PeruDocumentoNacionalDeIdentidadView`.

References: https://es.wikipedia.org/wiki/Documento_Nacional_de_Identidad_(Per%C3%BA)
