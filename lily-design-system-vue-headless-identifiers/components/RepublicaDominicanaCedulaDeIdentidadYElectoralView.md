# RepublicaDominicanaCedulaDeIdentidadYElectoralView

A headless Vue 3 read-only display for the Dominican Republic's Cédula de Identidad y Electoral.

Format: 7 or 8 digits plus a trailing Modulus-11 check character computed with repeating weights 2-7 (K represents 10).

Companion: `RepublicaDominicanaCedulaDeIdentidadYElectoralInput`.

References: https://es.wikipedia.org/wiki/Junta_Central_Electoral_(Rep%C3%BAblica_Dominicana)
