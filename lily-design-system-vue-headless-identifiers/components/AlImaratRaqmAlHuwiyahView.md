# AlImaratRaqmAlHuwiyahView

A headless Vue 3 read-only display for the United Arab Emirates' Emirates ID number.

Format: 7 or 8 digits plus a trailing Modulus-11 check character computed with repeating weights 2-7 (K represents 10).

Companion: `AlImaratRaqmAlHuwiyahInput`.

References: https://en.wikipedia.org/wiki/Emirates_ID
