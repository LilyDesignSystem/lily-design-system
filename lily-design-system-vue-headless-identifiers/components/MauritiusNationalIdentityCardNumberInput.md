# MauritiusNationalIdentityCardNumberInput

A headless Vue 3 input for Mauritius's National Identity Card number.

Format: 7 or 8 digits plus a trailing Modulus-11 check character computed with repeating weights 2-7 (K represents 10).

Companion: `MauritiusNationalIdentityCardNumberView`.

References: https://arthurdejong.org/python-stdnum/doc/2.2/stdnum.mu.nid
