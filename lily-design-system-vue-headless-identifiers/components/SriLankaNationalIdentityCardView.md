# SriLankaNationalIdentityCardView

A headless Vue 3 read-only display for Sri Lanka's National Identity Card (NIC) number.

Format: 7 or 8 digits plus a trailing Modulus-11 check character computed with repeating weights 2-7 (K represents 10).

Companion: `SriLankaNationalIdentityCardInput`.

References: https://en.wikipedia.org/wiki/National_identity_card_(Sri_Lanka)
