# OzbekistonJismoniyShaxsningShaxsiyIdentifikatsionRaqamiInput

A headless Vue 3 input for Uzbekistan's Personal identification number (JShShIR / PINFL).

Format: 7 or 8 digits plus a trailing Modulus-11 check character computed with repeating weights 2-7 (K represents 10).

Companion: `OzbekistonJismoniyShaxsningShaxsiyIdentifikatsionRaqamiView`.

References: https://kun.uz/en/news/2026/01/26/how-to-find-your-pinfl
