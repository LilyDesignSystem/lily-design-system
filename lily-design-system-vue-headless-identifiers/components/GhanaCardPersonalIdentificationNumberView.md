# GhanaCardPersonalIdentificationNumberView

A headless Vue 3 read-only display for Ghana's Ghana Card PIN.

Format: 7 or 8 digits plus a trailing Modulus-11 check character computed with repeating weights 2-7 (K represents 10).

Companion: `GhanaCardPersonalIdentificationNumberInput`.

References: https://en.wikipedia.org/wiki/Ghana_Card
