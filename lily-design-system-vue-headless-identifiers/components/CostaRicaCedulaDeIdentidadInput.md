# CostaRicaCedulaDeIdentidadInput

A headless Vue 3 input for Costa Rica's Cédula de Identidad.

Format: 7 or 8 digits plus a trailing Modulus-11 check character computed with repeating weights 2-7 (K represents 10).

Companion: `CostaRicaCedulaDeIdentidadView`.

References: https://es.wikipedia.org/wiki/C%C3%A9dula_de_identidad_(Costa_Rica)
