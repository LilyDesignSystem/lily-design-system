# GuatemalaCodigoUnicoDeIdentificacionView

A headless Vue 3 read-only display for Guatemala's Código Único de Identificación (CUI).

Format: 7 or 8 digits plus a trailing Modulus-11 check character computed with repeating weights 2-7 (K represents 10).

Companion: `GuatemalaCodigoUnicoDeIdentificacionInput`.

References: https://www.renap.gob.gt/sites/default/files/boletines-publicaciones/inforenap_163_-_08042021_-_que_es_el_cui.pdf
