# Lily Design System™ — Solid Helpers Skill

A Claude Skill ([`SKILL.md`](SKILL.md)) that explains Lily Design System™'s 21 Solid 2.0 helper packages
(`@lilydesignsystem/solid-*`): which one to reach for, how to install and wire it, its controlled and uncontrolled props,
render-prop icons, server rendering, and the label packs that localise the grid-like helpers.

It is one of three Solid skills, with
[`lily-design-system-solid-headless-skill`](../lily-design-system-solid-headless-skill/) and
[`lily-design-system-solid-skill`](../lily-design-system-solid-skill/).

Spec: [spec/index.md](spec/index.md). Agents: [AGENTS.md](AGENTS.md).
