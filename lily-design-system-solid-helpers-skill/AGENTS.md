## Overview

A Claude Skill explaining the 21 Solid 2.0 helper packages, `@lilydesignsystem/solid-*`: which to reach for, their props, render-prop icons, server rendering and the label packs. The skill itself is [`SKILL.md`](SKILL.md); the `@AGENTS/*.md` files above are the
binding design-principle rules every subproject carries, copied from the repository root by `bin/sync`.

## Verify

`bin/test` checks the required files. Before changing `SKILL.md`, check each claim against the package it describes.
